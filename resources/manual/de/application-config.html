Anwendungseinstellungen

Bildschirm zur Verwaltung der globalen Anwendungseinstellungen und der Datenstruktur. Sie können Anzeigeeinstellungen, Verhaltensoptionen und externe Integrationen anpassen.

Obere Aktionsschaltflächen
Schaltfläche Beschreibung
Servereinstellungen (nur Administratoren) Öffnet den Serverkonfigurationsbildschirm für Port, TLS, Zugriffsbeschränkungen usw. Nur für Administratorkonten sichtbar.
Neu laden Aktualisiert die Daten vom Server. Langes Drücken erzwingt ein vollständiges Neuladen.

Allgemeine Einstellungen

Sprache Dropdown Wählen Sie die Oberflächensprache: ja (Japanisch), en (Englisch), zh (Chinesisch), ko (Koreanisch), es (Spanisch), fr (Französisch), de (Deutsch).

Anzeigeeinstellungen

Anzeigeeinstellungen
Einstellung Typ Beschreibung
Anzeigezeitraum des Lebensprotokolls Kontrollkästchen + Zahl Legt die Anzahl der Tage fest, die in der Lebensprotokoll-Ansicht angezeigt werden. -1 für unbegrenzt. Ein kürzerer Zeitraum lädt schneller.

Standard-Aufgabentafel Dropdown + Hinzufuegen-Schaltfläche Legt die Standardtafel im Aufgabenbildschirm fest. Verwenden Sie die Hinzufuegen-Schaltfläche, um neue Tafeln zu erstellen.

Datenstrukturverwaltung

Diese Schaltflächen öffnen spezielle Editoren zur Verwaltung der Organisation Ihrer Daten.

Datenstrukturverwaltung
Schaltfläche Beschreibung
Tag-Struktur Verwaltet die Tag-Hierarchie und Tag-Gruppierungen. Sie können Tags erstellen, umbenennen, neu anordnen und in Eltern-Kind-Beziehungen organisieren.
Ablagestruktur Verwaltet Datenspeicherorte und Ablagen. Sie können hinzufuegen, entfernen oder konfigurieren, wo Datensätze gespeichert werden.
Profilstruktur Verwaltet Geräte- und Profilkonfigurationen. Ermöglicht die Bearbeitung gerätespezifischer Einstellungen.
Datensatztyp-Struktur Verwaltet, welche Datensatztypen in welchen Repositories gespeichert werden.
Vorlagenstruktur Verwaltet Notizblock-Textvorlagen für die Schnelleingabe. Sie können vorgefertigte Texteinträge erstellen und bearbeiten.
Zusammenfassungsansicht Verwaltet Datenaggregation und Konfigurationen der Zusammenfassungsansichten.
Zugehörige Informationen Verwaltet die Strukturen zugehöriger Informationen.
Dashboard Konfigurieren Sie die Suchbedingungen für die Aggregationsansicht und Aufgaben, die auf dem Dashboard angezeigt werden.

Untere Aktionsschaltflächen
Schaltfläche Beschreibung
Anwenden Speichert alle Aenderungen.

Fußzeile

Am unteren Bildschirmrand werden Anwendungsinformationen angezeigt:

  • Versionsnummer — Klickbarer Link zur Projektseite.
  • Build-Zeitstempel — Datum und Uhrzeit der Erstellung der Anwendung.
  • Commit-Hash — Der Git-Commit, aus dem der Build erstellt wurde.
Tipp: Drücken Sie nach dem Aendern der Einstellungen auf "Anwenden", um zu speichern. Drücken Sie "Abbrechen", um alle Aenderungen zu verwerfen.
Tipp: Für Smartphones stellen Sie die Bildspalten auf 1-2 ein. Für Desktop-Bildschirme eignen sich 3-5 Spalten gut.
Tipp: Um GPS-Kartenfunktionen zu nutzen, aktivieren Sie die Maps JavaScript API in der Google Cloud Console und geben Sie den API-Schlüssel unter Externe Integration ein.
