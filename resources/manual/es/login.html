Pantalla de inicio de sesión

Pantalla de autenticación para iniciar sesión en gkill. Introduzca su ID de usuario y contraseña para acceder a la aplicación.

Elementos de la pantalla

Elementos de la pantalla
Elemento Descripción
Campo de ID de usuario Introduzca el ID de usuario de su cuenta gkill.
Campo de contraseña Introduzca la contraseña de la cuenta.
Botón de inicio de sesión Ejecuta el inicio de sesión con las credenciales introducidas.
Indicador de versión Muestra el número de versión actual de gkill en la esquina superior derecha.

Procedimiento

  1. Introduzca el ID de usuario de su cuenta en el campo correspondiente.
  2. Introduzca la contraseña en el campo correspondiente.
  3. Haga clic en el botón "Iniciar sesión" o pulse Enter para autenticarse.
  4. Tras una autenticación exitosa, será redirigido a la página predeterminada configurada en los ajustes.
Consejo: En la primera ejecución, se mostrara automáticamente una pantalla de registro de cuenta. Siga las instrucciones en pantalla para crear su cuenta de usuario y establecer la contraseña de administrador.
Consejo: También puede iniciar sesión pulsando Enter, lo que permite enviar directamente después de introducir la contraseña.
Sesión: La sesión se mantiene activa durante 30 días. Si la sesión caduca, se le redirigirá automáticamente a esta pantalla de inicio de sesión.
Solución de problemas: Si no puede iniciar sesión, verifique su ID de usuario y contraseña.
