Primer registro de cuenta

  1. Al iniciar gkill por primera vez, la pantalla de registro de cuenta aparecera automáticamente.
  2. Ingrese un ID de usuario (este será el nombre de su cuenta).
  3. Ingrese una contraseña y vuelva a ingresarla para confirmar.
  4. Ingrese una contraseña de administrador y confirmela (establece la contraseña de la cuenta admin creada automáticamente, utilizada para la gestión del servidor).
  5. Presione el botón "Registrar" para crear la cuenta.
  6. Será redirigido a la pantalla de inicio de sesión. Inicie sesión con la cuenta que acaba de crear.
Consejo: La cuenta admin se crea automáticamente cuando el servidor se inicia por primera vez. Esta pantalla establece la contraseña de admin y crea su cuenta de usuario normal al mismo tiempo.

Después de iniciar sesión, se mostrara la pantalla predeterminada (Vista de registro de vida por defecto). Configure los ajustes basicos como el idioma y el tema oscuro en la pantalla de configuración.

Tu primer registro en 60 segundos

  1. Inicia sesión.
  2. Se muestra la pantalla Vista de registro de vida.
  3. Toca el botón "+" en la esquina inferior derecha de la pantalla.
  4. Selecciona "Bloc de notas" en el menú.
  5. Escribe lo que quieras registrar en el área de texto (por ejemplo: Hoy almorce curry).
  6. Pulsa el botón "Guardar" y el registro aparecera inmediatamente en el cronograma de la Vista de registro de vida.
Consejo: La forma básica de agregar registros es usando el botón "+" en la pantalla Vista de registro de vida. Una vez que aprendas la sintaxis del bloc de notas, podras registrar tareas, valores de estado de ánimo y más de la misma manera. Consulta el Tutorial para más detalles.
Consejo: Tocar el botón "+" abre un menú; mantener pulsado abre directamente el bloc de notas.
Consejo: La pantalla Saihate también está disponible para registros desde la pantalla de bloqueo o registros rápidos. Consulta la ayuda de Saihate para más detalles.

Glosario

Glosario
Termino Descripción
Registro Termino general para los registros en gkill. Abarca todos los tipos de registro, incluyendo notas, marcas de tiempo, tareas y más
Sintaxis del bloc de notas Sintaxis de entrada de texto utilizada en el bloc de notas. Al agregar simbolos al inicio de cada línea, puedes crear diferentes tipos de registros a la vez
Marca de tiempo Función de seguimiento de tiempo. Registra los tiempos de inicio y fin de trabajos o actividades
Saihate Pantalla para añadir registros de forma segura incluso desde la pantalla de bloqueo. Funciona como centro de adición de registros
Vista de registros Pantalla para listar y buscar registros
Vista de Agregación Función para mostrar agregaciones y estadísticas de datos
Información Relacionada Función que busca y muestra automáticamente información relacionada
Repositorio Ubicación de almacenamiento de registros. En la interfaz se muestra como «Repositorio». Puedes usar múltiples repositorios para diferentes propositos
Perfil Conjunto de configuraciones agrupadas por dispositivo
