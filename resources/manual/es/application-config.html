Ajustes de la aplicación

Pantalla para gestionar la configuración general de la aplicación y la estructura de datos. Puede ajustar las preferencias de visualización, opciones de comportamiento e integraciones externas.

Botones de acción superiores

Botones de acción superiores
Botón Descripción
Configuración del servidor (solo administradores) Abre la pantalla de configuración del servidor para puerto, TLS, restricciones de acceso, etc. Solo visible para cuentas de administrador.
Recargar Actualiza los datos desde el servidor. Mantenga pulsado para forzar una recarga completa.
Cerrar sesión Finaliza la sesión actual y cierra sesión.

Configuración general

Configuración general
Ajuste Tipo Descripción
Idioma Desplegable Selecciona el idioma de la interfaz: ja (japones), en (ingles), zh (chino), ko (coreano), es (espanol), fr (frances), de (aleman).
Tema oscuro Casilla de verificacion Activa o desactiva el modo oscuro. Adecuado para entornos con poca luz.
Recarga en caliente Casilla de verificacion Cuando está activado, la vista del registro de vida se actualiza automáticamente al detectar cambios en los datos.
Mostrar etiquetas en la lista Casilla de verificacion Controla si se muestran las etiquetas en las tarjetas de registros en las vistas de lista.
Mostrar pie de página de comparticion Casilla de verificacion Controla si se muestran las opciones de compartir en el área del pie de página.

Configuración de visualización

Configuración de visualización
Ajuste Tipo Descripción
Período de visualización del registro de vida Casilla + Número Establece el número de días de registros a mostrar en la vista del registro de vida. -1 para ilimitado. Un período más corto carga más rápido.
Página predeterminada Desplegable Elige la página que se muestra después de iniciar sesión.
Columnas de imágenes del registro de vida Número (1-10) Establece el número de columnas de la cuadricula de miniaturas en la vista del registro de vida. Ajuste según el tamaño de su pantalla.
Tablero de tareas predeterminado Desplegable + Botón agregar Establece el tablero predeterminado en la pantalla de tareas. Use el botón de agregar para crear nuevos tableros.

Integración externa

Integración externa
Ajuste Tipo Descripción
Bookmarklet Solo lectura URL del bookmarklet JavaScript para la barra de marcadores del navegador. Permite guardar marcadores en gkill con un clic desde cualquier página web.
Clave API de Google Map Entrada de texto Introduce la clave API de Google Map para habilitar las funciones de mapa GPS. La vista de mapa requiere esta clave para funcionar.

Gestión de estructura de datos

Estos botones abren editores dedicados para gestionar como se organizan sus datos.

Gestión de estructura de datos
Botón Descripción
Estructura de etiquetas Gestiona la jerarquia de etiquetas y sus agrupaciones. Puede crear, renombrar, reordenar y organizar etiquetas en relaciones padre-hijo.
Estructura de Repositorio Gestiona las ubicaciones de almacenamiento de datos (Repositorio). Puede agregar, eliminar o configurar donde se almacenan los registros.
Estructura de perfiles Gestiona las configuraciones de dispositivos y perfiles. Permite editar ajustes por dispositivo.
Estructura de tipos de registro Gestiona que tipos de registro se almacenan en que repositorios.
Estructura de plantillas Gestiona las plantillas de texto del bloc de notas para entrada rápida. Puede crear y editar textos predefinidos.
Vista de resumen Gestiona la agregación de datos y las configuraciones de vistas de resumen.
Información relacionada Gestiona las estructuras de información relacionada.
Panel Configure las condiciones de búsqueda para la Vista de agregación y las tareas que se muestran en el Panel.

Botones de acción inferiores

Botones de acción inferiores
Botón Descripción
Aplicar Guarda todos los cambios.
Cancelar Descarta los cambios y cierra la pantalla.

Pie de página

La parte inferior de la pantalla muestra información de la aplicación:

  • Número de versión — Enlace clickeable a la página del proyecto.
  • Marca de tiempo de compilacion — Fecha y hora en que se compilo la aplicación.
  • Hash del commit — El commit de Git a partir del cual se creo la compilacion.
Consejo: Después de cambiar los ajustes, pulse "Aplicar" para guardar. Pulse "Cancelar" para descartar todos los cambios.
Consejo: Para telefonos moviles, establezca las columnas de imágenes en 1-2. Para pantallas de escritorio, 3-5 columnas funciona bien.
Consejo: Para usar las funciones de mapa GPS, habilite la API Maps JavaScript en Google Cloud Console e introduzca la clave API en Integración externa.
