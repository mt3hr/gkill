Paramètres de l'application

Écran de gestion des paramètres globaux de l'application et de la structure des données. Vous pouvez ajuster les préférences d'affichage, les options de comportement et les intégrations externes.

Boutons d'action superieurs

Boutons d'action superieurs
Bouton Description
Paramètres du serveur (administrateurs uniquement) Ouvre l'écran de configuration du serveur pour le port, TLS, les restrictions d'accès, etc. Visible uniquement pour les comptes administrateurs.
Recharger Actualise les données depuis le serveur. Appui long pour forcer un rechargement complet.
Deconnexion Termine la session en cours et se deconnecte.

Paramètres generaux

Paramètres generaux
Paramètre Type Description
Langue Liste deroulante Choisir la langue de l'interface : ja (japonais), en (anglais), zh (chinois), ko (coreen), es (espagnol), fr (francais), de (allemand).
Theme sombre Case a cocher Active ou désactivé le mode sombre. Adapte aux environnements peu eclaires.
Rechargement a chaud Case a cocher Lorsqu'il est active, la vue du journal de vie se rafraîchit automatiquement lorsque des changements de données sont detectes.
Afficher les tags dans la liste Case a cocher Controle si les tags sont affiches sur les fiches d'enregistrement dans les vues en liste.
Afficher le pied de page de partage Case a cocher Controle si les options de partage sont affichées dans la zone du pied de page.

Paramètres d'affichage

Paramètres d'affichage
Paramètre Type Description
Période d'affichage du journal de vie Case a cocher + Nombre Definit le nombre de jours d'enregistrements a afficher dans la vue du journal de vie. -1 pour illimité. Une période plus courte charge plus rapidement.
Page par defaut Liste deroulante Choisir la page affichee après la connexion.
Colonnes d'images du journal de vie Nombre (1-10) Definit le nombre de colonnes de la grille de miniatures dans la vue du journal de vie. Ajustez en fonction de la taille de votre écran.
Tableau de tâches par defaut Liste deroulante + Bouton ajouter Definit le tableau par defaut dans l'écran des tâches. Utilisez le bouton d'ajout pour créer de nouveaux tableaux.

Integration externe

Integration externe
Paramètre Type Description
Bookmarklet Lecture seule URL du bookmarklet JavaScript pour la barre de favoris du navigateur. Permet d'enregistrer des favoris dans gkill en un clic depuis n'importe quelle page web.
Clé API Google Map Saisie de texte Entrez votre clé API Google Maps pour activer les fonctions de carte GPS. La vue carte necessite cette clé pour fonctionner.

Gestion de la structure des données

Ces boutons ouvrent des editeurs dedies pour gérer l'organisation de vos données.

Gestion de la structure des données
Bouton Description
Structure des étiquettes Gere la hiérarchie des étiquettes et leurs regroupements. Vous pouvez créer, renommer, reorganiser et organiser les étiquettes en relations parent-enfant.
Structure des dépôts Gere les emplacements de stockage des données et les dépôts. Vous pouvez ajouter, supprimer ou configurer les emplacements de stockage des enregistrements.
Structure des profils Gere les configurations des appareils et des profils. Permet de modifier les paramètres par appareil.
Structure des types d'enregistrement Gere quels types d'enregistrement sont stockes dans quels dépôts.
Structure des modèles Gere les modèles de texte du bloc-notes pour la saisie rapide. Vous pouvez créer et modifier des textes predefinies.
Vue de synthese Gere l'agrégation des données et les configurations des vues de synthese.
Informations associées Gere les structures d'informations associées.
Tableau de bord Configurez les conditions de recherche pour la Vue d'agrégation et les tâches affichées dans le tableau de bord.

Boutons d'action inferieurs

Boutons d'action inferieurs
Bouton Description
Appliquer Enregistre toutes les modifications.
Annuler Annule les modifications et ferme l'écran.

Pied de page

Le bas de l'écran affiche les informations de l'application :

  • Numéro de version — Lien cliquable vers la page du projet.
  • Horodatage de compilation — Date et heure de compilation de l'application.
  • Hash du commit — Le commit Git a partir duquel la compilation a ete créée.
Astuce : Après avoir modifie les paramètres, appuyez sur "Appliquer" pour enregistrer. Appuyez sur "Annuler" pour annuler toutes les modifications.
Astuce : Pour les smartphones, definissez les colonnes d'images sur 1-2. Pour les écrans de bureau, 3-5 colonnes convient bien.
Astuce : Pour utiliser les fonctions de carte GPS, activez l'API Maps JavaScript dans Google Cloud Console et entrez la clé API dans Integration externe.
