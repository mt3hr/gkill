Gestion des comptes

Cet écran gère les comptes utilisateur. Seuls les administrateurs peuvent y accéder.

Bouton supérieur

Appuyez sur le bouton Ajouter un compte pour créer un nouveau compte.

Liste des comptes

Les comptes enregistrés sont affichés dans une liste. Chaque ligne de compte contient les éléments suivants :

Liste des comptes
ÉlémentDescription
Case à cocher activer/désactiverBascule l'état du compte entre activé et désactivé
ID utilisateurAffiche l'ID utilisateur du compte
Bouton d'attribution de stockageAttribue des dépôts de données à l'utilisateur
Bouton de réinitialisation du mot de passeGénère un lien de réinitialisation du mot de passe

Bouton inférieur

Fermer : Ferme l'écran de gestion des comptes.

Conseil : Le compte admin est crée automatiquement lors du premier démarrage du serveur. Les comptes ajoutés depuis l'écran de gestion des comptes sont des utilisateurs normaux (sans privileges d'administrateur). Les comptes sont geres par activation/desactivation plutot que par suppression.

Procédure de réinitialisation du mot de passe

Procédure administrateur

  1. Ouvrez Configuration du serveur > Gestion des comptes.
  2. Appuyez sur le bouton "Reinitialiser le mot de passe" de l'utilisateur concerne.
  3. Appuyez sur OK dans la boite de dialogue de confirmation pour générer le lien de reinitialisation.
  4. Copiez le lien et partagez-le avec l'utilisateur.

Procédure utilisateur

  1. Ouvrez le lien dans le navigateur.
  2. Entrez le nouveau mot de passe deux fois.
  3. Appuyez sur le bouton "Definir".
  4. Vous serez redirige vers l'écran de connexion ; connectez-vous avec le nouveau mot de passe.
Conseil : Le lien de reinitialisation est a usage unique. S'il a expire, demandez a l'administrateur d'en générer un nouveau.

Attribution du stockage

Le bouton "Attribution du stockage" vous permet d'attribuer des dépôts de données a chaque utilisateur. Consultez Gestion du stockage dans la configuration du serveur pour obtenir des détails sur l'ajout et la gestion des dépôts.
