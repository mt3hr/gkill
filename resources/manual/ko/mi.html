주요 기능

칸반 보드

작업은 보드(열)별로 분류되어 표시됩니다. 각 보드는 작업의 상태나 카테고리를 나타내며 작업의 진행 관리에 활용할 수 있습니다.

사이드바(필터)

사이드바에서는 다음 필터 조건을 설정하여 작업을 좁힐 수 있습니다.

  • 텍스트 검색
  • 태그를 통한 필터
  • 기간 지정
  • 보드 선택

상세 패널

작업을 선택하면 상세 패널에 다음 정보가 표시됩니다.

  • 작업의 제목과 내용
  • 소속 보드
  • 기한 정보
  • 부여된 태그
  • 관련된 기록
팁: 기본으로 표시할 보드는 설정 화면의 "기본 작업 보드 이름"에서 변경할 수 있습니다.
팁: 사이드바의 필터 조건을 조합하면 필요한 작업을 빠르게 찾을 수 있습니다.
