Laufend

Bildschirm, der die aktuell laufenden Zeiterfassungssitzungen als Liste anzeigt. Ermöglicht die Verwaltung der aktiven Zeitmessung.

Symbolleistenschaltflächen

Schaltfläche Beschreibung
⚙ Einstellungen Öffnet den Einstellungsbildschirm der Anwendung.
❔ Hilfe Zeigt die Hilfe für den aktuellen Bildschirm an.

Hauptfunktionen

Liste der laufenden Sitzungen

Die aktuell aktiven Zeiterfassungssitzungen werden in Listenform angezeigt. Jede Sitzung enthält die folgenden Informationen.

  • Sitzungsname (Titel)
  • Startzeit
  • Verstrichene Zeit

Sitzung stoppen

Durch Tippen auf die Stopp-Schaltfläche einer Sitzung können Sie diese beenden. Die Endzeit wird automatisch aufgezeichnet.

Floating-Action-Schaltfläche („+“)

Durch Tippen auf die „+“-Schaltfläche unten rechts können Sie schnell einen neuen Eintrag hinzufügen.

Menü zum Hinzufügen

Menüpunkt Beschreibung
NotizblockGibt eine Textnotiz im Notizblockformat ein.
Zeit-NotizblockÖffnet den Hybridbildschirm aus Notizeingabe und Liste der Zeiterfassungen.
Numerische DatensätzeZeichnet numerische Daten auf.
LesezeichenSpeichert eine URL.
ZeiterfassungStartet eine neue Zeiterfassungssitzung.
AufgabeFügt eine neue Aufgabe hinzu.
AusgabeZeichnet einen Betrag auf.
StimmungZeichnet einen Stimmungswert (0–10) auf.
HochladenLädt eine Datei hoch und zeichnet sie auf.
Zwischenablage speichernSpeichert den Inhalt der Zwischenablage (Bild, Text, PDF usw.) direkt als Datei. Screenshots oder kopierte Bilder lassen sich so schnell erfassen.
Tipp: Falls Sie vergessen haben, eine Zeiterfassung zu stoppen, können Sie den Eintrag nachträglich bearbeiten und die Endzeit korrigieren.
Tastenkürzel: Drücken Sie auf diesem Bildschirm die Eingabetaste, um den Notizblock-Dialog zu öffnen. Dies ist praktisch, um schnell Einträge hinzuzufügen.
Tastenkürzel: Drücken Sie Strg+V, um den Inhalt der Zwischenablage direkt als Datei zu speichern. Nützlich zum schnellen Speichern von Screenshots oder kopierten Bildern.
