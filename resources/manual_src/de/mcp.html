KI-Integration

Durch die Verbindung von KI-Assistenten wie Claude mit gkill können Sie Ihre Lebensprotokoll-Einträge per natürlicher Konversation suchen, hinzufügen und bearbeiten.

Was Sie tun können

AktionBeispiel
Einträge suchen„Zeige mir meine Mittagessen-Notizen der letzten Woche" / „Fasse diesen Monat Ausgaben zusammen"
Einträge hinzufügen„Füge eine Notiz für heute hinzu" / „Erstelle eine Aufgabe"
Einträge aktualisieren / löschen„Markiere diese Aufgabe als erledigt"
GPS / Dateien abrufen„Zeige meine heutige Route"
Einstellungen prüfen„Liste meine Vorlagen auf"
Ihre Notizen lesenLiest zuerst die Beschreibungen, die Sie in den Einstellungen zu Tags, Speicherorten, Boards und Vorlagen geschrieben haben, und sucht Einträge so, wie Sie sie tatsächlich nutzen
Die Nutzung selbst nachschlagenDie KI schlägt die Regeln für Suchbedingungen und Seitenwechsel über eine eingebaute Hilfefunktion selbst nach. Findet sie etwas nicht, bitten Sie sie: „Schau in der gkill-Hilfe nach"
Skills nutzenDie KI liest die Anleitungen (Skills), die Sie in den Einstellungen hinterlegt haben, und arbeitet danach. Sie können die KI auch Skills erstellen oder korrigieren lassen

Integrationstypen

TypWas er kannStartbefehlWerkzeugePort (HTTP)
Nur-LesenEinträge nur anzeigen und suchen. Hinzufügen oder Ändern ist nicht möglichgkill_server mcp --kind read148808
Nur-SchreibenEinträge hinzufügen, aktualisieren und löschen. Kann zudem Ablage-, Tag- und Board-Namen lesengkill_server mcp --kind write338809
Lesen & SchreibenEinträge anzeigen, hinzufügen, aktualisieren und löschengkill_server mcp --kind readwrite378810

Der MCP-Server ist Teil von gkill_server und wird mit gkill_server mcp --kind <Typ> gestartet (gkill_server selbst muss laufen). Verbindung und Zugangsdaten kommen aus Umgebungsvariablen oder aus der Konfigurationsdatei configs/gkill_mcp.json, die beim ersten Start erzeugt wird. Protokolle landen in logs/gkill_mcp_<Typ>.log (die Dateien je Stufe teilen sich das Präfix).

Jeder Typ enthält ein Werkzeug zum Auflisten der verwendeten Erweiterungen. Die Inhalte der über Erweiterungen importierten Einträge können direkt zusammen mit den Suchergebnissen empfangen werden.

Skills

Ein Skill ist eine Anleitung, die Sie für KI-Assistenten hinterlegen (zum Beispiel, wie die Wochenzusammenfassung erstellt wird oder welche Tags eine Art von Eintrag bekommt). Skills werden pro Benutzer gespeichert, und jeder verbundene KI-Assistent nutzt dieselben Skills. Vor der Arbeit prüft die KI die Liste der Skills und liest den passenden.

Ein Skill ist ein Ordner mit SKILL.md auf oberster Ebene. Beginnen Sie SKILL.md mit Name und Beschreibung in der folgenden Form und schreiben Sie danach die Schritte. Der Ordner kann außerdem Referenzdokumente, Skripte und andere Dateien enthalten.

---
name: weekly-summary
description: Schritte für die Wochenzusammenfassung
---
# Schritte
1. ...
VorgangVorgehen
Hinzufügen oder ersetzenLaden Sie unter „Skills“ in den Einstellungen den Ordner als Zip hoch. Prüfen Sie, welche Dateien hinzugefügt, gelöscht oder geändert werden, und drücken Sie „Anwenden“, um den gleichnamigen Skill vollständig zu ersetzen.
Ansehen und mitnehmen„Anzeigen“ zeigt den Inhalt jeder Datei. „Herunterladen“ speichert den Skill als Zip, das Sie lokal bearbeiten und unverändert wieder hochladen können.
Löschen„Löschen“ unter „Skills“ in den Einstellungen entfernt den ganzen Skill.
Von der KI erstellt oder korrigiertMit einer Integration, die schreiben darf, kann die KI Skills erstellen und ihre Dateien neu schreiben. Die KI kann keine Skills löschen.
Tipp: Änderungen an Skills gelten sofort, und es wird kein Verlauf gespeichert. Bevor die KI einen Skill ändert, sichern Sie bei Bedarf eine Kopie mit „Herunterladen“. Namen bestehen aus Kleinbuchstaben, Ziffern und Bindestrichen (bis zu 64 Zeichen), Dateinamen nur aus Buchstaben, Ziffern und ._-. gkill führt keine Skripte aus.

Dateiübergabe

Wie Dateieinträge (Bilder, Videos, Dokumente) der KI gezeigt werden, wechselt automatisch je nach Verbindungsart.

VerbindungsartÜbergabemethode
Lokale Verbindung (KI auf demselben PC)Der tatsächliche Dateipfad wird an die KI übergeben, die die Datei direkt lesen kann.
Remote-Verbindung (KI über das Internet)Eine zeitlich begrenzte dedizierte URL wird ausgestellt, und die KI ruft die Datei über diese URL ab. Bei Bildern werden sowohl Miniaturansicht als auch Originalgröße bereitgestellt. gkill selbst muss nicht öffentlich zugänglich sein.
Tipp: Die Größenbeschränkung für die eingebettete Übertragung (Standard 8 MB) kann mit der Umgebungsvariable GKILL_MCP_MAX_FILE_BYTES angepasst werden, die URL-Gültigkeitsdauer (Standard 1 Stunde) mit GKILL_MCP_FILE_LINK_TTL_MS.

Einrichtung (Claude Desktop)

Fügen Sie Folgendes zur Claude-Desktop-Konfigurationsdatei (claude_desktop_config.json) hinzu.

Nur-Lesen-Integration

{
  "mcpServers": {
    "gkill": {
      "command": "gkill_server",
      "args": ["mcp", "--kind", "read"],
      "env": {
        "GKILL_BASE_URL": "http://localhost:9999",
        "GKILL_USER": "ihre-benutzer-id",
        "GKILL_PASSWORD_SHA256": "sha256-hash-ihres-passworts"
      }
    }
  }
}
Tipp: GKILL_PASSWORD_SHA256 ist der SHA256-Hash Ihres Passworts. Sie können ihn mit den auf Ihrem Betriebssystem verfügbaren Tools generieren.

Einrichtung (Claude Code)

claude mcp add gkill \
  --env GKILL_BASE_URL=http://localhost:9999 \
  --env GKILL_USER=ihre-benutzer-id \
  --env GKILL_PASSWORD_SHA256=ihr-hash \
  -- gkill_server mcp --kind read
Tipp: gkill_server muss im PATH liegen (sonst den vollständigen Pfad angeben). Um den Typ zu wechseln, setzen Sie --kind auf write oder readwrite.

Aus der Ferne nutzen (HTTP-Verbindung)

Wenn die KI nicht auf demselben PC läuft, kann der MCP-Server selbst per HTTP lauschen, sodass eine KI aus dem Internet eine Verbindung herstellt. Dieser Modus autorisiert die Verbindung per OAuth, daher muss gkill selbst nicht im Internet veröffentlicht werden.

Die Autorisierung erfolgt je Verbindungsart (nur Lesen, Schreiben oder Lesen und Schreiben). Eine als „nur Lesen“ autorisierte Verbindung kann nicht zum Schreiben verwendet werden. Wenn Sie die Art wechseln oder eine bisher funktionierende Verbindung wegen fehlender Berechtigung fehlschlägt, trennen Sie sie auf der KI-Seite und autorisieren Sie sie erneut.

# Beispiel: Lesen & Schreiben per HTTP bereitstellen
MCP_PORT=8810 MCP_OAUTH_ISSUER=https://example.com \
GKILL_BASE_URL=http://localhost:9999 \
GKILL_USER=ihre-benutzer-id \
GKILL_PASSWORD_SHA256=ihr-hash \
gkill_server mcp --kind readwrite --transport http
Tipp: Sie können auch den gkill-Server selbst im Internet veröffentlichen. Setzen Sie dann GKILL_BASE_URL auf seine öffentliche Adresse und aktivieren Sie TLS (HTTPS) unter Servereinstellungen.
