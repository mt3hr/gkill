Notizblock

Bildschirm, in dem Sie Ihr Lebensprotokoll mit der Notizblock-Syntax aufzeichnen. Als Text können Sie mehrere Eintragstypen auf einmal eingeben.

Bildschirmelemente

Element Beschreibung
Texteingabebereich Der Haupttextbereich, in dem Sie Daten mit der Notizblock-Syntax eingeben. Sie können Einträge über mehrere Zeilen frei schreiben.
Vorlagenschaltfläche Fügt eine häufig verwendete Notizblock-Vorlage in den Textbereich ein. Sie wählen aus den in den Einstellungen festgelegten Vorlagen.
Speicherschaltfläche Sendet den eingegebenen Inhalt an den Server und erstellt die Einträge.
Registerkarten Damit können Sie mehrere Entwürfe gleichzeitig offen halten. Jede Registerkarte enthält einen eigenen Text.
Schaltfläche zum Hinzufügen einer Registerkarte Fügt eine neue leere Registerkarte hinzu.
Schaltfläche zum Schließen einer Registerkarte Schließt diese Registerkarte. Enthält sie noch Text, wird vorher nachgefragt.

Umgang mit Registerkarten

Sie können mehrere Entwürfe nebeneinander offen halten. Fällt Ihnen beim Schreiben eines Eintrags etwas anderes ein, fügen Sie eine Registerkarte hinzu, schreiben Sie es dort und kehren Sie später zur ursprünglichen zurück.

Aktion Ergebnis
Schaltfläche zum Hinzufügen drücken Eine leere Registerkarte kommt hinzu.
Auf den Namen einer Registerkarte klicken Der Editor wechselt zu deren Inhalt.
Schaltfläche zum Schließen drücken Diese Registerkarte wird geschlossen. Enthält sie noch Text, wird vorher nachgefragt.
Speichern-Schaltfläche drücken Nur der Inhalt dieser Registerkarte wird gespeichert, danach wird sie geschlossen. Die übrigen bleiben erhalten.
Eine Vorlage auswählen Eine neue Registerkarte öffnet sich mit der Vorlage darin. Der begonnene Text geht nicht verloren.

Eine Registerkarte wird nach der Vorlage benannt, wenn sie aus einer Vorlage geöffnet wurde, sonst nach der ersten Zeile ihres Textes. Noch leere Registerkarten haben keinen Namen.

Mehrere Notizblöcke öffnen

Wenn Sie im „+"-Menü eines anderen Bildschirms „Notizblock" wählen, öffnet sich jedes Mal ein weiteres Notizblock-Fenster. So können Sie sie nebeneinander legen und einen Datensatz schreiben, während Sie einen anderen ansehen.

Die Tab-Liste ist für alle Fenster gemeinsam. Ein in einem Fenster angelegtes Tab erscheint auch in der Tab-Liste des anderen. Beim Schließen eines Fensters geht der Entwurf nicht verloren.

Welches Tab ein Fenster gerade zeigt, gilt dagegen nur für dieses Fenster. Sie können dasselbe Tab in zwei Fenstern öffnen; auch dann wird der Datensatz beim Speichern aus beiden nur einmal angelegt.

Tipp: Begonnener Text bleibt auch nach dem Schließen des Bildschirms erhalten. Beim nächsten Öffnen sind die zuvor geöffneten Registerkarten wieder da.

Überblick über die Notizblock-Syntax

Die Notizblock-Syntax ist ein zeilenweise strukturiertes Textformat. Mit einer einzigen Texteingabe können Sie folgende Einträge gesammelt anlegen:

  • Notiz: Aufzeichnung von Textnotizen
  • Zeiterfassung: Starten und Beenden von Zeitmessungen
  • Aufgaben: Hinzufügen und Aktualisieren von Aufgaben
  • Lesezeichen: Speichern von URLs
  • Numerische Datensätze: Aufzeichnung numerischer Daten
  • Ausgaben: Aufzeichnung von Geldbeträgen
  • Stimmung: Aufzeichnung eines Stimmungswerts (0–10)
  • Tagging: Hinzufügen von Tags zu Einträgen

Bedienschritte

  1. Geben Sie den Inhalt des Eintrags mit der Notizblock-Syntax in den Texteingabebereich ein.
  2. Fügen Sie bei Bedarf über die Vorlagenschaltfläche einen Textbaustein ein. Die Vorlage wird in einer neuen Registerkarte geöffnet, der begonnene Text geht also nicht verloren.
  3. Klicken Sie auf die Speichern-Schaltfläche, um den Eintrag zu erstellen.
  4. Enthält der Text ein bisher nie verwendetes Tag, erscheint die Rückfrage „Dies ist ein neues Tag. Möchten Sie es hinzufügen?" Wenn das Tag stimmt, fahren Sie fort.
  5. Nach erfolgreichem Speichern wird diese Registerkarte geschlossen. Die übrigen behalten ihren Text. Bleibt keine übrig, wird eine leere Registerkarte bereitgestellt.
  6. Schlägt das Speichern fehl, wird nichts aus dieser Registerkarte gespeichert (es bleiben keine halb geschriebenen Einträge zurück). Die Registerkarte bleibt geöffnet: Beheben Sie die Ursache und speichern Sie erneut. Nur eine Typzeile gefolgt von ! zu schreiben ist ebenfalls ein Fehler (kein Inhalt) und speichert nichts; die betroffene Zeile wird rosa angezeigt.
Tipp: Die Rückfrage bei neuen Tags verhindert, dass sich durch Tippfehler sehr ähnliche Tags ansammeln. Weicht der angezeigte Tag-Name von Ihrer Absicht ab, gehen Sie zurück und korrigieren Sie ihn.
Tipp: Tags, die Sie im Notizblock vergeben, erscheinen auch als Vorschläge unter „Tag aus Verlauf hinzufügen“, sowohl im Tag-Feld der Hinzufügen- und Bearbeiten-Bildschirme als auch im Kontextmenü eines Eintrags. Sie bleiben als ein Satz je Eintrag erhalten, und der Satz des zuletzt gespeicherten Eintrags steht vorn.
Tipp: Mit Vorlagen können Sie effizienter eingeben. Es ist praktisch, häufig verwendete Eintragsmuster als Vorlage zu hinterlegen.
Tipp: Auch ohne die Notizblock-Syntax zu kennen, können Sie mit Vorlagen sofort mit dem Aufzeichnen beginnen.
Tipp: Auf anderen Bildschirmen öffnet jede Auswahl von „Notizblock" im Menü + ein weiteres Notizblock-Fenster. Jedes Fenster kann eine andere Registerkarte zeigen; zeigen zwei Fenster dieselbe Registerkarte, erscheint das Getippte sofort in beiden.
