Notizblock

Notizblock-Bildschirm zur Aufzeichnung von Lebensereignissen mit Notizblock-Syntax. Die Notizblock-Syntax ist ein zeilenstrukturiertes Textformat für die Stapeleingabe verschiedener Datensätze.

Umgang mit Registerkarten

Sie können mehrere Entwürfe nebeneinander offen halten. Fällt Ihnen beim Schreiben eines Eintrags etwas anderes ein, fügen Sie eine Registerkarte hinzu, schreiben Sie es dort und kehren Sie später zur ursprünglichen zurück.

Aktion Ergebnis
Schaltfläche zum Hinzufügen drücken Eine leere Registerkarte kommt hinzu.
Auf den Namen einer Registerkarte klicken Der Editor wechselt zu deren Inhalt.
Schaltfläche zum Schließen drücken Diese Registerkarte wird geschlossen. Enthält sie noch Text, wird vorher nachgefragt.
Speichern-Schaltfläche drücken Nur der Inhalt dieser Registerkarte wird gespeichert, danach wird sie geschlossen. Die übrigen bleiben erhalten.
Eine Vorlage auswählen Eine neue Registerkarte öffnet sich mit der Vorlage darin. Der begonnene Text geht nicht verloren.

Eine Registerkarte wird nach der Vorlage benannt, wenn sie aus einer Vorlage geöffnet wurde, sonst nach der ersten Zeile ihres Textes. Noch leere Registerkarten erhalten eine Nummer.

Tipp: Begonnener Text bleibt auch nach dem Schließen des Bildschirms erhalten. Beim nächsten Öffnen sind die zuvor geöffneten Registerkarten wieder da.

Über den Notizblock

Der Notizblock verwendet ein gkill-eigenes Textformat, mit dem mehrere Datensätze in einem einzigen Text massenhaft erstellt werden können. Jede Zeile stellt einen Befehl oder einen Dateneintrag dar.

Tipp: Mit der Vorlagenschaltfläche können Sie häufig verwendete Eingabeformate schnell einfügen, ohne die Notizblock-Syntax auswendig lernen zu müssen.

Bedienschritte

  1. Geben Sie den Inhalt des Eintrags mit der Notizblock-Syntax in den Texteingabebereich ein.
  2. Fügen Sie bei Bedarf über die Vorlagenschaltfläche einen Textbaustein ein. Die Vorlage wird in einer neuen Registerkarte geöffnet, der begonnene Text geht also nicht verloren.
  3. Klicken Sie auf die Speichern-Schaltfläche, um den Eintrag zu erstellen.
  4. Enthält der Text ein bisher nie verwendetes Tag, erscheint die Rückfrage „Dies ist ein neues Tag. Möchten Sie es hinzufügen?" Wenn das Tag stimmt, fahren Sie fort.
  5. Nach erfolgreichem Speichern wird diese Registerkarte geschlossen. Die übrigen behalten ihren Text. Bleibt keine übrig, wird eine leere Registerkarte bereitgestellt.
Tipp: Die Rückfrage bei neuen Tags verhindert, dass sich durch Tippfehler sehr ähnliche Tags ansammeln. Weicht der angezeigte Tag-Name von Ihrer Absicht ab, gehen Sie zurück und korrigieren Sie ihn.
Tipp: Mit Vorlagen können Sie effizienter eingeben. Es ist praktisch, häufig verwendete Eintragsmuster als Vorlage zu hinterlegen.
Tipp: Auf anderen Bildschirmen öffnet jede Auswahl von „Notizblock" im Menü + ein weiteres Notizblock-Fenster. Jedes Fenster kann eine andere Registerkarte zeigen; zeigen zwei Fenster dieselbe Registerkarte, erscheint das Getippte sofort in beiden.
