Zeitstempel-Notizblock

Hybridbildschirm, der die Notizeingabe und die laufenden Zeiterfassungen gleichzeitig anzeigt. Notizen und Zeitmessung lassen sich so effizient auf einem einzigen Bildschirm verwalten.

Symbolleistenschaltflächen

Schaltfläche Beschreibung
⚙ Einstellungen Öffnet den Einstellungsbildschirm der Anwendung.
❔ HilfeZeigt die Hilfe für den aktuellen Bildschirm an.

Bildschirmlayout

Bereich Beschreibung
Obere Hälfte: Notizblock-Eingabebereich Derselbe Texteingabebereich wie im Notizblock-Bildschirm. Sie können Daten mit der Notizblock-Syntax eingeben, Vorlagen einfügen und speichern.
Untere Hälfte: Liste der laufenden Zeiterfassungen Zeigt die Liste der aktuell aktiven Zeiterfassungssitzungen an. Das Stoppen der einzelnen Sitzungen ist ebenfalls von hier aus möglich.

Hauptmerkmale

  • Automatische Aktualisierung: Wenn Sie über die Notizblock-Eingabe einen Eintrag speichern, wird die Liste in der unteren Hälfte automatisch aktualisiert. Neu gestartete Zeiterfassungen erscheinen sofort in der Liste.
  • Gleichzeitige Bedienung: Während Sie eine Notiz schreiben, können Sie laufende Zeiterfassungen prüfen und stoppen.
  • Notizblock-Integration: Wenn Sie Start und Stopp einer Zeiterfassung in der Notizblock-Syntax angeben, wird dies in Echtzeit in der Liste unten übernommen.

Bedienschritte

  1. Geben Sie im Textbereich der oberen Hälfte einen Eintrag in der Notizblock-Syntax ein.
  2. Senden Sie den Eintrag über die Speichern-Schaltfläche.
  3. Wenn Sie den Start einer Zeiterfassung angegeben haben, erscheint die neue Sitzung in der Liste der unteren Hälfte.
  4. Über die Liste in der unteren Hälfte können Sie laufende Sitzungen stoppen.

FAB (Floating-Action-Schaltfläche) „+“

Durch Tippen auf die „+“-Schaltfläche unten rechts öffnet sich ein Menü zum Hinzufügen verschiedener Einträge:

MenüpunktBeschreibung
NotizblockGibt eine Textnotiz im Notizblockformat ein.
Zeit-NotizblockÖffnet den Hybridbildschirm aus Notizeingabe und Liste der Zeiterfassungen.
Numerische DatensätzeZeichnet numerische Daten auf.
LesezeichenSpeichert eine URL.
ZeiterfassungStartet eine neue Zeiterfassungssitzung.
AufgabeFügt eine neue Aufgabe hinzu.
AusgabeZeichnet einen Betrag auf.
StimmungZeichnet einen Stimmungswert (0–10) auf.
HochladenLädt eine Datei hoch und zeichnet sie auf.
Langes Drücken: Langes Drücken der „+“-Schaltfläche öffnet direkt den Notizblock. Praktisch, wenn Sie schnell eine Notiz erfassen möchten.
Tipp: Für die tägliche Erfassung ist dieser Bildschirm am effizientesten. Sie können Notizen schreiben und gleichzeitig Ihre Arbeitszeit verwalten.
Tipp: Die Notizblock-Eingabe in der oberen Hälfte bietet dieselben Funktionen wie der Notizblock-Bildschirm. Auch Vorlagen können verwendet werden.
Tastenkürzel: Drücken Sie auf diesem Bildschirm die Eingabetaste, um den Notizblock-Dialog zu öffnen. Dies ist praktisch, um schnell Einträge hinzuzufügen.
