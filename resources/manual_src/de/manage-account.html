Kontoverwaltung

Dieser Bildschirm verwaltet Benutzerkonten. Nur Administratoren haben Zugriff.

Obere Schaltfläche

Drücken Sie die Schaltfläche Konto hinzufügen, um ein neues Konto zu erstellen.

Kontoliste

Registrierte Konten werden in einer Liste angezeigt. Jede Kontozeile enthält die folgenden Elemente:

ElementBeschreibung
Kontrollkästchen Aktivieren/DeaktivierenSchaltet den Kontostatus zwischen aktiviert und deaktiviert um (das Konto, mit dem Sie angemeldet sind, kann nicht umgeschaltet werden)
Benutzer-IDZeigt die Benutzer-ID des Kontos an
Schaltfläche Speicherort zuweisenWeist dem Benutzer Ablagen zu
Schaltfläche ErweiterungseinstellungenÖffnet die Liste der Erweiterungen dieses Benutzers
Schaltfläche Passwort zurücksetzenGeneriert einen Link zum Zurücksetzen des Passworts

Untere Schaltfläche

Schließen: Schließt den Bildschirm zur Kontoverwaltung.

Tipp: Das admin-Konto wird beim ersten Serverstart automatisch erstellt. Über die Kontoverwaltung hinzugefügte Konten sind normale Benutzer (ohne Administratorrechte). Konten werden durch Aktivieren/Deaktivieren verwaltet, nicht durch Löschen.

Passwort zurücksetzen

Hat ein Benutzer sein Passwort vergessen, stellt ein Administrator mit den folgenden Schritten einen Link zum Zurücksetzen des Passworts aus.

Schritte für Administratoren

  1. Öffnen Sie im Bildschirm Servereinstellungen die „Kontoverwaltung“.
  2. Drücken Sie in der Zeile des betreffenden Benutzers die Schaltfläche „Passwort zurücksetzen“.
  3. Drücken Sie im Bestätigungsdialog auf „OK“; daraufhin wird ein Link zum Zurücksetzen des Passworts erzeugt.
  4. Kopieren Sie den angezeigten Link und geben Sie ihn an den Benutzer weiter (per Nachricht, E-Mail usw.).

Schritte für Benutzer

  1. Öffnen Sie den Link, den Sie vom Administrator erhalten haben, im Browser.
  2. Geben Sie das neue Passwort ein und zur Bestätigung ein zweites Mal.
  3. Drücken Sie die Schaltfläche „Festlegen“, um das neue Passwort zu setzen.
  4. Sie werden zum Anmeldebildschirm weitergeleitet; melden Sie sich mit dem neuen Passwort an.
Tipp: Der Link zum Zurücksetzen ist nur einmal verwendbar; nach der Verwendung wird er ungültig. Er ist 72 Stunden ab Ausstellung gültig, und das Ablaufdatum wird im Dialog mit dem Link angezeigt. Nach Ablauf können Sie im selben Dialog über die Schaltfläche „Link neu ausstellen“ einen neuen Link ausstellen.

Ablagen zuweisen

Jedem Benutzer werden „Ablagen“ zugewiesen, in denen seine Daten gespeichert werden. Mit der Schaltfläche „Speicherort zuweisen“ öffnen Sie einen Dialog, in dem Sie die Ablagen dieses Benutzers festlegen. Einzelheiten finden Sie unter „Ablagen verwalten“ in den Servereinstellungen.

Einstellungen der Erweiterungen

Drücken Sie in der Zeile eines Benutzers auf die Schaltfläche „Erweiterungseinstellungen“, um die Liste seiner Erweiterungen zu öffnen. Dort stehen Name, Version und Beschreibung jeder Erweiterung sowie, ob sie läuft. „Einstellungen“ in einer Zeile öffnet den Einstellungsbildschirm, den die Erweiterung selbst mitbringt; dort können Sie etwa ihre Quellordner ändern und speichern.

Tipp: Die Quellordner legen fest, welche Ordner gkill lesen darf. Daher kann nur ein Administrator diesen Bildschirm öffnen. Was Erweiterungen sind, steht unter Plugins.
