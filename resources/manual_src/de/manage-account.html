Kontoverwaltung

Dieser Bildschirm verwaltet Benutzerkonten. Nur Administratoren haben Zugriff.

Obere Schaltfläche

Drücken Sie die Schaltfläche Konto hinzufügen, um ein neues Konto zu erstellen.

Kontoliste

Registrierte Konten werden in einer Liste angezeigt. Jede Kontozeile enthält die folgenden Elemente:

ElementBeschreibung
Kontrollkästchen Aktivieren/DeaktivierenSchaltet den Kontostatus zwischen aktiviert und deaktiviert um
Benutzer-IDZeigt die Benutzer-ID des Kontos an
Schaltfläche SpeicherzuweisungWeist dem Benutzer Daten-Repositories zu
Schaltfläche Passwort zurücksetzenGeneriert einen Link zum Zurücksetzen des Passworts

Untere Schaltfläche

Schließen: Schließt den Bildschirm zur Kontoverwaltung.

Hinweis: Das admin-Konto wird beim ersten Serverstart automatisch erstellt. Über die Kontoverwaltung hinzugefugte Konten sind normale Benutzer (ohne Administratorrechte). Konten werden durch Aktivieren/Deaktivieren verwaltet, nicht durch Löschen.

Passwort-Reset-Verfahren

Administrator-Verfahren

  1. Öffnen Sie Servereinstellungen > Kontoverwaltung.
  2. Drücken Sie die Schaltfläche "Passwort zurucksetzen" des betreffenden Benutzers.
  3. Drücken Sie OK im Bestätigungsdialog, um den Reset-Link zu generieren.
  4. Kopieren Sie den Link und teilen Sie ihn mit dem Benutzer.

Benutzer-Verfahren

  1. Öffnen Sie den Link im Browser.
  2. Geben Sie das neue Passwort zweimal ein.
  3. Drücken Sie die Schaltfläche "Festlegen".
  4. Sie werden zum Anmeldebildschirm weitergeleitet; melden Sie sich mit dem neuen Passwort an.
Hinweis: Der Reset-Link ist nur einmal verwendbar. Wenn er abgelaufen ist, bitten Sie den Administrator, einen neuen zu generieren.

Speicher-Zuweisung

Die Schaltfläche "Speicherzuweisung" ermoglicht es Ihnen, jedem Benutzer Daten-Repositories zuzuweisen. Weitere Informationen zum Hinzufügen und Verwalten von Repositories finden Sie unter Speicherverwaltung in den Servereinstellungen.
