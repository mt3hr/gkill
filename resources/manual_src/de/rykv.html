Lebensprotokoll-Ansicht

Bildschirm, der Ihr gesamtes Lebensprotokoll mit Bild-Miniaturansichten als Liste anzeigt. Mit mehreren Filterspalten können Sie Daten nach unterschiedlichen Bedingungen gleichzeitig ansehen.

Symbolleistenschaltflächen

Schaltfläche Beschreibung
☰ Seitenleiste Blendet die Seitenleiste zum Suchen und Filtern ein oder aus.
📄 Details Blendet das Detailpanel des ausgewählten Eintrags ein oder aus.
📊 Aggregationsansicht Blendet die Ansicht für Statistik und Analyse ein oder aus.
📅 Kalender Blendet die Kalenderansicht ein oder aus. Klicken Sie oben im Kalender auf Jahr und Monat, um ein Datum auszuwählen. Das wirkt wie ein Klick auf die Zelle dieses Tages: Die Liste springt zu diesem Tag.
🗺 Karte Blendet die Kartenanzeige der GPS-Protokolle ein oder aus. Klicken Sie oben auf der Karte auf das Datum, um den auf der Karte angezeigten Tag auszuwählen (Suchbedingungen und Liste bleiben unverändert).
⚙ Einstellungen Öffnet den Einstellungsbildschirm der Anwendung.
❔ HilfeZeigt die Hilfe für den aktuellen Bildschirm an.

Hauptfunktionen

Listenansicht mit Bild-Miniaturansichten

Zeigt die Einträge in einem mehrspaltigen Rasterlayout an. Bei Einträgen, die Bilder oder Dateien enthalten, wird eine Miniaturansicht angezeigt. Die Spaltenanzahl lässt sich im Einstellungsbildschirm auf 1 bis 10 Spalten ändern.

Seitenleiste (Filter und Suche)

In der Seitenleiste können Sie die folgenden Bedingungen angeben, um die Einträge einzugrenzen.

  • Textsuche (Stichwort)
  • Filtern nach Tags
  • Angabe eines Zeitraums (wählen Sie den Datumsbereich im Kalender; bei Bedarf können Sie auch eine Start- und eine Endzeit angeben. Ein Zeitfeld leeren Sie über das „×“ darin. Bleibt eine Zeit leer, reicht der Bereich von 0 Uhr des ersten Tages bis zum Ende des letzten. Um die Zeitraumangabe ganz aufzuheben, drücken Sie „Leeren“)
  • Tageszeit und Wochentag (auf einen Stundenbereich innerhalb des Tages eingrenzen. Wochentage: nur die gedrückten Tage; ist keiner gedrückt, zählen alle Wochentage)
  • Filtern nach Zeiterfassung (grenzt auf Einträge aus der Zeit ein, in der eine bestimmte Zeiterfassung lief)
  • Filtern nach Standort (grenzt über einen auf der Karte festgelegten Bereich nach Standortdaten ein)
  • Auswahl des Eintragstyps
  • Auswahl der Ablage und des Profils

Filterspalte hinzufügen

Über die „+“-Schaltfläche können Sie eine neue Filterspalte hinzufügen. So lassen sich die Ergebnisse unterschiedlicher Filterbedingungen nebeneinander vergleichen.

Detailpanel

Wenn Sie einen Eintrag auswählen, werden im Detailpanel alle Informationen zu diesem Eintrag angezeigt.

URLs im Text eines Eintrags werden automatisch zu Links und lassen sich direkt öffnen. Satzzeichen und schließende Klammern am Satzende gehören nicht zum Link, sodass sich auch eine mitten im Satz notierte URL korrekt öffnen lässt.

Statistik der Aggregationsansicht

Zeigt statistische Auswertungen und Analyseergebnisse der Eintragsdaten an. So erkennen Sie Tendenzen und Muster Ihrer Einträge.

GPS-Kartenanzeige

Zeigt GPS-Protokolldaten auf einer Karte an. Bewegungsrouten und Standortinformationen lassen sich visuell nachvollziehen. Die Konfiguration eines Google Maps API-Schlüssels ist erforderlich.

Tipp: Die Anzahl der Bildspalten lässt sich im Einstellungsbildschirm ändern. Auf dem Smartphone werden 1–2 Spalten, auf dem PC 3–5 Spalten empfohlen.
Tipp: Es ist praktisch, mehrere Filterspalten hinzuzufügen und Einträge unterschiedlicher Bedingungen nebeneinander zu vergleichen.
Tipp: Der Standardwert des Anzeigezeitraums kann im Einstellungsbildschirm unter „Lebenslog-Ansicht Anzeigetage“ geändert werden.

Tags verwenden

Tags sind Etiketten, mit denen Sie Einträge einordnen und ordnen. Einem Eintrag können mehrere Tags zugewiesen werden.

Ein Tag hinzufügen

  1. Tippen und halten Sie (mobil) bzw. klicken Sie mit der rechten Maustaste (Desktop) auf einen Eintrag in der Zeitachse.
  2. Wählen Sie im Kontextmenü „Tag hinzufügen“.
  3. Geben Sie den Tag-Namen ein und fügen Sie ihn hinzu. Vorhandene Tags werden als Vorschläge angezeigt.

Wenn Sie ein kürzlich verwendetes Tag anhängen möchten, nutzen Sie „Tag aus Verlauf hinzufügen“ im Kontextmenü: Sie wählen es einfach aus der Liste.

Geben Sie einen bisher nie verwendeten Tag-Namen ein, wird vor dem Speichern nachgefragt: „Dies ist ein neues Tag. Möchten Sie es hinzufügen?“ Das verhindert, dass sich durch Tippfehler sehr ähnliche Tags ansammeln.

Ein so neu angelegtes Tag wird automatisch auch den Filterbedingungen der gerade geöffneten Spalten hinzugefügt. Damit verschwindet ein Eintrag nicht aus der Liste, wenn Sie ihn mit einem neuen Tag in einer nach Tags gefilterten Spalte anlegen.

Ein Tag bearbeiten oder löschen

  1. Tippen und halten Sie (mobil) bzw. klicken Sie mit der rechten Maustaste (Desktop) auf ein Tag in der Zeitachse.
  2. Wählen Sie im Kontextmenü „Tag bearbeiten“ oder „Tag löschen“.

Tag-Hierarchie

Unter „Tag-Struktur“ im Einstellungsbildschirm können Sie Anzeigenamen und Reihenfolge der Tags verwalten. Wenn Sie häufig verwendete Tags weiter oben anordnen, finden Sie sie in der Vorschlagsliste bei der Tag-Eingabe leichter.

Tipp: Wenn Sie in der Notizblock-Syntax #Tag-Name eingeben, wird beim Absenden des Textes automatisch ein Tag vergeben. Weitere Details finden Sie in der Notizblock-Syntaxreferenz.

Details zum Datei-Upload

Über „Hochladen“ im Menü der „+“-Schaltfläche können Sie Dateien wie Bilder, Videos und Dokumente in gkill speichern.

Bedienschritte

  1. Wählen Sie über die „+“-Schaltfläche „Hochladen“.
  2. Wählen Sie die Ziel-Ablage für den Upload (eine Ablage für Dateien).
  3. Prüfen und passen Sie die zugehörige Zeit (den Aufzeichnungszeitpunkt der Datei) an.
  4. Wählen Sie die Datei(en) aus und laden Sie sie hoch. Sie können mehrere Dateien auf einmal auswählen. Klicken Sie im Dialog auf den Bereich „Hier klicken oder Dateien ablegen“, um sie auszuwählen, oder ziehen Sie die Dateien per Drag & Drop hinein.

Unterstützte Dateiformate

Bilder (JPEG, PNG, GIF, WEBP), Videos (MP4 usw.), PDF, ZIP und andere gängige Dateiformate werden unterstützt. Markdown-Dateien (.md / .markdown) werden in Listen- und Detailansicht formatiert dargestellt (Überschriften, Tabellen usw.), und auch Diagramme in Mermaid-Schreibweise werden als Grafik dargestellt.

Beschränkung der Upload-Größe

Pro Upload können Sie bis zu etwa 1 GB senden. Wenn Sie mehrere große Dateien hochladen möchten, teilen Sie den Vorgang bitte auf mehrere Uploads auf.

Tastenkürzel: Drücken Sie Strg+V, um Bilder oder Text aus der Zwischenablage direkt als Datei zu speichern. Praktisch, um Screenshots schnell festzuhalten.

Den Inhalt einer ZIP-Datei ansehen

Den Inhalt hochgeladener ZIP-Dateien können Sie direkt am Bildschirm öffnen, ohne ihn auf den Rechner zu entpacken. Dateien mit der Endung .cbz werden ebenfalls als ZIP behandelt.

So öffnen Sie ihn

  1. Tippen und halten Sie (mobil) bzw. klicken Sie mit der rechten Maustaste (Desktop) auf den Eintrag der ZIP-Datei.
  2. Wählen Sie im Kontextmenü „ZIP-Inhalt durchsuchen“.
  3. Die Ordner und Dateien in der ZIP-Datei werden als Liste angezeigt.

Darin navigieren

  • Ein Klick auf einen Ordner führt hinein. Zum Zurückgehen nutzen Sie den Navigationspfad oben oder „..“.
  • Ein Klick auf eine Bilddatei öffnet die Vorschau; von dort blättern Sie direkt zum nächsten Bild.
  • Ein Klick auf eine Textdatei zeigt deren Inhalt direkt an.
  • Ein Klick auf eine Video- oder Audiodatei spielt sie direkt ab. Sie können zur vorherigen oder nächsten Datei wechseln oder sie in einem neuen Tab öffnen. Kann der Browser das Format nicht wiedergeben, weist eine Meldung darauf hin und Sie können die Datei zum Abspielen herunterladen.
  • Ein Klick auf eine PDF-Datei öffnet sie in einem neuen Tab.
  • Einzelne Dateien lassen sich auch herunterladen.
  • Zu große Dateien lassen sich nicht in der Vorschau anzeigen; darauf weist eine Meldung hin.
Tipp: „ZIP-Inhalt durchsuchen“ erscheint nur im Menü, wenn Sie den Eintrag einer ZIP-Datei auswählen. Bei anderen Einträgen wird es nicht angezeigt.

Einen Eintrag zur Aufgabe machen und den Inhalt kopieren

Einen Eintrag, um den Sie sich später kümmern möchten, können Sie zur Aufgabe machen, ohne seinen Inhalt umzuschreiben. Wählen Sie im Kontextmenü des Eintrags „Als Aufgabe anlegen“, legen Sie Boardname, Fälligkeit sowie geplanten Beginn und geplantes Ende fest und speichern Sie. Die erstellte Aufgabe erscheint auch im Aufgabenbildschirm und lässt sich als erledigt abhaken.

Mit „Inhalt kopieren“ im Kontextmenü kopieren Sie den Text des Eintrags in die Zwischenablage. Mit „ID kopieren“ kopieren Sie die ID des Eintrags.

GPS-Karte verwenden

Wenn Sie die Kartenschaltfläche in der Symbolleiste einschalten, werden die GPS-Bewegungsrouten für den Zeitraum der Einträge auf der Karte angezeigt.

GPS-Protokoll hochladen

  1. Wählen Sie über die „+“-Schaltfläche „Hochladen“.
  2. Wählen Sie als Ziel die Ablage für GPS-Protokolle.
  3. Wählen Sie die GPX-Datei aus und laden Sie sie hoch. Klicken Sie auf den Bereich „Hier klicken oder .gpx-Dateien ablegen“, um sie auszuwählen, oder ziehen Sie sie per Drag & Drop hinein.
  4. Schalten Sie nach dem Hochladen die Kartenschaltfläche ein, um die Bewegungsroute anzuzeigen.

Google Maps API-Schlüssel konfigurieren

Für die Karte ist ein Google Maps API-Schlüssel erforderlich. Geben Sie Ihren Schlüssel unter „Google Map API-Schlüssel“ im Einstellungsbildschirm (Schaltfläche „Einstellungen“ in der Symbolleiste der Lebensprotokoll-Ansicht) ein und speichern Sie mit „Anwenden“. Die Einstellung ist unter „Externe Integration“ auf der Seite Einstellungsbildschirm beschrieben.

Tipp: Einen Google Maps API-Schlüssel erhalten Sie in der Google Cloud Console. Sie benötigen einen Schlüssel, für den die Maps JavaScript API aktiviert ist.

Gespeicherte Suchbedingungen abrufen

Suchbedingungen, die Sie unter „Suchbedingungen“ im Einstellungsbildschirm unter einem Namen gespeichert haben, lassen sich über die runde Schaltfläche unten rechts in der Seitenleiste abrufen. Wählen Sie einen Namen, wird diese Bedingung unverändert in die Seitenleiste übernommen. Wurde nichts gespeichert, wird die Schaltfläche nicht angezeigt.

Die aktuellen Suchkriterien teilen

Aktivieren Sie „Freigabe-Fußzeile anzeigen“ im Einstellungsbildschirm, und am unteren Rand der Seitenleiste erscheint eine Freigabe-Fußzeile. Ein Druck auf die Schaltfläche „Teilen“ an ihrem linken Rand fragt zuerst, wie Sie die Einträge weitergeben möchten. Mit „Diese Ansicht teilen“ werden die aktuell verwendeten Suchkriterien in einen Freigabelink verwandelt. Geteilt wird nicht ein einzelner Eintrag, sondern alle Einträge, die diesen Kriterien entsprechen. Bereits erstellte Links können über „Freigabeverwaltung“ am rechten Rand aufgelistet, bearbeitet und gelöscht werden.

Die aktuellen Suchergebnisse als HTML-Datei weitergeben

Ein Freigabelink lässt sich nur ansehen, solange diese Anwendung läuft. Wenn Sie etwas weitergeben möchten, ohne dass das Gegenüber etwas vorbereiten muss, können Sie die gerade gefilterten Suchergebnisse in eine HTML-Datei schreiben. Wer sie erhält, öffnet sie einfach im Browser, und da alles in der Datei steckt, nimmt sie auch keine Verbindung zu dieser Anwendung auf.

So erzeugen Sie die Datei

  1. Drücken Sie in der Freigabe-Fußzeile am unteren Rand der Seitenleiste die Schaltfläche „Teilen“ an ihrem linken Rand (ist die Freigabe-Fußzeile nicht zu sehen, aktivieren Sie im Einstellungsbildschirm „Freigabe-Fußzeile anzeigen“).
  2. Wählen Sie „HTML exportieren“.
  3. Wählen Sie, was einbezogen wird und in welcher Form exportiert wird (siehe Tabelle unten).
  4. Mit „Exportieren“ wird die fertige Datei heruntergeladen. Bei vielen Einträgen oder Bildern dauert das eine Weile.

Was Sie wählen können

Element Beschreibung
Titel Geben Sie eine Überschrift (optional) ein, die oben links in der exportierten Ansicht angezeigt wird.
Ziel Wählen Sie zwischen „Alle sichtbaren Spalten“ und „Fokussierte Spalte“.
Was einbezogen wird Wählen Sie, ob Tags, Texte, Benachrichtigungen, Zeiterfassungen, Standortdaten und Plugin-Inhalte einbezogen werden.
Ansichten Wählen Sie, ob die exportierte Datei die Auswertung, die Karte und die Suchleiste behält. Eine beibehaltene Suchleiste grenzt nur innerhalb der exportierten Einträge ein (Bedingungen für Stichwort, Zeiterfassung und Standort wirken sich dort nicht aus, auch wenn Sie sie eingeben).
Medien Wählen Sie für Bilder und Videos „Nur Miniaturansichten“, „Originale einbeziehen“ oder „Nicht einbetten“. Auch das Limit pro Datei und das Gesamtlimit lassen sich festlegen.
Ausgabeformat „Eine einzelne HTML-Datei“ ist in sich geschlossen. „HTML und gleichnamiger Ordner“ legt Bilder in einen Ordner daneben und ist dadurch leichter als eine einzelne Datei, aber beide müssen zusammen weitergegeben werden (bei „Nicht einbetten“ steht nur „Eine einzelne HTML-Datei“ zur Auswahl).
Wenn eine Grenze überschritten wird: Alles, was nicht in die Mediengrenzen passte, wird in der exportierten Datei als „Nicht enthalten“ angezeigt. Da die Lücke sichtbar ist, können Sie bei Bedarf die Grenze anheben und erneut exportieren.

Was die empfangende Person sieht

Die exportierte Datei ist nur zum Lesen. Einträge lassen sich weder hinzufügen noch bearbeiten oder mit Tags versehen. Ein Doppelklick auf einen Eintrag öffnet die Details, von dort aus lassen sich auch verwandte Einträge verfolgen. Die Karte ist die einzige Ausnahme: Die Karte selbst wird von außen geladen, der Verlauf erscheint also erst, wenn die empfangende Person ihren eigenen Kartenschlüssel einträgt. Der eingegebene Schlüssel wird nirgends gespeichert und verschwindet beim Schließen der Seite; er muss daher bei jedem Öffnen neu eingegeben werden.

Wenn gemeldet wird, dass eine Ablage nicht geladen werden kann

Einträge aus den anderen Ablagen können weiterhin angezeigt werden. Diese Meldung allein bedeutet nicht, dass Ihre Einträge verloren sind.

  1. Prüfen Sie, ob die externe Festplatte oder der USB-Speicher richtig angeschlossen ist.
  2. Prüfen Sie bei einem Ort im Netzwerk die Netzwerkverbindung, die Freigabe und die Leseberechtigung für den Ordner.
  3. Laden Sie nach Wiederherstellung der Verbindung die Ansicht neu. Wenn Sie den Einstellungsbildschirm öffnen können, laden Sie auch die Ablagen neu.
  4. Entfernen Sie bis zur Wiederherstellung Suchbedingungen, die nur auf die in der Warnung genannte Ablage eingrenzen.
  5. Wenn die Meldung bleibt, wenden Sie sich mit dem Namen der Ablage und dem Zeitpunkt an den Administrator.
