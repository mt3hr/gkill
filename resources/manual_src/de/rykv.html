Lebensprotokoll-Ansicht

Bildschirm zum Durchsuchen von Lebensprotokollen mit Miniaturansichten. Unterstützt mehrere Anzeigemodi und Filterfunktionen.

Symbolleistenschaltflächen

Schaltfläche Beschreibung
☰ Seitenleiste Öffnet/schließt die Seitenleiste zum Filtern und Navigieren.
📄 Details Zeigt/verbirgt das Detailpanel des Datensatzes.
📊 Zusammenfassungsansicht Zeigt den Bildschirm für statistische Analyse an.
📅 Kalender Zeigt die Kalenderansicht an.
🗺 Karte Zeigt Datensätze mit GPS-Informationen auf der Karte an.
⚙ Einstellungen Öffnet den Einstellungsbildschirm der Anwendung.
❔ HilfeZeigt die Hilfe für den aktuellen Bildschirm an.

Hauptfunktionen

Listenansicht mit Bild-Miniaturansichten

Zeigt die Einträge in einem mehrspaltigen Rasterlayout an. Bei Einträgen, die Bilder oder Dateien enthalten, wird eine Miniaturansicht angezeigt. Die Spaltenanzahl lässt sich im Einstellungsbildschirm auf 1 bis 10 Spalten ändern.

Seitenleiste (Filter und Suche)

In der Seitenleiste können Sie die folgenden Bedingungen angeben, um die Einträge einzugrenzen.

  • Textsuche (Stichwort)
  • Filtern nach Tags
  • Angabe eines Zeitraums
  • Auswahl des Eintragstyps
  • Auswahl der Ablage

Filterspalte hinzufügen

Über die „+“-Schaltfläche können Sie eine neue Filterspalte hinzufügen. So lassen sich die Ergebnisse unterschiedlicher Filterbedingungen nebeneinander vergleichen.

Detailpanel

Wenn Sie einen Eintrag auswählen, werden im Detailpanel alle Informationen zu diesem Eintrag angezeigt.

Statistik der Aggregationsansicht

Zeigt statistische Auswertungen und Analyseergebnisse der Eintragsdaten an. So erkennen Sie Tendenzen und Muster Ihrer Einträge.

GPS-Kartenanzeige

Zeigt GPS-Protokolldaten auf einer Karte an. Bewegungsrouten und Standortinformationen lassen sich visuell nachvollziehen. Die Konfiguration eines Google Maps API-Schlüssels ist erforderlich.

Tipp: Die Anzahl der Bildspalten lässt sich im Einstellungsbildschirm ändern. Auf dem Smartphone werden 1–2 Spalten, auf dem PC 3–5 Spalten empfohlen.
Tipp: Es ist praktisch, mehrere Filterspalten hinzuzufügen und Einträge unterschiedlicher Bedingungen nebeneinander zu vergleichen.
Tipp: Der Standardwert des Anzeigezeitraums kann in den Einstellungen unter „Lebenslog-Ansicht Anzeigetage“ geändert werden.

Tags verwenden

Ein Tag hinzufügen

  1. Halten Sie einen Datensatz gedrückt oder klicken Sie mit der rechten Maustaste, um das Kontextmenü zu öffnen.
  2. Wählen Sie "Tag hinzufügen".
  3. Geben Sie den Tag-Namen ein (vorhandene Tags werden als Vorschläge angezeigt).

Wenn Sie ein kürzlich verwendetes Tag anhängen möchten, nutzen Sie „Tag aus Verlauf hinzufügen" im Kontextmenü: Sie wählen es einfach aus der Liste.

Geben Sie einen bisher nie verwendeten Tag-Namen ein, wird vor dem Speichern nachgefragt: „Dies ist ein neues Tag. Möchten Sie es hinzufügen?" Das verhindert, dass sich durch Tippfehler sehr ähnliche Tags ansammeln.

Ein Tag bearbeiten oder löschen

  1. Halten Sie das zu ändernde Tag gedrückt oder klicken Sie mit der rechten Maustaste darauf.
  2. Wählen Sie "Bearbeiten" oder "Löschen" aus dem Menü.

Tag-Strukturverwaltung

Sie können Anzeigenamen und Reihenfolge der Tags unter Einstellungen > Tag-Struktur verwalten.

Tipp: Wenn Sie #Tag-Name in der Notizblock-Syntax schreiben, wird der Datensatz automatisch mit einem Tag versehen. Weitere Details finden Sie in der Notizblock-Syntaxreferenz.

Datei-Upload-Details

Bedienschritte

  1. Tippen Sie auf die „+“-Schaltfläche und wählen Sie „Datei hochladen“.
  2. Wählen Sie die Ziel-Ablage (Ablage für die Dateiverwaltung).
  3. Bestätigen und passen Sie das zugehörige Datum und die Uhrzeit an.
  4. Wählen Sie die hochzuladende(n) Datei(en) aus (mehrere Dateien möglich). Sie können Dateien auch per Drag & Drop in den Bereich „Dateien hier ablegen“ im Dialog ziehen.

Unterstützte Dateiformate

Bilder (JPEG/PNG/GIF/WEBP), Videos (MP4 usw.), PDF, ZIP und andere.

Markdown-Dateien (.md / .markdown) werden in Listen- und Detailansicht formatiert dargestellt (Überschriften, Tabellen), und mermaid-Codeblöcke werden als Diagramme gerendert.

Beschränkung der Upload-Größe

Die monatliche Obergrenze für Uploads legt der Administrator unter „Monatliche Upload-Größenbeschränkung" in der Serverkonfiguration fest. Der Anfangswert ist -1 (unbegrenzt).

Tipp: Drücken Sie Strg+V, um den Inhalt der Zwischenablage direkt als Datei zu speichern.

Den Inhalt einer ZIP-Datei ansehen

Den Inhalt hochgeladener ZIP-Dateien können Sie direkt am Bildschirm öffnen, ohne ihn auf den Rechner zu entpacken. Dateien mit der Endung .cbz werden ebenfalls als ZIP behandelt.

So öffnen Sie ihn

  1. Tippen und halten Sie (mobil) bzw. klicken Sie mit der rechten Maustaste (Desktop) auf den Eintrag der ZIP-Datei.
  2. Wählen Sie im Kontextmenü „ZIP-Inhalt durchsuchen".
  3. Die Ordner und Dateien in der ZIP-Datei werden als Liste angezeigt.

Darin navigieren

  • Ein Klick auf einen Ordner führt hinein. Zum Zurückgehen nutzen Sie den Navigationspfad oben oder „..".
  • Ein Klick auf eine Bilddatei öffnet die Vorschau; von dort blättern Sie direkt zum nächsten Bild.
  • Einzelne Dateien lassen sich auch herunterladen.
  • Zu große Dateien lassen sich nicht in der Vorschau anzeigen; darauf weist eine Meldung hin.
Tipp: „ZIP-Inhalt durchsuchen" erscheint nur im Menü, wenn Sie den Eintrag einer ZIP-Datei auswählen. Bei anderen Einträgen wird es nicht angezeigt.

Einen Eintrag zur Aufgabe machen und den Inhalt kopieren

Einen Eintrag, um den Sie sich später kümmern möchten, können Sie zur Aufgabe machen, ohne seinen Inhalt umzuschreiben. Wählen Sie im Kontextmenü des Eintrags „Als Aufgabe anlegen", legen Sie Boardname, Fälligkeit sowie geplanten Beginn und geplantes Ende fest und speichern Sie. Die erstellte Aufgabe erscheint auch in der Aufgabenansicht und lässt sich als erledigt abhaken.

Mit „Inhalt kopieren" im Kontextmenü kopieren Sie den Text des Eintrags in die Zwischenablage. Mit „ID kopieren" kopieren Sie die ID des Eintrags.

GPS-Karte verwenden

Eine GPS-Aufzeichnung hochladen

  1. Tippen Sie auf die "+"-Schaltfläche und wählen Sie "Datei hochladen".
  2. Wählen Sie das für GPS-Aufzeichnungen vorgesehene Repository.
  3. Wählen Sie die GPX-Datei aus. Sie können sie auch per Drag & Drop in den Bereich „.gpx-Dateien hier ablegen" ziehen.
  4. Aktivieren Sie die Kartenschaltfläche, um die Anzeige zu bestätigen.

Google Maps API-Schlüssel konfigurieren

Gehen Sie zu Einstellungen > Anzeigeeinstellungen > Google Maps API-Schlüssel und geben Sie Ihren Schlüssel ein.

Tipp: Holen Sie sich Ihren API-Schlüssel in der Google Cloud Console, indem Sie die Maps JavaScript API aktivieren.

Die aktuellen Suchkriterien teilen

Aktivieren Sie „Freigabe-Fußzeile anzeigen“ im Einstellungsbildschirm, und am unteren Rand der Seitenleiste erscheint eine Freigabe-Fußzeile. Ein Druck auf die Schaltfläche „Teilen“ an ihrem linken Rand verwandelt die aktuell verwendeten Suchkriterien in einen Freigabelink. Geteilt wird nicht eine einzelne Aufzeichnung, sondern alle Aufzeichnungen, die diesen Kriterien entsprechen. Bereits erstellte Links können über „Freigabeverwaltung“ am rechten Rand aufgelistet, bearbeitet und gelöscht werden.
