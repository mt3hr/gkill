Speicherverwaltung

Daten-Repositories sind die Speicherorte für Aufzeichnungen. Mehrere Repositories können je nach Verwendungszweck oder Gerat konfiguriert werden.

Die benutzerspezifische Zuweisung wird über die Schaltfläche "Speicherzuweisung" in der Kontoverwaltung verwaltet.

So fugen Sie ein Repository hinzu

  1. Öffnen Sie Kontoverwaltung > Speicherzuweisung des gewunschten Benutzers.
  2. Drücken Sie die Schaltfläche "Hinzufügen".
  3. Konfigurieren Sie folgende Elemente: Anzeigename, Typ, Pfad, Als Schreibziel verwenden, Aktiviert.
  4. Drücken Sie "Speichern".
