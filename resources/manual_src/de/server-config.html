Speicherverwaltung

Daten-Repositories sind die Speicherorte für Aufzeichnungen. Mehrere Repositories können je nach Verwendungszweck oder Gerat konfiguriert werden.

Die benutzerspezifische Zuweisung wird über die Schaltfläche "Speicherzuweisung" in der Kontoverwaltung verwaltet.

So fugen Sie ein Repository hinzu

  1. Öffnen Sie Kontoverwaltung > Speicherzuweisung des gewunschten Benutzers.
  2. Drücken Sie die Schaltfläche "Hinzufügen".
  3. Konfigurieren Sie folgende Elemente: Anzeigename, Typ, Pfad, Als Schreibziel verwenden, Aktiviert. Im Auswahlfeld für den Typ stehen alphanumerische Namen wie kmemo oder timeis; was sie bedeuten, zeigt die Tabelle unten.
  4. Drücken Sie "Speichern".

Repository-Typen

Im Auswahlfeld für den Typ stehen alphanumerische Namen. Folgendes speichert jeder davon.

Anzeige im AuswahlfeldWas gespeichert wird

directoryHochgeladene Dateien (Bilder, Videos, Dokumente usw.)
gpslogGPS-Protokolle im GPX-Format
git_commit_logGit-Commit-Historie (schreibgeschützt)
rekyouReposts (erneut angezeigte frühere Einträge)
mirekyouRepost-Aufgaben (vorhandene Einträge, die zu Aufgaben gemacht wurden)
tagTags an Einträgen
textErgänzende Texte an Einträgen
notificationBenachrichtigungen (Erinnerungen) an Einträgen
Tipp: tag / text / notification / rekyou / mirekyou speichern Informationen, die an Einträgen hängen, nicht die Einträge selbst. Sie werden normalerweise bei der Ersteinrichtung automatisch angelegt und müssen nicht nachträglich hinzugefügt werden.
Tipp: Sie können mehrere Repositories desselben Typs hinzufügen (z.B. nach Gerat getrennt).
Tipp: Die Option "Als Schreibziel verwenden" sollte nur für ein Repository pro Typ aktiviert sein.
