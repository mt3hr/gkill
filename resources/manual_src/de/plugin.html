Plugins

Mit einem installierten Plugin erscheinen auch Einträge, die in anderen Diensten als gkill liegen, in derselben Liste wie Ihre gkill-Einträge. So können Sie an einer Stelle nachvollziehen, was Sie an einem bestimmten Tag gemacht haben.

Verfügbare Plugins

Standardmäßig sind die folgenden sechs enthalten.

Plugin Was importiert wird
ChatGPT Aus ChatGPT exportierter Gesprächsverlauf
Claude.ai Aus Claude.ai exportierter Gesprächsverlauf
ClaudeCode Chat-Protokolle von Claude Code
Codex Arbeitsprotokolle der Codex-CLI
Fitbit Gesundheitsdaten aus Google Takeout (Schritte, Herzfrequenz, verbrauchte Kalorien usw., zu einem Wert pro Tag zusammengefasst)
GoogleLocation Standortverlauf aus Google Takeout (wird auf der Karte angezeigt; es werden keine Einträge erstellt)
Tipp: Diese Namen werden auch verwendet, wenn Sie in der Seitenleiste der Eintragsliste nach „Ablage" filtern. Wenn Sie nur Plugin-Einträge sehen möchten, filtern Sie nach diesen Namen.

So richten Sie ein Plugin ein

Ein Plugin einzurichten bedeutet, Dateien abzulegen. Gehen Sie die Schritte der Reihe nach durch.

  1. Legen Sie die ausführbare Datei des Plugins in den Ordner plugins innerhalb des gkill-Basisordners. Der genaue Ort ist ein Ordner mit Ihrer Benutzer-ID und darin ein Ordner mit dem Plugin-Namen, beide unter plugins angelegt.
  2. Starten Sie gkill. Wenn das Plugin zum ersten Mal geladen wird, entsteht im selben Ordner automatisch die Konfigurationsdatei config.json.
  3. Öffnen Sie config.json in einem Texteditor und tragen Sie unter source_dirs den Ordner ein, in dem die zu importierenden Daten liegen.
  4. Wenn Sie in der Lebensprotokoll-Ansicht suchen, erscheinen sie wie jeder andere Eintrag in der Liste.
Tipp: Wenn bereits eine config.json vorhanden ist, überschreibt gkill sie nie. Ihre Einstellungen gehen beim Bearbeiten nicht verloren.

So geben Sie den Quellordner an

In source_dirs können Sie sowohl einen Ordner- als auch einen Dateipfad angeben. Es gelten folgende Regeln.

Schreibweise Bedeutung
Ein Pfad, der mit ~ beginnt Bezeichnet einen Ort relativ zu Ihrem eigenen Basisordner
* ** ? [] Behandelt einen Teil des Ordner- oder Dateinamens als „beliebig"
Wenn Sie einen Ordner angeben Es wird bis in die Unterordner hinein nach den Zieldateien gesucht
Wenn Sie direkt eine Datei angeben Der Inhalt dieser Datei wird unverändert eingelesen
Wenn Sie es leer lassen ChatGPT und Claude.ai sehen im Plugin-Ordner nach; ClaudeCode und Codex jeweils am Standardspeicherort ihrer CLI-Protokolle

Beim Importieren von Google-Takeout-Daten

Legen Sie für Gesundheitsdaten und Standortverlauf die von Google Takeout heruntergeladene ZIP-Datei unentpackt in einen Ordner. Selbst entpackte Ordner werden nicht gelesen.

Tragen Sie in source_dirs den Ordner ein, der die ZIP-Datei enthält. Sie können auch den Pfad der ZIP-Datei selbst angeben.

Art der Ablage Was passiert
Mehrere aufgeteilte ZIP-Dateien nebeneinander in einem Ordner Sie werden zusammen als ein einziger Download gelesen
Ein neuerer Download in einem anderen Ordner Bei überlappenden Daten wird nur der neuere verwendet. Zeiträume, die es nur im älteren gibt, bleiben erhalten
Tipp: Alte Downloads müssen Sie nicht löschen. Auch bei überlappenden Daten werden Werte wie Schrittzahlen niemals doppelt gezählt.
Tipp: Einträge in config.json, die mit _ (Unterstrich) beginnen, dienen nur der Erläuterung des Formats. Sie können sie löschen.
Tipp: Nach dem Bearbeiten von config.json müssen Sie gkill nicht neu starten. Die neuen Einstellungen gelten ab der nächsten Suche.

Was möglich ist und was nicht

Von einem Plugin importierte Einträge sind schreibgeschützt. Damit die Quelldaten unversehrt bleiben, kann gkill sie nicht verändern.

Aktion Möglich?
Tag hinzufügen / Tag aus Verlauf hinzufügen Ja
Text hinzufügen Ja
Benachrichtigung hinzufügen Ja
Repost Ja
Als Aufgabe anlegen Ja
Inhalt kopieren / ID kopieren Ja
Bearbeiten Nein (wird nicht im Menü angezeigt)
Löschen Nein (wird nicht im Menü angezeigt)
Tipp: Wenn Sie die importierten Gespräche mit Tags versehen, finden Sie sie später über den Tag-Filter der Lebensprotokoll-Ansicht wieder.

Wenn Sie alles neu importieren möchten

Was ein Plugin importiert, wird gespeichert, damit die Anzeige schnell bleibt. Wenn Sie die Quelle stark verändert haben und alles neu einlesen möchten, beenden Sie gkill und führen Sie den folgenden Befehl aus.

gkill_server clear_cache plugin BENUTZER-ID

Beim nächsten Start von gkill werden die Daten bei einer Suche wieder aus der Quelle gelesen.

Wenn nichts richtig angezeigt wird

Symptom Was zu prüfen ist
Es erscheint kein einziger Eintrag Prüfen Sie, ob die Quelldateien tatsächlich in dem Ordner liegen, den Sie in source_dirs eingetragen haben. Ein Tippfehler im Pfad ist die häufigste Ursache.
Die Konfigurationsdatei wird nicht erstellt Prüfen Sie, ob die ausführbare Datei am richtigen Ort liegt. Die Ordnernamen sind Ihre Benutzer-ID und danach der Plugin-Name, in dieser Reihenfolge.
Der Inhalt bleibt der alte Importieren Sie alles mit dem oben beschriebenen Verfahren neu.
„Abrufen des Plugin-Inhalts fehlgeschlagen" wird angezeigt Möglicherweise startet die ausführbare Datei des Plugins nicht. Prüfen Sie, ob sie unbeschädigt ist und ob Sie die Berechtigung zum Ausführen haben.
Tipp: Drücken Sie lange (mobil) oder klicken Sie mit der rechten Maustaste (Desktop) auf einen Eintrag und wählen Sie „Erweiterungseinstellungen“, um den Einstellungsbildschirm zu öffnen. Dort können Sie die Quellordner ändern und speichern. Das direkte Bearbeiten der config.json im Erweiterungsordner funktioniert weiterhin.
