Port

Ein einziger Bildschirm, auf dem jede Aktion als Fenster geöffnet wird.

Port zeigt nur einen Hintergrund und eine "+"-Schaltfläche. Über "+" können Sie Lebenslog-Ansicht, Aufgaben, Laufend und Dashboard als Fenster öffnen und nebeneinander verwenden, ohne den Bildschirm zu wechseln. Ziehen Sie ein Fenster zum Verschieben oder fassen Sie die untere rechte Ecke zum Ändern der Größe. Position und Größe bleiben erhalten.

Zum Hinzufügen eines Eintrags verwenden Sie die Gruppe "Einträge" desselben Menüs: Notizblock, Stempel-Notizblock, Zahl, Lesezeichen, Stempelbuch, Aufgabe, Ausgabe, Stimmung, Hochladen und Zwischenablage speichern.

Tipp: Verwenden Sie Saihate, wenn Sie nur Einträge hinzufügen möchten, und Port, wenn Sie beim Arbeiten zwischen mehreren Bildschirmen wechseln. Port kann über das Titelmenü auch zu anderen Bildschirmen wechseln.

Symbolleisten-Schaltflächen

Schaltfläche Beschreibung
Hilfe Zeigt die Hilfe zum aktuellen Bildschirm.
Einstellungen Öffnet den Einstellungsbildschirm.

Die "+"-Schaltfläche

Ein Druck auf die "+"-Schaltfläche unten rechts öffnet ein in zwei Gruppen geteiltes Menü.

Gruppe Beschreibung
Ansichten Öffnet Lebenslog-Ansicht / Aufgaben / Laufend / Dashboard als Fenster. Sie können mehrere Fenster derselben Ansicht nebeneinander öffnen, bis zu einer Höchstzahl; ist diese erreicht, wird das vorderste nur nach vorne geholt.
Einträge Öffnet ein Fenster zum Hinzufügen dieser Art von Eintrag.

Ein Fenster schließen

Schließen Sie mit dem "x" oben rechts im Fenster, der Escape-Taste oder der Zurück-Schaltfläche des Browsers. Es schließt sich das vorderste Fenster.
