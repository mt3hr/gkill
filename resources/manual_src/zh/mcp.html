AI 集成

通过将 Claude 等 AI 助手与 gkill 连接，您可以通过自然对话搜索、添加和编辑生活日志记录。

可以做的事情

操作示例
搜索记录"显示上周的午餐笔记" / "汇总本月支出"
添加记录"添加今天的备忘录" / "创建一个任务"
更新 / 删除记录"将此任务标记为已完成"
获取 GPS / 文件"显示今天的路线"
查看设置"列出我的模板"
参考使用备注先读取您在设置界面为标签、存储位置、看板和模板填写的“说明”，再按照您的使用方式查找记录
自行学习用法AI 会通过内置的「帮助」功能，自己查阅搜索条件和翻页的规则。找不到时，可以对它说「查一下 gkill 的帮助」
使用技能AI 会阅读您在设置画面中登记的操作手册（技能），并按照其中的步骤工作。也可以让 AI 创建或修改技能

集成类型

类型可以做什么启动命令工具数HTTP 时的端口
只读仅查看和搜索记录，不能添加或修改。可以读取技能gkill_server mcp --kind read148808
只写添加、更新和删除记录。同时也可以获取存储库名称、标签名和板名。除了读取技能，还可以创建和改写技能gkill_server mcp --kind write338809
读写查看、添加、更新和删除记录。除了读取技能，还可以创建和改写技能gkill_server mcp --kind readwrite378810

MCP 服务器是 gkill_server 的一部分，通过 gkill_server mcp --kind <类型> 启动（gkill_server 本身必须处于运行状态）。连接目标和凭据可通过环境变量指定，也可通过首次启动时自动生成的配置文件 configs/gkill_mcp.json 指定。日志输出到 logs/gkill_mcp_<类型>.log（按级别拆分的文件使用相同前缀）。

无论哪种类型，都包含 1 个用于获取插件列表的工具。插件导入的记录正文可以直接包含在搜索结果中接收。

技能

技能是预先交给 AI 的操作手册（例如：如何制作每周总结、某类记录要加哪些标签）。技能按用户保存，无论从哪个 AI 助手连接，都使用相同的技能。AI 在工作前会查看技能列表，阅读内容相符的技能后再开始工作。

一个技能就是一个文件夹，顶层放置 SKILL.md。在 SKILL.md 的开头按下面的格式写名称和说明，后面写步骤。同一文件夹中还可以放参考资料、脚本、素材等文件。

---
name: weekly-summary
description: 制作每周总结的步骤
---
# 步骤
1. ...
操作方法
添加・替换在设置画面的“技能”中，把文件夹打包成 zip 上传。确认将新增、删除、更改的文件后按“应用”，同名技能会被整体替换。
查看・导出用“查看”可以看到各文件的内容。用“下载”可以保存为 zip，在本地修改后直接重新上传。
删除在设置画面“技能”中按“删除”，整体删除该技能。
由 AI 创建・修改在可以写入的集成中，AI 可以创建技能或改写其中的文件。AI 不能删除技能。

zip 的内容按以下规则取入。

  • 技能的名称由 zip 中 SKILL.md 里写的 name 决定（不是 zip 的文件名或文件夹名）。
  • 如果内容被一层文件夹包着（例如把“下载”得到的 zip 原样重新上传），会去掉这一层再取入。
  • 以点开头的文件和文件夹、__MACOSX、Thumbs.db、desktop.ini 不会取入（上传前的确认中会列在“将忽略的文件”）。
  • 名称只能使用小写英文字母、数字和连字符（最多 64 个字符），且开头和结尾必须是字母或数字。
  • 文件名（文件夹名同样）只能使用英文字母、数字和 ._-，必须以字母或数字开头，且不能以点结尾。不能使用 Windows 的保留名 CON、PRN、AUX、NUL、COM1～COM9、LPT1～LPT9（不区分大小写，带扩展名也一样，例如 con.txt）。仅大小写不同的名称，以及同名的文件和文件夹（例如文件 a 与文件夹 a 中的 a/b）不能同时存在。只要有文件不符合这些规则，上传就会以“无法将 zip 作为技能读取”停止。
提示: 对技能的更改会立即生效，且不保留更改历史。让 AI 修改之前，如有需要请先用“下载”保存一份。gkill 不会执行脚本。

文件的传递

向AI展示文件记录（图片、视频、文档）的方式会根据连接形式自动切换。

连接形式传递方式
本地连接（同一台电脑上的AI）文件的实际路径将传递给AI，AI可以直接读取文件。
远程连接（通过互联网的AI）将签发带有效期的专用URL，AI从该URL获取文件。图片会同时提供缩略图和原尺寸版本。无需公开gkill本体。
提示： 嵌入传输的大小上限（默认8MB）可通过环境变量 GKILL_MCP_MAX_FILE_BYTES 调整，URL的有效期（默认1小时）可通过 GKILL_MCP_FILE_LINK_TTL_MS 调整。嵌入传输的大小上限在 AI 读取技能文件时同样生效：SKILL.md 以外超过上限的文件会出现在列表中，但内容不会传给 AI（如有需要，请用“下载”取得 zip）。AI 不指定文件读取技能时（通常的读法），SKILL.md 无论大小都会完整传给 AI（若将 SKILL.md 作为文件指定读取，则适用与其他文件相同的上限）。

设置方法（Claude Desktop）

在 Claude Desktop 配置文件（claude_desktop_config.json）中添加以下内容。

只读集成

{
  "mcpServers": {
    "gkill": {
      "command": "gkill_server",
      "args": ["mcp", "--kind", "read"],
      "env": {
        "GKILL_BASE_URL": "http://localhost:9999",
        "GKILL_USER": "您的用户ID",
        "GKILL_PASSWORD_SHA256": "密码的SHA256哈希值"
      }
    }
  }
}
提示： GKILL_PASSWORD_SHA256 是密码的 SHA256 哈希值。可以使用操作系统提供的工具生成。

设置方法（Claude Code）

claude mcp add gkill \
  --env GKILL_BASE_URL=http://localhost:9999 \
  --env GKILL_USER=您的用户ID \
  --env GKILL_PASSWORD_SHA256=哈希值 \
  -- gkill_server mcp --kind read
提示: 假定 gkill_server 已在 PATH 中（否则请写完整路径）。要更改类型时，把 --kind 改为 write 或 readwrite。

远程使用（HTTP 连接）

如果 AI 不在同一台电脑上，可以让 MCP 服务器自身通过 HTTP 监听，供互联网上的 AI 连接。此方式在连接时会进行 OAuth 授权，因此无需把 gkill 本体公开到互联网上。

授权按连接种类（只读、写入、读写）分别进行。以只读方式授权的连接不能直接用于写入。更换种类后，或者原本可用的连接开始因权限不足而失败时，请在 AI 侧断开该连接并重新授权。

# 以 HTTP 方式监听读写服务器的示例
MCP_PORT=8810 MCP_OAUTH_ISSUER=https://example.com \
GKILL_BASE_URL=http://localhost:9999 \
GKILL_USER=您的用户ID \
GKILL_PASSWORD_SHA256=哈希值 \
gkill_server mcp --kind readwrite --transport http
提示： 也可以把 gkill 服务器本身公开到互联网上使用。此时请将 GKILL_BASE_URL 设为公开地址，并在服务器设置中启用 TLS（HTTPS）。
