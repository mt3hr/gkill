AI 集成

通过将 Claude 等 AI 助手与 gkill 连接，您可以通过自然对话搜索、添加和编辑生活日志记录。

可以做的事情

操作示例
搜索记录"显示上周的午餐笔记" / "汇总本月支出"
添加记录"添加今天的备忘录" / "创建一个任务"
更新 / 删除记录"将此任务标记为已完成"
获取 GPS / 文件"显示今天的路线"
查看设置"列出我的模板"

集成类型

类型可以做什么要执行的文件工具数HTTP 时的端口
只读仅查看和搜索记录，不能添加或修改gkill-read-server.mjs98808
只写添加、更新和删除记录。同时也可以获取存储库名称、标签名和板名gkill-write-server.mjs248809
读写查看、添加、更新和删除记录gkill-readwrite-server.mjs298810

无论哪种类型，都包含 1 个用于获取插件列表的工具。插件导入的记录正文可以直接包含在搜索结果中接收。

文件的传递

向AI展示文件记录（图片、视频、文档）的方式会根据连接形式自动切换。

连接形式传递方式
本地连接（同一台电脑上的AI）文件的实际路径将传递给AI，AI可以直接读取文件。
远程连接（通过互联网的AI）将签发带有效期的专用URL，AI从该URL获取文件。图片会同时提供缩略图和原尺寸版本。无需公开gkill本体。
提示： 嵌入传输的大小上限（默认8MB）可通过环境变量 GKILL_MCP_MAX_FILE_BYTES 调整，URL的有效期（默认1小时）可通过 GKILL_MCP_FILE_LINK_TTL_MS 调整。

设置方法（Claude Desktop）

在 Claude Desktop 配置文件（claude_desktop_config.json）中添加以下内容。

只读集成

{
  "mcpServers": {
    "gkill": {
      "command": "node",
      "args": ["C:/path/to/gkill/src/mcp/gkill-read-server.mjs"],
      "env": {
        "GKILL_BASE_URL": "http://localhost:9999",
        "GKILL_USER": "您的用户ID",
        "GKILL_PASSWORD_SHA256": "密码的SHA256哈希值"
      }
    }
  }
}
提示： GKILL_PASSWORD_SHA256 是密码的 SHA256 哈希值。可以使用操作系统提供的工具生成。

设置方法（Claude Code）

claude mcp add gkill \
  --env GKILL_BASE_URL=http://localhost:9999 \
  --env GKILL_USER=您的用户ID \
  --env GKILL_PASSWORD_SHA256=哈希值 \
  -- node /path/to/gkill/src/mcp/gkill-read-server.mjs
提示: 请将上面的路径改为您放置 gkill 源代码的位置。要更改类型时，把文件名换成 gkill-write-server.mjs 或 gkill-readwrite-server.mjs。

远程使用（HTTP 连接）

如果 AI 不在同一台电脑上，可以让 MCP 服务器自身通过 HTTP 监听，供互联网上的 AI 连接。此方式在连接时会进行 OAuth 授权，因此无需把 gkill 本体公开到互联网上。

# 以 HTTP 方式监听读写服务器的示例
MCP_TRANSPORT=http MCP_PORT=8810 MCP_OAUTH_ISSUER=https://example.com \
GKILL_BASE_URL=http://localhost:9999 \
GKILL_USER=您的用户ID \
GKILL_PASSWORD_SHA256=哈希值 \
node /path/to/gkill/src/mcp/gkill-readwrite-server.mjs
提示： 也可以把 gkill 服务器本身公开到互联网上使用。此时请将 GKILL_BASE_URL 设为公开地址，并在服务器设置中启用 TLS（HTTPS）。
