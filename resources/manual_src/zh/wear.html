手表（Wear OS）

通过 Wear OS 手表（如 Pixel Watch），可以用记事本模板记录、结束进行中的打卡，以及记录心情。需要两个应用：手表上的「gkill wear」和手机上的「gkill wear 设置」。记录由手机中继发送到服务器，因此手机必须在身边并已与手表配对。

需要准备

  • 已与手机配对的 Wear OS 手表
  • 手机可以连接的 gkill 服务器（如果运行在家中的电脑上，请在服务器设置中允许来自其他设备的连接）
  • gkill 的用户 ID 和密码

手机端设置

  1. 在手机上安装并打开「gkill wear 设置」。
  2. 输入服务器 URL、用户 ID 和密码，然后点击「保存并测试连接」。
  3. 连接自签名 HTTPS 服务器时，请打开「允许自签名证书」。首次连接测试会显示证书指纹，确认是自己服务器的证书后点击「信任并保存」（如果不认识，请点击「拒绝」）。
  4. 显示「连接成功」即设置完成。手表端无需设置。
http:// 只能用于手机本机（localhost）。连接家庭网络或外部的服务器请使用 https://。

在手表上的用法

打开手表的磁贴或「gkill wear」应用，会看到三个入口。

入口 功能
📝 记录 选择记事本模板进行记录。模板是在设置页面「记事本模板」中编辑的内容（首次通过手机获取，之后显示缓存；「🔄 刷新」可重新获取）。
▶ 进行中 列出正在计时的打卡。选择一项后确认「要结束吗？」，即记录结束时间。
⭐️ 心情 用五颗星记录心情。点击星星的左半或右半可按 0.5 为单位选择（1～10），与网页版的心情记录值相同。

显示语言

手表和手机的界面语言跟随设备的语言设置，支持 7 种语言（日语、英语、中文、韩语、西班牙语、法语、德语）。更改手表语言后，磁贴会自动重新绘制。

连续发送相同内容时

如果刚刚发送过相同内容，会提示「刚刚已保存了相同的内容。仍要发送吗？」。这是为了防止通信重发导致重复登记。确实想再记录一次时，请选择「仍要发送」。

遇到问题时

提示 处理
无法连接到手机 请确认手表已与手机配对，并确认手机的蓝牙已开启。
手机响应超时 在手机上打开「gkill wear 设置」，用「保存并测试连接」确认连接。同时确认服务器是否在运行、URL 是否已更改。
✕ 错误：登录失败 在手机的设置应用中重新输入用户 ID 和密码。更改密码后需要在所有设备上重新登录。
记录了却不在列表中显示 从手表写入的记录，其创建来源保存为「gkill wear」。如果搜索条件限制了创建来源或记录位置，请检查条件。
