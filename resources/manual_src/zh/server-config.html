服务器设置

此画面用于配置服务器行为。仅管理员可以访问。

顶部按钮

点击账户管理按钮可打开账户管理画面。

底部按钮

应用: 保存设置。
取消: 放弃更改并关闭画面。

更改设置后需要重新启动服务器才能生效。

存储位置管理

存储位置（存储库）是gkill保存记录数据的目录或场所。可以根据用途（文本备忘录、文件、GPS日志等）和设备分别设置多个存储位置。

存储位置的配置通过账户管理画面的"存储分配按钮"对每个用户进行设置。

添加存储位置

  1. 打开账户管理画面，点击目标用户的"存储分配按钮"。
  2. 点击"添加"按钮添加新的存储位置。
  3. 配置以下项目：
    • 显示名称: 在生活日志视图和筛选器中显示的名称
    • 类型：保存的数据种类。下拉列表中排列着 kmemo、timeis 这样的英数字名称。各自代表什么请参阅下面的表格
    • 路径: 保存数据的目录路径（文件管理时也可使用glob格式）
    • 用作写入目标: 新增记录时是否保存到此存储位置
    • 启用: 是否将此存储位置作为搜索和显示对象
  4. 点击"保存"按钮使配置生效。

类型选择

类型下拉列表中排列的是英数字的名称。它们分别保存什么内容如下所示。

下拉列表的显示保存的内容
kmemo备忘录
timeis打卡（时间的记录）
mi任务
nlog支出
urlog书签
lantana心情
kc数值记录
directory上传的文件（图片、视频、文档等）
gpslogGPX格式的GPS日志
git_commit_logGit的提交历史（只读）
rekyou转发（再次展示过去的记录）
mirekyou转发任务（把已有的记录设为任务的东西）
tag给记录附加的标签
text给记录附加的补充文本
notification给记录附加的通知（提醒）
提示：tag / text / notification / rekyou / mirekyou 保存的不是记录本身，而是附加在记录上的信息。通常在初次设置时就已自动创建，无需事后添加。
提示: 可以添加同类型的多个存储位置。例如，按设备分别设置文本备忘录用存储位置，可以整理各设备的数据。
提示: 开启"用作写入目标"的存储位置将成为新记录的保存目标。同类型有多个存储位置时，只将需要写入的一个设为开启。
