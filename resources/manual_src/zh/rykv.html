生活日志视图

以缩略图方式浏览生活日志的界面。支持多种显示模式和筛选功能。

工具栏按钮

按钮 说明
☰ 侧边栏 打开/关闭侧边栏，用于筛选和导航。
📄 详细 显示/隐藏记录的详细面板。
📊 汇总视图统计 显示统计分析界面。
📅 日历 显示日历视图。
🗺 地图 在地图上显示带有GPS信息的记录。
⚙ 设置 打开应用程序设置界面。
❔ 帮助显示当前画面的帮助。

浮动操作按钮（+）

点击画面右下角的"+"按钮，展开菜单，快速创建以下记录：

类型说明
备忘录创建文本备忘录。
时间+备忘录创建带有时间戳的备忘录。
数值记录数值数据。
书签保存URL书签。
打卡簿开始时间跟踪会话。
任务创建新任务。
支出记录支出信息。
心情记录心情值（0-10）。
上传上传文件。
保存剪贴板将剪贴板内容（截图、图像、文本、PDF 等）直接保存为文件记录。
提示：长按"+"按钮可以直接打开记事本输入界面，方便快速批量输入。

主要功能

带图片缩略图的列表显示

以多列网格布局显示记录。包含图片或文件的记录会显示缩略图。列数可以在设置界面中更改为1～10列。

侧边栏（筛选·搜索）

可以在侧边栏中指定以下条件来缩小记录范围。

  • 文本搜索（关键词）
  • 按标签筛选
  • 指定期间
  • 选择记录类型
  • 选择记录存储位置

添加筛选列

可以通过"+"按钮添加新的筛选列。可以将不同筛选条件的结果并排比较。

详细面板

选中记录后，详细面板会显示该记录的全部信息。

汇总视图统计

显示记录数据的统计和分析结果。可以掌握记录的趋势和模式。

GPS地图显示

在地图上显示GPS日志数据。可以直观地确认移动轨迹和位置信息。需要设置Google Maps API密钥。

提示：图片列数可以在设置界面中更改。智能手机推荐1～2列，PC推荐3～5列。
提示：添加多个筛选列，将不同条件的记录并排比较会很方便。
提示：显示期间的默认值可以在设置界面的「生活日志视图显示天数」中更改。
快捷键： 在此画面按Enter键可打开记事本对话框，方便快速添加记录。
快捷键： 按 Ctrl+V 可将剪贴板内容直接保存为文件，便于快速保存截图或复制的图片。

使用标签

标签是用于分类和整理记录的标注。一条记录可以附加多个标签。

添加标签

  1. 在时间轴上长按记录（移动端）或右键点击（桌面端）。
  2. 从上下文菜单中选择"添加标签"。
  3. 输入标签名称并添加。已有的标签会作为输入候选显示。

编辑或删除标签

  1. 在时间轴上长按标签（移动端）或右键点击（桌面端）。
  2. 从上下文菜单中选择"编辑标签"或"删除标签"。

标签层级管理

在设置画面的"标签结构"中可以管理标签的显示名称和排列顺序。将常用标签置于顶部，便于在标签候选列表中找到它们。

提示： 在记事本语法中输入 #标签名，发送文本时会自动附加标签。详情请参阅记事本语法参考。

文件上传详情

通过"+"按钮菜单中的"上传"，可以将图片、视频、文档等文件保存到gkill。

操作步骤

  1. 从"+"按钮中选择"上传"。
  2. 选择上传目标的存储位置（文件管理用存储库）。
  3. 确认并调整相关日期（文件的记录日期）。
  4. 选择文件并上传。可以一次选择多个文件。也可以将文件拖放到对话框中显示"将文件拖放到此处"的区域来添加。

支持的文件格式

支持图片（JPEG、PNG、GIF、WEBP）、视频（MP4等）、PDF、ZIP及其他常见文件格式。ZIP文件上传后可以浏览其内容（右键点击记录→"打开ZIP内容"）。Markdown文件（.md / .markdown）在列表和详情视图中将以带有标题和表格的富文本形式显示，mermaid代码块将渲染为图表。

上传大小限制

每月上传大小上限由管理员在服务器设置中配置。达到上限时会显示错误消息（设置为 -1 时为无限制）。

快捷键： 按 Ctrl+V 可将剪贴板中的图片或文本直接保存为文件。便于快速记录截图。

GPS地图使用方法

开启工具栏的地图按钮后，记录时间段内的GPS移动轨迹将显示在地图上。

GPS日志的上传步骤

  1. 从"+"按钮中选择"上传"。
  2. 选择"GPS记录用"的存储位置（GPS日志用存储库）。
  3. 选择GPX文件并上传。也可以拖放到显示"将.gpx文件拖放到此处"的区域来添加。
  4. 上传后，开启地图按钮即可显示移动轨迹。

Google Maps API密钥的设置

地图显示需要Google Maps API密钥。请在设置画面（生活日志视图工具栏"设置"→"显示设置"）的"Google Maps API密钥"中输入API密钥并保存。

提示： Google Maps API密钥可在 Google Cloud Console 获取。需要启用了Maps JavaScript API的密钥。
