Storage Management

Storage (repositories) are the directories or locations where gkill saves your record data. You can configure multiple storage locations by purpose (text memos, files, GPS logs, etc.) or by device.

Storage configuration is done per user via the "Storage Assignment" button in Account Management.

Adding Storage

  1. Open Account Management and click the "Storage Assignment" button for the target user.
  2. Click "Add" to add a new storage location.
  3. Configure the following fields:
    • Display Name: The name shown in the Life Log View and filter panels
    • Type: The kind of data to store. The dropdown lists alphanumeric names such as kmemo or timeis. See the table below for what each one means
    • Path: The directory path where data is saved (glob patterns supported for file management type)
    • Use as Write Target: Whether new records of this type should be saved here
    • Enabled: Whether this storage is included in search and display
  4. Click "Save" to apply the configuration.

Storage Types

The type dropdown lists alphanumeric names. Here is what each one stores.

What the dropdown showsWhat gets stored
kmemoMemos
timeisTimestamps (time records)
miTasks

directoryUploaded files (images, videos, documents, ...)
gpslogGPS logs in GPX format
git_commit_logGit commit history (read-only)
rekyouReposts (past records shown again)
mirekyouRepost tasks (existing records made into tasks)
tagTags attached to records
textSupplementary texts attached to records
notificationNotifications (reminders) attached to records
Tip: tag / text / notification / rekyou / mirekyou store information attached to records rather than the records themselves. They are normally created for you during initial setup, so you do not need to add them later.
Tip: Multiple storage locations of the same type can be added. For example, you can separate text memo storage by device to keep each device's data organized.
Tip: Only one storage location per type should have "Use as Write Target" enabled. This determines where new records of that type are saved when multiple storage locations of the same type exist.
