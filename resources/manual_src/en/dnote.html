Aggregation View

A screen for aggregating and visualizing life log data based on conditions. You can define Items, Lists, Trend Graphs, and Correlation Graphs for comparing multiple metrics.

Tip: The Aggregation View is a toggle feature within the Life Log View screen. Click the aggregation icon in the Life Log View toolbar to display it.

Definition Management

Element Description
Tabs Each aggregation definition is displayed as a tab. Click a tab to switch between definitions.
Definition Name A text field where you can edit the name of the aggregation definition.
+ Button (next to tabs) Adds a new aggregation definition.
Delete Button Deletes the currently displayed aggregation definition.
Add / delete column buttons (edit screen) Add or remove the "columns" that stack items vertically. The button at the right end of the table adds a column, and the button above a column deletes that column together with its items. The last column cannot be deleted.

Screen Elements

Element Description
Date Range Displays the time period for aggregation.
Download Button Downloads the aggregation results in JSON format.
+ Button (floating) Displays a menu for adding an Item, List, Trend Graph, or Correlation Graph.

Items (Single Aggregate Value)

Displays aggregate values of data matching the conditions in the format: "Title: Prefix [Aggregate Result] Suffix".

Setting Type Description
Title Text Input Sets the display name of the item.
Prefix Text Input Text displayed before the aggregate value.
Suffix Text Input Text displayed after the aggregate value.
Aggregate Target Dropdown Selects the aggregation method (count, sum, average, max, min, etc.).
Predicate Group Condition Editor Filters the aggregation targets using AND/OR conditions.

Lists (Grouped Aggregation)

Displays aggregation results grouped by key in a list format.

Setting Type Description
Title / Prefix / Suffix Text Input Same settings as Items.
Aggregate Target Dropdown Selects the aggregation method.
Group Key Dropdown Choose what to group by (title, data type, tag, shop, mood, month, week, day of week, date, and so on). "Title" groups by memo bodies, the titles of numeric records, timestamps and tasks, expense items, bookmark titles and Git commit messages.
Predicate Group Condition Editor Filters the aggregation targets using AND/OR conditions.

Trend Graph (Time-Series Aggregation)

Aggregates matching data into fixed time periods and displays the trend as a line or bar chart. Hover over a point on the chart to see the aggregate value for each period.

Setting Type Description
Title Text input Sets the display name of the trend graph.
Aggregate Target Dropdown Selects the aggregation method (count, sum, average, max, min, etc.).
Granularity Dropdown Selects the time period unit: "Daily", "Weekly", or "Monthly".
Chart Type Dropdown Selects "Line" or "Bar".
Predicate Group Condition editor Narrows down the aggregation target with AND/OR conditions.

Correlation Graph

Aggregate 2 to 10 metrics by the same day, week, or month and display their relationships as a heatmap and scatter plot. Each metric has its own name, aggregate target, and conditions.

Select a cell to see the coefficient, number of paired periods, p-value, 95% confidence interval, and scatter plot. Pearson and Spearman are available.

With a positive time lag, the row metric is compared from an earlier period to the column metric from a later period. Periods missing either observation are excluded.

Selecting "Treat periods without records as 0" on a metric includes periods with no records for that metric as observations of 0. Use it to compare days when something happened against days when it did not, for events that do not occur every day such as purchases or stamps. It is available only for count and sum metrics, and periods before you started recording also become 0, so narrow the date range.

"Where to count stamps that span periods" lets you choose, per metric, whether a time entry that spans periods is split across them or counted whole in the period it started or ended. For stamps such as sleep that you want to compare with the metrics of the morning they ended, choose "Whole stamp in the period it ended".

Predicate Group Editing

Element Description
Logic Select AND / OR / NOT to set how conditions are combined.
Add Predicate Adds a new condition to the group.
Add Group Adds a nested predicate group.
Delete Group Deletes this predicate group.
Each Condition Sets the condition type and value (filter by data type, tag, title, amount, mood value, etc.).

Operations

Operation Description
Double-click While viewing, double-clicking an item or a list row opens the records used for the aggregation. On the edit screen, it opens the item's editing screen (the record list does not open).
Right-click Displays the context menu (Edit / Delete).
Drag & Drop Changes the display order of items, lists, and trend graphs.

Besides these, you can pick conditions that compare with the record you currently have selected: "Title equals target", "All tags equal target", "Some tags equal target", "Data type equals target" and "ID equals target". See "Conditions that compare with the selected record" in Related Information for details.

Bottom Action Buttons

Button Description
Apply Saves all definition changes.
Cancel Discards changes and closes the dialog.
Tip: Items are useful for single aggregate values (e.g. monthly total expenses), Lists for grouped aggregations (e.g. expenses by store), and Trend Graphs for tracking changes over time (e.g. weekly mood changes, monthly expense trends).
Tip: Combine conditions to create complex aggregation queries.
Tip: Use drag & drop to freely reorder the display of items and lists.
Tip: Aggregation results can be downloaded as JSON for analysis with external tools.
