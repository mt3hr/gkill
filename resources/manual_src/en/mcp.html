AI Integration

By connecting AI assistants such as Claude to gkill, you can search, add, and edit your life log records through natural conversation.

What You Can Do

ActionExample
Search records"Show me last week's lunch notes" / "Summarize this month's expenses"
Add records"Add a memo for today" / "Create a task"
Update / delete records"Mark this task as done"
Retrieve GPS / files"Show my route for today"
Check settings"List my templates"
Read your notesReads the descriptions you wrote on tags, storage locations, boards and templates in the settings screen first, and searches records the way you actually use them
Learn how to use itThe AI looks up the rules for search conditions and paging by itself through a built-in help feature. If it cannot find something, ask it to "check the gkill help"
Using skillsThe AI reads the procedures (skills) you registered in the settings screen and works as they say. You can also have the AI create or fix skills

Integration Types

TypeWhat it can doCommandToolsPort (HTTP)
Read-onlyView and search records only. Adding or modifying is not allowedgkill_server mcp --kind read148808
Write-onlyAdd, update and delete records. It can also read storage names, tag names and board namesgkill_server mcp --kind write338809
Read & WriteView, add, update and delete recordsgkill_server mcp --kind readwrite378810

The MCP server is part of gkill_server and starts with gkill_server mcp --kind <type> (gkill_server itself must be running). The connection and credentials come from environment variables or from the config file configs/gkill_mcp.json, which is generated on first start. Logs go to logs/gkill_mcp_<type>.log (per-level files share the prefix).

Every type includes one tool for listing the plugins in use. The contents of records imported by plugins can be received inline with the search results.

Skills

A skill is a procedure you leave for AI assistants (for example, how to build the weekly summary, or which tags to put on a kind of record). Skills are stored per user, and every AI assistant you connect uses the same skills. Before working, the AI checks the list of skills and reads the one that matches the task.

A skill is one folder with SKILL.md at its top. Start SKILL.md with the name and description in the form below, then write the steps. The folder can also hold reference documents, scripts and other files.

---
name: weekly-summary
description: Steps for building the weekly summary
---
# Steps
1. ...
OperationHow
Add or replaceIn "Skills" on the settings screen, upload the folder as a zip. Check which files will be added, deleted or changed, then press "Apply" to replace the whole skill with the same name.
View and take out"View" shows the contents of each file. "Download" saves the skill as a zip that you can edit locally and upload again as it is.
Delete"Delete" in "Skills" on the settings screen removes the whole skill.
Created or fixed by the AIWith an integration that can write, the AI can create skills and rewrite their files. The AI cannot delete skills.
Tip: Changes to skills take effect immediately and no history is kept. Before letting the AI change a skill, keep a copy with "Download" if you need one. Names use lowercase letters, digits and hyphens (up to 64 characters), and file names use only letters, digits and ._-. gkill never runs scripts.

File Delivery

How file records (images, videos, documents) are shown to the AI switches automatically depending on the connection type.

Connection TypeDelivery Method
Local connection (AI on the same PC)The file's actual path is passed to the AI, which can read the file directly.
Remote connection (AI over the internet)An expiring dedicated URL is issued, and the AI fetches the file from that URL. For images, both a thumbnail and the full-size version are provided. There is no need to expose gkill itself.
Tip: The size limit for embedded transfer (default 8MB) can be adjusted with the GKILL_MCP_MAX_FILE_BYTES environment variable, and the URL expiration (default 1 hour) with GKILL_MCP_FILE_LINK_TTL_MS.

Setup (Claude Desktop)

Add the following to the Claude Desktop configuration file (claude_desktop_config.json).

Read-only integration

{
  "mcpServers": {
    "gkill": {
      "command": "gkill_server",
      "args": ["mcp", "--kind", "read"],
      "env": {
        "GKILL_BASE_URL": "http://localhost:9999",
        "GKILL_USER": "your-user-id",
        "GKILL_PASSWORD_SHA256": "sha256-hash-of-your-password"
      }
    }
  }
}
Tip: GKILL_PASSWORD_SHA256 is the SHA256 hash of your password. You can generate it using tools available on your operating system or online SHA256 calculators.

Setup (Claude Code)

Run the following command in your terminal.

# Add read-only integration
claude mcp add gkill \
  --env GKILL_BASE_URL=http://localhost:9999 \
  --env GKILL_USER=your-user-id \
  --env GKILL_PASSWORD_SHA256=your-hash \
  -- gkill_server mcp --kind read
Tip: gkill_server is assumed to be on your PATH (write the full path otherwise). To change the type, set --kind to write or readwrite.

Using it Remotely (HTTP Connection)

If the AI is not on the same PC, you can have the MCP server itself listen over HTTP so an AI on the internet can connect. This mode authorises the connection with OAuth, so you do not need to expose gkill itself to the internet.

Authorisation is granted per connection type (read-only, write, or read-write). A connection authorised as read-only cannot be used for writing. If you switch types, or a connection that used to work starts failing for lack of permission, disconnect it on the AI side and authorise it again.

# Example: serve read & write over HTTP
MCP_PORT=8810 MCP_OAUTH_ISSUER=https://example.com \
GKILL_BASE_URL=http://localhost:9999 \
GKILL_USER=your-user-id \
GKILL_PASSWORD_SHA256=your-hash \
gkill_server mcp --kind readwrite --transport http
Tip: You can also publish the gkill server itself to the internet. In that case set GKILL_BASE_URL to its public address and enable TLS (HTTPS) from Server Settings.
