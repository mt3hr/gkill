Record View

The Record view displays individual record details. A record is the core entity in gkill, representing any recorded life event. Each record has a type, timestamp, tags, and type-specific data.

Record Details

Each record view shows:

  • Timestamp: When the event occurred.
  • Tags: Associated tags displayed as chips. Tags help with filtering and organization.
  • Related Timestamps: Any linked time tracking sessions (Time Log) associated with this record.
  • Storage Name: The data storage where this record is stored.
  • Type-specific content: The main data of the record (text, URL, amount, etc.).

Context Menu

Right-click (or long-press on mobile) on a record to access the context menu. The available items vary slightly depending on the record type.

  • Add tag from history: Pick from recently used tags and attach one right away.
  • Add Tag / Edit Tag: Attach a new tag or edit existing tags on the record.
  • Add Text / Edit Text: Attach a supplementary text note or edit existing text.
  • Repost: Push this record back onto the timeline at the current time.
  • Make Task: Turn this record into a task without rewriting its content.
  • Add Notification / Edit Notification: Set a reminder notification for this record, or edit an existing one.
  • Edit: Open the record for editing.
  • History: View the change history of tags, texts and notifications.
  • Copy content: Copy the body of the record to the clipboard.
  • Copy ID: Copy the record ID to the clipboard.
  • Plugin Settings: Shown only for records imported by a plugin; opens that plugin's settings screen.
  • Browse ZIP contents: Shown only for ZIP file records; opens the contents on screen.
  • Open Folder / Open File: Shown only when gkill runs on the same device; opens the file with your OS default app.
  • Delete: Remove the record. The tags, texts and notifications attached to it, together with the reposts and repost tasks that refer to it, are deleted as well.
Tip: Tags are a powerful way to organize your records across types. You can filter by tags in the Life Log View and Tasks views to find related records quickly.
Tip: Records imported by a plugin are read-only. "Edit" and "Delete" are not shown, but you can still add tags and texts or use "Make Task".
