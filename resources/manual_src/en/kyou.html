Record View

This screen shows the details of an individual record. You can check the detailed information of each record type.

Toolbar

ButtonDescription
⚙ SettingsOpens the application settings screen.

Record Types Shown

Record typeDescription
MemoShows the content of a text memo.
BookmarkShows the saved URL and title.
TaskShows the task's status, due date and board.
MoodShows a mood value from 0 to 10.
ExpenseShows the amount and what the money was spent on.
Time EntryShows the start and end times and the elapsed time.
FileShows a preview of the uploaded file. Text files (.txt) display their content directly on the screen. Markdown files (.md / .markdown) are shown as rich text with headings, tables, code blocks, images and so on, and diagrams written in Mermaid notation are also drawn as graphics. If a link in the content is a relative path pointing to a file in the same storage, double-clicking it opens that record's dialog.
NumericShows the title and the numeric data.
RepostShows a record that reposts another record at a different date and time.
Repost TaskAn existing record made usable as a task. The original record's content is shown as-is, with a due date and a completion checkbox.
Plugin recordShows a record imported by a plugin from a service other than gkill. See Plugins for details.
GPS LogShows GPS location log data.
Git Commit LogShows commit information from a Git repository.
NotificationA record that sends a reminder notification at a specified date and time.

Information Shown for Every Record

The following information is shown for every record type.

  • Tags: The list of tags attached to the record.
  • Related time: Date and time information related to the record.
  • Storage name: The name of the storage where the data is saved.

Context Menu

Right-click (or long-press) a record to open the context menu, where you can do the following. The items shown vary slightly depending on the record type.

  • Add tag from history: Pick from recently used tags and attach one right away.
  • Add Tag / Edit Tag: Add or edit tags.
  • Add Text / Edit Text: Add or edit a supplementary text.
  • Repost: Push this record back onto the timeline at the current time.
  • Make Task: Turn this record into a task as it is, without rewriting its content.
  • Add Notification / Edit Notification: Add or edit a reminder notification.
  • Edit: Edit the content of the record.
  • History: View the change history of tags, texts and notifications.
  • Copy content: Copy the body of the record to the clipboard.
  • Copy ID: Copy the record ID to the clipboard.
  • Browse ZIP contents: Shown only for ZIP file records; opens the contents on screen.
  • Open Folder / Open File: Shown only when gkill is open on the same device; opens the record's file with your OS default app.
  • Delete: Delete the record. The tags, texts and notifications attached to it, together with the reposts and repost tasks that refer to it, are deleted as well. If the deletion fails partway, nothing is deleted.
Tip: You can add and edit tags directly from the record details screen.
Tip: Records imported by a plugin are read-only. "Edit" and "Delete" are not shown, but you can still add tags and texts or use "Make Task".
