Task Board

A screen for managing tasks as a Kanban board. Tasks are sorted into boards so you can see progress at a glance.

Toolbar

Button Description
☰ Sidebar Shows or hides the sidebar used for searching and filtering.
📄 Detail view Shows or hides the detail panel for the selected record.
📅 Calendar Shows or hides the calendar view.
⚙ Settings Opens the application settings screen.
❔ Help Displays help for the current screen.

Main Features

Kanban board

Tasks are shown sorted into boards (columns). Each board stands for a state or a category of task and helps you keep track of progress.

Sidebar (filters)

The sidebar lets you narrow down the tasks with the following conditions.

  • Text search
  • Filter by tag
  • Date range
  • Board selection

Detail panel

When you select a task, the detail panel shows the following information.

  • Task title and content
  • The board it belongs to
  • Due date
  • Attached tags
  • Related records
Tip: The board shown by default can be changed with "Default Task Board Name" in the settings screen.

Turning an existing record into a task

A record you want to deal with later can become a task without rewriting its content. In the Life Log View or elsewhere, long-press (mobile) or right-click (desktop) the record and choose "Make Task". Set the board name, due date and the planned start and end, then save: it appears on the board of this screen and can be checked off just like any other task.

Tasks made this way have no title field, because the original record's content is shown as-is.

Note: If you delete the original record, the task made from it has nothing left to display.
Tip: Combining the sidebar filters lets you find the tasks you need quickly.

Floating Action Button (+)

Tapping the "+" button at the bottom right of the screen opens the menu for adding records.

Menu item Description
Memo Pad Enters a text memo in memo pad form.
Time Tracking + Memo Opens the hybrid screen with memo entry and the list of timestamps.
Numeric Record Records numeric data.
Bookmark Saves a URL.
Time Log Starts a new timestamp session.
Task Adds a new task.
Expense Records an amount.
Mood Records a mood value (0-10).
Upload Uploads and records a file.
Save Clipboard Saves the clipboard contents (image, text, PDF and so on) directly as a file. Handy for quickly recording screenshots or copied images.
Long-press: Long-pressing the "+" button opens the Memo Pad directly. Handy when you want to take a note quickly.
Shortcut: Press Enter on this screen to open the Memo Pad dialog. Convenient when you want to add a record quickly.
Shortcut: Press Ctrl+V to save the clipboard contents directly as a file. Useful for quickly recording screenshots or images.
