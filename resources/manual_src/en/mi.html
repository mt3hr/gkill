Task Board

A screen for managing tasks as a Kanban board. Tasks are sorted into boards so you can see progress at a glance.

Toolbar

Button Description
☰ Sidebar Shows or hides the sidebar used for searching and filtering.
📄 Detail view Shows or hides the detail panel for the selected record.
📅 Calendar Shows or hides the calendar view. Click the year and month at the top of the calendar to pick a date. Picking a date works like clicking that day's cell: the list moves to that day.
⚙ Settings Opens the application settings screen.
❔ Help Displays help for the current screen.

Main Features

Kanban board

Tasks are shown sorted into boards (columns). Each board stands for a state or a category of task and helps you keep track of progress.

Boards are not only picked from the list: you can also create one on the spot by typing a new name. If you try to save with a board name you have never used before, a confirmation appears so that typos do not slip through. Once you confirm and save, that board joins the list of boards.

Sidebar (filters)

The sidebar lets you narrow down the tasks with the following conditions.

  • Text search
  • Completion state (Unchecked, Checked, All)
  • Sort order (Created At, Due Date/Time, Start Date/Time, End Date/Time, and so on)
  • Filter by tag
  • Period (choose the date range in the calendar and, if needed, also set a start time and an end time. Press the "×" inside a time field to empty it. To remove the period itself, press "Clear")
  • Board selection

Detail panel

When you select a task, the detail panel shows the following information.

  • Task title and content
  • The board it belongs to
  • Due date
  • Attached tags
  • Related records

Turning an existing record into a task

A record you want to deal with later can become a task without rewriting its content. In the Life Log View or elsewhere, long-press (mobile) or right-click (desktop) the record and choose "Make Task". Set the board name, due date and the planned start and end, then save: it appears on the board of this screen and can be checked off just like any other task.

Tasks made this way have no title field, because the original record's content is shown as-is.

Note: If you delete the original record, the task made from it is deleted along with it. There is no way to keep only the task.
Tip: The board shown by default can be changed with "Default Task Board Name" in the settings screen.
Tip: Combining the sidebar filters lets you find the tasks you need quickly.

Recalling Saved Search Conditions

Task search conditions you saved under a name in "Search Conditions" on the settings screen can be recalled from the round button at the bottom right of the sidebar. Choosing a name applies that condition to the sidebar as it is. When nothing has been saved, the button itself is not shown.

Sharing the Current Search Criteria

Turn on "Show Share Footer" in the settings screen and a share footer appears at the bottom of the sidebar. Pressing the "Share" button at its left end asks how you want to hand the records over. Choosing "Share this view" turns the search criteria you are currently using into a share link. What gets shared is not a single record, but every record matching those criteria. Links you have already created can be listed, edited and deleted from "Share Management" at the right end.

Handing Over the Current Boards as an HTML File

A share link only works while this app is running. When you want to hand something over without the recipient setting anything up, you can write the boards you are currently viewing out to an HTML file. The recipient just opens it in a browser, and because everything is contained in the file, it never communicates with this app.

How to Export

  1. In the share footer at the bottom of the sidebar, press the "Share" button on the left (if you cannot see the share footer, turn on "Show Share Footer" in the settings screen).
  2. Choose "Export HTML".
  3. Choose what to include and which format to write out (see the table below).
  4. Press "Export" and the resulting file is downloaded. It takes a while when there are many tasks or images.

Available Options

Item Description
Title Enter an optional heading to display at the top left of the exported screen.
Target Choose between "All boards shown" and "Focused board".
What to include Choose whether to include tags, texts, notifications, time records, location history, and plugin contents.
Screens Choose whether to keep the Search sidebar inside the exported file. A kept sidebar only narrows down the tasks that were exported.
Media Choose images and videos from "Thumbnails only", "Include originals", or "Do not embed". You can also set the limit per file and the total limit.
Output format "A single HTML file" is self-contained. "HTML and a folder of the same name" puts images and other media in a folder next to it, so it is lighter than a single file, but you must hand over both together (when "Do not embed" is selected, only "A single HTML file" can be chosen).
When a limit is exceeded: Anything that did not fit within the media limit is shown as "Not included" inside the exported file. Since the omission is visible, you can raise the limit and export again if needed.

What the Recipient Sees

The exported file is read-only. Tasks cannot be added, edited, checked off, or moved between boards. Double-clicking a task opens its details, from which related records can also be followed. If you kept the search condition sidebar, you can narrow by tag, check state, board and period, but text search and changing the sort order are not available (the order is fixed as it was at export time).
