Port

A single screen where every operation opens as a window.

Port shows only a background and a "+" button. From "+" you can open Life Log View, Tasks, In Progress and Dashboard as windows and use them side by side without switching screens. Drag a window to move it, or grab its bottom-right corner to resize it. The position and size are kept the next time you open it.

To add a record, use the "Records" group of "+". It lists Notepad, Time Entry Notepad, Numeric Records, Bookmarks, Time Tracker, Tasks, Expenses, Mood, Upload and Save Clipboard.

Which one to use: Use Home Hub when you only want to add records, and Port when you want to work while moving between several screens. In Port, you can also click the title to move to other screens.

Toolbar buttons

Button Description
Help Shows help for the current screen.
Settings Opens the settings screen.

The "+" button

Pressing the "+" button at the bottom right opens a menu split into two groups.

Group Description
Screens Opens Life Log View / Tasks / In Progress / Dashboard as a window. You can open several windows of the same screen side by side, up to a limit; once the limit is reached, the frontmost one is simply brought forward.
Records Opens a window for adding that kind of record.

Closing a window

Close with the "×" at the top right of the window, the Escape key, or the browser Back button. The frontmost window is the one that closes.
