Memo Pad

A screen for recording your life log with memo pad syntax. You can enter several kinds of record at once, all as text.

Toolbar

Button Description
⚙ Settings Opens the application settings screen.
❔ Help Displays help for the current screen.

Screen Elements

Element Description
Text input area The main text area where you enter data with memo pad syntax. You can write records freely across several lines.
Template button Inserts a frequently used memo pad template into the text area. You choose from the templates defined in the settings.
Save button Sends what you typed to the server and creates the records.
Tabs Lets you keep several drafts at once. Each tab holds its own text.
Add tab button Adds a new empty tab.
Close tab button Closes that tab. You are asked first if it still has text.

Working with tabs

You can keep several drafts side by side. If you remember something else while writing one record, press the add tab button, write it in a new tab, and come back to the original tab later.

Action Result
Press the add tab button An empty tab is added.
Click a tab name The editor switches to that tab.
Press the close tab button That tab is closed. You are asked first if it still has text.
Press the save button Only that tab is saved, and the saved tab is closed. The other tabs stay as they are.
Choose a template A new tab opens with the template in it. Your unfinished text is not lost.

A tab is named after the template when it was opened from one, otherwise after the first line of its text. Tabs with nothing written yet are numbered.

Tip: Unfinished text is kept when you close the screen. The tabs you had open come back the next time you open it.

Memo Pad Syntax Overview

Memo pad syntax is a text format structured line by line. A single text entry can create all of the following records at once.

  • Memo: records a text memo
  • Timestamp: starts and stops time tracking
  • Task: adds and updates tasks
  • Bookmark: saves a URL
  • Numeric record: records numeric data
  • Expense: records an amount
  • Mood: records a mood (0-10)
  • Tagging: attaches tags to records

Steps

  1. Enter the content of your records in the text input area using memo pad syntax.
  2. Insert a predefined text with the template button if you need one. The template opens in a new tab, so your unfinished text is not lost.
  3. Click the save button to create the records.
  4. If the text contains a tag you have never used before, you are asked "This is a new tag. Do you want to add it?". If the tag is what you meant, carry on.
  5. Once saved successfully, that tab is closed. The other tabs keep their text. When no tab is left, an empty one is prepared for you.
Tip: The new-tag confirmation exists to stop near-duplicate tags piling up because of typos. If the tag name shown is not what you meant, go back and correct it.
Tip: Templates make entry much faster. It helps to set up your frequent recording patterns as templates.
Tip: You do not have to memorise memo pad syntax; with templates you can start recording straight away.
Tip: On other screens, choosing "Memo Pad" from the + menu opens another memo pad window each time. Each window can show a different tab, and when two windows show the same tab, what you type in one appears in the other.
