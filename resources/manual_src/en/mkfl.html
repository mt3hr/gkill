Time Tracking + Memo

This is a hybrid screen that shows memo input and your ongoing time entries at the same time. You can manage memo recording and time tracking efficiently on a single screen.

Toolbar

ButtonDescription
⚙ SettingsOpens the application settings screen.
❔ HelpShows help for the current screen.

Screen Layout

AreaDescription
Top half: Memo Pad input areaThe same text input area as the Memo Pad screen. You enter data in Memo Pad syntax, and you can insert templates and save. As on the Memo Pad screen, tabs let you keep several drafts at once.
Bottom half: Ongoing time entriesShows the list of currently active time tracking sessions. You can also stop each session from here.

Main Features

  • Auto-refresh: When you save a record from the Memo Pad input, the time entry list in the bottom half is refreshed automatically. A newly started time entry appears in the list right away.
  • Work on both at once: You can check and stop ongoing time entries while writing memos.
  • Memo Pad integration: When you write the start or stop of a time entry in Memo Pad syntax, it is reflected in the list below in real time.

How to Use

  1. Enter records in Memo Pad syntax in the text area in the top half.
  2. Send the records with the Save button.
  3. If you wrote the start of a time entry, a new session appears in the list in the bottom half.
  4. You can stop ongoing sessions from the list in the bottom half.
Tip: For everyday recording, this screen is the most efficient. You can manage your working time while writing memos.
Tip: The Memo Pad input in the top half has the same features as the Memo Pad screen. Templates are available too.
