Account Management

This screen manages user accounts. Only administrators can access it.

Top Button

Press the Add Account button to create a new account.

Account List

Registered accounts are displayed in a list. Each account row contains the following items:

ItemDescription
Enable/Disable checkboxToggle the account between enabled and disabled
User IDDisplays the account's user ID
Storage Allocation buttonAssign data repositories to the user
Password Reset buttonGenerate a password reset link

Bottom Button

Close: Close the account management screen.

Tip: The admin account is automatically created when the server first starts. Accounts added from the Account Management screen are regular users (without admin privileges). Accounts are managed by enabling/disabling rather than deleting.

Password Reset Procedure

If a user forgets their password, an admin can issue a password reset link using the following steps.

Admin Steps

  1. Open the Server Config screen and click "Account Management".
  2. Click the "Password Reset" button in the target user's row.
  3. Click "OK" in the confirmation dialog — a reset link is generated.
  4. Copy the displayed link and share it with the user (via message, email, etc.).

User Steps

  1. Open the reset link received from the admin in a browser.
  2. Enter a new password and confirm it by entering it again.
  3. Click "Set" to apply the new password.
  4. You will be redirected to the login screen — log in with your new password.
Tip: The reset link is single-use and becomes invalid after use. If the link has expired, ask the admin to generate a new one.

Storage Assignment

Assign storage locations (repositories) where each user's data will be saved. Click "Storage Assignment" to open the storage configuration dialog for that user. See Server Config → "Storage Management" for details.
