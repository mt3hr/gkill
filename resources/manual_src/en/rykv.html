Life Log View

A screen that lists your whole life log with image thumbnails. You can use several filter columns to look at your data under different conditions at the same time.

Toolbar

Button Description
☰ Sidebar Shows or hides the sidebar used for searching and filtering.
📄 Detail view Shows or hides the detail panel for the selected record.
📊 Aggregation View Shows or hides the statistics and analysis view.
📅 Calendar Shows or hides the calendar view.
🗺 Map Shows or hides the map view for GPS logs.
⚙ Settings Opens the application settings screen.
❔ Help Displays help for the current screen.

Main Features

List with image thumbnails

Records are shown in a multi-column grid layout. Records containing images or files show a thumbnail. The number of columns can be set from 1 to 10 in the settings screen.

Sidebar (filter and search)

The sidebar lets you narrow down records with the following conditions.

  • Text search (keyword)
  • Filter by tag
  • Date range
  • Record type selection
  • Storage selection

Adding filter columns

The "+" button adds a new filter column. You can place the results of different filter conditions side by side and compare them.

Detail panel

When you select a record, the detail panel shows all of its information.

Aggregation View statistics

Shows statistics and analysis of your record data, so you can see trends and patterns.

GPS map display

Shows GPS log data on a map. You can see your routes and locations visually. A Google Maps API key must be configured.

Tip: The number of image columns can be changed in the settings screen. 1-2 columns work well on a phone, 3-5 on a PC.
Tip: Adding several filter columns is handy for comparing records under different conditions side by side.
Tip: The default display period can be changed with "Life Log View Display Days" in the settings screen.

Using Tags

Tags are labels for sorting and organising records. A single record can carry several tags.

Adding a tag

  1. Long-press (mobile) or right-click (desktop) a record in the timeline.
  2. Choose "Add Tag" from the context menu.
  3. Type the tag name and add it. Existing tags appear as suggestions.

To attach a tag you used recently, use "Add tag from history" in the context menu: you just pick it from the list.

If you type a tag name you have never used before, you are asked "This is a new tag. Do you want to add it?" before saving. This check stops near-duplicate tags piling up because of typos.

Editing or deleting a tag

  1. Long-press (mobile) or right-click (desktop) the tag shown on a record.
  2. Choose "Edit Tag" or "Delete Tag" from the context menu.

Tag structure

"Tag Structure" in the settings screen lets you manage the display names and order of tags. Putting frequently used tags near the top makes them easier to find in the suggestion list.

Tip: Typing #tagname in memo pad syntax attaches the tag automatically when the text is submitted. See the Memo Pad Syntax Reference for details.

File Upload Details

"Upload" in the "+" button menu saves files such as images, videos and documents to gkill.

Steps

  1. Choose "Upload" from the "+" button.
  2. Choose the target storage (one meant for files).
  3. Check and adjust the related date and time (when the file was recorded).
  4. Select the files and upload them. Several files can be selected at once. You can also drag and drop files onto the "Drop files here" area in the dialog.

Supported file types

Images (JPEG, PNG, GIF, WEBP), videos (MP4 and so on), PDF, ZIP and most other common file formats are supported. Markdown files (.md / .markdown) are shown as rich text with headings and tables in the list and detail views, and mermaid code blocks are rendered as diagrams.

Upload size limit

The monthly upload size limit is set by the administrator under "Monthly Upload Size Limit" in the server settings. The initial value is -1 (unlimited).

Shortcut: Press Ctrl+V to save an image or text from the clipboard directly as a file. Ideal for quickly recording screenshots.

Looking Inside a ZIP File

You can open the contents of an uploaded ZIP file right on screen, without extracting it to your computer. Files with the extension .cbz are treated as ZIP files too.

How to open it

  1. Long-press (mobile) or right-click (desktop) the record of the ZIP file.
  2. Choose "Browse ZIP contents" from the context menu.
  3. The folders and files inside the ZIP are shown as a list.

Moving around inside

  • Clicking a folder takes you into it. To go back up a level, use the breadcrumb trail at the top of the screen or "..".
  • Clicking an image file opens a preview, and you can page straight on to the next image.
  • Individual files can also be downloaded.
  • Files that are too large cannot be previewed, and a message says so.
Tip: "Browse ZIP contents" only appears in the menu when you select the record of a ZIP file. It is not shown for other records.

Making a Record a Task and Copying Its Content

A record you want to deal with later can become a task without rewriting its content. Choose "Make Task" in the record's context menu, set the board name, due date and the planned start and end, then save. The task you create also appears on the Task Board and can be checked off.

Choosing "Copy content" in the context menu copies the body of the record to the clipboard. "Copy ID" copies the record's ID.

Using the GPS Map

Turning on the map button in the toolbar shows the GPS route for the period of the records on a map.

Uploading GPS logs

  1. Choose "Upload" from the "+" button.
  2. Choose a storage meant for GPS logs as the destination.
  3. Select and upload your GPX file. You can also drag and drop it onto the "Drop GPX files here" area.
  4. After uploading, turn on the map button to see the route.

Setting the Google Maps API key

A Google Maps API key is required for the map. Enter your key under "Google Maps API Key" in the settings screen (toolbar "Settings" → "Display Settings") and save.

Tip: You can obtain a Google Maps API key from Google Cloud Console. The key needs the Maps JavaScript API enabled.

Sharing the Current Search Criteria

Turn on "Show Share Footer" in the settings screen and a share footer appears at the bottom of the sidebar. Pressing the "Share" button at its left end turns the search criteria you are currently using into a share link. What gets shared is not a single record, but every record matching those criteria. Links you have already created can be listed, edited and deleted from "Share Management" at the right end.
