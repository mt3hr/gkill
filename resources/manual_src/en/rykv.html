Life Log View

The Life Log View is the primary life-log browsing screen. It displays all your recorded events as a timeline of image thumbnails and text entries, allowing you to review and explore your history.

Thumbnail Grid

Records are displayed as a multi-column grid of thumbnails and text previews. You can configure the number of columns from 1 to 10 in the application settings.

ColumnsBest For
1-2Detailed reading on mobile devices. Shows more text per entry.
3-5Balanced view on tablets and small desktops.
6-10Overview browsing on large screens. Shows many records at once.

Filter Sidebar

The sidebar provides powerful filtering options:

  • Date range: Set start and end dates to narrow the time period.
  • Record type: Show only specific types (memos, bookmarks, files, etc.).
  • Tags: Filter by one or more tags.
  • Storage: Filter by data storage.
  • Text search: Search within record content.

Detail Panel

When enabled, selecting a record opens the detail panel showing its full content, tags, related timestamps, and edit controls. This is the same information shown in the Record view.

Summary View Analytics

The Summary View statistics panel shows charts and aggregate data about your records, including:

  • Record count trends over time
  • Type distribution breakdowns
  • Tag usage frequency
  • Activity patterns

GPS Map View

If GPS data is available (from GPX logs or geotagged files), records are plotted on an interactive map. This requires a Google Maps API key configured in Settings.

Tip: The "Life Log View Display Days" can be configured in Settings. Set a shorter period for faster loading, or a longer period for broader browsing.
Tip: Adjust the number of image columns in Settings to match your screen size and browsing style. Fewer columns show more detail; more columns provide a broader overview.

Using Tags

Tags are labels you can attach to records to categorize and organize them. Multiple tags can be attached to a single record.

Adding a Tag

  1. Long-press (mobile) or right-click (desktop) a record in the timeline.
  2. Select "Add Tag" from the context menu.
  3. Type the tag name and confirm. Existing tags will appear as suggestions.

Editing or Deleting a Tag

  1. Long-press (mobile) or right-click (desktop) the tag displayed on a record.
  2. Select "Edit Tag" or "Delete Tag" from the context menu.

Tag Structure

In Settings → "Tag Structure", you can manage display names and ordering of tags. Placing frequently used tags higher makes them easier to find in the autocomplete list.

Tip: In Notepad syntax, entering #tagname automatically attaches a tag when the text is submitted. See the Notepad Syntax Reference for details.

File Upload Details

From the "+" FAB menu, select "Upload" to save images, videos, documents, and other files to gkill.

Steps

  1. Select "Upload" from the "+" FAB menu.
  2. Choose the target storage (a file management repository).
  3. Confirm or adjust the record date/time associated with the file.
  4. Select the file(s) to upload. Multiple files can be selected at once. You can also drag & drop files onto the "Drop files here" zone in the dialog.

Supported File Types

Images (JPEG, PNG, GIF, WEBP), videos (MP4, etc.), PDFs, ZIPs, and most common file formats are supported. ZIP files can be browsed after upload (right-click the record → "Browse ZIP Contents"). Markdown files (.md / .markdown) are rendered as rich text with headings and tables in list and detail views, and mermaid code blocks are rendered as diagrams.

Upload Size Limit

The monthly upload size limit is configured by the administrator in Server Config. If the limit is reached, an error message will appear. (A value of -1 means unlimited.)

Shortcut: Press Ctrl+V to save clipboard content (image, text, PDF, etc.) directly as a file. Ideal for quickly saving screenshots.

Using the GPS Map

Enable the Map button in the toolbar to display GPS tracks on an interactive map for the currently selected time period.

Uploading GPS Logs

  1. Select "Upload" from the "+" FAB menu.
  2. Choose a GPS log storage as the destination.
  3. Select and upload your GPX file. You can also drag & drop it onto the "Drop .gpx files here" zone.
  4. Enable the Map button to view the track on the map.

Google Maps API Key

A Google Maps API key is required for map display. Go to Settings (toolbar "Settings" → "Display Settings") and enter your key in the "Google Maps API Key" field.

Tip: You can obtain a Google Maps API key from Google Cloud Console. Enable the Maps JavaScript API for your key.
