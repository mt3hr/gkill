Home Hub

A screen for safely recording even from the lock screen. It serves as a quick-add hub where you can rapidly create any type of record.

Saihate is a lightweight hub specialized for adding new records. It omits browsing and editing functions, so there is no risk of accidentally modifying existing records. It operates within an authenticated session, meaning it is only accessible while logged in.

When to use which screen: Use Saihate when you want to quickly jot down a memo or time entry, Life Log View when you want to browse or search your records, and Notepad when you want to batch-enter records via text input.

Navigation

The Home Hub provides navigation links to all main screens:

  • Memo Pad — Open the Memo Pad.
  • Tasks — Open the task board.
  • Life Log View — Open the life-log browser.
  • In Progress — View active time sessions.
  • Time Tracking + Memo — Open the combined memo + time tracking view.

FAB "+" Quick-Add Menu

The floating action button (FAB) with a "+" icon at the bottom-right opens a quick-add menu for creating new records:

Record TypeDescription
MemoCreate a new text memo. Opens the memo creation dialog.
Time + MemoStart a new time tracking session and simultaneously attach a memo to it.
NumericRecord a numeric counter value (e.g., counting events or items).
BookmarkSave a URL with an optional title and notes.
Time LogStart a new time tracking session.
TaskCreate a new task and assign it to a board.
ExpenseLog a financial expense with amount and description.
MoodRecord your current mood on a scale of 0 to 10.
UploadUpload a file or image from your device.
Tip: Long-press the "+" FAB button to directly open the Memo Pad for fast batch entry, skipping the quick-add menu entirely.
Tip: Home Hub is the default landing page after login. If you prefer a different screen, you can change the "Default View on Startup" in Settings.
Shortcut: Press Enter on this screen to open the Memo Pad dialog. This is convenient for quickly adding records.
