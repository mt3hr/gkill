Home Hub

A screen for safely adding records even from the lock screen. It works as a hub for quickly creating any type of record.

The Home Hub has no browsing or editing features; it is dedicated to adding. There is no risk of changing an existing record by mistake. It runs inside an authenticated session, so it is only available while you are logged in.

Which screen to use: Use the Home Hub when you want to jot down a memo or a timestamp quickly, the Life Log View when you want to look back through or search your records, and the Memo Pad when you want to enter several records at once as text.

Toolbar

Button Description
🔄 Reload Reloads the data. Long-press: performs a forced reload.
Logout Logs you out.
❔ Help Displays help for the current screen.

Floating Action Button (+)

Tapping the "+" button at the bottom right of the screen opens the menu for adding records.

Menu item What it adds Description
Memo Pad Text entry Opens the screen for entering memos and other records with memo pad syntax.
Time Tracking + Memo Text and timestamps Opens the screen that manages memo entry and running timestamps side by side.
Numeric Record Record a number Records any numeric data.
Bookmark Record a URL Saves the URL of a web page as a bookmark.
Time Log Start timing Starts a new timestamp session.
Task Add a task Creates a new task.
Expense Record an amount Records the amount and details of an expense.
Mood Record a mood (0-10) Records how you feel right now as a number from 0 to 10.
Upload Upload a file Uploads and records files such as images or documents.
Long-press: Long-pressing the "+" button opens the Memo Pad directly. Handy when you want to take a note quickly.
Tip: The screen shown first after login can be changed with "Default View on Startup" in the settings screen.
Shortcut: Press Enter on this screen to open the Memo Pad dialog. Convenient when you want to add a record quickly.
