Login Screen

The authentication screen for signing in to gkill. Enter your user ID and password to access the application.

Screen Elements

Element Description
User ID field Enter the user ID of your gkill account. It is case-sensitive.
Password field Enter the password for the account.
Login button Signs you in with the credentials you entered.
Version display The current gkill version number is shown on the screen.

Steps

  1. Enter the user ID of your account in the user ID field.
  2. Enter your password in the password field.
  3. Click the "Login" button or press Enter to sign in.
  4. On success you are taken to the default screen set in the settings.
Tip: On the very first run, the account registration screen appears automatically. Follow the on-screen instructions to create your user account and set the administrator password.
Tip: A session lasts 30 days after login. You do not need to sign in again until it expires.
Tip: You can also log in with the Enter key, so you can submit right after typing your password.
Troubleshooting: If you cannot log in, check that your user ID and password are correct.
