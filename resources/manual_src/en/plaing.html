Active Sessions

A screen that lists the timestamp sessions currently in progress. Use it to manage your running time tracking.

Toolbar

Button Description
⚙ Settings Opens the application settings screen.
❔ Help Displays help for the current screen.

Main Features

List of running sessions

The timestamp sessions that are currently active are shown as a list. Each session includes the following information.

  • Session name (title)
  • Start time
  • Elapsed time

Stopping a session

Tapping the stop button on a session ends it. The end time is recorded automatically.

Floating Action Button (+)

Tapping the "+" button at the bottom right of the screen lets you add a new record quickly.
