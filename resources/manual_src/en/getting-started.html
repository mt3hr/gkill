Getting Started

gkill is an application for recording and browsing daily life logs.

What You Can Do with gkill

Record Type Description
Memo Record text memos
Time Stamp Record start and end times
Task Manage tasks on a Kanban board
Mood Record your mood as a value from 0 to 10
Expense Record expense amounts and details
Bookmark Save web page URLs
Numeric Record Record arbitrary numeric data
File Upload and record images or documents
Repost Push a past record back onto the timeline at the current time
Repost Task Add a due date and a completion checkbox to an existing record and treat it as a task
Notification Attach a reminder to a record for a date and time you choose
GPS Log Import GPX files and show your route on a map
Git Commit Log Read and show the commit history of a Git repository you specify
Plugin records Import and show records left in services other than gkill

Initial Setup

How to Launch

EnvironmentLaunch Method
WindowsRun gkill.exe or gkill_server.exe
Browser / PWAStart gkill_server and access http://localhost:9999 in your browser
AndroidInstall the APK and launch the app. On first launch, the "All files access" permission is required (data is stored in /sdcard/gkill)

First Account Registration

  1. When you launch gkill for the first time, the account registration screen will appear automatically.
  2. Enter a user ID (this will be your account name).
  3. Enter a password, then enter it again for confirmation.
  4. Enter an Admin Password and confirm it (this sets the password for the auto-created admin account, used for server management).
  5. Press the "Register" button to create your account.
  6. You will be redirected to the login screen. Log in with the account you just created.
Tip: The admin account is automatically created when the server starts for the first time. This screen sets the admin Admin Password and creates your regular user account at the same time.

After login, the default screen (Life Log View by default) will be displayed. Configure basic settings such as language and dark theme in the settings screen.

Your First Record in 60 Seconds

  1. Log in.
  2. The Life Log View appears (by default, Life Log View opens immediately after login).
  3. Tap the "+" button at the bottom right of the screen.
  4. Select "Memo Pad" from the menu.
  5. Enter what you want to record in the text area (e.g., Had curry for lunch today).
  6. Press the "Save" button — your record is created and immediately appears in the Life Log View timeline.
Tip: Adding records through the "+" button in the Life Log View is the standard approach. You can confirm your records right there in the same screen. See the Tutorial for details.
Tip: Tapping the "+" button opens a menu; long-pressing opens the Memo Pad directly.
Tip: For lock-screen access or quick capture, use the "Home Hub" screen. See Home Hub Help for details.

Glossary

Term Description
Record A general term for records in gkill. It encompasses all record types including memos, time stamps, tasks, and more
Memo Pad Syntax A text input syntax used in the Memo Pad. By adding symbols at the beginning of each line, you can create different types of records at once
Time Stamp A time tracking feature. Records the start and end times of work or activities
Home Hub A screen for safely adding records even from the lock screen. Functions as a hub for adding various records
Life Log View A screen for listing and searching records
Aggregation View A feature for displaying data aggregation and statistics
Related Information A feature that automatically searches for and displays related information
Storage A storage location for records. You can use multiple storages for different purposes
Profile A set of settings for each device you use, so you can keep the same setup across devices
Tag A label you attach to a record. A record can have several, and they act as markers when you search later
Repost Task An existing record made usable as a task without rewriting it
Sharing A feature that lets you show selected records via a link, even to people without a gkill account
Plugin An add-on that imports records from services other than gkill and shows them in the list
