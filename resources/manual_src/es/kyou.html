Vista de registro

Pantalla que muestra los detalles de un registro individual. Puede consultar la información detallada de varios tipos de registros.

Botones de la barra de herramientas

Botón Descripción
⚙ Ajustes Abre la pantalla de ajustes de la aplicación.
❔ AyudaMuestra la ayuda de la pantalla actual.

Tipos de registro mostrados

Tipo de registro Descripción
Nota Muestra el contenido de notas de texto.
Marcadores Muestra las URLs y titulos guardados.
Tareas Muestra el estado, fecha límite e información del tablero de la tarea.
Estado de ánimo Muestra el valor de ánimo de 0 a 10.
Gastos Muestra el monto y el contenido del gasto.
Registro de tiempo Muestra la hora de inicio/fin y el tiempo transcurrido.
Archivo Muestra una vista previa del archivo subido. Los archivos de texto (.txt) muestran su contenido directamente en la vista. Los archivos Markdown (.md / .markdown) se muestran con formato enriquecido (encabezados, tablas, bloques de código, imágenes) y los bloques de código mermaid se representan como diagramas. Si un enlace del contenido es una ruta relativa a un archivo del mismo repositorio, al hacer doble clic se abre el diálogo de ese registro.
Registros numéricos Muestra el título y los datos numéricos.
Notificación Muestra las notificaciones asociadas a un registro.
Repost Muestra registros republicados en otra fecha/hora.
Tarea de repost Un registro existente que puede usarse como tarea. El contenido del registro original se muestra tal cual, con fecha límite y casilla de completado.
Registro de complemento Un registro importado por un complemento desde un servicio distinto de gkill. Consulte Complementos para más detalles.
Registro GPS Muestra datos de registro de ubicación GPS.
Registro de commit Git Muestra la información de commits del repositorio Git.

Información comun mostrada

En todos los tipos de registro se muestra la siguiente información:

  • Etiquetas: Lista de etiquetas asignadas al registro
  • Tiempo relacionado: Información de fecha y hora relacionada con el registro
  • Repositorio: Nombre del repositorio donde se almacenan los datos

Menú contextual

Haga clic derecho (o mantenga pulsado en móvil) sobre un registro para abrir el menú contextual. Los elementos disponibles varían un poco según el tipo de registro.

  • Agregar etiqueta del historial: Elija entre las etiquetas usadas recientemente y añádala de inmediato.
  • Agregar etiqueta / Editar etiqueta: Añade o edita etiquetas.
  • Agregar texto / Editar texto: Añade o edita un texto complementario.
  • Repost: Vuelve a mostrar este registro en la lista con la hora actual.
  • Convertir en tarea: Convierte este registro en tarea sin reescribir su contenido.
  • Agregar notificación / Editar notificación: Añade o edita un recordatorio.
  • Editar: Edita el contenido del registro.
  • Historial: Consulta el historial de cambios de etiquetas, textos y notificaciones.
  • Copiar contenido: Copia el cuerpo del registro al portapapeles.
  • Copiar ID: Copia el ID del registro al portapapeles.
  • Configuración del complemento: Se muestra solo en registros importados por un complemento; abre su pantalla de configuración.
  • Explorar contenido ZIP: Solo aparece en registros de archivos ZIP; abre su contenido en pantalla.
  • Abrir carpeta / Abrir archivo: Solo aparece cuando gkill se ejecuta en el mismo dispositivo; abre el archivo con la aplicación predeterminada del sistema.
  • Eliminar: Elimina el registro. Al hacerlo, se eliminan también las etiquetas, los textos y las notificaciones añadidos a ese registro, así como los reposts y las tareas de repost que hacen referencia a él.
Consejo: Puede agregar o editar etiquetas directamente desde la pantalla de detalles del registro.
Consejo: Los registros importados por un complemento son de solo lectura. No aparecen «Editar» ni «Eliminar», pero sí puede añadir etiquetas y textos o usar «Convertir en tarea».
