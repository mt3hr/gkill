Vista de registro

Pantalla que muestra los detalles de un registro individual. Puede consultar la información detallada de varios tipos de registros.

Botones de la barra de herramientas

Botón Descripción
⚙ Ajustes Abre la pantalla de ajustes de la aplicación.
❔ AyudaMuestra la ayuda de la pantalla actual.

Tipos de registro mostrados

Tipo de registro Descripción
Nota Muestra el contenido de notas de texto.
Marcadores Muestra las URLs y titulos guardados.
Tareas Muestra el estado, fecha límite e información del tablero de la tarea.
Estado de ánimo Muestra el valor de ánimo de 0 a 10.
Gastos Muestra el monto y el contenido del gasto.
Registro de tiempo Muestra la hora de inicio/fin y el tiempo transcurrido.
Archivo Muestra una vista previa del archivo subido. Los archivos de texto (.txt) muestran su contenido directamente en la vista. Los archivos Markdown (.md / .markdown) se muestran con formato enriquecido (encabezados, tablas, bloques de código, imágenes) y los bloques de código mermaid se representan como diagramas. Si un enlace del contenido es una ruta relativa a un archivo del mismo repositorio, al hacer doble clic se abre el diálogo de ese registro.
Registros numéricos Muestra el título y los datos numéricos.
Notificación Muestra las notificaciones asociadas a un registro.
Repost Muestra registros republicados en otra fecha/hora.
Registro GPS Muestra datos de registro de ubicación GPS.
Registro de commit Git Muestra la información de commits del repositorio Git.

Información comun mostrada

En todos los tipos de registro se muestra la siguiente información:

  • Etiquetas: Lista de etiquetas asignadas al registro
  • Tiempo relacionado: Información de fecha y hora relacionada con el registro
  • Repositorio: Nombre del repositorio donde se almacenan los datos

Menú contextual

Al hacer clic derecho (o mantener pulsado) en un registro, se muestra un menú contextual con las siguientes opciones:

  • Editar
  • Eliminar
  • Compartir
  • Agregar/Editar etiqueta
  • Agregar/Editar texto
  • Agregar/Editar notificación
  • Historial
  • Copiar ID
Consejo: Puede agregar o editar etiquetas directamente desde la pantalla de detalles del registro.
