Saihate

Pantalla para añadir registros de forma segura incluso desde la pantalla de bloqueo. Funciona como centro para añadir rápidamente todo tipo de registros.

Saihate no tiene funciones para ver ni editar registros: está especializado en añadirlos. Así no hay riesgo de modificar por error un registro existente. Funciona dentro de una sesión autenticada, lo que significa que solo es accesible mientras se ha iniciado sesión.

Cuándo usar cada pantalla: Use Saihate para anotar rápidamente una nota o entrada de tiempo, la Vista de Registro de Vida para buscar y explorar sus registros, y el Bloc de Notas para registrar en lote mediante entrada de texto.

Botones de la barra de herramientas

Botón Descripción
🔄 Recargar Recarga los datos. Mantener pulsado: fuerza la recarga.
Cerrar sesión Cierra la sesión.
❔ AyudaMuestra la ayuda de la pantalla actual.

Botón de acción flotante (+)

Al tocar el botón «+» de la esquina inferior derecha, aparece el menú para añadir los distintos tipos de registro.

Elemento del menú Contenido Descripción
Bloc de notas Entrada de texto Abre la pantalla para introducir notas y otros registros con la sintaxis del bloc de notas.
Bloc de notas de tiempo Texto + registro de tiempo Abre la pantalla que gestiona a la vez la entrada de notas y las entradas de tiempo en curso.
Registros numéricos Registrar un número Registra cualquier dato numérico.
Marcadores Registrar una URL Guarda la URL de una página web como marcador.
Registro de tiempo Iniciar la medición del tiempo Inicia una nueva sesión de registro de tiempo.
Tareas Añadir una tarea Crea una nueva tarea.
Gastos Registrar un importe Registra el importe y el concepto de un gasto.
Estado de ánimo Registrar el ánimo (0-10) Registra su estado de ánimo actual con un valor de 0 a 10.
Subir Subir un archivo Sube y registra archivos como imágenes o documentos.
Mantener pulsado: Si mantiene pulsado el botón «+», se abre directamente el bloc de notas. Es útil cuando quiere tomar una nota rápidamente.
Consejo: La pantalla que se muestra al iniciar sesión se puede cambiar en la configuración con la opción «Vista por defecto al iniciar».
Atajo: Presione Enter en esta pantalla para abrir el diálogo del bloc de notas. Es conveniente para agregar registros rápidamente.
