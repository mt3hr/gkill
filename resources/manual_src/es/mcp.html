Integración con IA

Al conectar asistentes de IA como Claude con gkill, puede buscar, agregar y editar sus registros de vida mediante conversación natural.

Lo que puede hacer

AcciónEjemplo
Buscar registros"Muéstrame las notas del almuerzo de la semana pasada" / "Resume los gastos de este mes"
Agregar registros"Agrega una nota para hoy" / "Crea una tarea"
Actualizar / eliminar registros"Marca esta tarea como completada"
Obtener GPS / archivos"Muéstrame mi ruta de hoy"
Verificar configuración"Lista mis plantillas"

Tipos de integración

TipoQué puede hacerArchivo a ejecutarHerramientasPuerto (HTTP)
Solo lecturaSolo ver y buscar registros. No puede agregar ni modificargkill-read-server.mjs108808
Solo escrituraAgregar, actualizar y eliminar registros. También puede obtener nombres de repositorios, etiquetas y tablerosgkill-write-server.mjs258809
Lectura y escrituraVer, agregar, actualizar y eliminar registrosgkill-readwrite-server.mjs308810

Todos los tipos incluyen dos herramientas adicionales para leer registros importados por complementos.

Entrega de archivos

La forma de mostrar los registros de archivos (imágenes, vídeos, documentos) a la IA cambia automáticamente según el tipo de conexión.

Tipo de conexiónMétodo de entrega
Conexión local (IA en el mismo PC)Se pasa a la IA la ruta real del archivo, que puede leerlo directamente.
Conexión remota (IA a través de internet)Se emite una URL exclusiva con caducidad y la IA obtiene el archivo desde esa URL. Para las imágenes se proporcionan tanto la miniatura como el tamaño original. No es necesario exponer gkill.
Consejo: El límite de tamaño de la transferencia incrustada (8MB por defecto) se ajusta con la variable de entorno GKILL_MCP_MAX_FILE_BYTES, y la caducidad de la URL (1 hora por defecto) con GKILL_MCP_FILE_LINK_TTL_MS.

Configuración (Claude Desktop)

Agregue lo siguiente al archivo de configuración de Claude Desktop (claude_desktop_config.json).

Integración de solo lectura

{
  "mcpServers": {
    "gkill": {
      "command": "node",
      "args": ["C:/path/to/gkill/src/mcp/gkill-read-server.mjs"],
      "env": {
        "GKILL_BASE_URL": "http://localhost:9999",
        "GKILL_USER": "su-id-de-usuario",
        "GKILL_PASSWORD_SHA256": "hash-sha256-de-su-contraseña"
      }
    }
  }
}
Consejo: GKILL_PASSWORD_SHA256 es el hash SHA256 de su contraseña. Puede generarlo con herramientas disponibles en su sistema operativo.

Configuración (Claude Code)

claude mcp add gkill \
  --env GKILL_BASE_URL=http://localhost:9999 \
  --env GKILL_USER=su-id-de-usuario \
  --env GKILL_PASSWORD_SHA256=su-hash \
  -- node /path/to/gkill/src/mcp/gkill-read-server.mjs
Consejo: Ajuste la ruta anterior al lugar donde colocó el código fuente de gkill. Para cambiar el tipo, sustituya el nombre del archivo por gkill-write-server.mjs o gkill-readwrite-server.mjs.

Uso remoto (conexión HTTP)

Si la IA no está en el mismo PC, puede hacer que el propio servidor MCP escuche por HTTP para que una IA en internet se conecte. Este modo autoriza la conexión mediante OAuth, por lo que no necesita exponer gkill a internet.

# Ejemplo: servir lectura y escritura por HTTP
MCP_TRANSPORT=http MCP_PORT=8810 MCP_OAUTH_ISSUER=https://example.com \
GKILL_BASE_URL=http://localhost:9999 \
GKILL_USER=su-id-de-usuario \
GKILL_PASSWORD_SHA256=su-hash \
node /path/to/gkill/src/mcp/gkill-readwrite-server.mjs
Consejo: También puede publicar el propio servidor gkill en internet. En ese caso, configure GKILL_BASE_URL con su dirección pública y habilite TLS (HTTPS) desde Configuración del servidor.
