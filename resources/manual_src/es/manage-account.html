Gestión de cuentas

Esta pantalla gestiona las cuentas de usuario. Solo los administradores pueden acceder.

Botón superior

Pulse el botón Agregar cuenta para crear una nueva cuenta.

Lista de cuentas

Las cuentas registradas se muestran en una lista. Cada fila de cuenta contiene los siguientes elementos:

ElementoDescripción
Casilla de activar/desactivarAlterna el estado de la cuenta entre activada y desactivada (no se puede alternar la cuenta con la que ha iniciado sesión)
ID de usuarioMuestra el ID de usuario de la cuenta
Botón de asignación de almacenamientoAsigna repositorios al usuario
Botón de configuración del complementoAbre la lista de complementos de ese usuario
Botón de restablecimiento de contraseñaGenera un enlace de restablecimiento de contraseña

Botón inferior

Cerrar: Cierra la pantalla de gestión de cuentas.

Consejo: La cuenta admin se crea automáticamente cuando el servidor se inicia por primera vez. Las cuentas agregadas desde la pantalla de gestión de cuentas son usuarios normales (sin privilegios de administrador). Las cuentas no se eliminan: se gestionan habilitándolas o deshabilitándolas.

Procedimiento de restablecimiento de contraseña

Si un usuario olvida su contraseña, el administrador emite un enlace de restablecimiento siguiendo estos pasos.

Procedimiento del administrador

  1. Abra «Gestión de cuentas» desde la pantalla de configuración del servidor.
  2. Pulse el botón «Restablecer contraseña» de la fila del usuario correspondiente.
  3. Pulse «OK» en el diálogo de confirmación para generar el enlace de restablecimiento.
  4. Copie el enlace que aparece y compártalo con el usuario (por mensaje, correo electrónico, etc.).

Procedimiento del usuario

  1. Abra en el navegador el enlace de restablecimiento que recibió del administrador.
  2. Introduzca la nueva contraseña y vuelva a introducirla para confirmarla.
  3. Pulse el botón «Configuración de contraseña» para establecer la nueva contraseña.
  4. Pasará a la pantalla de inicio de sesión; inicie sesión con la nueva contraseña.
Consejo: El enlace de restablecimiento es de un solo uso: deja de ser válido en cuanto se usa. Es válido durante 72 horas desde su emisión y la fecha de caducidad se muestra en el diálogo del enlace. Una vez caducado, use el botón "Volver a emitir el enlace" del mismo diálogo para generar uno nuevo.

Asignación de repositorios

A cada usuario se le asignan los «repositorios» donde se guardan sus datos. Al pulsar el botón de asignación de almacenamiento se abre el diálogo para configurar los repositorios de ese usuario. Para más detalles, consulte «Gestión de repositorios» en Configuración del servidor.

Configuración de los complementos

Pulse el botón «Configuración del complemento» en la fila de un usuario para abrir la lista de sus complementos. Se muestran el nombre, la versión y la descripción de cada uno, y si está en ejecución. El botón «Configuración» de una fila abre la pantalla de configuración que ofrece el propio complemento, donde puede cambiar y guardar, por ejemplo, sus carpetas de origen.

Consejo: Las carpetas de origen deciden qué carpetas puede leer gkill, por lo que solo un administrador puede abrir esta pantalla. Consulte Complementos para saber qué son los complementos.
