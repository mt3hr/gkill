Primeros Pasos > Gestión de Cuentas

Gestión de cuentas

Esta pantalla gestiona las cuentas de usuario. Solo los administradores pueden acceder.

Botón superior

Pulse el botón Añadir cuenta para crear una nueva cuenta.

Lista de cuentas

Las cuentas registradas se muestran en una lista. Cada fila de cuenta contiene los siguientes elementos:

ElementoDescripción
Casilla de activar/desactivarAlterna el estado de la cuenta entre activada y desactivada (no se puede alternar la cuenta con la que ha iniciado sesión)
ID de usuarioMuestra el ID de usuario de la cuenta
Botón de asignación de almacenamientoAsigna repositorios de datos al usuario
Botón de restablecimiento de contraseñaGenera un enlace de restablecimiento de contraseña

Botón inferior

Cerrar: Cierra la pantalla de gestión de cuentas.

Consejo: La cuenta admin se crea automáticamente cuando el servidor se inicia por primera vez. Las cuentas agregadas desde la pantalla de gestión de cuentas son usuarios normales (sin privilegios de administrador). Las cuentas se gestionan habilitandolas/deshabilitandolas en lugar de eliminarlas.

Procedimiento de restablecimiento de contraseña

Procedimiento del administrador

  1. Abra Configuración del servidor > Gestión de cuentas.
  2. Pulse el botón "Restablecer contraseña" del usuario correspondiente.
  3. Pulse Aceptar en el dialogo de confirmacion para generar el enlace de restablecimiento.
  4. Copie el enlace y compartalo con el usuario.

Procedimiento del usuario

  1. Abra el enlace en el navegador.
  2. Introduzca la nueva contraseña dos veces.
  3. Pulse el botón "Establecer".
  4. Será redirigido a la pantalla de inicio de sesión; inicie sesión con la nueva contraseña.
Consejo: El enlace de restablecimiento es de un solo uso. Es válido durante 72 horas desde su emisión y la fecha de caducidad se muestra en el diálogo del enlace. Una vez caducado, use el botón "Volver a emitir el enlace" del mismo diálogo para generar uno nuevo.

Asignacion de almacenamiento

El botón "Asignacion de almacenamiento" le permite asignar repositorios de datos a cada usuario. Consulte Gestión del almacenamiento en la configuración del servidor para obtener detalles sobre como agregar y administrar repositorios.
