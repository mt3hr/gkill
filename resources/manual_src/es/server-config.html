Los cambios requieren reiniciar el servidor para que surtan efecto.

Gestión del almacenamiento

Los repositorios de datos son los lugares donde se guardan los registros. Se pueden configurar múltiples repositorios según el proposito o dispositivo.

La asignacion por usuario se gestiona mediante el botón "Asignacion de almacenamiento" en Gestión de cuentas.

Como agregar un repositorio

  1. Abra Gestión de cuentas > Asignacion de almacenamiento del usuario deseado.
  2. Pulse el botón "Agregar".
  3. Configure los siguientes elementos: nombre para mostrar, tipo, ruta, usar como destino de escritura, habilitado. El desplegable de tipo muestra nombres alfanuméricos como kmemo o timeis; consulte la tabla siguiente para saber qué significa cada uno.
  4. Pulse "Guardar".

Tipos de repositorio

El desplegable de tipo muestra nombres alfanuméricos. Esto es lo que almacena cada uno.

Lo que muestra el desplegableLo que se almacena
kmemoNotas
timeisMarcas de tiempo (registros de tiempo)
miTareas
nlogGastos
urlogMarcadores
lantanaÁnimo
kcRegistros numéricos
directoryArchivos subidos (imágenes, vídeos, documentos...)
gpslogRegistros GPS en formato GPX
git_commit_logHistorial de commits de Git (solo lectura)
rekyouReposts (registros pasados mostrados de nuevo)
mirekyouTareas de repost (registros existentes convertidos en tareas)
tagEtiquetas añadidas a los registros
textTextos complementarios añadidos a los registros
notificationNotificaciones (recordatorios) añadidas a los registros
Consejo: tag / text / notification / rekyou / mirekyou guardan información añadida a los registros, no los registros en sí. Normalmente se crean durante la configuración inicial, así que no hace falta añadirlos después.
Consejo: Puede agregar múltiples repositorios del mismo tipo (por ejemplo, separados por dispositivo).
Consejo: La opción "Usar como destino de escritura" solo debe estar activada para un repositorio por tipo.
