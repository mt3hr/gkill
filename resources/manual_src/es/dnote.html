Vista de agregación

Pantalla para agregar y visualizar datos del registro de vida. Se pueden definir Elementos, Listas, Gráficos de tendencia y Gráficos de correlación para comparar varias métricas.

Consejo: La vista de agregación es una función de alternancia dentro de la vista de registro de vida. Haga clic en el icono de agregación en la barra de herramientas de la vista de registro de vida para mostrarla.

Gestión de definiciones

Elemento Descripción
Pestañas Cada definición de agregación se muestra como una pestaña. Haga clic en una pestaña para cambiar.
Nombre de definición Campo de texto para editar el nombre de la definición de agregación.
Botón ＋ (junto a pestañas) Añade una nueva definición de agregación.
Botón eliminar Elimina la definición de agregación que se muestra actualmente.

Elementos de la pantalla

Elemento Descripción
Rango de fechas Muestra el período objetivo de la agregación.
Botón de descarga Descarga los resultados de agregación en formato JSON.
Botón ＋ (flotante) Muestra un menú para añadir un Elemento, una Lista, un Gráfico de tendencia o un Gráfico de correlación.

Elementos (valor agregado individual)

Muestra el valor agregado de los datos que coinciden con las condiciones en el formato «Título: Prefijo [Resultado] Sufijo».

Configuración Tipo Descripción
Título Entrada de texto Establece el nombre visible del elemento.
Prefijo Entrada de texto Texto que se muestra antes del valor agregado.
Sufijo Entrada de texto Texto que se muestra después del valor agregado.
Objetivo de agregación Desplegable Selecciona el método de agregación (cantidad, suma, promedio, máximo, mínimo, etc.).
Grupo de condiciones Editor de condiciones Filtra los objetivos de agregación con condiciones AND/OR.

Listas (agregación por grupo)

Muestra los resultados agregados agrupados por clave en formato de lista.

Configuración Tipo Descripción
Título / Prefijo / Sufijo Entrada de texto Misma configuración que los elementos.
Objetivo de agregación Desplegable Selecciona el método de agregación.
Clave de grupo Desplegable Elija el criterio de agrupación (título, tipo de dato, etiqueta, tienda, ánimo, mes, semana, día de la semana, fecha, etc.). Con «Título» se agrupan el cuerpo de las notas, los títulos de registros numéricos, marcas de tiempo y tareas, los conceptos de gasto, los títulos de los marcadores y los mensajes de commit de Git.
Grupo de condiciones Editor de condiciones Filtra los objetivos de agregación con condiciones AND/OR.

Gráfico de tendencia (agregación temporal)

Agrega los datos que coinciden con las condiciones en períodos fijos y muestra la evolución como gráfico de línea o de barras. Al pasar el cursor sobre un punto del gráfico se muestra el valor agregado de cada período.

Configuración Tipo Descripción
Título Entrada de texto Establece el nombre visible del gráfico de tendencia.
Objetivo de agregación Desplegable Selecciona el método de agregación (recuento, suma, promedio, máximo, mínimo, etc.).
Granularidad Desplegable Selecciona la unidad de período: «Diario», «Semanal» o «Mensual».
Tipo de gráfico Desplegable Selecciona «Línea» o «Barras».
Grupo de condiciones Editor de condiciones Filtra el objetivo de agregación con condiciones AND/OR.

Gráfico de correlación

Agrega de 2 a 10 métricas por el mismo día, semana o mes y muestra sus relaciones mediante un mapa de calor y un gráfico de dispersión. Cada métrica tiene nombre, objetivo de agregación y condiciones.

Seleccione una celda para ver el coeficiente, el número de períodos emparejados, el valor p, el intervalo de confianza del 95 % y la dispersión. Están disponibles Pearson y Spearman; los resultados inferenciales de Spearman son aproximaciones analíticas. La correlación no demuestra causalidad.

Con un desfase positivo, la métrica de fila de un período anterior se compara con la métrica de columna de uno posterior. Se excluyen los períodos sin alguna observación.

Edición de grupo de condiciones

Elemento Descripción
Lógica de unión Seleccione AND / OR / NOT para configurar cómo se combinan las condiciones.
Añadir condición Añade una nueva condición al grupo.
Añadir grupo Añade un grupo de condiciones anidado.
Eliminar grupo Elimina este grupo de condiciones.
Cada condición Configura el tipo y valor de la condición (filtrar por tipo de datos, etiqueta, título, importe, valor de ánimo, etc.).

Operaciones

Operación Descripción
Doble clic Abre la pantalla de edición de un elemento, lista o gráfico de tendencia.
Clic derecho Muestra el menú contextual (editar/eliminar).
Arrastrar y soltar Permite cambiar el orden de visualización de elementos, listas y gráficos de tendencia.

Además, puede elegir condiciones que comparan con el registro que tiene seleccionado: «El título es igual al del objetivo», «Todas las etiquetas son iguales a las del objetivo», «Alguna etiqueta es igual a las del objetivo», «El tipo de dato es igual al del objetivo» y «El ID es igual al del objetivo». Consulte «Condiciones que comparan con el registro seleccionado» en Información relacionada.

Botones de acción inferiores

Botón Descripción
Aplicar Guarda los cambios de todas las definiciones.
Cancelar Descarta los cambios y cierra el diálogo.
Consejo: Los elementos son útiles para valores agregados individuales (ej: gastos totales del mes), las listas para agregaciones por grupo (ej: gastos por tienda) y los gráficos de tendencia para seguir la evolución (ej: cambios de ánimo semanales, evolución mensual de gastos).
Consejo: Combinando condiciones se pueden crear criterios de agregación complejos.
Consejo: Con arrastrar y soltar puede cambiar libremente el orden de visualización de elementos y listas.
Consejo: Los resultados de agregación se pueden descargar como JSON para analizarlos con herramientas externas.
