集計ビュー

ライフログのデータを条件に基づいて集計・可視化する画面です。単一の集計値を表示する「アイテム」、キーごとにグループ化して集計する「リスト」、時系列の推移をグラフ表示する「トレンドグラフ」の3種類を定義できます。

ヒント: 集計ビューはライフログビュー画面内のトグル機能です。ライフログビュー画面のツールバーにある集計アイコンをクリックすると表示されます。

定義の管理

要素 説明
タブ 各集計定義がタブとして表示されます。タブをクリックして切り替えます。
定義名 テキストフィールドで集計定義の名前を編集できます。
＋ボタン（タブ横） 新しい集計定義を追加します。
削除ボタン 現在表示中の集計定義を削除します。

画面の要素

要素 説明
日付範囲 集計対象の期間を表示します。
ダウンロードボタン 集計結果をJSON形式でダウンロードします。
＋ボタン（フローティング） メニューが表示され、アイテム追加・リスト追加・トレンドグラフ追加を選択できます。

アイテム（単一集計値）

条件に一致するデータの集計値を「タイトル: プレフィックス [集計結果] サフィックス」の形式で表示します。

設定項目 種類 説明
タイトル テキスト入力 アイテムの表示名を設定します。
プレフィックス テキスト入力 集計値の前に表示するテキストです。
サフィックス テキスト入力 集計値の後に表示するテキストです。
集計対象 ドロップダウン 集計方法を選択します（件数、合計、平均、最大、最小など）。
条件グループ 条件エディタ AND/OR条件で集計対象を絞り込みます。

リスト（グループ集計）

キーごとにグループ化して集計した結果をリスト形式で表示します。

設定項目 種類 説明
タイトル / プレフィックス / サフィックス テキスト入力 アイテムと同様の設定です。
集計対象 ドロップダウン 集計方法を選択します。
グループキー ドロップダウン グループ化の基準を選択します（タイトル、データタイプ、タグ、店名、気分値、月、週、曜日、日付など）。「タイトル」を選ぶと、メモの本文・数値記録や打刻やタスクのタイトル・支出の品目・ブックマークのタイトル・Gitのコミットメッセージがまとめてグループの見出しになります。
条件グループ 条件エディタ AND/OR条件で集計対象を絞り込みます。

トレンドグラフ（時系列集計）

条件に一致するデータを一定期間ごとに区切って集計し、推移を折れ線グラフまたは棒グラフで表示します。グラフの点にカーソルを合わせると各期間の集計値が表示されます。

設定項目 種類 説明
タイトル テキスト入力 トレンドグラフの表示名を設定します。
集計対象 ドロップダウン 集計方法を選択します（件数、合計、平均、最大、最小など）。
集計粒度 ドロップダウン 集計する期間の単位を「日」「週」「月」から選択します。
グラフ種別 ドロップダウン 「折れ線」または「棒」を選択します。
条件グループ 条件エディタ AND/OR条件で集計対象を絞り込みます。

条件グループの編集

要素 説明
結合ロジック AND / OR / NOT を選択して条件の結合方法を設定します。
条件追加 グループに新しい条件を追加します。
グループ追加 ネストされた条件グループを追加します。
グループ削除 この条件グループを削除します。
各条件 条件タイプと値を設定します（データタイプ、タグ、タイトル、金額、店名、気分値、コード行数などで絞り込み）。

このほか、いま選んでいる記録と見比べて絞り込む条件も選べます。「タイトルが対象と等しい」「タグがすべて対象と等しい」「タグが一部対象と等しい」「データタイプが対象と等しい」「IDが対象と等しい」の5つです。詳しくは関連情報の「選んだ記録と比べる条件」をご覧ください。

操作方法

操作 説明
ダブルクリック アイテム・リスト・トレンドグラフの編集画面を開きます。
右クリック コンテキストメニューを表示します（編集・削除）。
ドラッグ＆ドロップ アイテム・リスト・トレンドグラフの並び順を変更できます。

下部アクションボタン

ボタン 説明
適用 すべての定義の変更を保存します。
キャンセル 変更を破棄してダイアログを閉じます。
ヒント: アイテムは単一の集計値（例：今月の支出合計）、リストはグループごとの集計一覧（例：店舗別支出）、トレンドグラフは推移の把握（例：週ごとの気分の変化、月ごとの支出推移）に使用すると便利です。
ヒント: 条件を組み合わせることで、複雑な集計条件を作成できます。
ヒント: ドラッグ＆ドロップでアイテムやリストの表示順を自由に変更できます。
ヒント: 集計結果はJSONでダウンロードして外部ツールで分析することもできます。
