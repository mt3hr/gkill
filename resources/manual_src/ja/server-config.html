サーバ設定

サーバの動作に関する設定を行う画面です。管理者のみアクセスできます。

上部ボタン

アカウント管理ボタンを押すと、アカウント管理画面が開きます。

下部ボタン

適用: 設定を保存します。
キャンセル: 変更を破棄して画面を閉じます。

設定の変更を反映するには、サーバの再起動が必要です。

記録保管場所の管理

記録保管場所は、gkillが記録データを保存するフォルダやファイルのことです。用途（メモ用・ファイル用・GPSログ用など）や端末ごとに、複数の記録保管場所を設定できます。

記録保管場所の設定は、アカウント管理画面の「保存先割当ボタン」から各ユーザに対して行います。

記録保管場所の追加

  1. アカウント管理画面を開き、対象ユーザの「保存先割当ボタン」を押します。
  2. 「追加」ボタンを押して新しい記録保管場所を追加します。
  3. 以下の項目を設定します：
    • 表示名: ライフログビューやフィルターに表示される名前
    • 種別: 保存するデータの種類。ドロップダウンには kmemo や timeis のような英数字の名前が並びます。どれが何を指すかは次の「種別の選択」の表をご覧ください
    • パス: データを保存するディレクトリのパス（ファイル管理の場合はglob形式も使用可）
    • 書き込み先として使用: 新しく記録を追加したときにこの記録保管場所に保存するかどうか
    • 有効: この記録保管場所を検索・表示対象とするかどうか
  4. 「保存」ボタンを押して設定を反映します。

種別の選択

種別のドロップダウンには英数字の名前が並びます。それぞれが何を保存するのかは次のとおりです。

ドロップダウンの表示保存されるもの
kmemoメモ
timeis打刻（時間の記録）
miタスク
nlog支出
urlogブックマーク
lantana気分
kc数値記録
directoryアップロードしたファイル（画像・動画・書類など）
gpslogGPXファイル形式のGPSログ
git_commit_logGitのコミット履歴（読み取り専用）
rekyouリポスト（過去の記録をもう一度流したもの）
mirekyouリポストタスク（すでにある記録をタスクにしたもの）
tag記録に付けたタグ
text記録に付けた補足テキスト
notification記録に付けた通知（リマインダー）
ヒント: tag / text / notification / rekyou / mirekyou は、記録そのものではなく記録に付け足した情報の保存先です。ふつうは初回セットアップのときに自動で作られているので、あとから追加する必要はありません。
ヒント: 同じ種別の記録保管場所を複数追加できます。例えば、端末ごとにテキストメモ用の記録保管場所を分けることで、端末ごとのデータを整理できます。
ヒント: 「書き込み先として使用」をオンにした記録保管場所が、新規記録の保存先になります。同じ種別で複数の記録保管場所がある場合は、書き込み先として使用する1つだけをオンにしてください。
