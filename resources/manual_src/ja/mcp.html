AI連携

Claude などの AI アシスタントと gkill を連携することで、会話形式でライフログを検索・追加・編集できるようになります。

できること

操作例
記録の検索「先週のランチ記録を見せて」「今月の支出を集計して」
記録の追加「今日のメモを追加して」「タスクを作って」
記録の更新・削除「このタスクを完了にして」
GPS・ファイルの取得「今日の移動経路を教えて」
設定の確認「テンプレート一覧を見せて」

連携の種類

種類できること実行するファイルツール数HTTP時のポート
読み取り専用記録の閲覧・検索のみ。追加・変更はできないgkill-read-server.mjs108808
書き込み専用記録の追加・更新・削除。あわせて記録保管場所名・タグ名・板名の取得もできるgkill-write-server.mjs258809
読み書き両用閲覧・追加・更新・削除のすべてgkill-readwrite-server.mjs308810

どの種類でも、プラグインで取り込んだ記録を読むためのツールが2つ含まれます。

ファイルの受け渡し

ファイル記録（画像・動画・ドキュメント）をAIに見せる方法は、接続形態に応じて自動的に切り替わります。

接続形態受け渡し方法
ローカル接続（同じPC上のAI）ファイルの保存場所（実パス）がAIに渡され、AIがファイルを直接読み取れます。
リモート接続（インターネット経由のAI）有効期限付きの専用URLが発行され、AIはそのURLからファイルを取得します。画像はサムネイルと原寸の両方が渡されます。gkill本体を公開する必要はありません。
ヒント: 埋め込み転送のサイズ上限（既定8MB）は環境変数 GKILL_MCP_MAX_FILE_BYTES、URLの有効期限（既定1時間）は GKILL_MCP_FILE_LINK_TTL_MS で調整できます。

設定方法（Claude Desktop）

Claude Desktop の設定ファイル（claude_desktop_config.json）に以下を追記します。

読み取り専用で連携する場合

{
  "mcpServers": {
    "gkill": {
      "command": "node",
      "args": ["C:/path/to/gkill/src/mcp/gkill-read-server.mjs"],
      "env": {
        "GKILL_BASE_URL": "http://localhost:9999",
        "GKILL_USER": "あなたのユーザーID",
        "GKILL_PASSWORD_SHA256": "パスワードのSHA256ハッシュ"
      }
    }
  }
}
ヒント: GKILL_PASSWORD_SHA256 はパスワードをSHA256でハッシュ化した値です。コマンドプロンプト（Windows）で certutil -hashfile - SHA256 などのツールで生成できます。

設定方法（Claude Code）

ターミナルで以下のコマンドを実行します。

# 読み取り専用で追加（環境変数は -- の前、実行コマンドは -- の後ろに書きます）
claude mcp add gkill \
  --env GKILL_BASE_URL=http://localhost:9999 \
  --env GKILL_USER=ユーザーID \
  --env GKILL_PASSWORD_SHA256=ハッシュ値 \
  -- node /path/to/gkill/src/mcp/gkill-read-server.mjs
ヒント: 上のパスは、gkillのソースを置いた場所に合わせて書き換えてください。種類を変えたいときは、ファイル名を gkill-write-server.mjs か gkill-readwrite-server.mjs に差し替えます。

リモートから使う（HTTP接続）

AIが同じPCにいない場合は、MCPサーバ自体をHTTPで待ち受けさせ、インターネット経由のAIから接続できます。この方式では接続時にOAuthによる認可が行われるため、gkill本体をインターネットに公開する必要はありません。

# 読み書き両用をHTTPで待ち受ける例
MCP_TRANSPORT=http MCP_PORT=8810 MCP_OAUTH_ISSUER=https://example.com \
GKILL_BASE_URL=http://localhost:9999 \
GKILL_USER=ユーザーID \
GKILL_PASSWORD_SHA256=ハッシュ値 \
node /path/to/gkill/src/mcp/gkill-readwrite-server.mjs
ヒント: gkillサーバ自体をインターネットに公開して使うこともできます。その場合は GKILL_BASE_URL に公開アドレスを指定し、サーバ設定でTLS（HTTPS）を有効にしてください。
