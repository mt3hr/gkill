ポート

1つの画面の中で、すべての操作をウィンドウとして開ける画面です。

ポートは背景と「+」ボタンだけの画面です。「+」から ライフログビュー / タスク / 実行中 / ダッシュボード をウィンドウとして開くと、画面を切り替えずに並べて使えます。ウィンドウはドラッグで動かせ、右下をつまむと大きさを変えられます。位置と大きさは次に開いたときも残ります。

記録の追加は「+」の「記録」グループから行います。メモ帳・打刻メモ帳・数値記録・ブックマーク・打刻帳・タスク・支出・気分・アップロード・クリップボードを保存が並んでいます。

使い分けのヒント: 追加だけしたいときはさいはて、いくつもの画面を行き来しながら作業したいときはポートを使いましょう。ポートはタイトルをクリックすると他の画面へ移動もできます。

ツールバーボタン

ボタン 説明
ヘルプ 現在の画面のヘルプを表示します。
設定 設定画面を開きます。

「+」ボタン

画面右下の「+」ボタンを押すと、2つのグループに分かれたメニューが出ます。

グループ 説明
画面 ライフログビュー / タスク / 実行中 / ダッシュボードをウィンドウとして開きます。同じ画面を並べて開くこともできますが、枚数には上限があり、上限に達している場合はいちばん手前に出すだけになります。
記録 それぞれの記録を追加するウィンドウを開きます。

ウィンドウを閉じる

ウィンドウ右上の「×」、Escape キー、ブラウザの「戻る」のどれでも閉じられます。閉じるのは一番手前にあるウィンドウです。
