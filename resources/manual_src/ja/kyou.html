記録画面

個別の記録の詳細を表示する画面です。各種記録タイプの詳細情報を確認できます。

ツールバーボタン

ボタン 説明
⚙ 設定 アプリケーション設定画面を開きます。
❔ ヘルプ 現在の画面のヘルプを表示します。

表示される記録タイプ

記録タイプ 説明
メモ テキストメモの内容を表示します。
ブックマーク 保存したURLとタイトルを表示します。
タスク タスクの状態・期限・ボード情報を表示します。
気分 0〜10の気分値を表示します。
支出 金額と支出内容を表示します。
打刻 開始・終了時刻と経過時間を表示します。
ファイル アップロードされたファイルのプレビューを表示します。テキストファイル（.txt）は内容を画面内に直接表示します。Markdownファイル（.md / .markdown）は見出し・表・コードブロック・画像などを整形したリッチ表示になり、mermaidコードブロックは図として描画されます。本文中のリンクが同じ記録保管場所内のファイルを指す相対パスの場合、ダブルクリックでその記録のダイアログを開けます。
数値記録 タイトルと数値データを表示します。
リポスト 他の記録を別の日時に再投稿した記録を表示します。
リポストタスク すでにある記録をタスクとして扱えるようにした記録です。元の記録の内容がそのまま表示され、期限や完了チェックが付きます。
プラグインの記録 プラグインが取り込んだ、gkill以外のサービスの記録を表示します。詳しくはプラグインをご覧ください。
GPSログ GPSの位置情報ログを表示します。
Gitコミットログ Gitリポジトリのコミット情報を表示します。
通知 指定した日時にリマインダーとして通知する記録です。

共通の表示情報

すべての記録タイプで以下の情報が表示されます。

  • タグ: 記録に付与されたタグの一覧
  • 関連時刻: 記録に関連する日時情報
  • 記録保管場所名: データが保存されている記録保管場所の名前

コンテキストメニュー

記録を右クリック（またはロングタップ）すると、コンテキストメニューが表示され、以下の操作ができます。記録の種類によって、表示される項目は多少変わります。

  • タグ履歴から追加: 最近使ったタグの一覧から選んで、すぐにタグを付けられます。
  • タグ追加 / タグ編集: タグの追加や編集を行います。
  • テキスト追加 / テキスト編集: 補足テキストの追加や編集を行います。
  • リポスト: その記録を、もう一度いまの時刻の一覧に流します。
  • タスクにする: その記録を、内容を書き直さずにそのままタスクとして扱えるようにします。
  • 通知追加 / 通知編集: リマインダー通知の追加や編集を行います。
  • 編集: 記録の内容を編集します。
  • 履歴: タグ・テキスト・通知の変更履歴を閲覧できます。
  • 内容コピー: 記録の本文をクリップボードにコピーします。
  • IDコピー: 記録のIDをクリップボードにコピーします。
  • プラグイン設定: プラグインが取り込んだ記録のときだけ表示され、そのプラグインの設定画面を開きます。
  • ZIP内容を閲覧: ZIPファイルの記録のときだけ表示され、中身を画面上で開けます。
  • フォルダを開く / ファイルを開く: gkillを同じ端末で開いているときだけ表示され、記録のファイルをOSの標準アプリで開きます。
  • 削除: 記録を削除します。このとき、その記録に付けたタグ・テキスト・通知と、その記録を参照しているリポスト・リポストタスクも一緒に削除されます。
ヒント: 記録の詳細画面から直接タグの追加や編集が可能です。
ヒント: プラグインが取り込んだ記録は読み取り専用です。「編集」「削除」は表示されませんが、タグやテキストを付けたり「タスクにする」ことはできます。
