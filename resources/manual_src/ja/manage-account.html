アカウント管理

ユーザアカウントを管理する画面です。管理者のみアクセスできます。

上部ボタン

アカウント追加ボタンを押すと、新しいアカウントを作成できます。

アカウント一覧

登録されているアカウントが一覧で表示されます。各アカウントの行には以下の項目があります。

項目説明
有効/無効チェックボックスアカウントの有効・無効を切り替えます
ユーザIDアカウントのユーザIDを表示します
保存先割当ボタンユーザにデータリポジトリを割り当てます
パスワードリセットボタンパスワードリセットリンクを生成します

下部ボタン

閉じる: アカウント管理画面を閉じます。

ヒント: admin アカウントはサーバ初回起動時に自動作成されます。アカウント管理画面から追加したアカウントは通常ユーザ（管理者権限なし）です。アカウントは削除ではなく、有効/無効の切り替えで管理します。

パスワードのリセット手順

ユーザがパスワードを忘れた場合、管理者が以下の手順でパスワードリセットリンクを発行します。

管理者の操作

  1. サーバ設定画面から「アカウント管理」を開きます。
  2. 対象ユーザの行にある「パスワードリセット」ボタンを押します。
  3. 確認ダイアログで「OK」を押すと、パスワードリセットリンクが生成されます。
  4. 表示されたリセットリンクをコピーして、対象ユーザに共有します（メッセージやメールなど）。

ユーザの操作

  1. 管理者から受け取ったリセットリンクをブラウザで開きます。
  2. 新しいパスワードを入力し、確認のためもう一度入力します。
  3. 「設定」ボタンを押すと新しいパスワードが設定されます。
  4. ログイン画面に遷移するので、新しいパスワードでログインします。
ヒント: リセットリンクは1回限りの使い切りです。リンクを使用すると無効になります。リンクが期限切れの場合は、管理者に再発行を依頼してください。

記録保管場所の割当

各ユーザにデータを保存する「記録保管場所」（リポジトリ）を割り当てます。「保存先割当ボタン」を押すと、そのユーザの記録保管場所を設定するダイアログが開きます。詳しくはサーバ設定の「記録保管場所の管理」をご覧ください。
