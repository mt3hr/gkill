はじめに

gkillは、日々のライフログ（生活記録）を記録・閲覧するためのアプリケーションです。

gkillでできること

記録タイプ 説明
メモ テキストメモを記録します
打刻 時間の開始・終了を記録します
タスク やるべきことをカンバンボードで管理します
気分 気分を0〜10の数値で記録します
支出 支出金額と内容を記録します
ブックマーク WebページのURLを保存します
数値記録 任意の数値データを記録します
ファイル 画像やドキュメントをアップロードして記録します
リポスト 過去の記録を、もう一度いまの時刻の一覧に流します
リポストタスク すでにある記録に期限や完了チェックを付けて、タスクとして扱います
通知 記録に指定した日時のリマインダーを付けます
GPSログ GPXファイルを取り込んで、移動経路を地図に表示します
Gitコミットログ 指定したGitリポジトリのコミット履歴を読み取って表示します
プラグインの記録 gkill以外のサービスに残った記録を取り込んで表示します

起動方法

環境起動方法
Windowsgkill.exe または gkill_server.exe を実行
ブラウザ / PWAgkill_server を起動し、ブラウザで http://localhost:9999 にアクセス
AndroidAPKをインストールしてアプリを起動。初回起動時に「すべてのファイルへのアクセス」の許可が必要です（データは /sdcard/gkill に保存されます）

初回アカウント登録

  1. gkillを初めて起動すると、アカウント登録画面が自動的に表示されます。
  2. ユーザーIDを入力します（これがあなたのアカウント名になります）。
  3. パスワードを入力し、確認のためもう一度入力します。
  4. 管理アカウントパスワードを入力し、確認のためもう一度入力します（自動作成される admin アカウントのパスワードです。サーバ管理に使用します）。
  5. 「登録」ボタンを押すと、アカウントが作成されます。
  6. ログイン画面にリダイレクトされるので、作成したアカウントでログインします。
ヒント: admin アカウントはサーバ初回起動時に自動作成されます。この画面では、admin アカウントの管理アカウントパスワード設定と、自分が使う通常ユーザアカウントの作成を同時に行います。

ログイン後、デフォルト画面（初期設定ではライフログビュー）が表示されます。設定画面で言語やダークテーマなどの基本設定を行ってください。

60秒で最初の記録

  1. ログインします。
  2. ライフログビュー画面が表示されます（初期設定ではログイン直後にライフログビューが開きます）。
  3. 画面右下の「+」ボタンをタップします。
  4. メニューから「メモ帳」を選択します。
  5. テキストエリアに記録したい内容を入力します（例: 今日のランチはカレーだった）。
  6. 「保存」ボタンを押すと記録が作成され、ライフログビューのタイムラインにすぐ表示されます。
ヒント: 記録の追加はライフログビュー画面の「+」ボタンから行うのが基本です。記録した内容はそのままライフログビューで確認できます。詳しい使い方はチュートリアルをご覧ください。
ヒント: 「+」ボタンをタップするとメニューが開きます。長押しするとメモ帳が直接開きます。
ヒント: ロック画面や素早い記録には「さいはて」画面も利用できます。詳しくはさいはて画面ヘルプをご覧ください。

用語集

用語 説明
記録 gkillにおけるデータの総称です。メモ、打刻、タスクなどすべての記録タイプを包括します
メモ帳構文 メモ帳で使用するテキスト入力構文です。行ごとに記号を付けることで、異なる種類の記録を一括作成できます
打刻 時間計測機能です。作業や活動の開始・終了時刻を記録します
さいはて ロック画面からでも安全に記録を追加できる画面です。各種記録の追加ハブとして機能します
ライフログビュー 記録を一覧表示・検索する画面です
集計ビュー データの集計・統計を表示する機能です
関連情報 関連する記録を自動検索・表示する機能です
記録保管場所 記録の保存先です。用途に応じて複数の記録保管場所を使い分けられます
プロファイル 使っている端末ごとの設定をまとめたものです。端末を変えても同じ設定で使い続けられます
タグ 記録に付けるラベルです。1つの記録に複数付けられ、あとから探すときの目印になります
リポストタスク すでにある記録を、書き直さずにそのままタスクとして扱えるようにしたものです
共有 選んだ記録を、gkillのアカウントがない人にもリンクで見せられる機能です
プラグイン gkill以外のサービスの記録を取り込んで一覧に表示する追加機能です
