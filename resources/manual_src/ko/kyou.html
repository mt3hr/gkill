기록 유형 설명

수치 기록 제목과 수치 데이터를 표시합니다.
리포스트 다른 날짜/시간에 다시 게시된 기록을 표시합니다.

GPS 로그 GPS 위치 로그 데이터를 표시합니다.

알림 알림 정보를 표시합니다.

공통 표시 정보

모든 기록 유형에서 다음 정보가 표시됩니다:

  • 태그: 기록에 부여된 태그 목록
  • 관련 시간: 기록과 관련된 날짜/시간 정보
  • 저장소: 데이터가 저장된 저장소의 이름

컨텍스트 메뉴

기록을 오른쪽 클릭(또는 모바일에서 길게 누르기)하면 컨텍스트 메뉴가 표시됩니다. 기록의 종류에 따라 표시되는 항목은 조금씩 달라집니다.

  • 태그 기록에서 추가: 최근에 사용한 태그 목록에서 골라 바로 붙일 수 있습니다.
  • 태그 추가 / 태그 편집: 태그를 추가하거나 편집합니다.
  • 텍스트 추가 / 텍스트 편집: 보충 텍스트를 추가하거나 편집합니다.
  • 리포스트: 그 기록을 지금 시각의 목록에 다시 흘려보냅니다.
  • 작업으로 만들기: 내용을 고쳐 쓰지 않고 그대로 작업으로 다룰 수 있게 합니다.
  • 알림 추가 / 알림 편집: 리마인더 알림을 추가하거나 편집합니다.
  • 편집: 기록의 내용을 편집합니다.
  • 이력: 태그·텍스트·알림의 변경 이력을 볼 수 있습니다.
  • 내용 복사: 기록의 본문을 클립보드에 복사합니다.
  • ID 복사: 기록의 ID를 클립보드에 복사합니다.
  • 플러그인 설정: 플러그인이 가져온 기록에서만 표시되며, 해당 플러그인의 설정 화면을 엽니다.
  • ZIP 내용 탐색: ZIP 파일 기록일 때만 표시되며, 내용을 화면에서 열 수 있습니다.
  • 폴더 열기 / 파일 열기: 같은 기기에서 gkill을 열고 있을 때만 표시되며, OS 기본 앱으로 파일을 엽니다.
  • 삭제: 기록을 삭제합니다.
팁: 기록 상세 화면에서 직접 태그를 추가하거나 편집할 수 있습니다.
힌트: 플러그인이 가져온 기록은 읽기 전용입니다. 「편집」「삭제」는 표시되지 않지만, 태그나 텍스트를 붙이거나 「작업으로 만들기」는 할 수 있습니다.
