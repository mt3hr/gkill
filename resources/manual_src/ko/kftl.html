메모장

메모장 구문을 사용하여 생활 이벤트를 기록하는 메모장 화면입니다. 메모장 구문은 다양한 기록을 일괄 입력할 수 있는 행 구조 텍스트 형식입니다.

툴바 버튼

버튼 설명
⚙ 설정 애플리케이션 설정 화면을 엽니다.
❔ 도움말현재 화면의 도움말을 표시합니다.

화면 요소

요소 설명
텍스트 입력 영역 메모장 구문으로 기록 내용을 입력하는 영역입니다.
템플릿 버튼 미리 정의된 메모장 템플릿 텍스트를 삽입합니다.
저장 버튼 저장 버튼을 클릭하여 입력된 메모장 텍스트를 분석하고 저장합니다.
탭 작성 중인 내용을 여러 개 함께 둘 수 있습니다. 탭마다 다른 내용을 입력할 수 있습니다.
탭 추가 버튼 새로운 빈 탭을 추가합니다.
탭 닫기 버튼 해당 탭을 닫습니다. 내용이 남아 있으면 먼저 확인합니다.

탭 사용법

작성 중인 내용을 여러 개 함께 둘 수 있습니다. 하나의 기록을 쓰는 도중에 다른 일이 떠올랐다면 탭 추가 버튼을 눌러 새 탭에 쓰고, 나중에 원래 탭으로 돌아올 수 있습니다.

조작 결과
탭 추가 버튼을 누른다 빈 탭이 늘어납니다.
탭 이름을 클릭한다 해당 탭의 내용으로 전환됩니다.
탭 닫기 버튼을 누른다 해당 탭을 닫습니다. 내용이 남아 있으면 먼저 확인합니다.
저장 버튼을 누른다 해당 탭의 내용만 기록하고, 저장된 탭은 닫힙니다. 다른 탭은 그대로 남습니다.
템플릿을 선택한다 새 탭이 열리고 거기에 템플릿이 들어갑니다. 작성 중인 내용은 사라지지 않습니다.

탭 이름은 템플릿에서 열었을 때는 템플릿 이름, 그렇지 않을 때는 내용의 첫 줄에서 만들어집니다. 아직 아무것도 쓰지 않은 탭에는 일련번호가 붙습니다.

메모장을 여러 개 열기

다른 화면의 「+」 메뉴에서 「메모장」을 고르면 그때마다 메모장 창이 한 개씩 늘어납니다. 나란히 놓을 수 있으므로 기록을 보면서 다른 기록을 쓰는 식으로 쓸 수 있습니다.

탭 목록은 모든 창에서 공통입니다. 한쪽 창에서 만든 탭은 다른 창의 탭 목록에도 나타납니다. 창을 닫아도 쓰던 내용은 사라지지 않습니다.

다만 「지금 어느 탭을 보여 주고 있는지」는 창마다 다릅니다. 같은 탭을 두 창에서 열어 나란히 볼 수도 있지만, 그 상태에서 양쪽에서 저장해도 기록은 한 번만 만들어집니다.

팁: 작성 중인 내용은 화면을 닫아도 남습니다. 다음에 열었을 때 열려 있던 탭이 그대로 복원됩니다.

메모장 구문에 대하여

메모장 구문은 gkill 고유의 텍스트 형식으로, 하나의 텍스트에서 여러 기록을 일괄 생성할 수 있습니다. 각 행은 하나의 명령 또는 데이터 항목을 나타냅니다.

팁: 템플릿 버튼을 사용하면 메모장 구문을 외우지 않아도 자주 사용하는 입력 형식을 빠르게 삽입할 수 있습니다.

조작 절차

  1. 텍스트 입력 영역에 메모장 구문으로 기록 내용을 입력합니다.
  2. 필요에 따라 템플릿 버튼에서 정형문을 삽입합니다. 템플릿은 새 탭에서 열리므로 작성 중인 내용은 사라지지 않습니다.
  3. 저장 버튼을 클릭하여 기록을 작성합니다.
  4. 아직 한 번도 사용한 적이 없는 태그가 포함되어 있으면 「새로운 태그입니다. 추가하시겠습니까?」라고 확인합니다. 그 태그로 괜찮다면 그대로 진행하세요.
  5. 정상적으로 저장되면 해당 탭이 닫힙니다. 다른 탭의 내용은 그대로 남습니다. 탭이 모두 없어지면 빈 탭이 하나 준비됩니다.
힌트: 새 태그 확인은 오타로 비슷한 태그가 늘어나는 것을 막기 위한 것입니다. 표시된 태그 이름이 의도한 것과 다를 때는 일단 돌아가서 고쳐 쓰세요.
팁: 템플릿을 활용하면 효율적으로 입력할 수 있습니다. 자주 사용하는 기록 패턴은 템플릿으로 설정해 두면 편리합니다.
팁: 다른 화면에서는 + 메뉴의 「메모장」을 선택할 때마다 메모장 창이 늘어납니다. 창마다 다른 탭을 열어 비교할 수 있고, 같은 탭을 열어 두면 한쪽에 입력한 내용이 다른 쪽에도 그대로 나타납니다.
