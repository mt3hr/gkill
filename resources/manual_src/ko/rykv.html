라이프로그 뷰

썸네일로 생활 로그를 탐색하는 화면입니다. 다양한 표시 모드와 필터 기능을 지원합니다.

툴바 버튼

버튼 설명
☰ 사이드바 필터링 및 탐색을 위한 사이드바를 열고 닫습니다.
📄 상세 기록의 상세 패널을 표시/숨깁니다.
📊 요약 뷰 통계 통계 분석 화면을 표시합니다.
📅 캘린더 캘린더 보기를 표시합니다.
🗺 지도 GPS 정보가 포함된 기록을 지도에 표시합니다.
⚙ 설정 애플리케이션 설정 화면을 엽니다.
❔ 도움말현재 화면의 도움말을 표시합니다.

주요 기능

이미지 썸네일 포함 목록 표시

기록을 여러 열의 그리드 레이아웃으로 표시합니다. 이미지나 파일이 포함된 기록은 썸네일이 표시됩니다. 열 수는 설정 화면에서 1~10열로 변경할 수 있습니다.

사이드바(필터·검색)

사이드바에서 다음 조건을 지정하여 기록을 좁힐 수 있습니다.

  • 텍스트 검색(키워드)
  • 태그를 통한 필터
  • 기간 지정
  • 기록 유형 선택
  • 기록 보관 장소 선택

필터 열 추가

"+" 버튼으로 새 필터 열을 추가할 수 있습니다. 서로 다른 필터 조건의 결과를 나란히 놓고 비교할 수 있습니다.

상세 패널

기록을 선택하면 상세 패널에 해당 기록의 모든 정보가 표시됩니다.

본문에 쓴 URL은 자동으로 링크가 되어 그대로 열 수 있습니다. 문장 끝의 문장 부호나 닫는 괄호는 링크에 포함되지 않으므로 문장 속에 URL을 써도 올바르게 열립니다.

집계 뷰 통계

기록 데이터의 통계·분석 결과를 표시합니다. 기록의 경향이나 패턴을 파악할 수 있습니다.

GPS 지도 표시

GPS 로그 데이터를 지도에 표시합니다. 이동 경로나 위치 정보를 시각적으로 확인할 수 있습니다. Google Maps API 키 설정이 필요합니다.

힌트: 이미지 열 수는 설정 화면에서 변경할 수 있습니다. 스마트폰에서는 1~2열, PC에서는 3~5열을 권장합니다.
힌트: 필터 열을 여러 개 추가하여 서로 다른 조건의 기록을 나란히 비교하면 편리합니다.
힌트: 표시 기간의 기본값은 설정 화면의 "라이프로그 뷰 표시 일수"에서 변경할 수 있습니다.

FAB(플로팅 액션 버튼) "+"

"+" 버튼을 클릭하면 메뉴가 펼쳐지며, 다음 유형의 기록을 빠르게 생성할 수 있습니다:

수치수치 데이터를 기록합니다.

팁: "+" 버튼을 길게 누르면 메모장 입력 화면이 직접 열려 빠른 일괄 입력이 가능합니다.
단축키: 이 화면에서 Enter 키를 누르면 메모장 대화상자가 열립니다. 빠르게 기록을 추가할 때 편리합니다.
단축키: Ctrl+V를 누르면 클립보드 내용을 파일로 직접 저장할 수 있습니다. 스크린샷이나 복사한 이미지를 빠르게 기록할 때 편리합니다.

태그 사용법

태그는 기록을 분류하고 정리하기 위한 레이블입니다. 하나의 기록에 여러 태그를 붙일 수 있습니다.

태그 추가

  1. 타임라인의 기록을 길게 누릅니다（모바일）또는 오른쪽 클릭합니다（데스크탑）.
  2. 컨텍스트 메뉴에서 "태그 추가"를 선택합니다.
  3. 태그 이름을 입력하여 추가합니다. 기존 태그는 입력 후보로 표시됩니다.

최근에 사용한 태그를 붙이고 싶을 때는 컨텍스트 메뉴의 「태그 기록에서 추가」를 사용하면 목록에서 고르는 것만으로 붙일 수 있습니다.

아직 한 번도 사용한 적이 없는 태그 이름을 입력하면 저장하기 전에 「새로운 태그입니다. 추가하시겠습니까?」라고 확인합니다. 오타로 비슷한 태그가 늘어나는 것을 막기 위한 확인입니다.

태그 편집 및 삭제

  1. 타임라인의 태그를 길게 누릅니다（모바일）또는 오른쪽 클릭합니다（데스크탑）.
  2. 컨텍스트 메뉴에서 "태그 편집" 또는 "태그 삭제"를 선택합니다.

태그 계층 구조 관리

설정 화면의 "태그 구조"에서 태그의 표시 이름과 정렬 순서를 관리할 수 있습니다. 자주 사용하는 태그를 상위에 배치하면 태그 후보 목록에서 쉽게 찾을 수 있습니다.

팁: 메모장 구문에서 #태그명을 입력하면 텍스트 전송 시 자동으로 태그가 붙습니다. 자세한 내용은 메모장 구문 참조를 참조하세요.

파일 업로드 상세

"+" 버튼 메뉴의 "업로드"를 통해 이미지, 동영상, 문서 등의 파일을 gkill에 저장할 수 있습니다.

작업 순서

  1. "+" 버튼에서 "업로드"를 선택합니다.
  2. 업로드 대상 저장소（파일 관리용 리포지토리）를 선택합니다.
  3. 관련 날짜（파일의 기록 날짜）를 확인 및 조정합니다.
  4. 파일을 선택하여 업로드합니다. 여러 파일을 한 번에 선택할 수 있습니다. 대화상자의 "여기에 파일을 드롭하세요"라고 표시된 영역에 파일을 드래그 앤 드롭하여 추가할 수도 있습니다.

지원 파일 형식

이미지（JPEG, PNG, GIF, WEBP）, 동영상（MP4 등）, PDF, ZIP 및 기타 일반적인 파일 형식을 지원합니다. Markdown 파일（.md / .markdown）은 목록·상세 표시에서 제목이나 표가 정리된 리치 표시가 되며, mermaid 코드 블록은 다이어그램으로 렌더링됩니다.

업로드 크기 제한

월간 업로드 크기 상한은 관리자가 서버 설정의 「월간 업로드 크기 상한」에서 설정합니다. 초기값은 -1（무제한）입니다.

단축키: Ctrl+V를 누르면 클립보드에 있는 이미지나 텍스트를 그대로 파일로 저장할 수 있습니다. 스크린샷을 빠르게 기록할 때 편리합니다.

ZIP 파일의 내용 보기

업로드한 ZIP 파일은 컴퓨터로 꺼내지 않아도 그대로 화면에서 내용을 열 수 있습니다. 확장자가 .cbz인 파일도 ZIP으로 다룹니다.

여는 방법

  1. ZIP 파일 기록을 길게 누르거나(모바일) 오른쪽 클릭합니다(데스크톱).
  2. 컨텍스트 메뉴에서 「ZIP 내용 탐색」을 선택합니다.
  3. ZIP 안의 폴더와 파일이 목록으로 표시됩니다.

안을 둘러보기

  • 폴더를 클릭하면 그 안으로 들어갑니다. 상위 계층으로 돌아갈 때는 화면 위쪽의 이동 경로 표시나 「..」을 사용합니다.
  • 이미지 파일을 클릭하면 미리보기가 열리고, 그대로 다음 이미지로 넘길 수 있습니다.
  • 텍스트 파일을 클릭하면 내용이 바로 표시됩니다.
  • 동영상이나 음성 파일을 클릭하면 그 자리에서 재생됩니다. 앞뒤 파일로 전환하거나 새 탭에서 열 수도 있습니다. 브라우저에서 재생할 수 없는 형식이면 그 취지가 표시되며, 내려받아 재생할 수 있습니다.
  • PDF 파일을 클릭하면 새 탭에서 열립니다.
  • 파일별로 내려받을 수도 있습니다.
  • 너무 큰 파일은 미리보기할 수 없으며, 그 취지의 메시지가 표시됩니다.
힌트: 「ZIP 내용 탐색」은 ZIP 파일 기록을 선택했을 때만 메뉴에 표시됩니다. 다른 기록에서는 표시되지 않습니다.

기록을 작업으로 만들기·내용 복사하기

「나중에 대응하고 싶은」 기록은 내용을 고쳐 쓰지 않아도 그대로 작업으로 만들 수 있습니다. 기록의 컨텍스트 메뉴에서 「작업으로 만들기」를 선택하고 보드 이름·기한·시작 예정·종료 예정을 설정해 저장하세요. 만든 작업은 작업 화면에도 나열되며 완료 체크를 붙일 수 있습니다.

컨텍스트 메뉴에서 「내용 복사」를 선택하면 그 기록의 본문을 클립보드에 복사할 수 있습니다. 「ID 복사」에서는 기록의 ID를 복사할 수 있습니다.

GPS 지도 사용법

도구 모음의 지도 버튼을 켜면 기록 기간에 해당하는 GPS 이동 경로가 지도에 표시됩니다.

GPS 로그 업로드 순서

  1. "+" 버튼에서 "업로드"를 선택합니다.
  2. 업로드 대상으로 "GPS 기록용" 저장소（GPS 로그용 리포지토리）를 선택합니다.
  3. GPX 파일을 선택하여 업로드합니다. "여기에 .gpx 파일을 드롭하세요"라고 표시된 영역으로의 드래그 앤 드롭으로도 추가할 수 있습니다.
  4. 업로드 후 지도 버튼을 켜면 이동 경로가 표시됩니다.

Google Maps API 키 설정

지도 표시에는 Google Maps API 키가 필요합니다. 설정 화면（라이프로그 뷰 도구 모음 "설정" → "표시 설정"）의 "Google Maps API 키"에 API 키를 입력하고 저장하세요.

팁: Google Maps API 키는 Google Cloud Console에서 발급받을 수 있습니다. Maps JavaScript API를 활성화한 키가 필요합니다.

저장한 검색 조건 불러오기

설정 화면의 「검색 조건」에서 이름을 붙여 저장한 검색 조건은 사이드바 오른쪽 아래의 둥근 버튼에서 불러올 수 있습니다. 이름을 선택하면 해당 조건이 사이드바에 그대로 반영됩니다. 하나도 저장하지 않았을 때는 버튼 자체가 표시되지 않습니다.

현재 검색 조건 공유하기

설정 화면에서 "공유 푸터 표시"를 켜면 사이드바 아래쪽에 공유 푸터가 표시됩니다. 왼쪽 끝의 "공유" 버튼을 누르면 지금 좁혀 놓은 검색 조건이 그대로 공유 링크가 됩니다. 공유되는 것은 기록 한 건이 아니라 그 조건에 해당하는 기록 전체입니다. 이미 만든 링크는 오른쪽 끝의 "공유 관리"에서 목록 확인, 편집, 삭제할 수 있습니다.
