포트

하나의 화면에서 모든 조작을 창으로 열 수 있는 화면입니다.

포트는 배경과 「+」 버튼만 있는 화면입니다. 「+」에서 라이프로그 뷰, 작업, 진행 중, 대시보드를 창으로 열면 화면을 전환하지 않고 나란히 사용할 수 있습니다. 창은 끌어서 옮기고, 오른쪽 아래를 잡으면 크기를 바꿀 수 있습니다. 위치와 크기는 다음에 열 때도 남습니다.

기록 추가는 같은 메뉴의 「기록」 그룹에서 합니다. 메모장, 타각 메모장, 수치 기록, 북마크, 타각장, 작업, 지출, 기분, 업로드, 클립보드 저장이 있습니다.

사용 구분 팁: 추가만 하고 싶을 때는 허브, 여러 화면을 오가며 작업할 때는 포트를 사용하세요. 포트는 제목을 클릭해 다른 화면으로 이동할 수도 있습니다.

툴바 버튼

버튼 설명
도움말 현재 화면의 도움말을 표시합니다.
설정 설정 화면을 엽니다.

「+」 버튼

화면 오른쪽 아래의 「+」 버튼을 누르면 두 그룹으로 나뉜 메뉴가 나옵니다.

그룹 설명
화면 라이프로그 뷰 / 작업 / 진행 중 / 대시보드를 창으로 엽니다. 같은 화면을 여러 개 나란히 열 수도 있지만 개수 제한이 있으며, 제한에 도달하면 맨 앞으로 가져오기만 합니다.
기록 해당 기록을 추가하는 창을 엽니다.

창 닫기

창 오른쪽 위의 「×」, Escape 키, 브라우저의 「뒤로」 중 어느 것으로도 닫을 수 있습니다. 닫히는 것은 가장 앞에 있는 창입니다.
