타임스탬프 메모장

메모 입력과 진행 중인 타임스탬프를 동시에 표시하는 하이브리드 화면입니다. 메모 기록과 시간 측정을 하나의 화면에서 효율적으로 관리할 수 있습니다.

툴바 버튼

버튼 설명
⚙ 설정 애플리케이션 설정 화면을 엽니다.
❔ 도움말현재 화면의 도움말을 표시합니다.

화면 레이아웃

영역 설명
상단: 메모장 입력 영역 메모장 화면과 동일한 텍스트 입력 영역입니다. 메모장 구문으로 데이터를 입력하고 템플릿 삽입 및 저장을 할 수 있습니다.
하단: 실행 중인 타임스탬프 목록 현재 활성화된 타임로그 세션 목록이 표시됩니다. 각 세션의 정지 조작도 여기에서 할 수 있습니다.

주요 특징

  • 자동 갱신: 메모장 입력으로 기록을 저장하면 하단의 타임스탬프 목록이 자동으로 갱신됩니다. 새로 시작한 타임스탬프가 즉시 목록에 반영됩니다.
  • 동시 조작: 메모를 작성하면서 진행 중인 타임스탬프를 확인하고 정지할 수 있습니다.
  • 메모장 연동: 메모장 구문으로 타임스탬프의 시작·정지를 기술하면 아래 목록에 실시간으로 반영됩니다.

조작 절차

  1. 상단의 텍스트 영역에 메모장 구문으로 기록을 입력합니다.
  2. 저장 버튼으로 기록을 전송합니다.
  3. 타임스탬프의 시작을 기술한 경우 하단 목록에 새 세션이 표시됩니다.
  4. 하단 목록에서 진행 중인 세션을 정지할 수 있습니다.
팁: 일상적인 기록에는 이 화면이 가장 효율적입니다. 메모를 작성하면서 작업 시간도 관리할 수 있습니다.
팁: 상단의 메모장 입력은 메모장 화면과 동일한 기능을 가지고 있습니다. 템플릿도 이용할 수 있습니다.
