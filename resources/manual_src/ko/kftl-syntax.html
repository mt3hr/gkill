메모장 구문 레퍼런스

메모장 구문은 gkill에서 사용하는 텍스트 기반 기록 형식입니다. 줄 앞에 접두사를 붙여 다양한 유형의 데이터를 한 번에 입력할 수 있습니다. 아래에 전체 19가지 문 유형을 소개합니다.

각 문 유형 상세

1. 메모 (접두사 없음)

접두사가 없는 줄은 메모 텍스트가 됩니다. 연속된 여러 줄은 하나의 메모로 합쳐집니다.

오늘 날씨가 좋았다
산책을 갔다

2. 태그: #

줄 앞에 #를 붙여 태그를 지정합니다. 여러 태그는 ,로 구분합니다.

#일기,날씨

아직 한 번도 사용한 적이 없는 태그 이름을 적고 저장하려고 하면 「새로운 태그입니다. 추가하시겠습니까?」라고 확인합니다. 오타로 비슷한 태그가 늘어나는 것을 막기 위한 확인입니다.

3. 텍스트 블록: --

--로 시작하고 --로 끝냅니다. 사이의 내용은 그대로 유지됩니다.

--
이것은
여러 줄
텍스트 블록입니다
--

4. 구분자: ,

새로운 레코드로 분할합니다. 이 줄 이후의 내용은 새 레코드에 속합니다.

첫 번째 메모
,
두 번째 메모

5. 구분자(+1초): ,,

구분자와 동일하지만 타임스탬프가 1초 증가합니다.

첫 번째 메모
,,
1초 후 메모

6. 관련 시각: ?

관련 날짜/시간을 설정합니다. 형식: ?YYYY-MM-DD, ?YYYY-MM-DD HH:MM, ?YYYY-MM-DD HH:MM:SS

?2025-03-15 14:30
주의: 줄 시작 부분의 #은 태그, ?는 날짜/시간으로 해석됩니다. 일반 텍스트로 사용하려면 텍스트 블록 (--)으로 감싸주세요.

7. 수치 기록: /num

다음 줄에 제목, 그다음 줄에 수치를 입력합니다.

/num
체중
65.5

8. 작업: /mi

이후 줄에 제목, 보드 이름, 예상 시작 시각, 예상 종료 시각, 마감일을 입력합니다(제목 이외는 생략 가능).

지출과 마찬가지로 # 로 시작하는 태그 줄과 -- 텍스트 블록을 도중에 쓸 수 있습니다. 이 줄들은 항목의 자리를 소비하지 않습니다.

/mi
보고서 작성
업무
2025-03-20

9. 기분: /mood

다음 줄에 기분 값(정수 0-10)을 입력합니다.

/mood
7

11. 타임로그(전체): /timeis

이후 줄에 제목, 시작 시각, 종료 시각을 입력합니다.

/timeis
회의
2025-03-15 10:00
2025-03-15 11:30

12. 타임로그 시작: /start

다음 줄에 제목을 입력합니다. 시작 시각은 현재 시각(또는 이전에 ? 관련 시각으로 지정한 시각)이 사용됩니다.

/start
작업 시작

특정 시각에 시작하려면 관련 시각을 사전에 지정합니다.

?2025-03-15 09:00
/start
작업 시작

13. 타임로그 종료: /end

다음 줄에 제목을 입력합니다. 일치하는 시작된 타임로그를 찾아 종료합니다.

/end
작업 시작

14. 타임로그 종료(존재 시): /end?

타임로그 종료와 동일하지만 일치하는 타임로그가 없어도 오류가 발생하지 않습니다.

/end?
작업 시작

15. 태그로 타임로그 종료: /endt

다음 줄에 태그 이름을 입력합니다. 해당 태그가 있는 타임로그를 찾아 종료합니다.

/endt
업무

16. 태그로 타임로그 종료(존재 시): /endt?

태그로 타임로그 종료와 동일하지만 일치하는 타임로그가 없어도 오류가 발생하지 않습니다.

/endt?
업무

17. 북마크: /url

다음 줄에 URL, 그다음 줄에 제목을 입력합니다.

/url
https://example.com

18. 리포스트 작업: ~~

~~로 시작하여 ~~로 끝납니다. 바로 위에 쓴 기록을 내용을 다시 쓰지 않고 그대로 작업으로 만듭니다. 제목 줄은 없습니다(원래 기록이 그대로 표시됩니다). 블록 안에는 보드 이름, 시작 예정 일시, 종료 예정 일시, 마감일을 순서대로 적습니다(모두 생략 가능). 날짜 앞에 ?를 붙이면 오류가 됩니다. #으로 시작하는 줄은 작업 자체의 태그가 되며, 보드 이름 앞이나 뒤 어느 쪽에 써도 됩니다.

나중에 읽을 기사 메모
~~
#업무
장보기
2025-03-20

2025-03-22
~~

19. 반복: ??

??로 시작하여 ??로 끝납니다. 바로 위에 쓴 기록을 날짜를 바꿔 여러 번 만듭니다. 블록 안에는 다음 네 줄을 순서대로 적습니다. 3번째와 4번째 줄은 생략할 수 있습니다(먼저 ??로 닫으면 됩니다).

줄의미쓰는 법
1반복할 날짜(필수)daily / fri / mon,wed,fri / 6w fri / monthly 15 / 2nd fri / last fri
2횟수 또는 종료일(필수)3 / 2026-12-31
3같은 기록이 이미 있어도 추가할지(생략 가능, 기본 no)no / yes
4언제부터 시작할지(생략 가능, 기본 현재)2026-09-12 / 9/12 18:00

이 예는 다음 금요일부터 매주 18:00의 「주간 보고」 작업을 3건 만듭니다. 기록이 가진 일시는 모두 같은 일수만큼 이동하므로 시작·종료·마감 사이의 간격은 그대로 유지됩니다. 일시를 하나도 적지 않은 작업에는 사용할 수 없습니다(반복된 날짜를 넣을 곳이 없기 때문입니다).

3번째 줄의 기본값이 no이므로 같은 내용을 다시 저장해도 늘어나지 않습니다. 저장에 실패하면 아무것도 만들어지지 않으므로, 같은 내용을 그대로 다시 저장하세요.

주의: 존재하지 않는 날짜는 건너뜁니다(monthly 31은 2월을, 5th fri는 다섯째 금요일이 없는 달을 건너뜁니다). 기록 시작(/start)과 기록 종료(/end, /end?, /endt, /endt?)에는 사용할 수 없습니다. 한 번의 저장으로 만들 수 있는 것은 1000건까지입니다.

20. 저장: !

문서를 종료하고 저장 처리를 실행합니다.

「!」 줄 자체는 값의 줄로 세지 않습니다. 예를 들어 /timeis 다음 줄에 「!」만 쓰면 제목이 없으므로 「내용이 없습니다」 오류가 되어 아무것도 저장되지 않습니다. 종류 줄의 다음 줄에 본문·숫자·제목을 쓴 뒤 「!」를 붙이세요.

내용이 없는 기록(본문 없는 메모, 제목 없는 작업, 가게 이름만 있는 지출, 값이 없는 숫자 기록), 붙일 대상이 없는 태그나 관련 시각, 읽을 수 없는 예정 일시는 저장하기 전에 줄별 오류로 표시됩니다(그 줄이 분홍색이 됩니다). 한 줄이라도 오류가 있으면 그 저장에서는 아무것도 기록되지 않습니다.

!
