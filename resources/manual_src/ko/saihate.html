허브 화면

잠금 화면에서도 안전하게 기록을 추가할 수 있는 화면입니다. 각종 기록을 빠르게 추가하기 위한 허브로 기능합니다.

허브에는 기록의 열람이나 편집 기능이 없고, 추가에 특화되어 있습니다. 실수로 기존 기록을 변경할 걱정이 없습니다. 인증된 세션 안에서 작동하므로 로그인 중에만 이용할 수 있습니다.

화면 사용 가이드: 빠르게 메모나 타임 기록을 남기고 싶을 때는 허브, 기록을 돌아보거나 검색하고 싶을 때는 라이프로그 뷰, 텍스트 입력으로 일괄 기록하고 싶을 때는 메모장을 사용하세요.

툴바 버튼

버튼 설명
🔄 새로고침 데이터를 다시 읽어 들입니다. 길게 누르기: 강제 새로고침을 실행합니다.
로그아웃 로그아웃합니다.
❔ 도움말 현재 화면의 도움말을 표시합니다.

플로팅 액션 버튼(+)

화면 오른쪽 아래의 "+" 버튼을 탭하면 각종 기록의 추가 메뉴가 표시됩니다.

메뉴 항목 내용 설명
메모장 텍스트 입력 메모장 구문으로 메모와 각종 기록을 입력하는 화면을 엽니다.
타임 기록 메모장 텍스트＋타임 기록 메모 입력과 진행 중인 타임 기록을 동시에 관리하는 화면을 엽니다.
수치 기록 수치를 기록 임의의 수치 데이터를 기록합니다.
북마크 URL을 기록 웹 페이지의 URL을 북마크로 저장합니다.
타임 트래커 시간 측정을 시작 새 타임 기록 세션을 시작합니다.
작업 작업을 추가 새 작업을 만듭니다.
지출 금액을 기록 지출 금액과 내용을 기록합니다.
기분 기분값(0~10)을 기록 현재 기분을 0~10의 수치로 기록합니다.
업로드 파일을 업로드 이미지나 문서 등의 파일을 업로드하여 기록합니다.
길게 누르기: "+" 버튼을 길게 누르면 메모장이 바로 열립니다. 빠르게 메모하고 싶을 때 편리합니다.
힌트: 로그인 후 처음 표시되는 화면은 설정 화면의 "시작 시 기본 화면"에서 변경할 수 있습니다.
단축키: 이 화면에서 Enter 키를 누르면 메모장 대화상자가 열립니다. 빠르게 기록을 추가하고 싶을 때 편리합니다.
