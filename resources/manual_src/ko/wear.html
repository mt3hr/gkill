시계(Wear OS)

Wear OS 시계(Pixel Watch 등)에서 메모장 템플릿으로 기록하거나, 진행 중인 타임 기록을 끝내거나, 기분을 기록할 수 있습니다. 시계 쪽 앱 「gkill wear」와 스마트폰 쪽 설정 앱 「gkill wear 설정」 두 가지를 사용합니다. 기록은 스마트폰이 중계하여 서버로 보내므로, 스마트폰이 가까이 있고 시계와 페어링되어 있어야 합니다.

준비물

  • 스마트폰과 페어링된 Wear OS 시계
  • 스마트폰에서 접속할 수 있는 gkill 서버(집 PC에서 실행 중이라면 서버 설정에서 다른 기기의 접속을 허용해 둡니다)
  • gkill의 사용자 ID와 비밀번호

스마트폰 쪽 설정

  1. 스마트폰에 「gkill wear 설정」을 설치하고 엽니다.
  2. 서버 URL·사용자 ID·비밀번호를 입력하고 「저장 및 연결 테스트」를 누릅니다.
  3. 자체 서명 HTTPS 서버에 연결할 때는 「자체 서명 인증서 허용」을 켭니다. 첫 연결 테스트에서 인증서 지문이 표시되므로 자기 서버의 것인지 확인하고 「신뢰하고 저장」을 누릅니다(짐작 가는 것이 없으면 「거부」하세요).
  4. 「연결 성공」이 표시되면 설정 완료입니다. 시계 쪽 설정은 없습니다.
http:// 로 연결할 수 있는 것은 스마트폰 자신(localhost)뿐입니다. 집 안이나 외부 서버에는 https:// 를 사용하세요.

시계에서의 사용법

시계의 타일 또는 앱 「gkill wear」를 열면 세 가지 입구가 있습니다.

입구 할 수 있는 일
📝 기록 메모장 템플릿을 골라 기록합니다. 템플릿은 설정 화면의 「메모장 템플릿」에서 편집한 것이 나열됩니다(처음에는 스마트폰을 통해 가져오고 이후에는 캐시에서 표시합니다. 「🔄 새로고침」으로 다시 가져올 수 있습니다).
▶ 진행 중 지금 측정 중인 타임 기록을 나열합니다. 하나를 고르면 「종료할까요?」라고 확인하고 종료 시각을 기록합니다.
⭐️ 기분 별 다섯 개로 기분을 기록합니다. 별의 왼쪽 반·오른쪽 반으로 0.5 단위(1~10)를 고를 수 있으며 웹의 기분 기록과 같은 값이 됩니다.

표시 언어

시계와 스마트폰 화면의 문구는 기기의 언어 설정에 맞춰 7개 언어(일본어·영어·중국어·한국어·스페인어·프랑스어·독일어)로 표시됩니다. 시계의 언어를 바꾸면 타일도 자동으로 다시 그려집니다.

같은 내용을 연달아 보냈을 때

직전에 같은 내용을 보냈다면 「같은 내용이 방금 저장되었습니다. 그래도 전송할까요?」라고 확인합니다. 통신 재전송으로 이중 등록되는 것을 막기 위한 것입니다. 일부러 같은 기록을 남기고 싶다면 「그래도 전송」을 고르세요.

잘 되지 않을 때

표시 대처
스마트폰에 연결할 수 없습니다 시계와 스마트폰의 페어링을 확인합니다. 스마트폰의 Bluetooth가 꺼져 있지 않은지도 확인하세요.
스마트폰의 응답이 시간 초과되었습니다 스마트폰에서 「gkill wear 설정」을 열고 「저장 및 연결 테스트」로 연결을 확인합니다. 서버가 멈추지 않았는지, URL이 바뀌지 않았는지도 확인하세요.
✕ 오류: 로그인에 실패했습니다 스마트폰의 설정 앱에서 사용자 ID와 비밀번호를 다시 입력합니다. 비밀번호를 바꾼 뒤에는 모든 기기에서 다시 로그인해야 합니다.
기록했는데 목록에 나오지 않음 시계에서 쓴 기록은 작성 앱이 「gkill wear」로 저장됩니다. 검색 조건에서 작성 앱이나 저장소를 좁히고 있다면 조건을 확인하세요.
