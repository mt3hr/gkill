저장소 관리

저장소는 gkill이 기록 데이터를 저장하는 디렉토리나 장소입니다. 용도（텍스트 메모용, 파일용, GPS 로그용 등）와 단말기별로 여러 저장소를 설정할 수 있습니다.

저장소 설정은 계정 관리 화면의 "저장소 할당 버튼"을 통해 각 사용자별로 수행합니다.

저장소 추가

  1. 계정 관리 화면을 열고 대상 사용자의 "저장소 할당 버튼"을 누릅니다.
  2. "추가" 버튼을 눌러 새 저장소를 추가합니다.
  3. 다음 항목을 설정합니다:
    • 표시 이름: 라이프로그 뷰와 필터에 표시되는 이름
    • 유형: 저장할 데이터의 종류. 드롭다운에는 kmemo나 timeis 같은 영숫자 이름이 나열됩니다. 어느 것이 무엇을 가리키는지는 아래 표를 참조하세요
    • 경로: 데이터를 저장하는 디렉토리 경로（파일 관리의 경우 glob 형식도 사용 가능）
    • 쓰기 대상으로 사용: 새 기록을 추가할 때 이 저장소에 저장할지 여부
    • 활성화: 이 저장소를 검색 및 표시 대상으로 할지 여부
  4. "저장" 버튼을 눌러 설정을 적용합니다.

유형 선택

유형 드롭다운에는 영숫자 이름이 나열됩니다. 각각 무엇을 저장하는지는 다음과 같습니다.

드롭다운의 표시저장되는 것
kmemo메모
timeis타임스탬프(시간의 기록)
mi작업
nlog지출
urlog북마크
lantana기분
kc숫자 기록
directory업로드한 파일(이미지·동영상·문서 등)
gpslogGPX 형식의 GPS 로그
git_commit_logGit의 커밋 이력(읽기 전용)
rekyou리포스트(과거의 기록을 다시 흘려보낸 것)
mirekyou리포스트 작업(이미 있는 기록을 작업으로 만든 것)
tag기록에 붙인 태그
text기록에 붙인 보충 텍스트
notification기록에 붙인 알림(리마인더)
힌트: tag / text / notification / rekyou / mirekyou 는 기록 자체가 아니라 기록에 덧붙인 정보의 저장소입니다. 보통 초기 설정 때 자동으로 만들어지므로 나중에 추가할 필요는 없습니다.
힌트: 같은 유형의 저장소를 여러 개 추가할 수 있습니다. 예를 들어 단말기별로 텍스트 메모용 저장소를 분리하면 각 단말기의 데이터를 정리할 수 있습니다.
힌트: "쓰기 대상으로 사용"을 켠 저장소가 새 기록의 저장 대상이 됩니다. 같은 유형에 여러 저장소가 있는 경우 쓰기 대상으로 사용할 하나만 켜두세요.
