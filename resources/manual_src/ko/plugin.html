플러그인

플러그인을 넣으면 gkill 이외의 서비스에 남아 있는 기록도 gkill의 기록과 같은 목록에 나란히 볼 수 있게 됩니다. 「그날 무엇을 하고 있었는지」를 한곳에서 돌아볼 수 있도록 하기 위한 기능입니다.

사용할 수 있는 플러그인

기본으로 다음 3가지가 준비되어 있습니다.

플러그인 가져오는 내용
ChatGPT ChatGPT에서 내보낸 대화 기록
Claude.ai Claude.ai에서 내보낸 대화 기록
ClaudeCode Claude Code의 채팅 로그
힌트: 여기에 표시된 이름은 기록 목록의 사이드바에서 「저장소」로 좁힐 때도 사용됩니다. 플러그인의 기록만 보고 싶을 때는 이 이름으로 좁혀 주세요.

도입 방법

플러그인 도입은 파일을 놓는 작업입니다. 순서대로 진행해 주세요.

  1. 플러그인의 실행 파일을 gkill 홈 폴더 안의 plugins 폴더에 놓습니다. 놓는 위치는 plugins 아래에 「사용자 ID」「플러그인 이름」 순으로 폴더를 만든 안쪽입니다.
  2. gkill을 시작합니다. 플러그인이 처음 읽힐 때 같은 폴더에 설정 파일 config.json이 자동으로 만들어집니다.
  3. config.json을 텍스트 편집기로 열고, source_dirs에 가져오고 싶은 데이터가 들어 있는 폴더를 적습니다.
  4. 라이프로그 뷰에서 검색하면 다른 기록과 똑같이 목록에 표시됩니다.
힌트: 이미 config.json이 있는 경우 gkill이 그것을 덮어쓰는 일은 없습니다. 설정을 고쳐 써도 사라지지 않으니 안심하세요.

가져올 폴더를 적는 방법

source_dirs에는 폴더 경로도 파일 경로도 적을 수 있습니다. 규칙은 다음과 같습니다.

적는 방법 의미
~로 시작하는 경로 자신의 홈 폴더를 기준으로 한 위치를 나타냅니다
* ** ? [] 폴더 이름이나 파일 이름의 일부를 「무엇이든 좋음」으로 다룹니다
폴더를 지정한 경우 그 안을 아래 계층까지 찾아 대상 파일을 발견합니다
파일을 직접 지정한 경우 그 파일의 내용을 그대로 읽어 들입니다
비워 둔 경우 ChatGPT·Claude.ai는 플러그인의 폴더를, ClaudeCode는 Claude Code의 표준 저장 위치를 봅니다
힌트: config.json 안에서 _(밑줄)로 시작하는 항목은 적는 방법을 설명하기 위해 놓여 있을 뿐입니다. 지워도 상관없습니다.
힌트: config.json을 고쳐 쓴 뒤 gkill을 다시 시작할 필요는 없습니다. 다음에 검색할 때부터 새 설정으로 읽힙니다.

할 수 있는 것과 할 수 없는 것

플러그인이 가져온 기록은 읽기 전용입니다. 가져온 원본 데이터를 망가뜨리지 않도록 gkill 쪽에서 고쳐 쓸 수 없습니다.

조작 가능 여부
태그 추가 / 태그 기록에서 추가 가능합니다
텍스트 추가 가능합니다
알림 추가 가능합니다
리포스트 가능합니다
작업으로 만들기 가능합니다
내용 복사 / ID 복사 가능합니다
편집 불가능합니다(메뉴에 표시되지 않습니다)
삭제 불가능합니다(메뉴에 표시되지 않습니다)
힌트: 가져온 대화에 태그를 붙여 두면 나중에 라이프로그 뷰의 태그 좁히기로 찾을 수 있게 됩니다.

다시 가져오고 싶을 때

플러그인이 가져온 내용은 표시를 빠르게 하기 위해 저장되어 있습니다. 가져올 원본을 크게 바꿨을 때 등 전부 다시 읽어 들이고 싶은 경우에는 gkill을 정지한 뒤 다음 명령을 실행해 주세요.

gkill_server clear_cache plugin 사용자ID

다음에 gkill을 시작해서 검색하면 원본에서 다시 읽어 들입니다.

제대로 표시되지 않을 때

증상 확인할 것
기록이 하나도 나오지 않는다 source_dirs에 적은 폴더에 원본 파일이 실제로 있는지 확인해 주세요. 경로를 잘못 적은 것이 흔한 원인입니다.
설정 파일이 만들어지지 않는다 실행 파일을 놓은 위치가 올바른지 확인해 주세요. 폴더 이름은 「사용자 ID」「플러그인 이름」 순입니다.
내용이 옛날 그대로 바뀌지 않는다 위의 「다시 가져오고 싶을 때」 절차로 다시 읽어 들여 주세요.
「플러그인 콘텐츠 가져오기에 실패했습니다」라고 표시된다 플러그인의 실행 파일이 시작되지 못했을 가능성이 있습니다. 실행 파일이 손상되지 않았는지, 실행할 권한이 있는지 확인해 주세요.
팁: 기록을 길게 누르거나(모바일) 오른쪽 클릭하여(데스크톱) “플러그인 설정”을 선택하면 해당 플러그인의 설정 화면이 열립니다. 가져올 폴더를 여기서 변경하고 저장할 수 있습니다. 플러그인 폴더의 config.json을 직접 편집해도 됩니다.
