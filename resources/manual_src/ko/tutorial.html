튜토리얼

gkill 사용법을 기본편과 응용편으로 나누어 설명합니다. 처음 사용하시는 분은 기본편부터 순서대로 읽어주세요.

이 대화 상자에 대해: 이 도움말 대화 상자는 마우스 클릭과 터치 조작이 뒤에 있는 화면으로 투과됩니다. 대화 상자를 표시한 상태에서 뒤에 있는 화면을 조작하며 실제로 시도해 볼 수 있습니다.
스마트폰에서 사용: gkill은 PWA(Progressive Web App)로 작동합니다. 브라우저 메뉴에서 "홈 화면에 추가"(iOS Safari) 또는 "앱 설치"(Android Chrome)를 선택하면 홈 화면에서 네이티브 앱처럼 바로 실행할 수 있습니다.

용어에 대해

gkill에서 데이터의 종류를 "기록 유형"(메모, 타임스탬프, 태스크 등), 조작하는 화면을 "화면명"(메모장, 타임스탬프 메모장, 태스크 등)이라고 합니다. 예를 들어 "메모"는 텍스트 메모라는 기록의 종류를 가리키고, "메모장"은 그 기록을 입력하기 위한 화면을 가리킵니다. "+" 버튼 메뉴에 표시되는 "메모장", "타임스탬프" 등은 각 기록을 추가하기 위한 화면명입니다.

화면 전환 방법

화면 상단 툴바에 표시된 페이지 제목(예: "라이프로그 뷰", "태스크" 등)을 탭하면 드롭다운 메뉴가 열려 각 화면으로 이동할 수 있습니다.

기본편

1. gkill에 로그인하기

최초 실행 시

gkill을 처음 실행하면 계정 등록 화면이 자동으로 표시됩니다.

  1. 사용자 ID를 입력합니다 (이것이 계정 이름이 됩니다).
  2. 비밀번호를 입력하고, 확인을 위해 한 번 더 입력합니다.
  3. 관리자 비밀번호를 입력하고 확인을 위해 한 번 더 입력합니다 (자동 생성된 admin 계정의 비밀번호이며, 서버 관리에 사용됩니다).
  4. "등록" 버튼을 누르면 계정이 생성됩니다.
  5. 로그인 화면으로 리다이렉트되므로, 생성한 계정으로 로그인합니다.

일반 로그인

  1. 사용자 ID 입력란에 계정의 사용자 ID를 입력합니다.
  2. 비밀번호 입력란에 비밀번호를 입력합니다.
  3. "로그인" 버튼을 클릭하거나 Enter 키를 누릅니다.
힌트: 로그인 후 세션은 30일간 유효합니다. 기한이 만료될 때까지 재로그인이 필요 없습니다.

2. 기록 추가하기

gkill에서는 다양한 종류의 라이프로그를 기록할 수 있습니다. 화면 오른쪽 하단의 "+" 버튼으로 기록을 추가합니다.

기록 유형용도입력 예
메모텍스트 메모를 남기기"오늘은 날씨가 좋았다"
타임스탬프시간 기록 (시작/종료)"회의 10:00~11:30"
태스크해야 할 일을 관리하기"보고서 작성하기"
지출지출 내역을 기록하기"편의점: 삼각김밥 1500원"
기분기분을 0~10 수치로 기록"7"
수치 기록수치 데이터를 기록하기"체중: 65.5"
북마크URL을 저장하기"https://example.com"
파일이미지나 파일 업로드사진, PDF 등
클립보드 저장클립보드 내용을 파일로 저장스크린샷, 복사한 이미지 등

기록 추가 절차

  1. 화면 오른쪽 하단의 "+" 버튼을 탭합니다.
  2. 추가하려는 기록 유형을 선택합니다.
  3. 입력 폼에 내용을 기입합니다.
  4. "저장" 버튼을 눌러 기록을 저장합니다.
힌트: 메모장 화면을 사용하면 여러 기록을 텍스트로 한꺼번에 일괄 입력할 수 있습니다. 자세한 내용은 이후의 "3. 메모장으로 여러 기록을 한꺼번에 입력하기"를 참조하세요.

3. 메모장으로 여러 기록을 한꺼번에 입력하기

메모장 화면에서는 텍스트를 작성하는 것만으로 여러 기록을 한 번에 생성할 수 있습니다.

기본 사용법

  1. 메모장 화면을 엽니다 ("+" 버튼 메뉴에서 "메모장" 선택).
  2. 텍스트 영역에 기록하고 싶은 내용을 입력합니다.
  3. "저장" 버튼 (！을 입력하여 전송도 가능)을 누릅니다.

템플릿을 사용한 입력

템플릿을 사용하면 정형문을 원터치로 입력할 수 있습니다.

  1. 메모장 화면에서 템플릿 목록에서 템플릿을 선택합니다.
  2. 템플릿 내용이 텍스트 영역에 삽입됩니다.
  3. 필요에 따라 내용을 편집하고 저장합니다.
힌트: 자주 사용하는 기록 패턴을 미리 템플릿으로 등록해 두면 편리합니다. 설정 화면의 "템플릿 구조"에서 관리할 수 있습니다.

4. 기록 확인 및 검색하기

라이프로그 뷰 화면에서 과거 기록을 목록 표시하고 검색할 수 있습니다.

기본 조작

  1. 화면 상단 내비게이션에서 라이프로그 뷰 화면을 엽니다.
  2. 기록이 날짜순으로 목록 표시됩니다.
  3. 날짜를 변경하여 특정 날의 기록을 확인할 수 있습니다.

검색과 필터링

  • 태그로 필터링: 특정 태그가 붙은 기록만 표시할 수 있습니다.
  • 날짜 범위: 시작일과 종료일을 지정하여 기간을 좁힐 수 있습니다.
  • 텍스트 검색: 키워드를 포함하는 기록을 검색할 수 있습니다.
힌트: 설정 화면의 "라이프로그 뷰 표시 일수"를 줄이면 로딩이 빨라집니다.

5. 태스크 관리하기

태스크 화면에서는 칸반 보드 형식으로 태스크를 관리할 수 있습니다.

태스크 생성

  1. 태스크 화면을 엽니다.
  2. "+" 버튼으로 태스크를 추가합니다.
  3. 제목, 보드 이름, 기한 등을 입력합니다.
  4. 저장하면 지정한 보드에 태스크가 표시됩니다.

태스크 완료

  1. 완료한 태스크를 탭하여 상세 정보를 엽니다.
  2. 체크 표시를 하여 태스크를 완료 처리합니다.
힌트: 보드를 여러 개 만들어 "업무", "개인", "쇼핑" 등 카테고리별로 관리하면 정리하기 쉬워집니다.

이미 있는 기록을 작업으로 만들기

「이거 나중에 해야지」라고 생각한 기록은 굳이 작업을 새로 쓰지 않아도 그대로 작업으로 만들 수 있습니다.

  1. 라이프로그 뷰 등에서 대상 기록을 길게 누르거나(모바일) 오른쪽 클릭합니다(데스크톱).
  2. 「작업으로 만들기」를 선택합니다.
  3. 보드 이름·기한·시작 예정·종료 예정을 설정해 저장합니다.
  4. 작업 화면의 보드에 나열되어 보통의 작업과 똑같이 체크를 붙일 수 있습니다.
힌트: 이 방법으로 만든 작업에는 제목 칸이 없습니다. 원래 기록의 내용이 그대로 표시되기 때문입니다. 원래 기록을 삭제하면 거기서 만든 작업도 함께 삭제되므로 주의하세요.

6. 설정 변경하기

설정 화면에서 애플리케이션의 동작을 커스터마이즈할 수 있습니다.

설정 화면 열기

  1. 화면 상단 툴바에 있는 톱니바퀴 아이콘을 탭합니다.
  2. 설정 화면이 열립니다.

자주 사용하는 설정

설정 항목설명
언어UI 표시 언어를 변경합니다.
다크 테마어두운 색상으로 전환합니다.
시작 화면로그인 후 처음 표시할 페이지를 선택합니다.
라이프로그 뷰 이미지 열 수이미지 썸네일의 열 수를 조정합니다.
힌트: 설정을 변경한 후 "적용" 버튼을 눌러주세요. "취소"를 누르면 변경 사항이 폐기됩니다.

8. 템플릿 활용하기

자주 사용하는 메모장 구문 패턴을 템플릿으로 저장해 두면 매번 입력하는 수고를 줄일 수 있습니다.

템플릿 관리

  1. 설정 화면을 엽니다.
  2. "템플릿 구조" 버튼을 클릭합니다.
  3. 템플릿의 추가, 편집, 삭제가 가능합니다.

템플릿 작성 예

예를 들어, 매일의 일기 템플릿을 작성하는 경우:

。일기
、
ーら

이 템플릿을 사용하면 메모장 화면에서 원터치로 일기 양식이 입력되어, 메모 내용과 기분 수치만 추가하면 기록할 수 있습니다.

힌트: 폴더를 사용하여 템플릿을 카테고리별로 정리하면 찾기 쉬워집니다.

9. 타임스탬프로 시간 기록하기

화면명 용도
타임스탬프 메모장 타임스탬프와 함께 메모를 입력하는 화면. 파일 업로드도 가능합니다.
진행 중 현재 활성화된 타임스탬프 세션 목록. 세션 종료 조작이 가능합니다.
메모장 메모장 구문을 사용하여 텍스트로 타임스탬프 시작/종료를 입력. 다른 기록과 일괄 입력이 가능합니다.

타임스탬프 기능을 사용하면 작업 시간이나 활동 시간을 정확하게 기록할 수 있습니다. "타임스탬프 메모장"은 메모 입력과 진행 중인 세션 관리를 동시에 수행하는 전용 화면이며, "메모장" 화면에서는 타임스탬프 접두사를 사용하여 다른 기록과 함께 일괄 입력할 수 있습니다.

타임스탬프 기본 조작

  1. 시작: 메모장에서 ーた 접두사를 사용하거나, "+" 메뉴에서 타임스탬프를 추가합니다. 제목과 시작 시각을 지정합니다.
  2. 종료: 메모장에서 ーえ 접두사를 사용하거나, 타임스탬프 편집 화면에서 종료 시각을 입력합니다. 제목이 일치하는 타임스탬프가 종료됩니다.

진행 중인 타임스탬프 관리

타임스탬프 목록 화면에서 현재 진행 중인 타임스탬프를 확인할 수 있습니다.

  • 진행 중인 타임스탬프가 목록으로 표시됩니다.
  • 탭하여 종료 시각을 설정할 수 있습니다.
힌트: 메모장 구문의 ーいえ를 사용하면 일치하는 타임스탬프가 없어도 오류가 발생하지 않습니다. 존재 확인 없이 안전하게 종료할 수 있습니다.

10. 집계 뷰로 데이터 분석하기

라이프로그 뷰 화면 내의 집계 뷰에서는 기록한 데이터를 집계표로 시각화할 수 있습니다.

집계 뷰 사용법

  1. 라이프로그 뷰 화면의 도구 모음에 있는 집계 아이콘을 클릭하여 집계 뷰를 표시합니다.
  2. 집계 종류나 기간을 선택합니다.
  3. 데이터가 집계표로 표시됩니다.

집계 설정

설정 화면의 "집계 뷰" 버튼에서 집계 방법이나 뷰 구성을 관리할 수 있습니다.

힌트: 기분 수치나 지출 데이터의 추이를 시계열로 확인하면 생활 패턴을 파악할 수 있습니다.

11. 외부 연동 활용하기

북마클릿으로 URL 기록

브라우저의 북마크 바에 북마클릿을 등록하면, 열람 중인 웹 페이지를 원클릭으로 gkill에 저장할 수 있습니다.

  1. 설정 화면의 "북마클릿"에 표시된 URL을 복사합니다.
  2. 브라우저의 북마크 바에 새 북마크로 등록합니다.
  3. 저장하고 싶은 웹 페이지를 열고 있을 때, 등록한 북마크를 클릭합니다.

GPS 기록과 지도 표시

GPS 로그를 기록하고 있는 경우, 지도 위에 이동 이력을 표시할 수 있습니다.

  1. 설정 화면에서 "Google Map API 키"를 설정합니다.
  2. GPS 데이터가 기록되어 있으면, 라이프로그 뷰에서 지도 표시를 이용할 수 있습니다.
힌트: Google Map API 키는 Google Cloud Console에서 Maps JavaScript API를 활성화하여 취득하세요.

플러그인으로 외부 서비스의 기록 가져오기

플러그인을 넣으면 gkill 이외의 서비스에 남아 있는 기록도 같은 목록에 나란히 볼 수 있게 됩니다. 기본으로 ChatGPT·Claude.ai·Claude Code 3가지가 준비되어 있습니다.

  1. 플러그인의 실행 파일을 정해진 폴더에 놓습니다.
  2. gkill을 시작하면 같은 폴더에 설정 파일이 자동으로 만들어집니다.
  3. 설정 파일에 가져오고 싶은 데이터가 들어 있는 폴더를 적습니다.
  4. 라이프로그 뷰에서 검색하면 다른 기록과 나란히 표시됩니다.
힌트: 자세한 순서는 플러그인을 참조하세요.

12. 기록 공유하기

gkill에서는 지금 좁혀 놓은 검색 조건을 그대로 공유 링크로 만들어 다른 사람에게 보여줄 수 있습니다. 공유되는 것은 기록 한 건이 아니라 그 검색 조건에 해당하는 기록 전체입니다.

공유 링크 생성 절차

  1. 설정 화면에서 "공유 푸터 표시"를 켭니다. 기본값은 꺼짐이므로 처음에 한 번만 필요합니다.
  2. 라이프로그 뷰 또는 태스크 화면에서 사이드바를 엽니다. 사이드바 아래쪽에 공유 푸터가 표시됩니다.
  3. 공유하고 싶은 내용이 될 때까지 사이드바에서 필터 조건을 조정합니다.
  4. 공유 푸터 왼쪽 끝의 "공유" 버튼을 누르고 제목과 공유 화면 유형, 포함할 데이터를 정한 뒤 저장합니다.
  5. 공유 URL이 생성됩니다. 용도에 따라 적절한 URL을 사용하세요:
URL 유형용도
로컬같은 기기 내 접속 (localhost)
LAN 내부같은 네트워크 내 다른 기기에서 접속
글로벌인터넷을 통한 외부 접속

공유 데이터 제어

공유 시 포함할 데이터를 선택할 수 있습니다.

옵션설명
태그기록에 붙은 태그를 공유에 포함
텍스트기록의 텍스트 내용을 공유에 포함
타임스탬프타임스탬프 시간 정보를 공유에 포함
위치 정보GPS 위치 정보를 공유에 포함
시간만기록의 시간 정보만 공유에 포함
힌트: LAN 내부 URL이나 글로벌 URL을 사용하려면 서버 설정에서 서버 주소를 설정해야 합니다. 이미 만든 공유 링크는 공유 푸터 오른쪽 끝의 "공유 관리"에서 목록 확인, 편집, 삭제할 수 있습니다.

공유 링크를 받은 분께

공유 링크를 열면 gkill 계정이 없어도 기록을 열람할 수 있습니다.

  • 표시되는 기록의 범위는 링크를 만든 사람의 설정에 따라 결정됩니다.
  • 기록의 편집이나 삭제는 할 수 없습니다 (열람만 가능).
  • 링크가 유효하지 않은 경우 보낸 사람에게 확인해 주세요.

13. 데이터 백업과 관리

서버 설정 (관리자용)

관리자 계정으로 로그인하면, 설정 화면에 "서버 설정" 버튼이 표시됩니다.

  • 포트 번호: 서버가 수신 대기하는 포트를 변경할 수 있습니다 (기본값: 9999).
  • TLS 설정: HTTPS 통신을 활성화할 수 있습니다.
  • 접근 제한: 로컬 접근만 허용하도록 제한할 수 있습니다.

계정 관리

관리자는 "계정 관리" 화면에서 사용자 계정의 추가, 활성화 및 비활성화가 가능합니다.

데이터 백업

gkill의 데이터는 모두 홈 디렉터리 (기본값: ~/gkill, Android 앱에서는 /sdcard/gkill)에 저장되어 있습니다. 이 디렉터리를 백업하면 모든 데이터를 보존할 수 있습니다.

힌트: 정기적으로 홈 디렉터리를 백업하는 것을 권장합니다. 특히 datas/와 configs/ 디렉터리가 중요합니다.
참고: 리포지토리 저장 위치는 홈 디렉터리 외부로도 설정할 수 있습니다. 외부 폴더에 둔 파일(외부 폴더에 둔 파일, Git 커밋 이력, 외부에 배치한 데이터베이스 등)을 사용하는 경우 홈 디렉터리만 복사하면 누락됩니다. 설정한 모든 리포지토리의 저장 위치도 함께 백업 대상에 포함하세요.
