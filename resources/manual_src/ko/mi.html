주요 기능

칸반 보드

작업은 보드(열)별로 분류되어 표시됩니다. 각 보드는 작업의 상태나 카테고리를 나타내며 작업의 진행 관리에 활용할 수 있습니다.

보드는 목록에서 고르기만 하는 것이 아니라 그 자리에서 새 이름을 입력해 만들 수도 있습니다. 아직 한 번도 사용한 적이 없는 보드 이름으로 저장하려고 하면 오타를 막기 위한 확인이 표시됩니다. 확인하고 저장하면 그 보드가 보드 목록에 추가됩니다.

사이드바(필터)

사이드바에서는 다음 필터 조건을 설정하여 작업을 좁힐 수 있습니다.

  • 텍스트 검색
  • 태그를 통한 필터
  • 기간 지정
  • 보드 선택

상세 패널

작업을 선택하면 상세 패널에 다음 정보가 표시됩니다.

  • 작업의 제목과 내용
  • 소속 보드
  • 기한 정보
  • 부여된 태그
  • 관련된 기록
팁: 기본으로 표시할 보드는 설정 화면의 "기본 작업 보드 이름"에서 변경할 수 있습니다.

이미 있는 기록을 작업으로 만들기

「나중에 대응하고 싶은」 기록은 내용을 고쳐 쓰지 않아도 그대로 작업으로 만들 수 있습니다. 라이프로그 뷰 등에서 기록을 길게 누르거나(모바일) 오른쪽 클릭하고(데스크톱) 「작업으로 만들기」를 선택하세요. 보드 이름·기한·시작 예정·종료 예정을 설정해 저장하면 이 화면의 보드에도 나열되어 보통의 작업과 똑같이 완료 체크를 붙일 수 있습니다.

이 방법으로 만든 작업에는 제목을 입력하는 칸이 없습니다. 원래 기록의 내용이 그대로 표시되기 때문입니다.

주의: 원래 기록을 삭제하면 거기서 만든 작업도 함께 삭제됩니다. 작업만 남겨 둘 수는 없습니다.
팁: 사이드바의 필터 조건을 조합하면 필요한 작업을 빠르게 찾을 수 있습니다.

FAB(플로팅 액션 버튼) "+"

화면 오른쪽 아래의 "+" 버튼을 탭하면 각종 기록 추가 메뉴가 표시됩니다.

메뉴 항목설명
메모장메모장 형식으로 텍스트 메모를 입력합니다.
타임스탬프 메모장메모 입력과 타임스탬프 목록의 하이브리드 화면을 엽니다.
수치 기록수치 데이터를 기록합니다.
북마크URL을 저장합니다.
타임로그새 타임로그 세션을 시작합니다.
작업새 작업을 추가합니다.
지출금액을 기록합니다.
기분기분값(0~10)을 기록합니다.
업로드파일을 업로드하여 기록합니다.
클립보드 저장클립보드 내용(이미지·텍스트·PDF 등)을 파일로 직접 저장합니다. 스크린샷이나 복사한 이미지를 빠르게 기록할 수 있습니다.
길게 누르기: "+" 버튼을 길게 누르면 메모장이 바로 열립니다. 빠르게 메모하고 싶을 때 편리합니다.
단축키: 이 화면에서 Enter 키를 누르면 메모장 대화상자가 열립니다. 빠르게 기록을 추가할 때 편리합니다.
단축키: Ctrl+V를 누르면 클립보드 내용을 파일로 직접 저장할 수 있습니다. 스크린샷이나 복사한 이미지를 빠르게 기록할 때 편리합니다.

저장한 검색 조건 불러오기

설정 화면의 「검색 조건」에서 이름을 붙여 저장한 작업용 검색 조건은 사이드바 오른쪽 아래의 둥근 버튼에서 불러올 수 있습니다. 이름을 선택하면 해당 조건이 사이드바에 그대로 반영됩니다. 하나도 저장하지 않았을 때는 버튼 자체가 표시되지 않습니다.

현재 검색 조건 공유하기

설정 화면에서 "공유 푸터 표시"를 켜면 사이드바 아래쪽에 공유 푸터가 표시됩니다. 왼쪽 끝의 "공유" 버튼을 누르면 지금 좁혀 놓은 검색 조건이 그대로 공유 링크가 됩니다. 공유되는 것은 기록 한 건이 아니라 그 조건에 해당하는 기록 전체입니다. 이미 만든 링크는 오른쪽 끝의 "공유 관리"에서 목록 확인, 편집, 삭제할 수 있습니다.
