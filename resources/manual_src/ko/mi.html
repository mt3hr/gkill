작업 화면

칸반 보드 형식으로 작업을 관리하는 화면입니다. 보드별로 작업을 분류하여 진행 상황을 시각적으로 파악할 수 있습니다.

주요 기능

칸반 보드

작업은 보드(열)별로 분류되어 표시됩니다. 각 보드는 작업의 상태나 카테고리를 나타내며 작업의 진행 관리에 활용할 수 있습니다.

보드는 목록에서 고르기만 하는 것이 아니라 그 자리에서 새 이름을 입력해 만들 수도 있습니다. 아직 한 번도 사용한 적이 없는 보드 이름으로 저장하려고 하면 오타를 막기 위한 확인이 표시됩니다. 확인하고 저장하면 그 보드가 보드 목록에 추가됩니다.

사이드바(필터)

사이드바에서는 다음 필터 조건을 설정하여 작업을 좁힐 수 있습니다.

  • 텍스트 검색
  • 완료 상태(미완료·완료·전체)
  • 정렬 순서(작성 일시·기한·시작 예정·종료 예정 등)
  • 태그를 통한 필터
  • 기간 지정(캘린더에서 날짜 범위를 고르고, 필요하면 시작 시각과 종료 시각도 지정할 수 있습니다. 시각 입력란은 안에 있는 「×」로 비울 수 있습니다. 기간 지정 자체를 해제할 때는 「지우기」를 누릅니다)
  • 보드 선택

상세 패널

작업을 선택하면 상세 패널에 다음 정보가 표시됩니다.

  • 작업의 제목과 내용
  • 소속 보드
  • 기한 정보
  • 부여된 태그
  • 관련된 기록

이미 있는 기록을 작업으로 만들기

「나중에 대응하고 싶은」 기록은 내용을 고쳐 쓰지 않아도 그대로 작업으로 만들 수 있습니다. 라이프로그 뷰 등에서 기록을 길게 누르거나(모바일) 오른쪽 클릭하고(데스크톱) 「작업으로 만들기」를 선택하세요. 보드 이름·기한·시작 예정·종료 예정을 설정해 저장하면 이 화면의 보드에도 나열되어 보통의 작업과 똑같이 완료 체크를 붙일 수 있습니다.

이 방법으로 만든 작업에는 제목을 입력하는 칸이 없습니다. 원래 기록의 내용이 그대로 표시되기 때문입니다.

주의: 원래 기록을 삭제하면 거기서 만든 작업도 함께 삭제됩니다. 작업만 남겨 둘 수는 없습니다.
팁: 기본으로 표시할 보드는 설정 화면의 "기본 작업 보드 이름"에서 변경할 수 있습니다.
팁: 사이드바의 필터 조건을 조합하면 필요한 작업을 빠르게 찾을 수 있습니다.

단축키: Ctrl+V를 누르면 클립보드 내용을 파일로 직접 저장할 수 있습니다. 스크린샷이나 복사한 이미지를 빠르게 기록할 때 편리합니다.

저장한 검색 조건 불러오기

설정 화면의 「검색 조건」에서 이름을 붙여 저장한 작업용 검색 조건은 사이드바 오른쪽 아래의 둥근 버튼에서 불러올 수 있습니다. 이름을 선택하면 해당 조건이 사이드바에 그대로 반영됩니다. 하나도 저장하지 않았을 때는 버튼 자체가 표시되지 않습니다.

현재 검색 조건 공유하기

설정 화면에서 "공유 푸터 표시"를 켜면 사이드바 아래쪽에 공유 푸터가 표시됩니다. 왼쪽 끝의 "공유" 버튼을 누르면 전달 방법을 고르는 화면이 나옵니다. "화면 공유"를 고르면 지금 좁혀 놓은 검색 조건이 그대로 공유 링크가 됩니다. 공유되는 것은 기록 한 건이 아니라 그 조건에 해당하는 기록 전체입니다. 이미 만든 링크는 오른쪽 끝의 "공유 관리"에서 목록 확인, 편집, 삭제할 수 있습니다.

현재 보드 내용을 HTML 파일로 전달하기

공유 링크는 이 앱이 실행되는 동안에만 볼 수 있습니다. 상대방이 아무것도 준비하지 않고 보게 하려면, 현재 열려 있는 보드 내용을 HTML 파일로 내보낼 수 있습니다. 받는 사람은 브라우저로 열기만 하면 읽을 수 있고, 파일 안에서 모두 완결되므로 이 앱과 통신하지 않습니다.

내보내는 순서

  1. 사이드바 하단의 공유 푸터에서 맨 왼쪽의 "공유" 버튼을 누릅니다(공유 푸터가 보이지 않으면 설정 화면에서 "공유 푸터 표시"를 켭니다).
  2. "HTML 내보내기"를 선택합니다.
  3. 무엇을 포함할지, 어떤 형식으로 내보낼지 선택합니다(아래 표).
  4. "내보내기"를 누르면 생성된 파일이 다운로드됩니다. 작업이나 이미지가 많으면 시간이 걸립니다.

선택할 수 있는 것

항목 설명
제목 내보낸 화면의 왼쪽 위에 표시할 제목(선택 사항)을 입력합니다.
대상 "표시된 모든 보드"와 "포커스된 보드" 중에서 선택합니다.
포함할 항목 태그, 텍스트, 알림, 타임 기록, 위치 정보, 플러그인 본문을 각각 포함할지 선택합니다.
화면 내보낸 파일 안에 검색 조건 사이드바를 남길지 선택합니다. 남긴 사이드바는 내보낸 작업 안에서만 좁힙니다.
미디어 이미지와 동영상을 "썸네일만", "원본도 포함", "포함하지 않음" 중에서 선택합니다. 파일당 및 전체 상한도 지정할 수 있습니다.
출력 형식 "HTML 파일 1개"는 파일 하나로 완결됩니다. "HTML과 같은 이름의 폴더"는 이미지 등을 옆 폴더에 나누어 두므로 파일 1개보다 가볍지만, 전달할 때는 둘을 함께 전달합니다("포함하지 않음"일 때는 "HTML 파일 1개"만 선택할 수 있습니다).
상한을 초과했을 때: 미디어 상한에 들어가지 못한 것은 내보낸 파일 안에서 "포함되지 않음"으로 표시됩니다. 빠진 것을 알 수 있으므로 필요하면 상한을 올려 다시 내보냅니다.

받는 사람에게 보이는 모습

내보낸 파일은 읽기 전용입니다. 작업 추가나 편집, 완료 체크, 보드 이동은 할 수 없습니다. 작업을 더블클릭하면 상세가 열리고 거기에서 관련 기록도 따라갈 수 있습니다. 검색 조건 사이드바를 남긴 경우 태그・완료 상태・보드・기간으로 좁힐 수 있지만, 문자 검색과 정렬 변경은 할 수 없습니다(내보낸 시점의 정렬로 고정됩니다).
