주요 기능

칸반 보드

작업은 보드(열)별로 분류되어 표시됩니다. 각 보드는 작업의 상태나 카테고리를 나타내며 작업의 진행 관리에 활용할 수 있습니다.

사이드바(필터)

사이드바에서는 다음 필터 조건을 설정하여 작업을 좁힐 수 있습니다.

  • 텍스트 검색
  • 태그를 통한 필터
  • 기간 지정
  • 보드 선택

상세 패널

작업을 선택하면 상세 패널에 다음 정보가 표시됩니다.

  • 작업의 제목과 내용
  • 소속 보드
  • 기한 정보
  • 부여된 태그
  • 관련된 기록
팁: 기본으로 표시할 보드는 설정 화면의 "기본 작업 보드 이름"에서 변경할 수 있습니다.
팁: 사이드바의 필터 조건을 조합하면 필요한 작업을 빠르게 찾을 수 있습니다.

FAB(플로팅 액션 버튼) "+"

화면 오른쪽 아래의 "+" 버튼을 탭하면 각종 기록 추가 메뉴가 표시됩니다.

메뉴 항목설명
메모장메모장 형식으로 텍스트 메모를 입력합니다.
타임스탬프 메모장메모 입력과 타임스탬프 목록의 하이브리드 화면을 엽니다.
수치 기록수치 데이터를 기록합니다.
북마크URL을 저장합니다.
타임로그새 타임로그 세션을 시작합니다.
작업새 작업을 추가합니다.
지출금액을 기록합니다.
기분기분값(0~10)을 기록합니다.
업로드파일을 업로드하여 기록합니다.
클립보드 저장클립보드 내용(이미지·텍스트·PDF 등)을 파일로 직접 저장합니다. 스크린샷이나 복사한 이미지를 빠르게 기록할 수 있습니다.
길게 누르기: "+" 버튼을 길게 누르면 메모장이 바로 열립니다. 빠르게 메모하고 싶을 때 편리합니다.
단축키: 이 화면에서 Enter 키를 누르면 메모장 대화상자가 열립니다. 빠르게 기록을 추가할 때 편리합니다.
단축키: Ctrl+V를 누르면 클립보드 내용을 파일로 직접 저장할 수 있습니다. 스크린샷이나 복사한 이미지를 빠르게 기록할 때 편리합니다.
