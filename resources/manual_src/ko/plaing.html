진행 중

현재 진행 중인 타임로그 세션을 목록으로 표시하는 화면입니다. 활성 시간 측정을 관리할 수 있습니다.

툴바 버튼

버튼 설명
⚙ 설정 애플리케이션 설정 화면을 엽니다.
❔ 도움말 현재 화면의 도움말을 표시합니다.

주요 기능

실행 중인 세션 목록

현재 활성화된 타임로그 세션이 목록 형식으로 표시됩니다. 각 세션에는 다음 정보가 포함됩니다.

  • 세션명(제목)
  • 시작 시각
  • 경과 시간

세션 정지

각 세션의 정지 버튼을 탭하면 해당 세션을 종료할 수 있습니다. 종료 시각이 자동으로 기록됩니다.

플로팅 액션 버튼("+")

화면 오른쪽 아래의 "+" 버튼을 탭하면 새 기록을 빠르게 추가할 수 있습니다.
