Écran de connexion

Écran d'authentification pour se connecter à gkill. Saisissez votre identifiant et votre mot de passe pour accéder à l'application.

Éléments de l'écran

Élément Description
Champ d'identifiant Saisissez l'identifiant de votre compte gkill.
Champ de mot de passe Saisissez le mot de passe du compte.
Bouton de connexion Lance la connexion avec les identifiants saisis.
Affichage de la version Le numéro de version actuel de gkill est affiché dans le coin supérieur droit de l'écran.

Procédure

  1. Saisissez l'identifiant de votre compte dans le champ d'identifiant.
  2. Saisissez votre mot de passe dans le champ de mot de passe.
  3. Cliquez sur le bouton « Connexion » ou appuyez sur Entrée pour vous authentifier.
  4. Une fois l'authentification réussie, vous arrivez sur l'écran par défaut défini dans les paramètres.
Astuce : Lors du premier lancement, l'écran d'inscription de compte s'affiche automatiquement. Suivez les instructions à l'écran pour créer votre compte utilisateur et définir le mot de passe administrateur.
Astuce : Une fois connecté, la session reste valable 30 jours. Vous n'avez pas besoin de vous reconnecter tant qu'elle n'a pas expiré.
Astuce : Vous pouvez aussi vous connecter avec la touche Entrée : il suffit de l'appuyer juste après avoir saisi le mot de passe.
En cas de problème : Si vous ne parvenez pas à vous connecter, vérifiez que votre identifiant et votre mot de passe sont corrects.
