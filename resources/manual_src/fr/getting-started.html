Premiers pas

gkill est une application permettant d'enregistrer et de consulter des journaux de vie quotidiens (life logs).

Ce que vous pouvez faire avec gkill

Type d'enregistrement Description
Mémo Enregistre des notes textuelles
Entrée de temps Enregistre le début et la fin d'une période de temps
Tâche Gère les choses à faire sur un tableau Kanban
Humeur Enregistre votre humeur avec une valeur de 0 à 10
Dépense Enregistre les montants et les détails des dépenses
Signet Enregistre l'URL de pages web
Enregistrement numérique Enregistre des données numériques arbitraires
Fichier Téléverse et enregistre des images ou des documents
Repost Fait réapparaître un ancien enregistrement dans la liste, à l'heure actuelle
Tâche de repost Ajoute une échéance et une case à cocher à un enregistrement existant pour le traiter comme une tâche
Notification Ajoute à un enregistrement un rappel à la date et à l'heure de votre choix
Journal GPS Importe des fichiers GPX et affiche le trajet sur une carte
Journal des commits Git Lit et affiche l'historique des commits du dépôt Git indiqué
Enregistrements des extensions Importe et affiche les enregistrements laissés dans des services autres que gkill

Comment démarrer

EnvironnementMéthode de lancement
WindowsExécuter gkill.exe ou gkill_server.exe
Navigateur / PWADémarrer gkill_server et accéder à http://localhost:9999 dans le navigateur
AndroidInstaller l'APK et lancer l'application. Au premier lancement, l'autorisation « Accès à tous les fichiers » est requise (les données sont stockées dans /sdcard/gkill)

Premier enregistrement de compte

  1. Lors du premier lancement de gkill, l'écran d'enregistrement de compte s'affiche automatiquement.
  2. Entrez un identifiant utilisateur (ce sera le nom de votre compte).
  3. Entrez un mot de passe, puis entrez-le à nouveau pour confirmer.
  4. Saisissez un mot de passe administrateur et confirmez-le (il s'agit du mot de passe du compte admin créé automatiquement, utilisé pour la gestion du serveur).
  5. Appuyez sur le bouton « Enregistrer » pour créer le compte.
  6. Vous êtes redirigé vers l'écran de connexion. Connectez-vous avec le compte que vous venez de créer.
Conseil : Le compte admin est créé automatiquement lors du premier démarrage du serveur. Cet écran définit le mot de passe administrateur du compte admin et crée en même temps votre compte utilisateur normal.

Après la connexion, l'écran par défaut (la Vue du journal de vie dans la configuration initiale) s'affiche. Configurez les paramètres de base, comme la langue ou le thème sombre, dans l'écran des paramètres.

Votre premier enregistrement en 60 secondes

  1. Connectez-vous.
  2. L'écran Vue du journal de vie s'affiche (dans la configuration initiale, la Vue du journal de vie s'ouvre juste après la connexion).
  3. Appuyez sur le bouton « + » en bas à droite de l'écran.
  4. Sélectionnez « Bloc-notes » dans le menu.
  5. Saisissez ce que vous souhaitez enregistrer dans la zone de texte (par exemple : J'ai mangé du curry au déjeuner aujourd'hui).
  6. Appuyez sur le bouton « Enregistrer » : l'enregistrement est créé et apparaît immédiatement dans la chronologie de la Vue du journal de vie.
Astuce : La méthode de base pour ajouter des enregistrements est d'utiliser le bouton « + » de l'écran Vue du journal de vie. Ce que vous avez enregistré se consulte directement dans la Vue du journal de vie. Consultez le Tutoriel pour plus de détails.
Astuce : Un appui sur le bouton « + » ouvre un menu ; un appui long ouvre directement le bloc-notes.
Astuce : L'écran Saihate est également disponible pour enregistrer depuis l'écran de verrouillage ou pour noter rapidement. Consultez l'aide de Saihate pour plus de détails.

Glossaire

Terme Description
Enregistrement Terme général désignant les données dans gkill. Il englobe tous les types d'enregistrement, comme les mémos, les entrées de temps et les tâches
Syntaxe du bloc-notes Syntaxe de saisie de texte utilisée dans le bloc-notes. En ajoutant des symboles à chaque ligne, vous pouvez créer différents types d'enregistrements en une seule fois
Entrée de temps Fonction de mesure du temps. Enregistre les heures de début et de fin d'un travail ou d'une activité
Saihate Écran permettant d'ajouter des enregistrements en toute sécurité même depuis l'écran de verrouillage. Il sert de point d'entrée pour ajouter les différents enregistrements
Vue du journal de vie Écran permettant de lister et rechercher des enregistrements
Vue d'agrégation Fonction qui affiche les agrégations et les statistiques des données
Informations associées Fonction qui recherche et affiche automatiquement les enregistrements associés
Dépôt Destination où sont enregistrées les données. Vous pouvez utiliser plusieurs dépôts selon les usages
Profil Ensemble de paramètres propres à chaque appareil utilisé, pour conserver la même configuration d'un appareil à l'autre
Tag Étiquette apposée sur un enregistrement. Un enregistrement peut en porter plusieurs ; elles servent de repère lors des recherches
Tâche de repost Un enregistrement existant rendu utilisable comme tâche sans le réécrire
Partage Fonction permettant de montrer les enregistrements choisis via un lien, même à des personnes sans compte gkill
Extension Fonction supplémentaire qui importe les enregistrements d'autres services que gkill et les affiche dans la liste
