Premiers pas

gkill est une application permettant d'enregistrer et de consulter des journaux de vie quotidiens (life logs).

Ce que vous pouvez faire avec gkill

Type d'enregistrement Description
Mémo Enregistre des notes textuelles
Horodatage Enregistre les heures de debut et de fin
Tâche Gere les tâches sur un tableau Kanban
Humeur Enregistre votre humeur avec une valeur de 0 a 10
Dépense Enregistre les montants et les détails des dépenses
Signet Sauvegarde des URLs de pages web
Enregistrement numérique Enregistre des données numériques arbitraires
Fichier Téléverse et enregistre des images ou des documents
Repost Remet un ancien enregistrement dans la liste à l'heure actuelle
Tâche de repost Ajoute une échéance et une case à cocher à un enregistrement existant pour le traiter comme une tâche
Notification Ajoute à un enregistrement un rappel à la date et à l'heure de votre choix
Journal GPS Importe des fichiers GPX et affiche le trajet sur une carte
Journal des commits Git Lit et affiche l'historique des commits du dépôt Git indiqué
Enregistrements des extensions Importe et affiche les enregistrements laissés dans des services autres que gkill

Premier enregistrement de compte

  1. Lors du premier lancement de gkill, l'écran d'enregistrement de compte s'affiche automatiquement.
  2. Entrez un identifiant utilisateur (ce sera le nom de votre compte).
  3. Entrez un mot de passe, puis entrez-le a nouveau pour confirmer.
  4. Saisissez un mot de passe administrateur et confirmez-le (il s'agit du mot de passe du compte admin crée automatiquement, utilise pour la gestion du serveur).
  5. Appuyez sur le bouton "Enregistrer" pour créer le compte.
  6. Vous serez redirige vers l'écran de connexion. Connectez-vous avec le compte que vous venez de créer.
Conseil : Le compte admin est crée automatiquement lors du premier démarrage du serveur. Cet écran definit le mot de passe admin et crée votre compte utilisateur normal en meme temps.

Après la connexion, l'écran par defaut (Vue du journal de vie par defaut) s'affiche. Configurez les paramètres de base tels que la langue et le theme sombre dans l'écran de configuration.

Votre premier enregistrement en 60 secondes

  1. Connectez-vous.
  2. L'écran Vue du journal de vie s'affiche.
  3. Appuyez sur le bouton "+" en bas a droite de l'écran.
  4. Sélectionnez "Bloc-notes" dans le menu.
  5. Saisissez ce que vous souhaitez enregistrer dans la zone de texte (par exemple : J'ai mange du curry au dejeuner aujourd'hui).
  6. Appuyez sur le bouton "Enregistrer" et l'enregistrement apparaitra immédiatement dans le fil chronologique de la Vue du journal de vie.
Astuce : La methode de base pour ajouter des enregistrements est d'utiliser le bouton "+" sur l'écran Vue du journal de vie. Une fois la syntaxe du bloc-notes maitrisee, vous pourrez enregistrer des tâches, des valeurs d'humeur et plus encore de la meme maniere. Consultez le Tutoriel pour plus de détails.
Astuce : Un appui sur le bouton "+" ouvre un menu ; un appui long ouvre directement le bloc-notes.
Astuce : L'écran Saihate est egalement disponible pour les enregistrements depuis l'écran de verrouillage ou les enregistrements rapides. Consultez l'aide de Saihate pour plus de détails.

Glossaire

Terme Description
Enregistrement Terme general pour les enregistrements dans gkill. Il englobe tous les types d'enregistrement, y compris les mémos, les horodatages, les tâches, etc.
Syntaxe bloc-notes Syntaxe de saisie de texte utilisée dans le bloc-notes. En ajoutant des symboles au debut de chaque ligne, vous pouvez créer differents types d'enregistrements en une seule fois
Horodatage Fonction de suivi du temps. Enregistre les heures de debut et de fin des travaux ou activités
Saihate Écran permettant d'ajouter des enregistrements en toute sécurité même depuis l'écran de verrouillage. Fonctionne comme un hub d'ajout d'enregistrements
Vue du journal de vie Écran permettant de lister et rechercher des enregistrements
Vue d'agrégation Fonction d'affichage des agregations et statistiques de données
Informations associées Fonction qui recherche et affiche automatiquement les informations associées
Dépôt Emplacement de stockage des enregistrements. Vous pouvez utiliser plusieurs dépôts pour differents usages
Profil Ensemble de paramètres propres à chaque appareil utilisé, pour conserver la même configuration d'un appareil à l'autre
Tag Étiquette apposée sur un enregistrement. Un enregistrement peut en porter plusieurs ; elles servent de repère lors des recherches
Tâche de repost Un enregistrement existant rendu utilisable comme tâche sans le réécrire
Partage Fonction permettant de montrer les enregistrements choisis via un lien, même à des personnes sans compte gkill
Extension Fonction supplémentaire qui importe les enregistrements d'autres services que gkill et les affiche dans la liste
