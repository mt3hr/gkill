Quand une erreur s'affiche

Lorsqu'une opération échoue, un message à bordure rouge apparaît en haut à droite de l'écran. Les erreurs ne disparaissent pas d'elles-mêmes : fermez-les avec le × en haut à droite. Si la même erreur se répète, elle est regroupée sur une seule carte avec un compteur tel que « ×3 ». Les avis de réussite (bordure noire) disparaissent après quelques secondes. Les cartes jaunes signifient « l'opération a réussi, mais quelque chose mérite vérification » ; elles restent aussi jusqu'à leur fermeture.

Lire le message

Partie Description
Première ligne (gras) Ce qui a échoué (ex. « Échec de l'ajout de la note »)
Deuxième ligne Ce qu'il faut essayer ensuite. Si la cause est connue, le conseil lui correspond ; sinon, c'est le conseil général pour ce type d'erreur
Dernière ligne (code) Le code d'erreur (un numéro commençant par ERR) et la classification de la cause (ex. db_busy). Les indiquer lors d'une demande d'aide accélère le diagnostic
Bouton copier Copie dans le presse-papiers le code, la cause, le texte, l'heure et le chemin de l'écran. Collez-le lorsque vous signalez le problème

Que faire selon la cause

Conseil de la deuxième ligne Que faire
Aucune destination d'écriture n'est configurée pour ce type d'enregistrement. Dans Paramètres → Attribuer le stockage, choisissez un dépôt d'écriture. Ouvrez Paramètres → Attribuer le stockage et choisissez un dépôt d'écriture pour ce type d'enregistrement
Le fichier du dépôt ne peut pas être ouvert. Vérifiez la connexion des disques externes, clés USB ou lecteurs réseau, puis Paramètres → Dépôt. Rebranchez le disque externe ou le lecteur réseau et vérifiez le chemin dans Paramètres → Dépôt
La base de données du dépôt est peut-être corrompue. Envisagez une restauration depuis une sauvegarde. Restaurez le fichier de base de données depuis une sauvegarde. Un dépôt corrompu est automatiquement exclu des recherches et un avertissement jaune s'affiche
Une autre opération (mise à jour du cache ou import) utilise la base de données. Patientez un instant puis réessayez. Patientez un instant puis recommencez l'opération
L'opération n'a pas abouti dans le temps imparti. Réduisez la période ou les conditions puis réessayez. Réduisez la période ou les conditions de recherche puis relancez la recherche
L'extension n'a pas répondu. Patientez puis réessayez, ou vérifiez son état dans Paramètres → Paramètres de l’extension. Patientez puis réessayez, ou vérifiez l'état dans Paramètres → Paramètres de l’extension
L'enregistrement cible est introuvable. Il a peut-être été supprimé ou modifié depuis un autre appareil. Rechargez la liste. Rechargez la liste. L'enregistrement a été supprimé ou modifié depuis un autre appareil
Le même enregistrement est déjà sauvegardé (envoi en double possible). Rechargez la liste et vérifiez. Rechargez la liste et vérifiez si le même enregistrement existe déjà
La limite de tentatives est atteinte. Patientez un moment (environ 15 minutes) puis réessayez. Attendez environ 15 minutes puis reconnectez-vous
Ce serveur n'autorise que l'accès local. Ouvrez-le depuis la même machine que le serveur ou modifiez les paramètres du serveur. Ouvrez l'application dans un navigateur sur la même machine que le serveur, ou vérifiez « n'autoriser que l'accès local » dans les paramètres du serveur
Il s'agit d'un problème côté serveur. Réessayez ; si cela persiste, consultez gkill_error.log sur le serveur. Recommencez l'opération ; si cela persiste, signalez-le avec le texte de « Copier les détails » et gkill_error.log
Une erreur réseau s'est produite. Vérifiez votre connexion. Vérifiez la connexion réseau. Sans connexion, impossible d'ajouter des enregistrements

Quand rien ne s'affiche

Si un bouton ne fait rien, rechargez la page. Les erreurs inattendues dans l'application s'affichent désormais aussi en haut à droite. Si le problème persiste, le fichier gkill_error.log du serveur conserve une ligne à l'heure de l'échec.
