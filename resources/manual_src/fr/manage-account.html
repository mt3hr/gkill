Gestion des comptes

Cet écran gère les comptes utilisateur. Seuls les administrateurs peuvent y accéder.

Bouton supérieur

Appuyez sur le bouton Ajouter un compte pour créer un nouveau compte.

Liste des comptes

Les comptes enregistrés sont affichés dans une liste. Chaque ligne de compte contient les éléments suivants :

ÉlémentDescription
Case à cocher activer/désactiverBascule l'état du compte entre activé et désactivé (le compte avec lequel vous êtes connecté ne peut pas être basculé)
ID utilisateurAffiche l'ID utilisateur du compte
Bouton d'attribution de stockageAttribue des dépôts de données à l'utilisateur
Bouton des paramètres de l'extensionOuvre la liste des extensions de cet utilisateur
Bouton de réinitialisation du mot de passeGénère un lien de réinitialisation du mot de passe

Bouton inférieur

Fermer : Ferme l'écran de gestion des comptes.

Conseil : Le compte admin est créé automatiquement lors du premier démarrage du serveur. Les comptes ajoutés depuis l'écran de gestion des comptes sont des utilisateurs normaux (sans droits d'administrateur). Les comptes ne se suppriment pas : on les gère en les activant ou en les désactivant.

Procédure de réinitialisation du mot de passe

Lorsqu'un utilisateur a oublié son mot de passe, l'administrateur émet un lien de réinitialisation en suivant les étapes ci-dessous.

Opérations de l'administrateur

  1. Depuis l'écran de configuration du serveur, ouvrez « Gestion des comptes ».
  2. Appuyez sur le bouton « Réinitialiser le mot de passe » sur la ligne de l'utilisateur concerné.
  3. Appuyez sur « OK » dans la boîte de dialogue de confirmation : le lien de réinitialisation du mot de passe est généré.
  4. Copiez le lien affiché et transmettez-le à l'utilisateur concerné (par message, e-mail, etc.).

Opérations de l'utilisateur

  1. Ouvrez dans le navigateur le lien de réinitialisation reçu de l'administrateur.
  2. Saisissez le nouveau mot de passe, puis saisissez-le une seconde fois pour confirmation.
  3. Appuyez sur le bouton « Définir » : le nouveau mot de passe est enregistré.
  4. Vous êtes redirigé vers l'écran de connexion ; connectez-vous avec le nouveau mot de passe.
Conseil : Le lien de réinitialisation est à usage unique : il devient invalide dès qu'il a été utilisé. Il est valable 72 heures après son émission et la date d'expiration est affichée dans la boîte de dialogue du lien. Une fois expiré, utilisez le bouton "Régénérer le lien" de la même boîte de dialogue pour en générer un nouveau.

Attribution des dépôts

Attribuez à chaque utilisateur les « dépôts » où ses données sont enregistrées. Le bouton d'attribution de stockage ouvre une boîte de dialogue qui permet de définir les dépôts de cet utilisateur. Pour plus de détails, consultez « Gestion du stockage » dans Configuration du serveur.

Paramètres des extensions

Appuyez sur le bouton « Paramètres de l'extension » sur la ligne d'un utilisateur pour ouvrir la liste de ses extensions. Le nom, la version et la description de chacune s'affichent, ainsi que son état de fonctionnement. Le bouton « Paramètres » d'une ligne ouvre l'écran de réglages fourni par l'extension elle-même, où vous pouvez modifier et enregistrer par exemple ses dossiers source.

Conseil : Les dossiers source déterminent quels dossiers gkill peut lire ; seul un administrateur peut donc ouvrir cet écran. Voir Extensions pour savoir ce que sont les extensions.
