Tableau de bord

Une vue d'ensemble qui permet de parcourir en un seul écran le journal de vie de la date sélectionnée. La moitié supérieure affiche la Vue d'agrégation et la carte GPS de ce jour, et la partie inférieure affiche vos tâches.

Boutons de la barre d'outils

Bouton Description
← (Jour précédent) Affiche les données du jour précédent.
Étiquette de date (ex: 2025/6/15 Dim) Cliquez pour ouvrir le sélecteur de calendrier.
→ (Jour suivant) Affiche les données du jour suivant.
❔ Aide Affiche l'aide pour l'écran actuel.
⚙ Paramètres Ouvre les paramètres de l'application.
Menu de navigation (clic sur le titre) Permet de naviguer vers chaque écran.

Zones d'affichage

Zone Description
Vue d'agrégation Affiche la Vue d'agrégation du jour sélectionné dans la moitié gauche. Vous pouvez affiner les conditions de recherche dans Paramètres.
Carte GPS Affiche le journal GPS du jour sélectionné sous forme de carte dans la moitié droite. Cliquez sur la date en haut de la carte pour choisir une date. Le jour choisi devient le jour affiché du tableau de bord : la Vue d'agrégation et la liste des tâches se déplacent aussi à ce jour (contrairement à la carte de l'écran Vue du journal de vie, ce n'est pas seulement la carte qui change).
Liste des tâches Affiche les tâches liées au jour sélectionné en bas, y compris les tâches dont l'échéance tombe ce jour-là. Vous pouvez affiner les conditions de recherche dans Paramètres.

Bouton d'action flottant (+)

Appuyez sur le bouton "+" en bas à droite pour ouvrir le menu d'ajout rapide d'enregistrements.

Élément de menu Contenu Description
Bloc-notes Saisie de texte Ouvre l'écran pour saisir des mémos et divers enregistrements avec la syntaxe du bloc-notes.
Bloc-notes d'entrées de temps Texte + entrées de temps Ouvre l'écran qui gère en même temps la saisie de mémos et les entrées de temps en cours.
Enregistrements numériques Enregistrer un nombre Enregistre des données numériques arbitraires.
Signets Enregistrer une URL Enregistre l'URL d'une page web en tant que signet.
Suivi du temps Démarrer une mesure du temps Démarre une nouvelle session d'entrée de temps.
Tâches Ajouter une tâche Crée une nouvelle tâche.
Dépenses Enregistrer un montant Enregistre le montant et la description d'une dépense.
Humeur Enregistrer une valeur d'humeur (0 à 10) Enregistre votre humeur actuelle sur une échelle de 0 à 10.
Téléverser Téléverser un fichier Téléverse et enregistre des fichiers tels que des images ou des documents.
Conseil : Appuyez longuement sur le bouton "+" pour ouvrir directement le Bloc-notes.
Raccourci : Appuyez sur Entrée pour ouvrir la boîte de dialogue du Bloc-notes.
Raccourci : Appuyez sur Ctrl+V pour enregistrer le contenu du presse-papiers directement en tant que fichier. Utile pour sauvegarder rapidement des captures d’écran.
Conseil : Vous pouvez configurer les conditions de recherche pour la Vue d'agrégation et les tâches depuis la section "Tableau de bord" de la boîte de dialogue ouverte par le bouton "Conditions de recherche" dans Paramètres.
