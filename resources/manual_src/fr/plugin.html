Extensions

Avec une extension installée, les enregistrements laissés dans des services autres que gkill apparaissent dans la même liste que vos enregistrements gkill. Cela vous permet de revenir en un seul endroit sur « ce que je faisais ce jour-là ».

Extensions disponibles

Trois extensions sont fournies en standard.

Extension Ce qu'elle importe
ChatGPT Historique des conversations exporté depuis ChatGPT
Claude.ai Historique des conversations exporté depuis Claude.ai
ClaudeCode Journaux de discussion de Claude Code
Astuce : Ces noms servent aussi lorsque vous filtrez par « dépôt » dans la barre latérale de la liste des enregistrements. Pour ne voir que les enregistrements des extensions, filtrez par ces noms.

Comment les installer

Installer une extension consiste à placer des fichiers. Suivez les étapes dans l'ordre.

  1. Placez l'exécutable de l'extension dans le dossier plugins situé dans le dossier personnel de gkill. L'emplacement exact se trouve dans un dossier portant votre identifiant, puis un dossier portant le nom de l'extension, tous deux créés sous plugins.
  2. Démarrez gkill. Au premier chargement de l'extension, le fichier de configuration config.json est créé automatiquement dans ce même dossier.
  3. Ouvrez config.json dans un éditeur de texte et indiquez dans source_dirs le dossier contenant les données à importer.
  4. En effectuant une recherche dans la Vue du journal de vie, ils s'affichent dans la liste comme n'importe quel autre enregistrement.
Astuce : Si un config.json existe déjà, gkill ne l'écrase jamais. Vos réglages ne seront pas perdus lorsque vous les modifierez.

Comment indiquer le dossier source

Dans source_dirs, vous pouvez indiquer aussi bien un chemin de dossier qu'un chemin de fichier. Les règles sont les suivantes.

Écriture Signification
Un chemin commençant par ~ Indique un emplacement relatif à votre propre dossier personnel
* ** ? [] Traite une partie du nom de dossier ou de fichier comme « n'importe quoi »
Si vous indiquez un dossier Il explore les sous-dossiers en profondeur pour trouver les fichiers visés
Si vous indiquez directement un fichier Il lit le contenu de ce fichier tel quel
Si vous le laissez vide ChatGPT et Claude.ai regardent le dossier de l'extension ; ClaudeCode regarde l'emplacement standard de Claude Code
Astuce : Les entrées de config.json commençant par _ (tiret bas) ne sont là que pour expliquer le format. Vous pouvez les supprimer.
Astuce : Il n'est pas nécessaire de redémarrer gkill après avoir modifié config.json. Les nouveaux réglages s'appliquent dès la recherche suivante.

Ce qui est possible et ce qui ne l'est pas

Les enregistrements importés par une extension sont en lecture seule. Afin de ne pas altérer les données d'origine, gkill ne peut pas les modifier.

Opération Possible ?
Ajouter un tag / Ajouter un tag depuis l'historique Oui
Ajouter du texte Oui
Ajouter une notification Oui
Repost Oui
Transformer en tâche Oui
Copier le contenu / Copier l'ID Oui
Modifier Non (n'apparaît pas dans le menu)
Supprimer Non (n'apparaît pas dans le menu)
Astuce : Si vous ajoutez des tags aux conversations importées, vous pourrez ensuite les retrouver avec le filtre par tags de la Vue du journal de vie.

Pour tout réimporter

Ce qu'une extension importe est conservé afin d'accélérer l'affichage. Si vous avez remplacé une grande partie de la source et souhaitez tout relire, arrêtez gkill puis exécutez la commande suivante.

gkill_server clear_cache plugin IDENTIFIANT

Au prochain démarrage de gkill, une recherche relira les données depuis la source.

Si rien ne s'affiche correctement

Symptôme À vérifier
Aucun enregistrement n'apparaît Vérifiez que les fichiers source existent bien dans le dossier indiqué dans source_dirs. Une erreur de saisie dans le chemin en est la cause la plus fréquente.
Le fichier de configuration n'est pas créé Vérifiez que l'exécutable est au bon endroit. Les noms de dossiers sont votre identifiant, puis le nom de l'extension, dans cet ordre.
Le contenu reste l'ancien Réimportez tout en suivant la procédure ci-dessus.
« Échec de la récupération du contenu de l'extension » s'affiche L'exécutable de l'extension ne démarre peut-être pas. Vérifiez qu'il n'est pas endommagé et que vous avez le droit de l'exécuter.
Remarque : Il n'existe pour l'instant aucun moyen de modifier les réglages des extensions depuis l'écran. Modifiez directement config.json.
