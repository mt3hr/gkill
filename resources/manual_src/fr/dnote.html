Vue d'agrégation

Écran d'agrégation et de visualisation des données du journal de vie. Vous pouvez définir quatre types : des Éléments, des Listes, des Graphiques de tendance et des Graphiques de corrélation pour comparer plusieurs indicateurs.

Astuce : La vue d'agrégation est une fonctionnalité à bascule intégrée à la vue journal de vie. Cliquez sur l'icône d'agrégation dans la barre d'outils de la vue journal de vie pour l'afficher.

Gestion des définitions

Élément Description
Onglets Chaque définition d'agrégation est affichée sous forme d'onglet. Cliquez sur un onglet pour basculer entre les définitions.
Nom de la définition Champ de texte permettant de modifier le nom de la définition d'agrégation.
Bouton ＋ (à côté des onglets) Ajoute une nouvelle définition d'agrégation.
Bouton supprimer Supprime la définition d'agrégation actuellement affichée.

Éléments de l'écran

Élément Description
Plage de dates Affiche la période utilisée pour l'agrégation.
Bouton de téléchargement Télécharge les résultats d'agrégation au format JSON.
Bouton ＋ (flottant) Affiche un menu pour ajouter un Élément, une Liste, un graphique de tendance ou un graphique de corrélation.

Éléments (valeur agrégée unique)

Affiche les valeurs agrégées des données correspondant aux conditions au format : « Titre : Préfixe [Résultat agrégé] Suffixe ».

Paramètre Type Description
Titre Saisie de texte Définit le nom d'affichage de l'élément.
Préfixe Saisie de texte Texte affiché avant la valeur agrégée.
Suffixe Saisie de texte Texte affiché après la valeur agrégée.
Cible d'agrégation Liste déroulante Sélectionne la méthode d'agrégation (comptage, somme, moyenne, max, min, etc.).
Groupe de conditions Éditeur de conditions Filtre les cibles d'agrégation à l'aide de conditions AND/OR.

Listes (agrégation groupée)

Affiche les résultats d'agrégation groupés par clé sous forme de liste.

Paramètre Type Description
Titre / Préfixe / Suffixe Saisie de texte Mêmes paramètres que pour les Éléments.
Cible d'agrégation Liste déroulante Sélectionne la méthode d'agrégation.
Clé de groupement Liste déroulante Choisissez le critère de regroupement (titre, type de données, tag, magasin, humeur, mois, semaine, jour de la semaine, date, etc.). Avec « Titre », le corps des notes, les titres des enregistrements numériques, horodatages et tâches, les postes de dépense, les titres des favoris et les messages de commit Git servent d'intitulé de groupe.
Groupe de conditions Éditeur de conditions Filtre les cibles d'agrégation à l'aide de conditions AND/OR.

Graphique de tendance (agrégation temporelle)

Agrège les données correspondant aux conditions par périodes fixes et affiche l'évolution sous forme de graphique en ligne ou en barres. Survolez un point du graphique pour afficher la valeur agrégée de chaque période.

Paramètre Type Description
Titre Saisie de texte Définit le nom affiché du graphique de tendance.
Cible d'agrégation Liste déroulante Sélectionne la méthode d'agrégation (nombre, somme, moyenne, maximum, minimum, etc.).
Granularité Liste déroulante Sélectionne l'unité de période : « Quotidien », « Hebdomadaire » ou « Mensuel ».
Type de graphique Liste déroulante Sélectionne « Ligne » ou « Barres ».
Groupe de conditions Éditeur de conditions Filtre la cible d'agrégation avec des conditions AND/OR.

Graphique de corrélation

Agrège de 2 à 10 métriques par même jour, semaine ou mois et affiche leurs relations sous forme de carte thermique et de nuage de points. Chaque métrique possède un nom, une cible d'agrégation et des conditions.

Sélectionnez une cellule pour afficher le coefficient, le nombre de périodes appariées, la valeur p, l'intervalle de confiance à 95 % et le nuage de points. Pearson et Spearman sont disponibles ; les résultats inférentiels de Spearman sont des approximations analytiques. Une corrélation ne prouve pas une causalité.

Avec un décalage positif, la métrique de ligne d'une période antérieure est comparée à la métrique de colonne d'une période ultérieure. Les périodes où une observation manque sont exclues.

Édition du groupe de conditions

Élément Description
Logique de combinaison Sélectionnez AND / OR / NOT pour définir comment les conditions sont combinées.
Ajouter une condition Ajoute une nouvelle condition au groupe.
Ajouter un groupe Ajoute un groupe de conditions imbriqué.
Supprimer le groupe Supprime ce groupe de conditions.
Chaque condition Définit le type et la valeur de la condition (filtrer par type de données, étiquette, titre, montant, valeur d'humeur, etc.).

Opérations

Opération Description
Double-clic Ouvre l'éditeur de l'élément, de la liste ou du graphique de tendance.
Clic droit Affiche le menu contextuel (Modifier / Supprimer).
Glisser-déposer Modifie l'ordre d'affichage des éléments, des listes et des graphiques de tendance.

Vous pouvez en outre choisir des conditions qui comparent avec l'enregistrement sélectionné : « Le titre est égal à la cible », « Tous les tags sont égaux à la cible », « Une partie des tags est égale à la cible », « Le type de données est égal à la cible » et « L'ID est égal à la cible ». Voir « Conditions qui comparent avec l'enregistrement sélectionné » dans Informations connexes.

Boutons d'action inférieurs

Bouton Description
Appliquer Enregistre toutes les modifications des définitions.
Annuler Annule les modifications et ferme le dialogue.
Astuce : Les Éléments sont utiles pour des valeurs agrégées uniques (ex : total des dépenses du mois), les Listes pour des agrégations par groupe (ex : dépenses par magasin) et les graphiques de tendance pour suivre l'évolution (ex : humeur par semaine, dépenses par mois).
Astuce : Combiner les conditions permet de créer des requêtes d'agrégation complexes.
Astuce : Utilisez le glisser-déposer pour réordonner librement l'affichage des éléments et des listes.
Astuce : Les résultats d'agrégation peuvent être téléchargés en JSON pour une analyse avec des outils externes.
