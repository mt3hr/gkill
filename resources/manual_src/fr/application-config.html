Paramètres de l'application

Écran de gestion des paramètres globaux de l'application et de la structure des données. Vous pouvez y ajuster de nombreuses options liées à l'affichage, au comportement et aux intégrations externes.

Boutons d'action supérieurs

Bouton Description
Paramètres du serveur (administrateurs uniquement) Ouvre les réglages détaillés du serveur (port, TLS, restrictions d'accès, etc.). Visible uniquement pour les utilisateurs disposant des droits d'administrateur.
Recharger Recharge les données depuis le serveur. Appui long : force le rechargement.
Déconnexion Termine la session en cours et vous déconnecte.

Paramètres généraux

Paramètre Type Description
Langue Liste déroulante Choisit la langue de l'interface. Le japonais (ja), l'anglais (en), le chinois (zh), le coréen (ko), l'espagnol (es), le français (fr) et l'allemand (de) sont pris en charge.
Thème sombre Case à cocher Active ou désactive le mode sombre. Adapté à une utilisation dans un environnement peu éclairé.
Rechargement à chaud Case à cocher Active ou désactive la mise à jour automatique des données de la Vue du journal de vie. Lorsqu'un changement est détecté, l'écran est actualisé automatiquement.
Afficher les tags dans la liste Case à cocher Indique si les tags attribués à chaque enregistrement sont affichés dans les écrans de liste.
Afficher le pied de page de partage Case à cocher Indique si les options de partage sont affichées dans le pied de page.

Paramètres d'affichage

Paramètre Type Description
Jours d'affichage du journal de vie Case à cocher + nombre Définit le nombre de jours affichés dans la Vue du journal de vie. -1 signifie illimité. Une période courte accélère le chargement.
Vue par défaut au démarrage Liste déroulante Choisit la page affichée en premier après la connexion.
Colonnes d'images du journal de vie Nombre (1 à 10) Définit le nombre de colonnes de miniatures d'images dans la Vue du journal de vie. Ajustez-le selon la taille de l'écran de votre appareil.
Nom du tableau de tâches par défaut Liste déroulante + bouton d'ajout Choisit le tableau affiché en premier dans l'écran des tâches. Le bouton d'ajout permet de créer un nouveau tableau.

Intégrations externes

Paramètre Type Description
Bookmarklet Lecture seule URL du bookmarklet JavaScript à ajouter à la barre de favoris du navigateur. Elle sert à ajouter un signet en un clic depuis le navigateur.
Clé API Google Map Saisie de texte Définit la clé API Google Maps utilisée par la fonction de carte GPS. Cette clé est nécessaire pour afficher la carte.

Gestion de la structure des données

Ces boutons gèrent la structure des données de l'application. Chaque bouton ouvre un éditeur dédié. Ces réglages sont partagés entre tous les appareils, tandis que « Nom du tableau de tâches par défaut » est un réglage propre à chaque appareil. Chaque élément et dossier de ces structures peut porter une « description » : indiquez à quoi il sert et comment vous l'utilisez, et l'intégration IA la lit comme indice pour retrouver vos enregistrements.

Bouton Description
Structure des tags Gère la hiérarchie et le regroupement des tags. Vous pouvez modifier les relations parent-enfant et l'ordre des tags.
Structure du dépôt Gère le regroupement, l'ordre et l'état de coche initial des dépôts affichés dans la barre latérale de recherche (l'ajout ou la suppression des dépôts eux-mêmes s'effectue dans Gestion des comptes, depuis les Paramètres du serveur).
Structure des profils Gère les paramètres de chaque appareil utilisé (profils). Vous pouvez modifier leur ordre et leur regroupement.
Structure des types d'enregistrement Gère le regroupement, l'ordre et l'état de coche initial des types d'enregistrement affichés dans la barre latérale de recherche.
Structure des tableaux Gère l'ordre des tableaux de tâches. Vous pouvez les réordonner, supprimer les tableaux que vous n'utilisez plus et modifier la « description » de chaque tableau.
Structure des modèles Gère les modèles de texte du bloc-notes. Vous pouvez créer et modifier des textes types pour la saisie rapide.
Vue d'agrégation Gère les méthodes d'agrégation des données et les réglages de la vue d'agrégation.
Informations associées Gère la structure des informations associées.
Conditions de recherche Regroupe dans une seule boîte de dialogue les réglages liés aux conditions de recherche. Elle comporte les trois sections suivantes :
  • Raccourcis de recherche : enregistrez sous un nom les conditions de recherche que vous utilisez souvent. Les raccourcis de la Vue du journal de vie et de l'écran des tâches s'ajoutent, se modifient, se réordonnent et se suppriment séparément, et s'appliquent en les choisissant avec le bouton d'appel situé en bas à droite de la barre latérale de chaque écran.
  • En cours : définit les conditions de recherche utilisées pour trouver les sessions d'entrée de temps en cours. Elles s'appliquent à la liste de l'écran En cours, aux sessions d'entrée de temps en cours affichées avec les détails d'un enregistrement et à toutes les entrées de temps visées par la fin d'entrée de temps de la syntaxe du bloc-notes. En activant « Personnaliser les critères de recherche », un bouton de modification des conditions apparaît et vous pouvez filtrer par étiquette et mot-clé. En le désactivant, vous revenez au comportement standard, qui porte sur toutes les entrées de temps.
  • Tableau de bord : définit les conditions de recherche des notes d'agrégation et des tâches affichées dans l'écran du tableau de bord.
Compétences Gère les procédures (compétences) transmises à l'IA par l'intégration IA. Pour chaque compétence, vous pouvez afficher son contenu, la télécharger en zip et la supprimer. Le téléversement d'un zip affiche d'abord les fichiers qui seront ajoutés, supprimés ou modifiés, puis remplace entièrement la compétence. Pour plus de détails, voir « Compétences » dans Intégration IA.

Boutons d'action inférieurs

Bouton Description
Appliquer Enregistre toutes les modifications.
Annuler Annule les modifications et ferme l'écran.

Pied de page

Le bas de l'écran affiche les informations de l'application.

  • Numéro de version — un clic ouvre le lien vers la page du projet.
  • Horodatage de compilation — date et heure de la compilation.
  • Hash du commit — indique le commit Git à partir duquel la compilation a été faite.
Astuce : Après avoir modifié les paramètres, appuyez sur « Appliquer » pour les enregistrer. Si vous appuyez sur « Annuler », les modifications sont abandonnées.
Astuce : Sur smartphone, 1 à 2 colonnes d'images du journal de vie sont plus lisibles ; sur PC, 3 à 5 colonnes.
Astuce : Pour utiliser la fonction de carte GPS, activez l'API Maps JavaScript dans Google Cloud Console, obtenez une clé API Google Map et saisissez-la.
