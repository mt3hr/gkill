Intégration IA

En connectant des assistants IA comme Claude à gkill, vous pouvez rechercher, ajouter et modifier vos journaux de vie par conversation naturelle.

Ce que vous pouvez faire

ActionExemple
Rechercher des enregistrements« Montre-moi mes notes de déjeuner de la semaine dernière » / « Résume les dépenses de ce mois »
Ajouter des enregistrements« Ajoute une note pour aujourd'hui » / « Crée une tâche »
Mettre à jour / supprimer« Marque cette tâche comme terminée »
Récupérer GPS / fichiers« Montre mon itinéraire d'aujourd'hui »

Transmission des fichiers

La manière de présenter les enregistrements de fichiers (images, vidéos, documents) à l'IA change automatiquement selon le type de connexion.

Type de connexionMéthode de transmission
Connexion locale (IA sur le même PC)Le chemin réel du fichier est transmis à l'IA, qui peut le lire directement.
Connexion distante (IA via internet)Une URL dédiée à durée limitée est émise et l'IA récupère le fichier depuis cette URL. Pour les images, la miniature et la taille originale sont toutes deux fournies. Il n'est pas nécessaire d'exposer gkill.
Astuce : La limite de taille du transfert intégré (8 Mo par défaut) se règle avec la variable d'environnement GKILL_MCP_MAX_FILE_BYTES, et la durée de validité de l'URL (1 heure par défaut) avec GKILL_MCP_FILE_LINK_TTL_MS.

Configuration (Claude Desktop)

Ajoutez ce qui suit au fichier de configuration de Claude Desktop (claude_desktop_config.json).

Intégration en lecture seule

{
  "mcpServers": {
    "gkill": {
      "command": "node",
      "args": ["C:/path/to/gkill/src/mcp/gkill-read-server.mjs"],
      "env": {
        "GKILL_BASE_URL": "http://localhost:9999",
        "GKILL_USER": "votre-id-utilisateur",
        "GKILL_PASSWORD_SHA256": "hash-sha256-de-votre-mot-de-passe"
      }
    }
  }
}
Conseil : GKILL_PASSWORD_SHA256 est le hachage SHA256 de votre mot de passe. Vous pouvez le générer avec les outils disponibles sur votre système d'exploitation.

Configuration (Claude Code)

claude mcp add gkill \
  --env GKILL_BASE_URL=http://localhost:9999 \
  --env GKILL_USER=votre-id-utilisateur \
  --env GKILL_PASSWORD_SHA256=votre-hash \
  -- node /path/to/gkill/src/mcp/gkill-read-server.mjs
Conseil : Adaptez le chemin ci-dessus à l’endroit où vous avez placé les sources de gkill. Pour changer de type, remplacez le nom du fichier par gkill-write-server.mjs ou gkill-readwrite-server.mjs.

Utilisation à distance (connexion HTTP)

Si l’IA n’est pas sur le même PC, vous pouvez faire écouter le serveur MCP lui-même en HTTP afin qu’une IA sur internet s’y connecte. Ce mode autorise la connexion via OAuth, il n’est donc pas nécessaire d’exposer gkill lui-même sur internet.

# Exemple : servir la lecture et l’écriture en HTTP
MCP_TRANSPORT=http MCP_PORT=8810 MCP_OAUTH_ISSUER=https://example.com \
GKILL_BASE_URL=http://localhost:9999 \
GKILL_USER=votre-id-utilisateur \
GKILL_PASSWORD_SHA256=votre-hash \
node /path/to/gkill/src/mcp/gkill-readwrite-server.mjs
Conseil : Vous pouvez aussi publier le serveur gkill lui-même sur internet. Dans ce cas, définissez GKILL_BASE_URL sur son adresse publique et activez TLS (HTTPS) depuis Paramètres du serveur.
