Configuration du serveur

Cet écran configure le comportement du serveur. Seuls les administrateurs peuvent y accéder.

Bouton supérieur

Appuyez sur le bouton Gestion des comptes pour ouvrir l'écran de gestion des comptes.

Boutons inférieurs

Appliquer : Enregistrer les paramètres.
Annuler : Annuler les modifications et fermer l'écran.

Les modifications nécessitent un redémarrage du serveur pour prendre effet.

Utiliser gkill depuis d'autres appareils

Par défaut, seul l'appareil qui exécute le serveur peut se connecter (l'adresse d'écoute est 127.0.0.1:9999 et « Autoriser l'accès local uniquement » est activé). Pour utiliser gkill depuis un smartphone ou un autre PC, un administrateur modifie ces deux paramètres.

  1. Définissez Adresse sur :9999 (toutes les interfaces) ou sur l'adresse IP de cet appareil sur le réseau local (ex. : 192.168.0.10:9999).
  2. Désactivez Autoriser l'accès local uniquement.
  3. Appuyez sur Appliquer. Le serveur redémarre et les autres appareils peuvent ouvrir http://(adresse IP de cet appareil):9999.
Application smartphone (Android) : Le serveur qui s'exécute dans l'application suit lui aussi les paramètres de cet écran. Si vous indiquez dans Adresse uniquement l'adresse IP de cet appareil sur le réseau local (ex. : 192.168.0.10:9999), l'écran de l'application elle-même ne pourra plus joindre le serveur. Pour servir aussi d'autres appareils, indiquez 0.0.0.0:9999 ou laissez la partie hôte vide, comme dans :9999 (si vous écrivez seulement 9999, sans les deux-points, l'écran de l'application ne pourra pas non plus s'ouvrir). De plus, si vous modifiez le port d'écoute ou Activer TLS puis appliquez, l'application rouvre son écran à la nouvelle adresse et vous devrez vous reconnecter.
Astuce : Lorsque vous servez d'autres appareils, il est recommandé d'activer Activer TLS (vous pouvez créer un certificat avec « Générer des fichiers TLS auto-signés »). Si TLS reste désactivé, les mots de passe circulent sur le réseau sans chiffrement.

Gestion du stockage

Les dépôts sont les dossiers et fichiers dans lesquels gkill enregistre vos données. Vous pouvez configurer plusieurs dépôts selon l'usage (mémos, fichiers, journaux GPS, etc.) ou selon l'appareil.

Les dépôts se configurent pour chaque utilisateur à partir du bouton d'attribution de stockage de l'écran de gestion des comptes.

Comment ajouter un dépôt

  1. Ouvrez l'écran de gestion des comptes et appuyez sur le bouton d'attribution de stockage de l'utilisateur concerné.
  2. Appuyez sur le bouton « Ajouter » pour ajouter un nouveau dépôt.
  3. Configurez les éléments suivants :
    • Nom d'affichage : nom affiché dans la vue du journal de vie et dans les filtres
    • Type : type de données à stocker. La liste déroulante affiche des noms alphanumériques comme kmemo ou timeis ; voir le tableau « Choix du type » ci-dessous pour leur signification
    • Chemin : chemin du répertoire où les données sont stockées (pour la gestion de fichiers, des caractères génériques comme * ou ** peuvent aussi être utilisés)
    • Utiliser comme destination d'écriture : indique si les nouveaux enregistrements doivent être enregistrés dans ce dépôt
    • Activé : indique si ce dépôt est inclus dans la recherche et l'affichage
  4. Appuyez sur le bouton « Enregistrer » pour appliquer les réglages.

Choix du type

La liste déroulante des types affiche des noms alphanumériques. Voici ce que chacun stocke.

Ce qu'affiche la liste déroulanteCe qui est stocké
kmemoMémos
timeisEntrées de temps (enregistrements du temps)
miTâches
nlogDépenses

directoryFichiers téléversés (images, vidéos, documents, etc.)
gpslogJournaux GPS au format GPX
git_commit_logHistorique des commits Git (lecture seule)
rekyouReposts (anciens enregistrements réaffichés)
mirekyouTâches de repost (enregistrements existants transformés en tâches)
tagTags apposés sur les enregistrements
textTextes complémentaires ajoutés aux enregistrements
notificationNotifications (rappels) ajoutées aux enregistrements
Astuce : tag / text / notification / rekyou / mirekyou stockent des informations rattachées aux enregistrements, et non les enregistrements eux-mêmes. Ils sont normalement créés lors de la configuration initiale ; vous n'avez donc pas à les ajouter ensuite.
Astuce : Vous pouvez ajouter plusieurs dépôts du même type. Par exemple, en séparant le dépôt des mémos textuels par appareil, vous pouvez organiser les données de chaque appareil.
Astuce : Le dépôt pour lequel « Utiliser comme destination d'écriture » est activé devient la destination des nouveaux enregistrements. S'il existe plusieurs dépôts du même type, n'activez cette option que pour celui que vous utilisez comme destination d'écriture.
