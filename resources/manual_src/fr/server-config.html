Configuration du serveur

Cet écran configuré le comportement du serveur. Seuls les administrateurs peuvent y accéder.

Bouton supérieur

Appuyez sur le bouton Gestion des comptes pour ouvrir l'écran de gestion des comptes.

Boutons inférieurs

Appliquer : Enregistrer les paramètres.
Annuler : Annuler les modifications et fermer l'écran.

Les modifications nécessitent un redémarrage du serveur pour prendre effet.

Gestion du stockage

Les dépôts de données sont les emplacements ou les enregistrements sont sauvegardes. Plusieurs dépôts peuvent etre configurés selon l'usage ou l'appareil.

L'attribution par utilisateur est geree via le bouton "Attribution du stockage" dans Gestion des comptes.

Comment ajouter un dépôt

  1. Ouvrez Gestion des comptes > Attribution du stockage de l'utilisateur souhaite.
  2. Appuyez sur le bouton "Ajouter".
  3. Configurez les éléments suivants : nom d'affichage, type, chemin, utiliser comme destination d'ecriture, active.
  4. Appuyez sur "Enregistrer".
