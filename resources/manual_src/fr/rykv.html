Vue du journal de vie

Écran pour parcourir les journaux de vie avec des miniatures. Prend en charge plusieurs modes d'affichage et fonctions de filtrage.

Boutons de la barre d'outils

Bouton Description
☰ Barre latérale Ouvre/ferme la barre latérale pour le filtrage et la navigation.
📄 Détails Affiche/masque le panneau de détails de l'enregistrement.
📊 Vue récapitulative Affiche l'écran d'analyse statistique.
📅 Calendrier Affiche la vue calendrier.
🗺 Carte Affiche les enregistrements avec des informations GPS sur la carte.
⚙ Paramètres Ouvre l'écran des paramètres de l'application.
❔ AideAffiche l'aide de l'écran actuel.

Fonctions principales

Affichage en liste avec miniatures d'images

Affiche les enregistrements dans une grille à plusieurs colonnes. Les enregistrements contenant des images ou des fichiers affichent une miniature. Le nombre de colonnes peut être modifié de 1 à 10 dans l'écran des paramètres.

Barre latérale (filtres et recherche)

La barre latérale permet de spécifier les conditions suivantes pour affiner les enregistrements.

  • Recherche textuelle (mot-clé)
  • Filtrage par étiquettes
  • Spécification d'une période
  • Sélection du type d'enregistrement
  • Sélection de l'emplacement de stockage des enregistrements

Ajouter une colonne de filtre

Le bouton « + » permet d'ajouter une nouvelle colonne de filtre. Vous pouvez ainsi comparer côte à côte les résultats de conditions de filtrage différentes.

Panneau de détails

Lorsque vous sélectionnez un enregistrement, le panneau de détails affiche toutes les informations de cet enregistrement.

Statistiques de la vue d'agrégation

Affiche les statistiques et les résultats d'analyse des données d'enregistrement. Vous pouvez ainsi saisir les tendances et les schémas de vos enregistrements.

Affichage de la carte GPS

Affiche les données du journal GPS sur une carte. Les itinéraires de déplacement et les informations de localisation peuvent être vérifiés visuellement. La configuration d'une clé API Google Maps est nécessaire.

Astuce : Le nombre de colonnes d'images peut être modifié dans l'écran des paramètres. 1 à 2 colonnes sont recommandées sur smartphone, et 3 à 5 colonnes sur PC.
Astuce : Il est pratique d'ajouter plusieurs colonnes de filtre et de comparer côte à côte des enregistrements répondant à des conditions différentes.
Astuce : La valeur par défaut de la période d'affichage peut être modifiée dans le paramètre « Jours d'affichage du journal de vie » de l'écran de configuration.

Utilisation des étiquettes

Ajouter une étiquette

  1. Maintenez appuyé ou faites un clic droit sur un enregistrement pour ouvrir le menu contextuel.
  2. Sélectionnez "Ajouter une étiquette".
  3. Tapez le nom de l'étiquette (les étiquettes existantes s'affichent comme suggestions).

Pour appliquer un tag récemment utilisé, servez-vous de « Ajouter un tag depuis l'historique » dans le menu contextuel : il suffit de le choisir dans la liste.

Si vous saisissez un nom de tag encore jamais utilisé, une confirmation « C'est un nouveau tag. Voulez-vous l'ajouter ? » apparaît avant l'enregistrement. Elle évite que des tags très proches se multiplient à cause de fautes de frappe.

Modifier ou supprimer une étiquette

  1. Maintenez appuyé ou faites un clic droit sur l'étiquette à modifier.
  2. Sélectionnez "Modifier" ou "Supprimer" dans le menu.

Gestion de la structure des étiquettes

Vous pouvez gérer les noms d'affichage et l'ordre des étiquettes dans Paramètres > Structure des étiquettes.

Astuce : En écrivant #nom_etiquette dans la syntaxe du bloc-notes, l'enregistrement sera automatiquement étiqueté. Consultez la Référence de syntaxe du bloc-notes pour plus de détails.

Détails du téléversement de fichiers

Procédure d'utilisation

  1. Appuyez sur le bouton « + » et sélectionnez « Téléverser un fichier ».
  2. Sélectionnez l'emplacement de stockage de destination (dépôt pour la gestion de fichiers).
  3. Confirmez et ajustez la date et l'heure associées.
  4. Sélectionnez le ou les fichiers à téléverser (plusieurs fichiers possibles). Vous pouvez aussi glisser-déposer les fichiers dans la zone « Déposez les fichiers ici » de la boîte de dialogue.

Formats de fichiers pris en charge

Images (JPEG/PNG/GIF/WEBP), vidéos (MP4, etc.), PDF, ZIP et autres.

Les fichiers Markdown (.md / .markdown) sont affichés en texte enrichi (titres, tableaux) dans les vues liste et détail, et les blocs de code mermaid sont rendus sous forme de diagrammes.

Limite de taille de téléversement

La limite mensuelle de taille de téléversement est définie par l'administrateur dans « Limite mensuelle de taille de téléversement » de la configuration du serveur. La valeur initiale est -1 (illimité).

Astuce : Appuyez sur Ctrl+V pour enregistrer le contenu du presse-papiers directement en tant que fichier.

Voir le contenu d'un fichier ZIP

Vous pouvez ouvrir le contenu des fichiers ZIP téléversés directement à l'écran, sans les extraire sur votre ordinateur. Les fichiers dont l'extension est .cbz sont eux aussi traités comme des ZIP.

Comment l'ouvrir

  1. Appuyez longuement (mobile) ou faites un clic droit (bureau) sur l'enregistrement du fichier ZIP.
  2. Choisissez « Parcourir le contenu ZIP » dans le menu contextuel.
  3. Les dossiers et fichiers contenus dans le ZIP s'affichent sous forme de liste.

Se déplacer à l'intérieur

  • Un clic sur un dossier vous fait entrer dedans. Pour remonter d'un niveau, utilisez le fil d'Ariane en haut de l'écran ou « .. ».
  • Un clic sur une image ouvre l'aperçu, et vous pouvez passer directement à l'image suivante.
  • Vous pouvez aussi télécharger chaque fichier séparément.
  • Les fichiers trop volumineux ne peuvent pas être prévisualisés ; un message vous en informe.
Astuce : « Parcourir le contenu ZIP » n'apparaît dans le menu que lorsque vous sélectionnez l'enregistrement d'un fichier ZIP. Il ne s'affiche pas pour les autres enregistrements.

Transformer un enregistrement en tâche et copier son contenu

Un enregistrement que vous souhaitez traiter plus tard peut devenir une tâche sans en réécrire le contenu. Choisissez « Transformer en tâche » dans le menu contextuel de l'enregistrement, renseignez le nom du tableau, l'échéance et les dates de début et de fin prévues, puis enregistrez. La tâche créée apparaît aussi dans la Vue des tâches et peut être cochée comme terminée.

En choisissant « Copier le contenu » dans le menu contextuel, vous copiez le corps de l'enregistrement dans le presse-papiers. « Copier l'ID » copie l'identifiant de l'enregistrement.

Utilisation de la carte GPS

Téléverser un enregistrement GPS

  1. Appuyez sur le bouton "+" et sélectionnez "Téléverser un fichier".
  2. Sélectionnez le dépôt destine aux enregistrements GPS.
  3. Sélectionnez le fichier GPX. Vous pouvez aussi le glisser-déposer dans la zone « Déposez les fichiers .gpx ici ».
  4. Activez le bouton de carte pour confirmer l'affichage.

Configurer la clé API Google Maps

Allez dans Paramètres > Paramètres d'affichage > Clé API Google Maps et entrez votre clé.

Astuce : Obtenez votre clé API dans Google Cloud Console en activant l'API Maps JavaScript.

Partager les critères de recherche actuels

Activez « Afficher le pied de page de partage » dans l’écran des paramètres et un pied de page de partage apparaît en bas de la barre latérale. En appuyant sur le bouton « Partager » à son extrémité gauche, les critères de recherche que vous utilisez deviennent un lien de partage. Ce qui est partagé n’est pas un seul enregistrement, mais tous les enregistrements correspondant à ces critères. Les liens déjà créés peuvent être listés, modifiés et supprimés depuis « Gestion des partages », à l’extrémité droite.
