Enregistrements

Écran affichant les détails d'un enregistrement individuel. Vous pouvez consulter les informations détaillées de chaque type d'enregistrement.

Boutons de la barre d'outils

Bouton Description
⚙ Paramètres Ouvre l'écran des paramètres de l'application.
❔ AideAffiche l'aide de l'écran actuel.

Types d'enregistrements affichés

Type d'enregistrement Description
Mémo Affiche le contenu des notes textuelles.
Signets Affiche l'URL et le titre enregistrés.
Tâches Affiche l'état, la date limite et les informations du tableau de la tâche.
Humeur Affiche la valeur d'humeur de 0 à 10.
Dépenses Affiche le montant et le contenu de la dépense.
Entrée de temps Affiche l'heure de début et de fin ainsi que le temps écoulé.
Fichier Affiche un aperçu du fichier téléchargé. Les fichiers texte (.txt) affichent leur contenu directement dans la vue. Les fichiers Markdown (.md / .markdown) sont affichés en texte enrichi (titres, tableaux, blocs de code, images) et les schémas écrits en syntaxe Mermaid sont affichés sous forme de diagrammes. Si un lien du contenu est un chemin relatif vers un fichier du même dépôt, un double-clic ouvre la boîte de dialogue de cet enregistrement.
Enregistrements numériques Affiche le titre et les données numériques.
Repost Affiche un enregistrement qui republie un autre enregistrement à une autre date et heure.
Tâche de repost Un enregistrement existant rendu utilisable comme tâche. Le contenu de l'enregistrement d'origine est affiché tel quel, avec une échéance et une case à cocher.
Enregistrement d'extension Affiche les enregistrements de services autres que gkill importés par une extension. Voir Extensions pour les détails.
Journal GPS Affiche les données de journal de localisation GPS.
Journal de commit Git Affiche les informations de commit d'un dépôt Git.
Notification Un enregistrement qui vous envoie un rappel à la date et à l'heure indiquées.

Informations communes affichées

Les informations suivantes sont affichées pour tous les types d'enregistrements :

  • Tags : liste des tags attribués à l'enregistrement
  • Heure associée : date et heure liées à l'enregistrement
  • Nom du dépôt : nom du dépôt où les données sont stockées

Menu contextuel

Faites un clic droit (ou un appui long) sur un enregistrement pour ouvrir le menu contextuel et effectuer les opérations suivantes. Les éléments affichés varient légèrement selon le type d'enregistrement.

  • Ajouter un tag depuis l'historique : Choisissez parmi les tags récemment utilisés et ajoutez-le aussitôt.
  • Ajouter un tag / Modifier un tag : Ajoute ou modifie des tags.
  • Ajouter du texte / Modifier le texte : Ajoute ou modifie un texte complémentaire.
  • Repost : Fait réapparaître cet enregistrement dans la liste, à l'heure actuelle.
  • Transformer en tâche : Permet de traiter cet enregistrement comme une tâche, tel quel, sans réécrire son contenu.
  • Ajouter une notification / Modifier la notification : Ajoute ou modifie un rappel.
  • Modifier : Modifie le contenu de l'enregistrement.
  • Historique : Consulte l'historique des modifications des tags, textes et notifications.
  • Copier le contenu : Copie le corps de l'enregistrement dans le presse-papiers.
  • Copier l'ID : Copie l'identifiant de l'enregistrement dans le presse-papiers.
  • Parcourir le contenu ZIP : Affiché uniquement pour les enregistrements de fichiers ZIP ; ouvre leur contenu à l'écran.
  • Ouvrir le dossier / Ouvrir le fichier : Affiché uniquement lorsque vous ouvrez gkill sur le même appareil ; ouvre le fichier de l'enregistrement avec l'application par défaut du système.
  • Supprimer : Supprime l'enregistrement. Les tags, textes et notifications qui lui sont attachés, ainsi que les reposts et les tâches de repost qui y font référence, sont supprimés en même temps. Si la suppression échoue en cours de route, rien n'est supprimé.
Astuce : Vous pouvez ajouter ou modifier des tags directement depuis l'écran de détails de l'enregistrement.
Astuce : Les enregistrements importés par une extension sont en lecture seule. « Modifier » et « Supprimer » ne s'affichent pas, mais vous pouvez ajouter des tags et des textes ou utiliser « Transformer en tâche ».
