Enregistrements

Écran affichant les détails d'un enregistrement individuel. Vous pouvez consulter les informations détaillées de differents types d'enregistrements.

Boutons de la barre d'outils

Bouton Description
⚙ Paramètres Ouvre l'écran des paramètres de l'application.
❔ AideAffiche l'aide de l'écran actuel.

Types d'enregistrements affiches

Type d'enregistrement Description
Mémo Affiche le contenu des notes textuelles.
Signets Affiche les URLs et titres enregistres.
Tâches Affiche l'état, la date limite et les informations du tableau de la tâche.
Humeur Affiche la valeur d'humeur de 0 a 10.
Depenses Affiche le montant et le contenu de la dépense.
Journal de temps Affiche l'heure de debut/fin et le temps écoulé.
Fichier Affiche un aperçu du fichier téléchargé. Les fichiers texte (.txt) affichent leur contenu directement dans la vue. Les fichiers Markdown (.md / .markdown) sont affichés en texte enrichi (titres, tableaux, blocs de code, images) et les blocs de code mermaid sont rendus sous forme de diagrammes. Si un lien du contenu est un chemin relatif vers un fichier du même dépôt, un double-clic ouvre la boîte de dialogue de cet enregistrement.
Enregistrements numériques Affiche le titre et les données numériques.
Repost Affiche les enregistrements republiés à une autre date/heure.
Tâche de repost Un enregistrement existant rendu utilisable comme tâche. Le contenu de l'enregistrement d'origine est affiché tel quel, avec une échéance et une case à cocher.
Enregistrement d'extension Un enregistrement importé par une extension depuis un service autre que gkill. Voir Extensions pour les détails.
Journal GPS Affiche les données de journal de localisation GPS.
Journal de commit Git Affiche les informations de commits du dépôt Git.
Notification Affiche les notifications et rappels.

Informations communes affichées

Les informations suivantes sont affichées pour tous les types d'enregistrements :

  • Etiquettes : Liste des étiquettes attribuees a l'enregistrement
  • Temps associé : Informations de date et heure liées a l'enregistrement
  • Dépôt : Nom du dépôt ou les données sont stockees

Menu contextuel

Faites un clic droit (ou un appui long sur mobile) sur un enregistrement pour ouvrir le menu contextuel. Les éléments affichés varient légèrement selon le type d'enregistrement.

  • Ajouter un tag depuis l'historique: Choisissez parmi les tags récemment utilisés et ajoutez-le aussitôt.
  • Ajouter un tag / Modifier un tag: Ajoute ou modifie des tags.
  • Ajouter du texte / Modifier le texte: Ajoute ou modifie un texte complémentaire.
  • Repost: Remet cet enregistrement dans la liste à l'heure actuelle.
  • Transformer en tâche: Transforme cet enregistrement en tâche sans réécrire son contenu.
  • Ajouter une notification / Modifier la notification: Ajoute ou modifie un rappel.
  • Modifier: Modifie le contenu de l'enregistrement.
  • Historique: Consulte l'historique des modifications des tags, textes et notifications.
  • Copier le contenu: Copie le corps de l'enregistrement dans le presse-papiers.
  • Copier l'ID: Copie l'identifiant de l'enregistrement dans le presse-papiers.
  • Paramètres de l’extension : Affiché uniquement pour les enregistrements importés par une extension ; ouvre son écran de réglages.
  • Parcourir le contenu ZIP: Affiché uniquement pour les enregistrements de fichiers ZIP ; ouvre leur contenu à l'écran.
  • Ouvrir le dossier / Ouvrir le fichier: Affiché uniquement lorsque gkill s'exécute sur le même appareil ; ouvre le fichier avec l'application par défaut du système.
  • Supprimer: Supprime l'enregistrement.
Astuce : Vous pouvez ajouter ou modifier des étiquettes directement depuis l'écran de détails de l'enregistrement.
Astuce : Les enregistrements importés par une extension sont en lecture seule. « Modifier » et « Supprimer » ne s'affichent pas, mais vous pouvez ajouter des tags et des textes ou utiliser « Transformer en tâche ».
