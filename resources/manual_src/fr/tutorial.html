Tutoriel

Ce guide explique comment utiliser gkill, en deux parties : les bases et les fonctions avancées. Si vous debutez, veuillez lire la partie basique en premier.

À propos de cette boite de dialogue : Cette boite de dialogue d'aide laisse passer les clics de souris et les interactions tactiles vers l'écran situe en arriere-plan. Vous pouvez interagir avec l'application tout en gardant cette boite de dialogue ouverte.
Utilisation sur smartphone : gkill fonctionne comme une PWA (Progressive Web App). Sélectionnez « Ajouter a l'écran d'accueil » (iOS Safari) ou « Installer l'application » (Android Chrome) depuis le menu de votre navigateur pour le lancer directement depuis votre écran d'accueil.

Terminologie

Dans gkill, les types de données sont appeles « types d'enregistrement » (Mémo, Horodatage, Tâche, etc.) et les écrans de travail sont appeles « noms d'écran » (Bloc-notes, Bloc-notes d'horodatage, Tâches, etc.). Par exemple, « Mémo » designe le type de donnée textuelle, tandis que « Bloc-notes » designe l'écran de saisie. Les éléments affiches dans le menu du bouton « + » sont des noms d'écran pour ajouter chaque type d'enregistrement.

Partie basique

1. Se connecter a gkill

Premier lancement

Lors du premier lancement de gkill, l'écran d'inscription s'affiche automatiquement.

  1. Saisissez un identifiant utilisateur (ce sera le nom de votre compte).
  2. Saisissez un mot de passe, puis confirmez-le en le saisissant une seconde fois.
  3. Saisissez un mot de passe administrateur et confirmez-le (il s'agit du mot de passe du compte admin crée automatiquement, utilise pour la gestion du serveur).
  4. Appuyez sur le bouton "Inscription" pour créer votre compte.
  5. Vous serez redirige vers l'écran de connexion. Connectez-vous avec le compte que vous venez de créer.

Connexion habituelle

  1. Saisissez l'identifiant de votre compte dans le champ prevu a cet effet.
  2. Saisissez votre mot de passe dans le champ correspondant.
  3. Cliquez sur le bouton "Connexion" ou appuyez sur la touche Entree.
Astuce : La session reste active pendant 30 jours après la connexion. Vous n'avez pas besoin de vous reconnecter avant l'expiration de ce délai.

2. Ajouter un enregistrement

gkill permet d'enregistrer differents types de journaux de vie. Ajoutez un enregistrement en appuyant sur le bouton "+" en bas a droite de l'écran.

Type d'enregistrementUsageExemple de saisie
MémoLaisser une note textuelle"Il faisait beau aujourd'hui"
PointageEnregistrer le temps (debut/fin)"Reunion 10h00-11h30"
TâcheGérer les choses a faire"Rediger le rapport"
DépenseEnregistrer les dépenses"Superette : sandwich 3,50 EUR"
HumeurEnregistrer l'humeur sur une echelle de 0 a 10"7"
Enregistrements numériquesEnregistrer des données numériques"Poids : 65,5"
SignetSauvegarder une URL"https://example.com"
FichierTéléverser des images ou fichiersPhotos, PDF, etc.
Enregistrer le presse-papiersEnregistrer le contenu du presse-papiers comme fichierCaptures d'écran, images copiees, etc.

Procédure d'ajout d'un enregistrement

  1. Appuyez sur le bouton "+" en bas a droite de l'écran.
  2. Sélectionnez le type d'enregistrement que vous souhaitez ajouter.
  3. Remplissez le formulaire de saisie.
  4. Appuyez sur le bouton "Enregistrer" pour sauvegarder.
Astuce : En utilisant l'écran du bloc-notes, vous pouvez saisir plusieurs enregistrements à la fois sous forme de texte. Pour plus de détails, consultez la section "3. Saisir plusieurs enregistrements à la fois avec le bloc-notes" ci-dessous.

3. Saisir plusieurs enregistrements à la fois avec le bloc-notes

L'écran du bloc-notes permet de créer plusieurs enregistrements simultanement en écrivant simplement du texte.

Utilisation de base

  1. Ouvrez l'écran du bloc-notes (sélectionnez "Bloc-notes" dans le menu du bouton "+").
  2. Saisissez le contenu que vous souhaitez enregistrer dans la zone de texte.
  3. Appuyez sur le bouton "Enregistrer" (vous pouvez egalement saisir ! et envoyer).

Saisie a l'aide de modèles

Les modèles vous permettent de saisir des textes predefinis en un seul geste.

  1. Sur l'écran du bloc-notes, sélectionnez un modèle dans la liste des modèles.
  2. Le contenu du modèle est insere dans la zone de texte.
  3. Modifiez le contenu si nécessaire, puis enregistrez.
Astuce : Il est pratique d'enregistrer a l'avance les schemas d'enregistrement que vous utilisez frequemment en tant que modèles. Vous pouvez les gérer depuis "Structure des modèles" dans l'écran de configuration.

4. Consulter et rechercher des enregistrements

L'écran de visualisation des journaux de vie vous permet d'afficher et de rechercher vos enregistrements passes.

Operations de base

  1. Ouvrez l'écran de visualisation des journaux de vie depuis la barre de navigation en haut de l'écran.
  2. Les enregistrements sont affiches par ordre chronologique.
  3. Changez la date pour consulter les enregistrements d'un jour spécifique.

Recherche et filtrage

  • Filtrer par tag : Vous pouvez afficher uniquement les enregistrements portant un tag spécifique.
  • Plage de dates : Vous pouvez restreindre la période en specifiant une date de debut et de fin.
  • Recherche textuelle : Vous pouvez rechercher les enregistrements contenant un mot-clé.
Astuce : Reduire le "nombre de jours affiches dans la vue des journaux de vie" dans l'écran de configuration accélère le chargement.

5. Gérer les tâches

L'écran des tâches permet de gérer vos tâches sous forme de tableau Kanban.

Creation d'une tâche

  1. Ouvrez l'écran des tâches.
  2. Ajoutez une tâche avec le bouton "+".
  3. Saisissez le titre, le nom du tableau, la date limite, etc.
  4. Une fois enregistrée, la tâche apparaît dans le tableau spécifié.

Achevement d'une tâche

  1. Appuyez sur la tâche terminée pour ouvrir les détails.
  2. Cochez la case pour marquer la tâche comme terminée.
Astuce : Creez plusieurs tableaux pour organiser par catégorie, comme "Travail", "Personnel", "Courses", etc.

Transformer en tâche un enregistrement existant

Un enregistrement dont vous vous dites « je m'en occuperai plus tard » peut devenir une tâche sans avoir à en rédiger une nouvelle.

  1. Dans la Vue du journal de vie ou ailleurs, appuyez longuement (mobile) ou faites un clic droit (bureau) sur l'enregistrement voulu.
  2. Choisissez « Transformer en tâche ».
  3. Renseignez le nom du tableau, l'échéance et les dates de début et de fin prévues, puis enregistrez.
  4. Elle apparaît sur le tableau de la Vue des tâches et se coche comme n'importe quelle autre tâche.
Astuce : Les tâches créées ainsi n'ont pas de champ de titre, car le contenu de l'enregistrement d'origine est affiché tel quel. Notez que si vous supprimez l'enregistrement d'origine, la tâche qui en est issue est supprimée en même temps.

Comment ouvrir l'écran de configuration

  2. L'écran de configuration s'ouvre.

Partie avancée

7. Maîtriser la syntaxe du bloc-notes

8. Exploiter les modèles

En sauvegardant les schemas de syntaxe du bloc-notes que vous utilisez frequemment en tant que modèles, vous evitez de les saisir a chaque fois.

Gestion des modèles

  1. Ouvrez l'écran de configuration.
  2. Cliquez sur le bouton "Structure des modèles".
  3. Vous pouvez ajouter, modifier ou supprimer des modèles.

Exemple de creation de modèle

Par exemple, pour créer un modèle de journal quotidien :

.journal
,
-ra

En utilisant ce modèle, l'ebauche du journal est saisie en un seul geste sur l'écran du bloc-notes, et il vous suffit d'ajouter le contenu du mémo et la valeur d'humeur pour completer l'enregistrement.

Astuce : Utilisez des dossiers pour organiser vos modèles par catégorie afin de les retrouver plus facilement.

9. Enregistrer le temps avec les pointages

Nom de l'écran Usage
Bloc-notes d'horodatage Saisir des notes avec horodatage. Le téléversement de fichiers est également possible.
En cours Liste des sessions de suivi du temps actives. Vous pouvez terminer des sessions ici.
Bloc-notes Démarrer et terminer le suivi du temps par texte avec la syntaxe du bloc-notes. Peut être combiné avec d'autres enregistrements en lot.

La fonction de pointage vous permet d'enregistrer precisement vos temps de travail et d'activité. Le "Bloc-notes d'horodatage" est un écran dedie combinant saisie de notes et gestion des sessions en cours, tandis que le "Bloc-notes" permet de démarrer/terminer le suivi du temps via des prefixes avec d'autres enregistrements en lot.

Operations de base du pointage

  1. Debut : Utilisez le prefixe -ta dans le bloc-notes ou ajoutez un pointage depuis le menu "+". Specifiez le titre et l'heure de debut.
  2. Fin : Utilisez le prefixe -e dans le bloc-notes ou saisissez l'heure de fin dans l'écran de modification du pointage. Le pointage dont le titre correspond sera cloture.

Gérer les pointages en cours

L'écran de liste des pointages vous permet de consulter les pointages actuellement en cours.

  • Les pointages en cours sont affiches dans une liste.
  • Appuyez dessus pour definir l'heure de fin.
Astuce : En utilisant -ie dans la syntaxe du bloc-notes, aucune erreur ne se produit meme s'il n'y a pas de pointage correspondant. Cela permet de cloturer en toute sécurité sans verification prealable.

10. Analyser les données avec la vue d'agrégation

La vue d'agrégation intégrée à la vue journal de vie vous permet de visualiser les données enregistrées sous forme de tableaux récapitulatifs.

Utilisation de la vue d'agrégation

  1. Cliquez sur l'icône d'agrégation dans la barre d'outils de la vue journal de vie pour afficher la vue d'agrégation.
  2. Sélectionnez le type d'agrégation et la période.
  3. Les données sont affichées sous forme de tableaux récapitulatifs.

Configuration de l'agrégation

Depuis le bouton "Vue d'agrégation" dans l'écran de configuration, vous pouvez gérer les methodes d'agrégation et la composition des vues.

Astuce : Suivre l'evolution de l'humeur et des dépenses dans le temps permet de mieux comprendre vos habitudes de vie.

11. Tirer parti des intégrations externes

Enregistrer des URL avec un bookmarklet

En ajoutant un bookmarklet a la barre de favoris de votre navigateur, vous pouvez sauvegarder la page Web consultee dans gkill en un seul clic.

  1. Copiez l'URL affichee dans "Bookmarklet" dans l'écran de configuration.
  2. Ajoutez-la en tant que nouveau favori dans la barre de favoris de votre navigateur.
  3. Lorsque vous consultez une page Web que vous souhaitez sauvegarder, cliquez sur le favori enregistre.

Enregistrement GPS et affichage sur carte

Si vous enregistrez des journaux GPS, vous pouvez afficher votre historique de deplacements sur une carte.

  1. Configurez la "Clé API Google Map" dans l'écran de configuration.
  2. Si des données GPS sont enregistrees, l'affichage cartographique est disponible dans la vue des journaux de vie.
Astuce : Pour obtenir une clé API Google Maps, activez l'API Maps JavaScript dans la console Google Cloud.

Importer les enregistrements de services externes avec des extensions

Avec une extension installée, les enregistrements laissés dans des services autres que gkill s'affichent dans la même liste. Trois extensions sont fournies en standard : ChatGPT, Claude.ai et Claude Code.

  1. Placez l'exécutable de l'extension dans le dossier prévu.
  2. Au démarrage de gkill, le fichier de configuration est créé automatiquement dans ce même dossier.
  3. Indiquez dans le fichier de configuration le dossier contenant les données à importer.
  4. En effectuant une recherche dans la Vue du journal de vie, ils apparaissent aux côtés des autres enregistrements.
Astuce : Voir Extensions pour la procédure détaillée.

12. Partager des enregistrements

Dans gkill, vous pouvez transformer les critères de recherche que vous utilisez actuellement en un lien de partage et le montrer à d'autres personnes. Ce qui est partagé n'est pas un seul enregistrement, mais tous les enregistrements correspondant à ces critères.

Comment générer un lien de partage

  1. Activez « Afficher le pied de page de partage » dans l'écran des paramètres. Cette option est désactivée par défaut, il suffit donc de le faire une fois au début.
  2. Ouvrez la barre latérale sur la vue de journal de vie ou sur l'écran des tâches. Le pied de page de partage apparaît en bas de la barre latérale.
  3. Ajustez les conditions de filtrage dans la barre latérale jusqu'à obtenir ce que vous souhaitez partager.
  4. Appuyez sur le bouton « Partager » à l'extrémité gauche du pied de page, définissez le titre, le type de vue de partage et les données à inclure, puis enregistrez.
  5. Une URL de partage sera générée. Utilisez l'URL appropriee selon votre besoin :
Type d'URLUsage
LocalAccès depuis le meme appareil (localhost)
Réseau localAccès depuis d'autres appareils sur le meme reseau
GlobalAccès externe via Internet

Controle des données partagees

Lors du partage, vous pouvez choisir quelles données inclure.

OptionDescription
TagsInclure les tags attachés a l'enregistrement
TexteInclure le contenu texte de l'enregistrement
HorodatagesInclure les informations d'horodatage
LocalisationInclure les informations de localisation GPS
Heure uniquementInclure uniquement les informations d'heure
Conseil : Pour utiliser les URLs Réseau local ou Global, vous devez configurer l'adresse du serveur dans les paramètres du serveur. Les liens déjà créés peuvent être listés, modifiés et supprimés depuis « Gestion des partages », à l'extrémité droite du pied de page de partage.

Pour les destinataires de liens partages

En ouvrant un lien partage, vous pouvez consulter les enregistrements sans avoir de compte gkill.

  • L'etendue des enregistrements affiches est determinee par les paramètres du createur du lien.
  • Vous ne pouvez ni modifier ni supprimer les enregistrements (consultation uniquement).
  • Si le lien n'est plus valide, veuillez contacter l'expediteur.

13. Sauvegarde et gestion des données

Configuration du serveur (administrateurs)

En vous connectant avec un compte administrateur, le bouton "Configuration du serveur" apparaît dans l'écran de configuration.

  • Numéro de port : Vous pouvez modifier le port d'ecoute du serveur (par defaut : 9999).
  • Configuration TLS : Vous pouvez activer la communication HTTPS.
  • Restriction d'accès : Vous pouvez limiter l'accès au reseau local uniquement.

Gestion des comptes

L'administrateur peut ajouter, activer et désactiver des comptes utilisateurs depuis l'écran "Gestion des comptes".

Sauvegarde des données

Toutes les données de gkill sont stockees dans le répertoire personnel (par defaut : ~/gkill ; /sdcard/gkill dans l'application Android). Il suffit de sauvegarder ce répertoire pour preserver l'ensemble de vos données.

Astuce : Il est recommandé de sauvegarder régulièrement le répertoire personnel. Les répertoires datas/ et configs/ sont particulièrement importants.
Remarque : L'emplacement des dépôts peut aussi être défini en dehors du répertoire personnel. Si vous utilisez des fichiers placés dans des dossiers externes (fichiers placés dans des dossiers externes, historiques de commits Git, bases de données situées à l’extérieur, etc.), copier uniquement le répertoire personnel les omettra. Veillez à inclure également dans votre sauvegarde l'emplacement de tous les dépôts configurés.
