Tutoriel

Ce guide explique comment utiliser gkill, en deux parties : les bases et les fonctions avancées. Si vous débutez, lisez d'abord la partie basique dans l'ordre.

À propos de cette boîte de dialogue : Cette boîte de dialogue d'aide laisse passer les clics de souris et les interactions tactiles vers l'écran situé en arrière-plan. Vous pouvez manipuler l'écran en arrière-plan pour essayer réellement, tout en gardant cette boîte de dialogue ouverte.
Utilisation sur smartphone : gkill fonctionne comme une PWA (Progressive Web App). Sélectionnez « Ajouter à l'écran d'accueil » (iOS Safari) ou « Installer l'application » (Android Chrome) depuis le menu de votre navigateur pour le lancer directement depuis votre écran d'accueil, comme une application.

Terminologie

Dans gkill, les types de données sont appelés « types d'enregistrement » (Mémo, Entrée de temps, Tâche, etc.) et les écrans de travail sont appelés « noms d'écran » (Bloc-notes, Bloc-notes d'entrées de temps, Tâches, etc.). Par exemple, « Mémo » désigne le type d'enregistrement « note textuelle », tandis que « Bloc-notes » désigne l'écran qui sert à saisir cet enregistrement. Les éléments affichés dans le menu du bouton « + », comme « Bloc-notes » ou « Suivi du temps », sont les noms des écrans qui servent à ajouter chaque type d'enregistrement.

Changer d'écran

Appuyez sur le titre de la page affiché dans la barre d'outils en haut de l'écran (par exemple « Vue du journal de vie » ou « Tâches ») pour ouvrir un menu déroulant et naviguer vers chaque écran.

Partie basique

1. Se connecter à gkill

Premier lancement

Lors du premier lancement de gkill, l'écran d'inscription de compte s'affiche automatiquement.

  1. Saisissez un identifiant utilisateur (ce sera le nom de votre compte).
  2. Saisissez un mot de passe, puis confirmez-le en le saisissant une seconde fois.
  3. Saisissez un mot de passe administrateur et confirmez-le (il s'agit du mot de passe du compte admin créé automatiquement, utilisé pour la gestion du serveur).
  4. Appuyez sur le bouton « Inscription » pour créer votre compte.
  5. Vous êtes redirigé vers l'écran de connexion. Connectez-vous avec le compte que vous venez de créer.

Connexion habituelle

  1. Saisissez l'identifiant de votre compte dans le champ d'identifiant.
  2. Saisissez votre mot de passe dans le champ de mot de passe.
  3. Cliquez sur le bouton « Connexion » ou appuyez sur la touche Entrée.
Astuce : Une fois connecté, la session reste valable 30 jours. Vous n'avez pas besoin de vous reconnecter avant son expiration.

2. Ajouter un enregistrement

gkill permet d'enregistrer différents types de journaux de vie. Ajoutez un enregistrement avec le bouton « + » en bas à droite de l'écran.

Type d'enregistrementUsageExemple de saisie
MémoLaisser une note textuelle« Il faisait beau aujourd'hui »
Entrée de tempsEnregistrer le temps (début et fin)« Réunion 10h00-11h30 »
TâcheGérer les choses à faire« Rédiger le rapport »
DépenseEnregistrer l'utilisation de votre argent« Supérette : sandwich 3,50 EUR »
HumeurEnregistrer l'humeur avec une valeur de 0 à 10« 7 »
Enregistrement numériqueEnregistrer des données numériques« Poids : 65,5 »
SignetEnregistrer une URL« https://example.com »
FichierTéléverser des images ou des fichiersPhotos, PDF, etc.
Enregistrer le presse-papiersEnregistrer le contenu du presse-papiers comme fichierCaptures d'écran, images copiées, etc.

Procédure d'ajout d'un enregistrement

  1. Appuyez sur le bouton « + » en bas à droite de l'écran.
  2. Sélectionnez le type d'enregistrement que vous souhaitez ajouter.
  3. Remplissez le formulaire de saisie.
  4. Appuyez sur le bouton « Enregistrer » pour sauvegarder l'enregistrement.
Astuce : Avec l'écran du bloc-notes, vous pouvez saisir plusieurs enregistrements d'un coup sous forme de texte. Pour plus de détails, consultez la section « 3. Saisir plusieurs enregistrements à la fois avec le bloc-notes » ci-dessous.

3. Saisir plusieurs enregistrements à la fois avec le bloc-notes

L'écran du bloc-notes permet de créer plusieurs enregistrements en une seule fois, simplement en écrivant du texte.

Utilisation de base

  1. Ouvrez l'écran du bloc-notes (sélectionnez « Bloc-notes » dans le menu du bouton « + »).
  2. Saisissez le contenu que vous souhaitez enregistrer dans la zone de texte.
  3. Appuyez sur le bouton « Enregistrer » (vous pouvez également saisir ! pour envoyer).

Saisie à l'aide de modèles

Les modèles vous permettent de saisir des textes types en une seule touche.

  1. Sur l'écran du bloc-notes, sélectionnez un modèle dans la liste des modèles.
  2. Le contenu du modèle est inséré dans la zone de texte.
  3. Modifiez le contenu si nécessaire, puis enregistrez.
Astuce : Il est pratique d'enregistrer à l'avance comme modèles les schémas d'enregistrement que vous utilisez souvent. Vous pouvez les gérer depuis « Structure des modèles » dans l'écran des paramètres.

4. Consulter et rechercher des enregistrements

L'écran Vue du journal de vie vous permet de lister et de rechercher vos enregistrements passés.

Opérations de base

  1. Ouvrez l'écran Vue du journal de vie depuis la navigation en haut de l'écran.
  2. Les enregistrements sont listés par ordre de date.
  3. Changez la date pour consulter les enregistrements d'un jour précis.

Recherche et filtrage

  • Filtrer par tag : Vous pouvez afficher uniquement les enregistrements portant un tag précis.
  • Plage de dates : Choisissez la date de début et la date de fin dans le calendrier (ainsi que l'heure de début et l'heure de fin si nécessaire) pour restreindre la période. Le « × » à l'intérieur d'un champ d'heure permet de le vider. Pour retirer complètement la période, appuyez sur « Effacer ».
  • Recherche textuelle : Vous pouvez rechercher les enregistrements contenant un mot-clé.
Astuce : Réduire « Jours d'affichage du journal de vie » dans l'écran des paramètres accélère le chargement.

5. Gérer les tâches

L'écran des tâches permet de gérer vos tâches sous forme de tableau Kanban.

Création d'une tâche

  1. Ouvrez l'écran des tâches.
  2. Ajoutez une tâche avec le bouton « + ».
  3. Saisissez le titre, le nom du tableau, l'échéance, etc.
  4. Une fois enregistrée, la tâche apparaît dans le tableau indiqué.

Achèvement d'une tâche

  1. Appuyez sur la tâche terminée pour ouvrir ses détails.
  2. Cochez la case pour marquer la tâche comme terminée.
Astuce : Créez plusieurs tableaux pour gérer vos tâches par catégorie, comme « Travail », « Personnel » ou « Courses » : elles seront plus faciles à organiser.

Transformer en tâche un enregistrement existant

Un enregistrement dont vous vous dites « je m'en occuperai plus tard » peut devenir une tâche tel quel, sans avoir à réécrire une tâche.

  1. Dans la Vue du journal de vie ou ailleurs, appuyez longuement (mobile) ou faites un clic droit (bureau) sur l'enregistrement voulu.
  2. Choisissez « Transformer en tâche ».
  3. Renseignez le nom du tableau, l'échéance et les dates de début et de fin prévues, puis enregistrez.
  4. La tâche apparaît sur le tableau de l'écran des tâches et se coche comme n'importe quelle autre tâche.
Astuce : Les tâches créées ainsi n'ont pas de champ de titre, car le contenu de l'enregistrement d'origine est affiché tel quel. Attention : si vous supprimez l'enregistrement d'origine, la tâche qui en est issue est supprimée en même temps.

  2. L'écran des paramètres s'ouvre.

Paramètres fréquemment utilisés

Partie avancée

7. Maîtriser la syntaxe du bloc-notes

La syntaxe du bloc-notes permet de saisir d'un coup différents types d'enregistrements, simplement en ajoutant un préfixe en début de ligne.

Principaux préfixes

PréfixeTypeExemple
(aucun)MémoIl faisait beau aujourd'hui
#Étiquette#journal,meteo
/miTâche/mi puis le titre à la ligne suivante
/startDébut d'entrée de temps/start puis le titre à la ligne suivante
/endFin d'entrée de temps/end puis le titre à la ligne suivante
/expenseDépense/expense puis, aux lignes suivantes, le nom du magasin, l'article et le montant
/moodHumeur/mood puis une valeur (0 à 10) à la ligne suivante
,SéparateurDivise pour passer à l'enregistrement suivant
!EnregistrerTermine la saisie et enregistre

Exemple de saisie groupée de plusieurs enregistrements

Journal du jour
#journal
,
/mi
Aller faire les courses
,
/expense
Supermarché
Pommes
200
Lait
180
,
/mood
8
!

Dans cet exemple, quatre enregistrements sont créés en une seule fois : un mémo, une tâche, une dépense et une humeur.

Astuce : Pour la syntaxe détaillée, consultez la Référence de syntaxe du bloc-notes.

8. Exploiter les modèles

En enregistrant comme modèles les schémas de syntaxe du bloc-notes que vous utilisez souvent, vous évitez de les saisir à chaque fois.

Gestion des modèles

  1. Ouvrez l'écran des paramètres.
  2. Cliquez sur le bouton « Structure des modèles ».
  3. Vous pouvez ajouter, modifier ou supprimer des modèles.

Exemple de création de modèle

Par exemple, pour créer un modèle de journal quotidien :

#journal
,
/mood

Avec ce modèle, l'ébauche du journal est saisie en une seule touche sur l'écran du bloc-notes, et il vous suffit d'ajouter le contenu du mémo et la valeur d'humeur pour compléter l'enregistrement.

Astuce : Utilisez des dossiers pour organiser vos modèles par catégorie afin de les retrouver plus facilement.

9. Enregistrer le temps avec les entrées de temps

Nom de l'écran Usage
Bloc-notes d'entrées de temps Écran qui permet d'utiliser en même temps la saisie du bloc-notes et la liste des entrées de temps en cours.
En cours Liste des sessions d'entrée de temps actuellement actives. Vous pouvez y terminer les entrées de temps.
Bloc-notes Saisir par texte le début et la fin d'une entrée de temps avec la syntaxe du bloc-notes. Peut être saisi en lot avec d'autres enregistrements.

La fonction d'entrée de temps vous permet d'enregistrer précisément vos temps de travail et d'activité. Le « Bloc-notes d'entrées de temps » est un écran dédié qui combine la saisie de mémos et la gestion des entrées de temps en cours, tandis que l'écran « Bloc-notes » permet de saisir les entrées de temps avec leurs préfixes (/start / /end) en même temps que d'autres enregistrements.

Opérations de base des entrées de temps

  1. Début : Utilisez le préfixe /start dans le bloc-notes, ou ajoutez une entrée de temps depuis le menu « + ». Indiquez le titre et l'heure de début.
  2. Fin : Utilisez le préfixe /end dans le bloc-notes, ou saisissez l'heure de fin dans l'écran de modification de l'entrée de temps. L'entrée de temps dont le titre correspond est terminée.

Gérer les entrées de temps en cours

L'écran de liste des entrées de temps vous permet de consulter les entrées de temps actuellement en cours.

  • Les entrées de temps en cours sont affichées dans une liste.
  • Appuyez sur l'une d'elles pour définir l'heure de fin.
Astuce : Avec /end? dans la syntaxe du bloc-notes, aucune erreur ne se produit même s'il n'existe pas d'entrée de temps correspondante. Vous pouvez ainsi terminer sans risque, sans vérifier au préalable qu'elle existe.

10. Analyser les données avec la vue d'agrégation

La vue d'agrégation de l'écran Vue du journal de vie vous permet de visualiser les données enregistrées sous forme de tableaux récapitulatifs.

Utilisation de la vue d'agrégation

  1. Cliquez sur l'icône d'agrégation dans la barre d'outils de la Vue du journal de vie pour afficher la vue d'agrégation.
  2. Sélectionnez le type d'agrégation et la période.
  3. Les données sont affichées sous forme de tableaux récapitulatifs.

Configuration de l'agrégation

Depuis le bouton « Vue d'agrégation » de l'écran des paramètres, vous pouvez gérer les méthodes d'agrégation et la composition des vues.

Astuce : Suivre l'évolution de l'humeur et des dépenses dans le temps permet de faire apparaître vos habitudes de vie.

11. Tirer parti des intégrations externes

Enregistrer des URL avec un bookmarklet

En ajoutant un bookmarklet à la barre de favoris de votre navigateur, vous pouvez enregistrer dans gkill, en un seul clic, la page web que vous consultez.

  1. Copiez l'URL affichée dans « Bookmarklet » de l'écran des paramètres.
  2. Ajoutez-la comme nouveau favori dans la barre de favoris de votre navigateur.
  3. Lorsque vous consultez une page web que vous souhaitez enregistrer, cliquez sur le favori ajouté.

Enregistrement GPS et affichage sur carte

Si vous enregistrez des journaux GPS, vous pouvez afficher votre historique de déplacements sur une carte.

  1. Configurez la « Clé API Google Map » dans l'écran des paramètres.
  2. Si des données GPS sont enregistrées, l'affichage de la carte est disponible dans la Vue du journal de vie.
Astuce : Pour obtenir une clé API Google Map, activez l'API Maps JavaScript dans Google Cloud Console.

Importer les enregistrements de services externes avec des extensions

Avec une extension installée, les enregistrements laissés dans des services autres que gkill s'affichent dans la même liste. ChatGPT, Claude.ai, Claude Code, Codex, Antigravity et d'autres sont fournis en standard.

  1. Placez l'exécutable de l'extension dans le dossier prévu.
  2. Au démarrage de gkill, le fichier de configuration est créé automatiquement dans ce même dossier.
  3. Indiquez dans le fichier de configuration le dossier contenant les données à importer.
  4. En effectuant une recherche dans la Vue du journal de vie, ils apparaissent aux côtés des autres enregistrements.
Astuce : Voir Extensions pour la procédure détaillée.

12. Partager des enregistrements

Dans gkill, vous pouvez transformer les critères de recherche que vous utilisez actuellement en un lien de partage et le montrer à d'autres personnes. Ce qui est partagé n'est pas un seul enregistrement, mais tous les enregistrements correspondant à ces critères.

Comment générer un lien de partage

  1. Activez « Afficher le pied de page de partage » dans l'écran des paramètres. Cette option est désactivée par défaut : il suffit donc de le faire une fois au début.
  2. Ouvrez la barre latérale dans la Vue du journal de vie ou dans l'écran des tâches. Le pied de page de partage apparaît en bas de la barre latérale.
  3. Ajustez les conditions de filtrage dans la barre latérale jusqu'à obtenir ce que vous souhaitez partager.
  4. Appuyez sur le bouton « Partager » à l'extrémité gauche du pied de page de partage, puis choisissez « Partager cette vue » sur l'écran qui demande comment transmettre les enregistrements.
  5. Définissez le titre, le type de vue de partage et les données à inclure, puis enregistrez.
  6. Une URL de partage est générée. Utilisez l'URL qui convient selon l'usage :
Type d'URLUsage
LocalAccès depuis le même appareil (localhost)
LANAccès depuis d'autres appareils du même réseau
GlobalAccès externe via Internet

Contrôle des données partagées

Lors du partage, vous pouvez choisir quelles données inclure.

OptionDescription
TagsInclure dans le partage les tags attribués aux enregistrements
TexteInclure dans le partage le contenu texte des enregistrements
Entrées de tempsInclure dans le partage les informations horaires des entrées de temps
LocalisationInclure dans le partage les informations de localisation GPS
Heure uniquementInclure dans le partage uniquement les informations horaires des enregistrements
Conseil : Pour utiliser les URL LAN ou Global, vous devez configurer l'adresse du serveur dans les paramètres du serveur. Les liens de partage déjà créés peuvent être listés, modifiés et supprimés depuis « Gérer les liens partagés », à l'extrémité droite du pied de page de partage.

Pour les destinataires d'un lien de partage

En ouvrant un lien de partage, vous pouvez consulter les enregistrements sans avoir de compte gkill.

  • L'étendue des enregistrements affichés est déterminée par les paramètres de la personne qui a créé le lien.
  • Vous ne pouvez ni modifier ni supprimer les enregistrements (consultation uniquement).
  • Si le lien n'est plus valide, contactez l'expéditeur.
Vous pouvez aussi transmettre un fichier HTML : Si vous voulez montrer vos enregistrements à quelqu'un chez qui gkill ne fonctionne pas, choisissez « Exporter en HTML » depuis « Partager » dans le pied de page de partage : vous obtenez un fichier HTML qui s'ouvre simplement dans un navigateur. Pour plus de détails, consultez l'aide de la Vue du journal de vie ou du Tableau de tâches.

13. Sauvegarde et gestion des données

Configuration du serveur (administrateurs)

En vous connectant avec un compte administrateur, le bouton « Paramètres du serveur » apparaît dans l'écran des paramètres.

  • Numéro de port : Vous pouvez modifier l'adresse et le port d'écoute du serveur (par défaut : 127.0.0.1:9999, accessible uniquement depuis le même appareil).
  • Configuration TLS : Vous pouvez activer la communication HTTPS.
  • Restriction d'accès : Vous pouvez limiter les connexions à l'accès local uniquement (activé par défaut).

Gestion des comptes

L'administrateur peut ajouter, activer et désactiver des comptes utilisateur depuis l'écran « Gestion des comptes ».

Sauvegarde des données

Toutes les données de gkill sont stockées dans le répertoire personnel (par défaut : ~/gkill ; /sdcard/gkill dans l'application Android). Pour la sauvegarde, quittez d'abord gkill, puis copiez ce répertoire. Copier pendant que gkill fonctionne peut capturer un état écrit à moitié ; comme les instants d'enregistrement des différentes bases de données ne coïncident pas non plus, une sauvegarde corrompue peut passer inaperçue jusqu'à la restauration. Si vous ne pouvez pas arrêter gkill, utilisez la fonction d'instantané (snapshot) de votre système de fichiers, qui capture l'ensemble de l'état à un instant donné.

Astuce : Il est recommandé de sauvegarder régulièrement. Les répertoires datas/ et configs/ sont particulièrement importants. Les répertoires caches/ et logs/ sont reconstruits au démarrage : il n'est pas nécessaire de les inclure.
Remarque : Les dépôts peuvent aussi être placés en dehors du répertoire personnel. Si vous importez des fichiers placés dans des dossiers externes, des historiques de commits Git, etc., copier uniquement le répertoire personnel les omettra. Incluez aussi dans votre sauvegarde l'emplacement de tous les dépôts configurés, au même moment que le reste.
Vérifiez la restauration : Une sauvegarde n'est réussie que lorsqu'elle peut être restaurée. De temps en temps, restaurez-la réellement à un emplacement distinct de votre environnement de production, et vérifiez que gkill démarre normalement et que vos enregistrements sont consultables par la recherche. Vous repérerez ainsi les oublis ou les incohérences avant d'en avoir besoin.
