Bloc-notes

Écran de bloc-notes pour enregistrer des événements de la vie via la syntaxe du bloc-notes. Le bloc-notes utilise un format de texte structuré par lignes permettant la saisie par lots de divers enregistrements.

Boutons de la barre d'outils

Bouton Description
⚙ Paramètres Ouvre l'écran des paramètres de l'application.
❔ AideAffiche l'aide de l'écran actuel.

Éléments de l'écran

Élément Description
Zone de texte Zone de saisie du contenu des enregistrements en syntaxe du bloc-notes.
Bouton de modèle Insere un texte de modèle de bloc-notes predefini.
Bouton d'enregistrement Cliquez sur le bouton d'enregistrement pour analyser et enregistrer le texte du bloc-notes saisi.

Bouton de fermeture d'onglet Ferme cet onglet. Une confirmation apparaît s'il contient encore du texte.

Utilisation des onglets

Vous pouvez conserver plusieurs brouillons côte à côte. Si vous pensez à autre chose pendant la rédaction d'un enregistrement, appuyez sur le bouton d'ajout d'onglet, écrivez-le dans un nouvel onglet et revenez ensuite à l'onglet d'origine.

Action Résultat
Appuyer sur le bouton d'ajout d'onglet Un onglet vide est ajouté.
Cliquer sur le nom d'un onglet L'éditeur bascule sur le contenu de cet onglet.
Appuyer sur le bouton de fermeture d'onglet Cet onglet est fermé. Une confirmation apparaît s'il contient encore du texte.
Appuyer sur le bouton d'enregistrement Seul le contenu de cet onglet est enregistré, et l'onglet enregistré est fermé. Les autres onglets restent tels quels.
Choisir un modèle Un nouvel onglet s'ouvre avec le modèle. Le texte en cours n'est pas perdu.

Le nom de l'onglet reprend celui du modèle lorsqu'il a été ouvert depuis un modèle, sinon la première ligne du texte. Les onglets encore vides portent un numéro.

Astuce : Le texte en cours est conservé même après la fermeture de l'écran. À la prochaine ouverture, les onglets que vous aviez reviennent tels quels.

À propos du bloc-notes

Le bloc-notes utilise un format de texte propre à gkill qui permet de créer en masse plusieurs enregistrements dans un seul texte. Chaque ligne représente une commande ou une entrée de données.

Astuce : En utilisant le bouton de modèle, vous pouvez insérer rapidement des formats de saisie couramment utilisés sans avoir à mémoriser la syntaxe du bloc-notes.

Procédure d'utilisation

  1. Saisissez le contenu de l'enregistrement avec la syntaxe du bloc-notes dans la zone de saisie de texte.
  2. Si nécessaire, insérez un texte type à l'aide du bouton de modèle. Le modèle s'ouvre dans un nouvel onglet, le texte en cours n'est donc pas perdu.
  3. Cliquez sur le bouton d'enregistrement pour créer l'enregistrement.
  4. Si le texte contient un tag encore jamais utilisé, une confirmation « C'est un nouveau tag. Voulez-vous l'ajouter ? » apparaît. Si le tag vous convient, poursuivez.
  5. Une fois l'enregistrement réussi, cet onglet est fermé. Les autres onglets conservent leur texte. S'il n'en reste aucun, un onglet vide est préparé.
Astuce : La confirmation de nouveau tag évite que des tags très proches se multiplient à cause de fautes de frappe. Si le nom affiché n'est pas celui que vous vouliez, revenez en arrière et corrigez-le.
Astuce : L'utilisation de modèles permet une saisie plus efficace. Il est pratique d'enregistrer comme modèles les schémas d'enregistrement que vous utilisez souvent.
Astuce : Sur les autres écrans, chaque choix de « Bloc-notes » dans le menu + ouvre une fenêtre supplémentaire. Chaque fenêtre peut afficher un onglet différent, et si deux fenêtres affichent le même onglet, ce que vous saisissez dans l'une apparaît dans l'autre.
