Bloc-notes

Écran pour enregistrer votre journal de vie avec la syntaxe du bloc-notes. Vous pouvez saisir d'un coup plusieurs types d'enregistrements sous forme de texte.

Boutons de la barre d'outils

Bouton Description
⚙ Paramètres Ouvre l'écran des paramètres de l'application.
❔ AideAffiche l'aide de l'écran actuel.

Éléments de l'écran

Élément Description
Zone de texte Zone de texte principale où vous saisissez les données avec la syntaxe du bloc-notes. Vous pouvez y écrire librement des enregistrements sur plusieurs lignes.
Bouton de modèle Insère dans la zone de texte un modèle de syntaxe du bloc-notes que vous utilisez souvent. Vous choisissez parmi les modèles définis dans les paramètres.
Bouton d'enregistrement Envoie le contenu saisi au serveur et crée les enregistrements.
Onglets Permettent de conserver plusieurs brouillons à la fois. Vous pouvez saisir un contenu différent dans chaque onglet.
Bouton d'ajout d'onglet Ajoute un nouvel onglet vide.
Bouton de fermeture d'onglet Ferme cet onglet. Une confirmation apparaît s'il contient encore du texte.

Utilisation des onglets

Vous pouvez conserver plusieurs brouillons côte à côte. Si vous pensez à autre chose pendant la rédaction d'un enregistrement, appuyez sur le bouton d'ajout d'onglet, écrivez-le dans un nouvel onglet et revenez ensuite à l'onglet d'origine.

Action Résultat
Appuyer sur le bouton d'ajout d'onglet Un onglet vide est ajouté.
Cliquer sur le nom d'un onglet L'éditeur bascule sur le contenu de cet onglet.
Appuyer sur le bouton de fermeture d'onglet Cet onglet est fermé. Une confirmation apparaît s'il contient encore du texte.
Appuyer sur le bouton d'enregistrement Seul le contenu de cet onglet est enregistré, et l'onglet enregistré est fermé. Les autres onglets restent tels quels.
Choisir un modèle Un nouvel onglet s'ouvre avec le modèle. Le texte en cours n'est pas perdu.

Le nom de l'onglet reprend celui du modèle lorsqu'il a été ouvert depuis un modèle, sinon la première ligne du texte. Les onglets encore vides n'ont pas de nom.

Ouvrir plusieurs blocs-notes

Choisir « Bloc-notes » dans le menu « + » d'un autre écran ouvre à chaque fois une fenêtre de bloc-notes supplémentaire. Vous pouvez les placer côte à côte et rédiger un enregistrement tout en en consultant un autre.

La liste des onglets est commune à toutes les fenêtres. Un onglet créé dans une fenêtre apparaît aussi dans la liste de l'autre. Fermer une fenêtre ne fait pas perdre le brouillon.

En revanche, l'onglet affiché est propre à chaque fenêtre. Vous pouvez ouvrir le même onglet dans deux fenêtres pour les comparer ; même alors, enregistrer depuis les deux ne crée l'enregistrement qu'une fois.

Astuce : Le texte en cours est conservé même après la fermeture de l'écran. À la prochaine ouverture, les onglets que vous aviez reviennent tels quels.

Aperçu de la syntaxe du bloc-notes

La syntaxe du bloc-notes est un format de texte structuré par lignes. Une seule saisie permet de créer d'un coup les enregistrements suivants :

  • Mémo : enregistrement de notes textuelles
  • Entrées de temps : démarrage et arrêt de la mesure du temps
  • Tâches : ajout et mise à jour de tâches
  • Signets : enregistrement d'URL
  • Enregistrements numériques : enregistrement de données numériques
  • Dépenses : enregistrement de montants
  • Humeur : enregistrement d'une valeur d'humeur (0 à 10)
  • Étiquetage : ajout d'étiquettes aux enregistrements

Procédure d'utilisation

  1. Saisissez le contenu de l'enregistrement avec la syntaxe du bloc-notes dans la zone de saisie de texte.
  2. Si nécessaire, insérez un texte type à l'aide du bouton de modèle. Le modèle s'ouvre dans un nouvel onglet, le texte en cours n'est donc pas perdu.
  3. Cliquez sur le bouton d'enregistrement pour créer l'enregistrement.
  4. Si le texte contient un tag encore jamais utilisé, une confirmation « C'est un nouveau tag. Voulez-vous l'ajouter ? » apparaît. Si le tag vous convient, poursuivez.
  5. Une fois l'enregistrement réussi, cet onglet est fermé. Les autres onglets conservent leur texte. S'il n'en reste aucun, un onglet vide est préparé.
  6. Si l'enregistrement échoue, rien de cet onglet n'est enregistré (aucun élément écrit à moitié ne subsiste). L'onglet reste ouvert : corrigez la cause et enregistrez à nouveau. N'écrire que la ligne de type suivie de ! est aussi une erreur (aucun contenu) et n'enregistre rien ; la ligne fautive apparaît en rose.
Astuce : La confirmation de nouveau tag évite que des tags très proches se multiplient à cause de fautes de frappe. Si le nom affiché n'est pas celui que vous vouliez, revenez en arrière et corrigez-le.
Astuce : Les tags ajoutés dans le bloc-notes apparaissent aussi comme candidats dans « Ajouter un tag depuis l'historique », dans le champ des tags des écrans d'ajout et de modification comme dans le menu contextuel d'un enregistrement. Ils sont conservés par lot, un par enregistrement, et le lot du dernier enregistrement sauvegardé vient en premier.
Astuce : L'utilisation de modèles permet une saisie plus efficace. Il est pratique d'enregistrer comme modèles les schémas d'enregistrement que vous utilisez souvent.
Astuce : Même sans connaître la syntaxe du bloc-notes, vous pouvez commencer à enregistrer tout de suite grâce aux modèles.
Astuce : Sur les autres écrans, chaque choix de « Bloc-notes » dans le menu + ouvre une fenêtre supplémentaire. Chaque fenêtre peut afficher un onglet différent, et si deux fenêtres affichent le même onglet, ce que vous saisissez dans l'une apparaît dans l'autre.
