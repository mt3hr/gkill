Bloc-notes

Écran de bloc-notes pour enregistrer des événements de la vie via la syntaxe du bloc-notes. Le bloc-notes utilise un format de texte structuré par lignes permettant la saisie par lots de divers enregistrements.

À propos du bloc-notes

Le bloc-notes utilise un format de texte propre à gkill qui permet de créer en masse plusieurs enregistrements dans un seul texte. Chaque ligne représente une commande ou une entrée de données.

Astuce : En utilisant le bouton de modèle, vous pouvez insérer rapidement des formats de saisie couramment utilisés sans avoir à mémoriser la syntaxe du bloc-notes.

Procédure d'utilisation

  1. Saisissez le contenu de l'enregistrement avec la syntaxe du bloc-notes dans la zone de saisie de texte.
  2. Si nécessaire, insérez un texte type à l'aide du bouton de modèle.
  3. Cliquez sur le bouton d'enregistrement pour créer l'enregistrement.
  4. Si le texte contient un tag encore jamais utilisé, une confirmation « C'est un nouveau tag. Voulez-vous l'ajouter ? » apparaît. Si le tag vous convient, poursuivez.
  5. Une fois l'enregistrement réussi, la zone de texte est vidée.
Astuce : La confirmation de nouveau tag évite que des tags très proches se multiplient à cause de fautes de frappe. Si le nom affiché n'est pas celui que vous vouliez, revenez en arrière et corrigez-le.
Astuce : L'utilisation de modèles permet une saisie plus efficace. Il est pratique d'enregistrer comme modèles les schémas d'enregistrement que vous utilisez souvent.

Astuce : Un appui long sur le bouton "+" ouvre directement l'écran de saisie du bloc-notes, permettant une saisie par lots rapide.
Raccourci : Appuyez sur Entrée sur cet écran pour ouvrir le bloc-notes. C'est pratique pour ajouter rapidement des enregistrements.
