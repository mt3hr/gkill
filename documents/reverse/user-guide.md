# gkill ユーザ向け導入資料

> **対象読者:** gkillをこれから使い始めるユーザー、および導入を支援する管理者向けの資料です。

## 1. gkillとは

gkillは**ライフログアプリケーション**です。日々のできごとを記録し、後から見返すことができます。

「都度、今の情報を細切れに記録する → gkillが時系列で表示 → 懐かしむ、あるいは自省する」

スタンドアロンで動作し、記録データはすべてローカルに保存されます。ただし一部の機能は外部と通信します: 地図表示、ブックマーク登録時のURLメタデータ取得、Webプッシュ通知の配信、プラグイン（ChatGPT/Claude.ai/Claude Code の履歴等）の利用時。これらを使わない限り外部通信は発生しません。

### 記録できるもの

| 記録種別 | 用途 | 例 |
|---|---|---|
| メモ | 自由なテキストメモ | 「今日は天気がいい」 |
| 打刻 | いつからいつまで何をしていたか | 「会社にいた」「カラオケ中」 |
| 気分 | 今の気分を0〜10の11段階で評価 | 気分: 7/10 |
| 数値記録 | 数値の記録 | 体重: 65.2, 腹筋: 30回 |
| 支出 | お金の出入り | 昼食: 800円 |
| ブックマーク | ウェブサイトメモ | 気になった記事のURL |
| タスク | 軽量TODO | 「牛乳を買う」 |
| ファイル | 画像・動画・ファイル | 写真、スクリーンショット |

このほか、既存の記録から派生して作られる記録があります。

| 記録種別 | 用途 |
|---|---|
| リポスト | 過去の記録をもう一度いまの時刻の一覧に流す |
| リポストタスク | 既存の記録に「期限」や「完了チェック」を付けてタスクとして扱う |
| 通知 | 記録に指定した日時のリマインダーを付ける |

また、以下は gkill が自動で取り込む記録です。

| 記録種別 | 用途 |
|---|---|
| Gitコミットログ | 指定したGitリポジトリのコミットを一覧に表示 |
| GPSログ | GPXファイルから位置情報を取り込み、地図で表示 |
| プラグインの記録 | プラグインが取り込んだ、gkill以外のサービスの記録（後述） |

### 補佐機能

| 機能 | 用途 |
|---|---|
| タグ | 記録にタグを付けて整理・検索を補助 |
| テキスト | 記録に補足テキストを付与 |
| 集計ビュー | 数値・支出・件数・気分などの集計（カスタマイズ可能） |
| 関連情報 | 選んだ記録に関連する記録を自動で並べる |
| テンプレート | よく使う記録をボタン1つで入力可能 |
| 共有 | 選んだ記録を、アカウントのない人にもリンクで見せる |

### 特長：「状況」から検索できる

打刻記録を使って、「どこで何をしていたか」という状況から記録を検索できます。

- 「友人Aと東京のカラオケに居た時の写真」
- 「会社にいる時の平均気分」

## 2. インストール方法

### Windows

1. [gkillダウンロードページ](https://github.com/mt3hr/gkill/releases/latest)からAssetsの「windows_amd64_gkill_vX.X.X.zip」をダウンロード
2. ZIPを解凍して「gkill.exe」を実行
3. 初回起動には時間がかかります（データベース初期化のため）

**体験版（サンプルデータ付き）:**
「gkill_sample_data_vX.X.X.zip」をダウンロード・展開し、`LAUNCH_GKILL_SAMPLE_DATA.bat`を起動すると、サンプルデータ入りで試せます。

### Android

1. Assetsから「gkill_vX.X.X.apk」をダウンロード
2. インストール
3. ホーム画面から起動

**注意:** 初回起動時に「すべてのファイルへのアクセス」の許可を求められます。
写真などを取り込むファイルリポジトリが共有ストレージ上のフォルダを参照するため、この権限が必要です。

データ（記録のデータベース、アカウント情報、ログ）はアプリ専用領域に保存されます。
以前のバージョンは共有ストレージの `/sdcard/gkill` に保存していたため、
全ファイルアクセス権を持つ他のアプリやUSB接続からも中身が読める状態でした。

**以前のバージョンから更新した場合:** 初回起動時に `/sdcard/gkill` の内容が
アプリ専用領域へ自動で複製されます。複製元は残したままにしているので、
記録が正しく引き継がれていることを確認したうえで `/sdcard/gkill` を手動で削除してください。
削除するまでは古いデータが共有ストレージに残ります。

### サーバーモード（上級者向け）

1. お使いの環境に合ったバイナリをダウンロード（linux_amd64等）
2. 「gkill_server」を実行
3. ブラウザで `http://localhost:9999` にアクセス
4. ブラウザからPWAとしてインストール可能

**サーバーモードのメリット:**
- PWA依存機能の安定動作
- プッシュ通知の確実性
- キャッシュ制御やアプリ起動時間の短縮

### Wear OS

スマートウォッチから、メモ帳と同じ書式でさっと記録を残せます。スマートフォン側の「コンパニオンアプリ」と、腕時計側の「ウォッチアプリ」の2つをインストールして使います。

1. スマートフォンにコンパニオンアプリをインストールし、gkillのユーザーIDとパスワードを入力しておきます
2. 腕時計にウォッチアプリをインストールします
3. 腕時計でウォッチアプリを開き、テンプレートを選びます
4. 選んだ内容がスマートフォン経由でgkillに送信され、記録されます

腕時計とスマートフォンはペアリング済みである必要があります。記録の送信はスマートフォンが中継するため、スマートフォンが手元にある状態で使ってください。

## 3. 初回起動〜パスワード設定

### 初回起動の流れ

1. **gkillを動かしているのと同じPC**のブラウザでアクセスすると「初回アカウント登録画面」が表示されます

   > スマートフォンやLANの別PCからアクセスした場合、この画面には自動で移動しません。
   > 初回登録用のリンクにはアカウントを乗っ取れる情報が含まれるため、同じPCからのアクセスにだけ渡す仕組みになっています。
   > その場合は、gkillを起動したときに画面（コンソール）へ表示される
   > `.../set_new_password?user_id=...` というURLを使ってください。
   > 見当たらないときは、gkillを動かしているPCで `gkill_server reset_password admin` を実行すると出し直せます。

2. 初回起動時、サーバーは管理用アカウント（admin）をパスワード未設定の状態で自動作成しています。この画面で普段使うアカウントの作成と、adminアカウントへのパスワード設定を同時に行います
3. 以下を入力してください:
   - **ユーザーID** — 普段のログインに使用するアカウント名（admin以外の任意の名前）
   - **パスワード** — このアカウントのログイン用パスワード
   - **管理用パスワード** — adminアカウントに設定するパスワード（サーバー設定変更時に使用）
4. 「登録」ボタンを押すと、新規アカウントの作成とadminのパスワード設定が完了し、ログイン画面に遷移します
5. 登録したユーザーID・パスワードでログインしてください

### ログイン後

ログインすると**ライフログビュー画面**が表示されます（設定でデフォルト画面を変更可能）。右下のフローティングボタン（+）から記録を始められます。

ログイン後のセッションは30日間有効です。期限が切れるまで再ログインは不要です。
ただし**パスワードを設定しなおすと、そのアカウントは全ての端末でログアウトされます**（同じパスワードを設定しなおした場合も同様）。

## 4. 基本操作

### 記録の追加

**方法1: 「+」ボタン（フローティングアクションボタン）**

各画面の右下にある「+」ボタンを押すと、記録種別を選択できます。

| メニュー項目 | 追加される記録 |
|---|---|
| メモ帳 | テキスト形式の一括入力画面 |
| 打刻メモ帳 | メモ入力と進行中の打刻を同時に扱う画面 |
| 数値記録 | 数値記録 |
| ブックマーク | ブックマーク |
| 打刻帳 | 打刻（時間記録） |
| タスク | タスク |
| 支出 | 支出記録 |
| 気分 | 気分値 |
| アップロード | ファイル |
| クリップボードを保存 | クリップボードの内容をそのままファイルとして保存 |

> 「クリップボードを保存」はライフログビュー画面・タスク画面・実行中画面に表示されます。ダッシュボード画面とさいはて画面のメニューには含まれません。

**方法2: メモ帳画面**

メモ帳では、gkill独自のテキスト書式（メモ帳構文）を使って、複数の記録を一度にテキストで入力できます。テンプレートをボタンで挿入できるため、よく使う記録パターンを素早く入力可能です。日本語プレフィックス（。、？、ーー等）と ASCII プレフィックス（`#`, `?`, `--`, `/mi`, `/mood` 等）の両方が使えます。全18種類の書式があります。

**方法3: ブックマークレット（ブラウザからブックマーク追加）**

ブラウザで閲覧中のページをワンクリックでブックマークとして記録できます。

1. gkill にログインする（ログイン時にブックマークレット専用セッションが自動作成されます）
2. 設定画面に表示されているブックマークレットのリンクを取得する
3. そのリンクをブラウザのブックマークバーにドラッグ＆ドロップで登録する
4. 任意のWebページでブックマークレットをクリックすると、そのページのURL・タイトルがブックマークとして自動保存されます

> **注意:** ブックマークレットは gkill サーバーが起動している間のみ動作します。ブックマークレット専用のセッションが使用されるため、通常のログインセッションとは独立しています。

**方法4: クリップボードから直接保存**

`Ctrl+V` を押すと、クリップボードにある画像・テキスト・PDF などをそのままファイルとして保存できます。スクリーンショットを素早く記録したいときに便利です。

### 記録の編集

1. 記録を表示し、コンテキストメニュー（右クリックまたは長押し）を開く
2. 「編集」を選択
3. 編集ダイアログで内容を変更
4. 保存

### 記録の削除

コンテキストメニューから「削除」を選択します。削除確認ダイアログが表示されます。

> **注意:** 記録を削除すると、その記録に付けたタグ・テキスト・通知と、その記録を参照しているリポスト・リポストタスクも**まとめて削除されます**。参照しているリポストがさらに別のリポストから参照されている場合は、そこまで連鎖して削除されます。

### 既存の記録をタスクにする

「後で対応したい」記録を、内容を書き直すことなくそのままタスクにできます。

1. 対象の記録のコンテキストメニュー（右クリックまたは長押し）を開く
2. 「タスクにする」を選択
3. 板名・期限・開始予定・終了予定を設定して保存

こうして作った記録は**リポストタスク**と呼ばれ、タスク画面にも表示されて完了チェックを付けられます。
元の記録の内容がそのまま表示されるため、タイトルを入力する欄はありません。

> **注意:** 元の記録を削除すると、そこから作ったリポストタスクも一緒に削除されます（タスク画面からも消えます）。

### 記録をもう一度流す（リポスト）

コンテキストメニューから「リポスト」を選ぶと、過去の記録をもう一度いまの時刻の一覧に流せます。定期的に見返したい記録に使います。

### 記録の内容をコピーする

コンテキストメニューから「内容コピー」を選ぶと、その記録の本文をクリップボードにコピーできます。
「IDコピー」を選ぶと記録のIDをコピーできます。

### ZIPファイルの内容を閲覧

アップロードしたZIPファイルの中身をブラウザ上で閲覧できます。拡張子が `.cbz` のファイルもZIPとして扱われます。

1. ライフログビュー画面等でZIPファイルの記録を表示
2. ZIPファイルの記録をコンテキストメニュー（右クリックまたは長押し）で開く
3. 「ZIP内容を閲覧」を選択
4. ZIP内のフォルダ・ファイル一覧が階層的に表示されます
5. フォルダをクリックして階層を掘り下げ、パンくずナビゲーションや「..」で上の階層に戻れます
6. 画像ファイルはプレビュー表示（ページ送りで次の画像に移動可能）
7. ファイルをクリックして開く/ダウンロードすることも可能

> **注意:** 「ZIP内容を閲覧」メニューはZIPファイルの記録に対してのみ表示されます。大きすぎるファイルはプレビューできず、その旨のメッセージが表示されます。

### 記録の検索

ライフログビュー画面で以下のフィルタを組み合わせて検索できます。

| フィルタ | 説明 |
|---|---|
| キーワード | テキスト全文検索 |
| 日付 / 時間帯 | 期間の指定 |
| タグ | タグでの絞り込み |
| 記録タイプ | メモ・打刻・タスクなど種別での絞り込み |
| 記録保管場所 | データの格納先での絞り込み |
| 場所 | GPS位置での絞り込み |

「+」ボタンでフィルター列を追加すると、異なる条件の結果を横に並べて比較できます。

### タグの付与

記録にタグを付けることで、後から検索しやすくなります。

1. 記録のコンテキストメニューから「タグ追加」を選択
2. タグ名を入力
3. 保存

最近使ったタグを付けたいときは、コンテキストメニューの「タグ履歴から追加」を使うと一覧から選ぶだけで付けられます。

これまで使ったことのないタグを入力すると、保存前に「新しいタグです。追加しますか？」と確認されます。
タイプミスで似たタグが増えるのを防ぐための確認です。メモ帳からの入力でも同様に確認されます。

### 通知（リマインダー）を設定する

記録に、指定した日時のリマインダーを付けられます。

1. 記録のコンテキストメニューから「通知追加」を選択
2. 通知内容・日付・時刻を入力して保存

タスクやリポストタスクを作るときにも、同じダイアログの中で通知を設定できます。設定した通知は「通知編集」で変更、「通知履歴」で変更履歴の確認ができます。

> **前提:** 通知を配信するには、管理者がサーバ設定の「通知サービス有効」をオンにしている必要があります。ブラウザで使う場合はPWAとしてインストールし、通知を許可してください。

### GPSログを取り込んで地図で見る

GPXファイルを取り込むと、移動経路をライフログビュー画面の地図に表示できます。

1. 「+」ボタンから「アップロード」を選択
2. ダイアログの「GPSLogファイル」タブを開く
3. GPSログ用の記録保管場所を選ぶ
4. 「ここにGPXファイルをドロップ」と表示された枠へGPXファイルをドラッグ＆ドロップ（ファイル選択でも可）
5. ツールバーの地図ボタンをオンにすると、記録の期間に対応する移動経路が表示されます

> **前提:** 地図表示にはGoogle Maps APIキーが必要です。設定画面の「GoogleMapAPIキー」に入力して保存してください。キーは Google Cloud Console で Maps JavaScript API を有効にして取得します。

### 記録を共有する

選んだ記録を、gkillのアカウントを持たない人にもリンクで見せられます。

1. 記録のコンテキストメニュー、または一覧の共有ボタンから「共有」を選択
2. 「現在の検索条件で共有します」の内容を確認し、共有のタイトルを入力
3. 含めるものをチェックで選ぶ

| オプション | 意味 |
|---|---|
| タスク時間のみ共有に含める | タスクの時間情報だけを共有する |
| タグを共有に含める | 記録に付けたタグも見せる |
| テキストを共有に含める | 記録に付けた補足テキストも見せる |
| 打刻状況を共有に含める | 関連する打刻の状況も見せる |
| 関連位置情報を共有に含める | 関連するGPSの位置情報も見せる |

4. 用途に応じてリンクを選びます

| リンクの種類 | 使いどころ |
|---|---|
| ローカル | 同じ端末のブラウザで開く |
| LAN内 | 同じネットワークにいる相手に見せる |
| グローバル | 外部に公開する（外部からアクセスできる設定が必要） |

共有したページは**閲覧専用**です。受け取った人はログインなしで閲覧でき、編集や削除はできません。共有をやめたいときは「共有管理」から共有リンクの一覧を開き、削除してください。

## 5. 各画面の使い方

### メモ帳画面

gkill独自のテキスト書式で記録を一括入力する画面です。

- テキストエリアにメモ帳構文で入力
- テンプレートボタンで定型文を挿入可能
- 「保存」で記録が保存される
- 複数種類の記録を一度に入力可能

### タスク画面 — タスクボード

タスク管理の画面です。

- ボード別にタスクを表示（カンバンボード）
- タスクのチェック（完了/未完了）
- ボードの切替、ソート順の変更
- 完了状態でのフィルタリング
- 「タスクにする」で作ったリポストタスクもここに並びます

### ライフログビュー画面 — 履歴閲覧

全記録を時系列で閲覧・検索する画面です。日常的にいちばんよく使う画面になります。

- 左側のサイドバーで検索条件を設定
- キーワード、日付、タグ、記録タイプ、記録保管場所、場所での絞り込み
- 画像サムネイル付きのグリッド表示（列数は設定画面で1〜10列に変更可能）
- ファイルアップロードも可能

### 集計ビュー

記録を集計・分析する機能です。ライフログビュー画面のツールバーにある集計アイコンで表示を切り替えます。ダッシュボード画面にも表示されます。

**集計の3ステップ:**

1. **条件（条件グループ）** — 集計対象を絞り込む。例：「タグが"食事"の記録だけ」「今月の記録だけ」。AND/OR/NOT の組み合わせが可能
2. **グループキー** — 何を基準にまとめるかを選ぶ。例：「日別」「曜日別」「タグ別」
3. **集計対象** — 何を計算するかを選ぶ。例：「件数」「支出合計」「気分の平均値」「作業時間の合計」

**使用例:**

| やりたいこと | 条件 | グループキー | 集計対象 |
|---|---|---|---|
| 日別の支出合計 | なし（全件） | 関連日 | 合計支出 |
| 曜日別の平均気分 | なし（全件） | 関連曜日 | 平均気分値 |
| "仕事"タグの月別作業時間 | タグ＝仕事 | 関連年月 | 合計作業時間 |
| 店別の支出合計 | なし（全件） | 店名 | 合計支出 |

表示できるものは3種類あります。

| 種類 | 内容 |
|---|---|
| 集計項目 | 単一の集計値を1行で表示 |
| 集計リスト | グループごとの集計値を一覧で表示 |
| トレンドグラフ | 集計値の推移を日・週・月の単位で折れ線または棒グラフで表示 |

### 関連情報

選んだ記録に関連する記録を自動で探して並べる機能です。ライフログビュー画面で記録を選んだときに表示されます。

- 「抽出条件」で時刻の近さ（日時が近い／以前／以後）を指定
- 「検索範囲（n時間）」で何時間ぶんを探すか指定
- 条件グループでは「タイトルが対象と等しい」「タグが一部対象と等しい」など、選んだ記録と見比べて絞り込む条件も使えます

「同じタグが付いた記録」「同じ種類の記録」を自動で並べたいときに便利です。

### 記録画面 — 記録詳細

個別の記録を詳細表示する画面です。

- 記録の本体データ
- 付帯情報（タグ、テキスト、通知）
- 関連する打刻情報
- コンテキストメニューから編集・削除・「タスクにする」・内容コピーなど

### 打刻メモ帳画面

メモ入力と進行中の打刻を同時に表示するハイブリッド画面です。メモの記録と時間計測を1つの画面で管理できます。

- 上半分: メモ帳入力エリア（メモ帳画面と同じテキスト入力。メモ帳構文での入力、テンプレート挿入、保存）
- 下半分: 実行中の打刻一覧（進行中の打刻の確認・停止操作）
- メモ帳入力で記録を保存すると、下半分の打刻一覧が自動更新される

> ファイルのアップロードはこの画面ではなく、ライフログビュー画面などの「+」ボタンから行います。

### 実行中画面 — 打刻一覧

現在進行中の打刻の一覧です。

- セッション名・開始時刻・経過時間の表示
- 打刻の終了操作

> 打刻を停止し忘れた場合は、あとから記録を編集して終了時刻を修正できます。

### ダッシュボード画面 — 日次サマリー

特定の1日を俯瞰する画面です。

- 集計結果（集計項目・集計リスト・トレンドグラフ）
- その日のGPSログを地図で表示
- その日のタスク一覧
- 日付ナビゲーション（前日・今日・翌日）で過去の日も確認できる

表示内容は設定画面の「ダッシュボード」で、「タスク検索条件」と「集計検索条件」として設定します。

### さいはて画面 — 記録特化

記録の追加だけに特化した画面です。他画面へのナビゲーションを持ちません。

- 「+」ボタンから各種記録の素早い追加
- ヘルプ、再読込、ログアウト操作

閲覧や編集の機能がないため、誤操作で既存の記録を変更してしまう心配がありません。主にスマートフォンのロック画面やホーム画面ウィジェットから直接起動して使います。

## 5.1 プラグインで外部の記録を取り込む

プラグインを導入すると、gkill 以外のサービスに溜まった記録を一覧に混ぜて表示できます。
標準で以下のプラグインが用意されています。

| プラグイン | 取り込む内容 |
|---|---|
| ChatGPT | ChatGPT の会話履歴 |
| Claude.ai | Claude.ai の会話履歴 |
| Claude Code | Claude Code のチャットログ |

### 使い方

1. プラグインの実行ファイルと `manifest.json` を `$HOME/gkill/plugins/{ユーザーID}/{プラグイン名}/` に配置する
   （`manifest.json` は必須。これが無いフォルダは読み込み対象から外れる。
   同梱プラグインなら `プラグイン実行ファイル --gkill-print-manifest > manifest.json` で生成できる）
2. gkill を起動する。初回起動時に同じフォルダへ `config.json` が自動生成される
3. `config.json` の `source_dirs` に、取り込みたいデータが置いてあるフォルダを書く
4. ライフログビュー画面で検索すると、他の記録と同じように表示される

`source_dirs` はワイルドカード（`*`、`**`）や `~` が使えます。
検索のたびに読み直されるため、変更しても gkill の再起動は不要です。
既に `config.json` がある場合、gkill がそれを上書きすることはありません。

> **注意:** 現在、プラグインの設定を画面から変更する導線はありません。`config.json` を直接編集してください。

取り込んだ内容は高速化のためキャッシュされます。キャッシュを作り直したい場合は
`gkill_server clear_cache plugin <ユーザーID>` を実行してください。

プラグインの記録は読み取り専用で、gkill 側から編集・削除はできません。
タグやテキストの付与、リポスト、「タスクにする」、通知の追加はできます。

## 5.2 AIアシスタントと連携する

Claude などのAIアシスタントからgkillの記録を読み書きさせることができます。設定はAIアシスタント側の設定ファイルで行います。

- 読み取り専用・書き込み専用・読み書き の3種類から選べます
- 同じパソコンで使う方法と、外出先から使う方法があります
- 手順の詳細は [mcp-setup-guide.md](mcp-setup-guide.md) を参照してください

## 6. 設定画面

アプリケーション設定は各画面のツールバーの歯車アイコンから、サーバー設定は設定画面からアクセスできます。

### よく使う設定

| 設定項目 | 説明 |
|---|---|
| 言語 | 表示言語を切り替えます（日本語・英語・中国語・韓国語・スペイン語・フランス語・ドイツ語） |
| ダークテーマ | 暗い配色に切り替えます |
| 起動時の画面 | ログイン後に最初に表示する画面を選びます（ライフログビュー／タスク／メモ帳／実行中／打刻メモ帳） |
| ライフログビュー表示日数 | 一覧に表示する期間の初期値 |
| ライフログビュー画像列数 | 画像サムネイルの列数（1〜10） |
| タスクデフォルト板名 | タスク画面で最初に表示するボード |
| GoogleMapAPIキー | 地図表示に必要なAPIキー |
| ブックマークレット | ブラウザに登録するブックマークレットのリンク |

### 記録保管場所の管理

記録データの格納先（記録保管場所）を管理します。用途（メモ用・ファイル用・GPSログ用など）や端末ごとに複数を設定できます。

- 記録保管場所の追加・削除・有効化/無効化
- 種別の指定（何を保存するか）
- 書き込み先として使用するかの指定

設定はアカウント管理画面の「保存先割当」から、各ユーザに対して行います。

> **注意:** 種別のドロップダウンには `kmemo` や `timeis` のような英数字の名前が並びます。どれが何を指すかは、サーバ設定のヘルプ（アプリ内の「？」ボタン）にある対応表を参照してください。

### テンプレート管理

メモ帳画面で使用するテンプレートを管理します。

- テンプレートの追加・編集・削除
- テンプレート構造の階層管理

### タグ構造管理

タグの階層構造を管理します。よく使うタグを上位に置くと、入力候補一覧で見つけやすくなります。

- タグのグループ分けと並び順の設定
- 上へ移動 / 下へ移動 / フォルダへ移動…

### プロファイル管理

使っている端末ごとの設定（プロファイル）を管理します。

- プロファイルの追加・編集・削除
- プロファイルごとの記録保管場所の割当

### アカウント管理（管理者のみ）

- ユーザーアカウントの追加・削除
- パスワードリセットリンクの発行
- 各ユーザへの記録保管場所の割当

## 7. よくある問題と解決方法

### 起動に関する問題

| 症状 | 解決方法 |
|---|---|
| 初回起動が遅い | データベース初期化中です。しばらくお待ちください |
| ポートが使用中 | 他のgkillプロセスが起動中でないか確認してください |
| 画面が表示されない | ブラウザで `http://localhost:9999` に直接アクセスしてみてください |

### 記録に関する問題

| 症状 | 解決方法 |
|---|---|
| 記録が保存されない | ログイン状態を確認してください。セッション有効期限は30日です |
| 検索結果が出ない | フィルタ条件を緩めてみてください。「クリア」ボタンでリセットできます |
| アップロードできない | 記録保管場所にファイル用のものが割り当てられているか確認してください。1か月あたりの上限はサーバ設定で管理者が設定します（初期値は無制限） |
| 地図が表示されない | 設定画面にGoogleMapAPIキーが入力されているか確認してください |

### 通知に関する問題

| 症状 | 解決方法 |
|---|---|
| 通知が届かない | 管理者がサーバ設定の「通知サービス有効」をオンにしているか確認し、PWAとしてインストールして通知許可を有効にしてください |
| 通知の時刻がずれる | 通知機能は環境に依存します。おおよその時刻で通知されます |

### 共有・プラグインに関する問題

| 症状 | 解決方法 |
|---|---|
| 共有リンクが開けない | 共有設定が削除されていないか、リンクの種類（ローカル／LAN内／グローバル）が相手の環境に合っているか確認してください |
| プラグインの記録が出てこない | `config.json` の `source_dirs` に書いたフォルダに、取り込み元のファイルが実際にあるか確認してください |
| プラグインの内容が古いまま | `gkill_server clear_cache plugin <ユーザーID>` でキャッシュを作り直してください |

### その他

| 症状 | 解決方法 |
|---|---|
| パスワードを忘れた | 管理者にパスワードリセットリンクの発行を依頼してください。**リンクの有効期限は72時間**です。切れた場合は発行しなおしてもらってください |
| 管理者（admin）のパスワードを忘れた | gkillを動かしているPCで `gkill_server reset_password admin` を実行してください。表示されたURLからパスワードを設定しなおせます。**パスワードは復元できない形で保存されているため、これが唯一の復帰方法です** |
| パスワードを設定したら他の端末からログアウトされた | 仕様です。パスワードを設定しなおすと、そのアカウントの全端末のログインが解除されます。各端末で新しいパスワードでログインしなおしてください |
| データを別のPCに移動したい | `$HOME/gkill/`フォルダをコピーしてください |

## 8. バックアップと復元

### アップグレード時の注意（パスワードの保存方式が変わったバージョン）

パスワードの保存方式を変更したバージョンへ更新すると、**初回起動時に全アカウントのパスワードが無効化されます**。
これは、以前の保存方式では設定ファイルを読めた人がそのままログインできてしまうためで、
包み直すのではなく全員に設定しなおしてもらう方式を選んでいます。

更新後にやること:

1. gkill を起動すると、画面（コンソール）に全アカウントのパスワード設定URLが表示されます。**控えてください**
2. 各URLを開いてパスワードを設定しなおします。**以前と同じパスワードで構いません**
3. リンクの有効期限は72時間です。切れた場合は `gkill_server reset_password <ユーザーID>` で出し直せます

更新前に `$HOME/gkill/configs/account.db` をコピーしておいてください。
**古いバージョンへ戻す場合は、このファイルも一緒に戻す必要があります**（新しい形式のファイルは古いバージョンでは開けません）。

複数の端末で gkill を動かしていて設定ディレクトリを同期している場合は、
**同期を止めて全端末を新しいバージョンに入れ替えてから**起動してください。
新しい形式の設定ファイルが古いバージョンの端末へ届くと、その端末が起動できなくなります。

### バックアップ

gkillの全データは `$HOME/gkill/` ディレクトリに保存されています。このディレクトリを丸ごとコピーすることでバックアップできます。

```
バックアップ対象:
$HOME/gkill/
├── configs/    ← 設定データベース
├── datas/      ← ユーザーデータ
├── caches/     ← キャッシュ（バックアップ不要、再生成可能）
├── logs/       ← ログ（バックアップ不要）
└── tls/        ← TLS証明書（使用している場合）
```

**最低限のバックアップ対象:**
- `configs/` — 全設定情報
- `datas/` — 全記録データ

> **重要:** 記録保管場所の保存先は `$HOME/gkill/datas/` の外部にも設定できます。外部のフォルダに置いたファイルやGitのコミット履歴などを取り込んでいる場合、`$HOME/gkill/` のコピーだけでは取りこぼします。**設定しているすべての記録保管場所の保存先（設定画面の記録保管場所一覧で確認できます）をバックアップ対象に含めてください。**

### 復元

1. gkillを停止
2. バックアップした `$HOME/gkill/` を元の場所にコピー
3. gkillを起動

**注意:** キャッシュは起動時に自動再生成されるため、バックアップに含めなくても問題ありません。

### 定期バックアップの推奨

重要な記録データを保護するため、定期的なバックアップを推奨します。`configs/`と`datas/`ディレクトリをコピーするだけで完了します。
