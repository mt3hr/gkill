# v1.1.8

## ⚠️ Android・Wear OS アプリを使っている方へ

このバージョンから、配布する APK を**正式なリリース署名**で作るようになりました。
これまでの APK は開発用の署名だったため、**署名が変わり、上書き更新ができません。**
お手数ですが、**一度アンインストールしてから新しい APK をインストール**してください。

## あっぷでーと

- ポート画面を追加。記録一覧・タスク・集計ノート・打刻を、1つの画面にフローティングウィンドウとして並べて使えます
- メモ帳をタブで複数開けるように。ウィンドウを分けても二重に登録されません
- メモ帳から既存の記録をタスクにできるように（リポストタスク）
- 追加・編集画面から、その場で新しいタグを追加できるように
- メモ帳の買い物メモで、商品ごとにタグやテキストを設定できるように
- タスク画面から、タグ・テキスト・通知を確認できるように
- 繰り返しの記録に対応
- 記録を追加したとき、一覧を全部引き直さずにその場へ差し込むように。追加が速くなり、表示位置も安定します
- 検索と取得を大幅に高速化（保管場所を指定した検索がキャッシュを使っていなかった問題、タグ絞り込みの走査、時間帯の判定などを改善）
- 記録取得のメモリ使用量を削減し、ページングの取りこぼしを修正
- 記録一覧・タスク・集計ノートを、最初の読み込みを待たずに表示するように
- 読めなくなった保管場所があっても、そこだけ切り離して残りで動くように（黙って落とさず警告します）
- ログを整理。既定のログレベルを変更し、障害の原因が `gkill_error.log` に残るように
- `dvnf` に `--ignore_pattern` を追加。書きかけのファイルを運ばないようにできます

### AI連携（MCP）

- 記録の検索を刷新（件数だけの取得・集計・保管場所の一覧・診断メッセージ）
- 記録の版履歴の取得と、削除の取り消しに対応
- ファイルのサムネイルを取得できるように
- 終了済みの打刻を進行中へ戻せるように
- 到達できなかったツール `gkill_get_idf_file_path` を削除し、認可の scope を1種類へ統一しました

## BugFix

- IDを大量に指定した検索が、エラーも出さずに0件になる不具合を修正
- 保管場所を指定した検索が、キャッシュを丸ごと迂回して非常に遅くなっていた不具合を修正
- タグを付けて追加した記録が、追加直後に一覧から消える不具合を修正
- 実在する記録にタグやテキストを付けるとエラーになる不具合を修正
- 削除した記録を検索で列挙できない不具合を修正
- キャッシュへ書き戻す保管場所の名前が実際の書き込み先と食い違う不具合を修正
- メモ帳の繰り返しで、同じ記録が何度も増えていく不具合を修正
- メモ帳の不具合を修正（日本語入力で保存マーカーが反応しない・素早く入力すると反応しない・テンプレートを選ぶと自動保存が走らない・タグ追加行が無限に増える）
- 記録のダイアログが開かない不具合を修正
- タスクの板を選ぶと `__root__` という板が表示される不具合を修正
- カレンダーで同じ日付を2回続けてクリックすると条件が無効になる不具合を修正
- 設定の取得に失敗したとき、読み込み中のまま止まっていたのをエラー表示と再試行に変更
- 集計ノートで `<br>` がそのまま表示される不具合を修正
- ポート画面で集計リストが潰れる不具合を修正
- 保管場所のフォルダにファイルが1つ紛れているだけで、すべてのAPIが内部エラーになる不具合を修正（Linux）
- 壊れた GPX ファイルが1つあるだけで、その保管場所の位置情報がすべて返らなくなる不具合を修正
- 同じコミットが二重に出る・同じ位置情報が何度も返る不具合を修正
- ffmpeg が入っていないだけでサムネイルの失敗が記録され、二度と生成されなくなる不具合を修正
- ホーム画面へ追加したときのアプリ情報の更新が端末に届かない不具合を修正
- 画面上部の色が意図しない色になる不具合と、製品版に開発ツールが含まれていた問題を修正
- Android で共有したとき、アプリ履歴から開き直すと二重に保存される問題に対処
- Windows で Android / Wear OS のテストが必ず失敗する問題を修正
- 依存パッケージの脆弱性を解消

## Other

- **異常時のHTTPステータスが正しく返るようになりました。** これまでは失敗しても 200 を返していました。応答の本文の形は変わっていないので、`errors` を見て判定している場合はそのままで動きます
- セキュリティ強化（2026-08 の外部監査対応）: 認証前の経路への送信サイズ上限と読み取り期限、MCP のHTTP経路の上限、設定取得のたびに外部サービスへ公開IPを問い合わせていた処理の廃止、Wear OS コンパニオンの平文通信をループバック限定に、Android のログから環境情報を除去
- 脆弱性の報告窓口（SECURITY.md）を追加
- 夜間の自動チェック（E2E / Android / Wear OS / 脆弱性検査）を追加
- 開発者向け資料を再編し、アーキテクチャ決定記録（ADR）を整備
