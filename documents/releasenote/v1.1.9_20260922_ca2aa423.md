# v1.1.9

## ⚠️ 更新するときの注意

- **腕時計（Wear OS）を使っている方**: スマホ側（`gkill_wear_companion`）と時計側（`gkill_wear_watch`）の APK を**両方いっしょに**入れ直してください。時計とスマホの間の通信経路の名前が変わったため、片方だけ更新すると、エラーも出ずに応答が返らなくなります。1.1.7 以前から更新する場合は、1.1.8 の注意（署名が変わったため、アンインストールしてからインストール）も引き続き必要です。
- **AI連携（MCP）を使っている方**: Node.js 版の MCP サーバは廃止し、`gkill_server mcp --kind read|write|readwrite [--transport stdio|http] [--config <path>]` に一本化しました。AI クライアント側の設定（起動コマンド）を差し替えてください。設定は `$HOME/gkill/configs/gkill_mcp.json` の 1 ファイルで、初回起動時に生成されます。ログは `$HOME/gkill/logs/gkill_mcp_<kind>.log` に出ます。詳しくはマニュアルの「AI連携（MCP）」を参照してください。
- **コマンドラインの `auto_tag` を使っている方**: `add_tag` に改名し、`--tag_by_rep_prefix` / `--tag_by_rep_name` は廃止しました。付ける対象は `--rule '<json>'` または `--rules_file <path>` で、検索条件（`{"tag": "<タグ名>", "query": {...}}`）として指定します。
- **新しくインストールする方**: サーバの待ち受けの初期値が `127.0.0.1:9999`（同じ端末からのみ）と「ローカルアクセスのみ許可」になりました。他の端末から使うには、サーバ設定の「アドレス」と「ローカルアクセスのみ許可」を変更してください。すでに動いているサーバの設定は変わりません。
- **ブックマーク**: 実行中画面の URL `/plaing` は `/playing` に変わりました（旧 URL からの転送はありません）。ブックマークやホーム画面のショートカットを直してください。

## あっぷでーと

- 保存・削除を操作単位でまとめて確定するように。タグやテキストを付けた追加が途中で失敗しても、記録だけ残ったり、タグだけ残ったりしなくなりました
- メモ帳の解釈と書き込みをサーバに一本化。Web・腕時計・AI連携のどこから送っても同じ結果になります。内容の無い記録は保存せず、どの行が問題かをエラーで示します
- エラーの表示に「誰の問題か・何が起きたか・次に何をするか」を載せ、閉じるまで残るように。マニュアルに「エラーが出たとき」ページを追加（7言語）
- ワード検索の対象を記録の種類ごとに定め、ID は前方一致だけに。除外語は付随テキストにも効くように
- 記録を開いたときの読み直しを高速化（版履歴をキャッシュから集め、往復を減らしました）
- サムネイルの生成を高速化。`vips`（libvips）が入っていればそれを使い、無ければこれまでどおり Go / ffmpeg で生成します。大きな写真の回転を縮小の後に行うようにし、生成が数倍速くなりました
- 集計ビューの相関グラフに「記録が無い期間を 0 とみなす」「日をまたぐ打刻の計上先」の指標を追加
- 設定の各項目（タグ・記録保管場所・記録種別・プロファイル・板・メモ帳テンプレート）に「説明」欄を追加。AI連携（MCP）からも読めます
- ライフログビューの時間帯検索の曜日ボタンを、何も選ばなければ全曜日、押した曜日があればその曜日だけ、に変更
- `gkill_server generate_plugin_cache <plugin_name|all> <user_id...>` を追加。サーバを起動せずにプラグインのキャッシュを構築できます
- サーバの待ち受けの初期値をループバック限定に（上の注意を参照）

### プラグイン

- zip に固めた Git リポジトリのコミットログを読むプラグイン `gkill_plugin_archived_git_commit_log` を追加
- プラグインが複数の記録保管場所名を名乗れるように
- ChatGPT / Claude.ai プラグインは、エクスポートした ZIP を解凍せずそのまま読むように。ZIP ではないものを指定すると設定画面で知らせます
- プラグインのログを gkill のログフォルダ（`$HOME/gkill/logs/gkill_plugin_<name>*.log`）に出すように

### 腕時計（Wear OS）

- 7言語対応（ja / en / zh / ko / es / fr / de）
- 星 5 個の気分記録を追加。アプリの表示名を「gkill wear」に変更
- 時計から書いた記録の作成アプリ名を `gkill_wear` に
- 「同じ内容を続けて送った」確認を、前回の保存から 30 分で打ち切るように（半日後に同じテンプレートを送っても確認が出なくなります）
- チップの見た目をタイルと揃え、重複確認画面をスクロールできるように

### AI連携（MCP）

- MCP サーバを Go に移植し `gkill_server mcp` に一本化（上の注意を参照）。応答は旧実装とバイト単位で一致することを確認しています
- `gkill_status` と `schema_revision` を追加。古いツール定義のまま呼ばれたときは再接続を案内します
- `gkill_get_mcp_help`（topic 別の詳細案内）を追加し、各ツールの説明を要約に。ツール一覧の転送量を減らしました
- 記録の取得で、ページ送りのたびに返却済みのタスクが再出現して残り件数が減らない不具合を修正
- 実利用の報告にもとづく調整: プラグイン本文を含めたときのサイズ上限、地図条件の入力検査、版履歴のページ送り、設定ツリーの絞り込み（compact / contains / descriptions）、ファイル URL のオプトイン、更新時に同じ値だけのパッチを断る、など
- メモ帳送信（`gkill_submit_kftl`）の再送キーを本文にひも付け、同じ本文は元の結果を再生し、別の本文は 409 で何も書かないように

## BugFix

- メモ帳の打刻終了（ーえ／ーいえ／ーたえ／ーいたえ）が、走っている打刻に当たらない不具合を修正
- メモ帳で「？？」の時刻を繰り返すと 2083 年で登録される不具合と、繰り返しの時刻が年まで固定されない不具合を修正
- メモ帳の「ーみ」で書いたタスクの作成端末と作成ユーザーが入れ替わって保存される不具合を修正
- Android / Termux で時間帯検索が常に 0 件になる不具合を修正（タイムゾーンの扱い）
- 記録のダイアログを開くと、親の一覧が「読み込み中」に見える不具合を修正
- 一覧を速くスクロールすると右上にエラー（ERR900101）が積み上がる不具合を修正
- 設定ツリーで子がすべてチェック済みでも親が中間状態になる不具合を修正
- `add_tag` で、画面から消したタグが二度と付け直されない不具合を修正
- Fitbit プラグインの歩数が、時計とスマホの行が同じ日に並ぶデータでほぼ 2 倍になる不具合を修正（キャッシュは自動で作り直されます）
- zip 化した Git リポジトリのコミット行を開くと画面が数十秒止まる不具合を修正
- 複数の zip に入っているコミットの記録保管場所名が揺れる不具合を修正
- MCP: stdio で要求の届き方によって処理が捨てられる不具合と、OAuth の `redirect_uri` に `javascript:` を受け付けていた問題（セキュリティ）を修正
- 依存パッケージの脆弱性を解消（GHSA-82fw-gwwq-j7x9）
