# v1.1.7

## あっぷでーと

- AIとの会話ログを取り込むプラグインを追加（Claude Code / Codex）
- Google Takeout を読むプラグインを追加（Fitbit・Google Health / ロケーション履歴）。ZIPは展開せずそのまま置いて使えます
- プラグインが型別のデータを提供できるように。数値記録として返せば推移グラフでそのまま集計でき、タグ一覧にも載ります
- ロケーション履歴の移動の軌跡を位置情報ログとして扱えるように
- タスクのリポスト（既存の記録をタスクにする）に対応
- 集計ノートに相関グラフを追加
- 集計ノートにブックマークの条件を追加
- 検索条件に名前を付けて保存・呼び出しできるように
- タスクの板構造を画面から編集できるように
- 記録の内容をコンテキストメニューからコピーできるように
- KFTLで新しいタグが追加されるとき確認を求めるように
- 記録を削除したとき、付随するタグ・テキスト・通知とリポストも一緒に削除するように
- 記録保管場所のルールでタグを自動付与する `auto_tag` コマンドを追加
- サムネイル・動画・ZIP・プラグインのキャッシュを消す `clear_cache` コマンドを追加
- パスワードを再設定するための `reset_password` コマンドを追加
- `update_cache` をログイン情報なしで実行できるように
- `dvnf` で端末名を指定できるように
- 検索を大幅に高速化（検索条件組み立ての計算量削減、索引の追加、時刻範囲検索の索引化、タグの絞り込み高速化）
- 集計ノート・Ryuuの読み込みを並列化し、記録1件あたりのリクエスト本数を削減
- サーバ応答をgzip圧縮するように

## BugFix

- 検索が固まったまま返ってこなくなる不具合を複数修正
- 古いタグやテキストが表示される・過去のタグで検索にヒットする不具合を修正
- 記録に付けたタグやテキストが最新にならない不具合を修正
- 関連日時だけを変更しても保存できない不具合を修正（メモ・数値・気分値・打刻）
- 追加・編集ダイアログが二重送信できてしまう問題と、エラー時に閉じない不具合を修正
- コンテキストメニューが画面からはみ出す不具合を修正
- サーバ設定画面に保存済みの設定が入ってこない不具合を修正
- 位置情報ログの期間計算が固まる不具合を修正
- 除外ワード検索が効いていなかった不具合を修正
- 複数の保管場所から最新版を選ぶ比較が逆になっていた不具合を修正
- 存在しないIDへの更新が新規レコードを作っていた不具合を修正
- 集計ノートの週別・曜日別の見出しとラベルが入れ違っていた不具合を修正
- 集計ノートで列を切り替えたときに別の列の集計が表示される不具合を修正
- 読み込み中の記録に「プラグインが見つかりません」と表示される不具合を修正
- Wear OS でKFTLテンプレートが更新されない不具合を修正
- 一覧・ダイアログの表示崩れを修正
- セッションIDをログに出さないように修正
- サムネイル・ZIP展開のキャッシュを利用者ごとに分離（他の利用者のものが見えていました）
- 共有情報の所有者をセッション由来にするよう修正
- 利用者ファイルの配信にセキュリティヘッダを追加
- Androidのデータ保存先をアプリ専用領域へ移し、WebViewのアクセス制限を強化
- 依存パッケージの脆弱性を解消

## Other

- 検索条件の形式を変更（使用フラグを廃止し、値が入っていればそのフィルタが有効に）。保存済みの検索条件は自動で変換されます
- 初回アカウント登録のURLを `/regist_first_account` から `/register_first_account` へ変更（旧URLからリダイレクトします）
- MCPのプラグイン本文の取得を、記録の取得への埋め込みに一本化
- GitHub Actions の CI（ビルド / テスト / 資料検査 / プラグイン）を新設
- 開発者向け資料とソースコードの説明コメントを整備
- 綴りの誤りと命名規約違反を一括修正（保存済みデータの読み込み互換は維持）
