# v1.1.10

## ⚠️ 更新するときの注意

- **スマートフォン（Android）アプリを使っている方**: データの置き場所が共有ストレージの `/sdcard/gkill` に戻りました。更新後の初回起動で「すべてのファイルへのアクセス」（Android 10 以下ではストレージへのアクセス）の許可を求められ、**許可するまでサーバは起動しません**。共有ストレージなので、すべてのファイルへのアクセスを許可した他のアプリや USB 接続からも、記録やアカウントの情報を読めます（1.1.7〜1.1.9 のアプリ専用領域より守りが弱くなります）。1.1.7〜1.1.9（アプリ専用領域にデータを置いていた版）から更新した場合、`/sdcard/gkill` が無いか空であれば、専用領域にあったデータが自動で複製されます（複製元は残します）。`/sdcard/gkill` に 1.1.6 以前の古い中身が残っているとそちらで起動するので、更新前に退避するか削除しておいてください。
- **同じくスマートフォン（Android）アプリ**: サーバの待受アドレスと TLS の設定が、設定画面の「サーバ設定」どおりにスマートフォンでも効くようになりました（これまでは保存しても Android では無視されていました）。アプリの画面が開くアドレスも同じ設定から決まり、ポートや TLS を変えて保存すると新しいアドレスへ開き直します（ログインし直しになります）。LAN にも公開するときは、「アドレス」を `0.0.0.0:9999` か `:9999` のように書き、「ローカルアクセスのみ許可」もオフにしてください（TLS の有効化をおすすめします）。「アドレス」に特定の LAN の IP アドレスだけを書くとアプリの画面から接続できなくなります（コロンを省いた `9999` だけの指定も、画面が開けなくなります）。
- **1.1.8 以前からスマートフォン（Android）アプリを使っている方**: 1.1.8 以前に作ったデータ（1.1.6 以前から `/sdcard/gkill` に残っている中身や、1.1.7・1.1.8 で作って専用領域から複製された中身）を使っていて、サーバ設定を変えていない場合は、「アドレス」が `:9999`（LAN にも公開）、「ローカルアクセスのみ許可」がオフのままです。これまではアプリがこの設定を無視して同じ端末からだけ受け付けていましたが、**更新後は同じ LAN の他の端末から接続できるようになります**。同じ端末だけで使う場合は、設定画面の「サーバ設定」で「アドレス」を `127.0.0.1:9999` に、「ローカルアクセスのみ許可」をオンにして保存してください。
- **腕時計（Wear OS）を使っている方**: スマホ側（`gkill_wear_companion`）の APK を入れ直してください。編集した打刻を時計から終了すると、後から入れた編集が巻き戻る不具合の修正です（下の BugFix）。時計側（`gkill_wear_watch`）に変更はありません。
- **AI連携（MCP）を使っている方**: ツール定義が変わりました（スキルのツールを read に 2 本・write / readwrite に 4 本追加、`gkill_status` / `gkill_get_mcp_help` とワード検索の説明文を変更）。AI クライアント側で再接続（ツール一覧の取り直し）をしてください。再接続しなくても既存のツールはそのまま使えますが、スキルのツールは再接続するまで見えません。
- **設定画面**: 「検索条件」「実行中」「ダッシュボード」の 3 つのボタンは、1 つの「検索条件」ダイアログ（検索ショートカット・実行中・ダッシュボードの 3 セクション。適用・キャンセルは 1 組）にまとまりました。保存されている設定の中身は変わりません。

## あっぷでーと

- 利用者ごとのスキル（AI に渡しておく手順書。例: 週のまとめの作り方、ある種類の記録に付けるタグ）を追加。設定画面の「スキル」で一覧・中身の表示・zip のダウンロード・zip のアップロード（追加・削除・変更されるファイルを確認してから丸ごと置き換え）・削除ができ、AI連携（MCP）からは一覧と中身の取得、書き込みできる連携では作成・修正ができます（削除は AI からはできません）。形式は Agent Skills と同じ（フォルダ 1 つ = スキル 1 つ、先頭に `SKILL.md`）で、保存先は `$HOME/gkill/skills/<ユーザーID>/<スキル名>/`。詳しくはマニュアルの「AI連携」の「スキル」を参照してください
- ワード検索の ID の前方一致を、7 文字以上の語だけに。気分の数字（`8` など）で、ハッシュがその数字で始まる git のコミットが混ざらなくなりました。UUID の貼り付けや git の短縮ハッシュ（7 文字）はこれまでどおり当たります
- メモ帳: タブ名の既定を通し番号から空に（本文もテンプレート名も無いタブは見出しが空）。番号は並びの添字で、前のタブを閉じると振り直されるため名前として役に立っていませんでした
- メモ帳: メモ帳で付けたタグも、追加画面のタグ欄の候補（タグ履歴）に入るように。保存に成功したあと、記録ごとのタグの組を履歴へ積みます
- 支出の追加画面をメモ帳の支出と同じ並び（「店名」→「タイトル」（品名）と「金額」の行）にし、「追加」で行を増やして一度に複数件を書けるように。店名・日時・タグは全行で共有し、全行をまとめて確定します（1 件でも失敗すれば何も残りません）。編集画面の並びも「店名」→「タイトル」→「金額」にそろえました
- ライフログビュー・タスクのカレンダーの年月表示と、地図の日付表示をクリックすると日付ピッカー（月・年の一覧から選べます）が開くように。‹ › とホイールでは 1 回で 1 か月しか動かず、10 年前へ行くには 120 回押す必要がありました。ライフログビューの地図では映す日だけを切り替え（検索条件と一覧は動かしません）、ダッシュボードでは表示日ごと移します
- 集計ビューの編集画面で列を追加・削除できるように（表の右端に「列を追加」、各列の上に「列を削除」。最後の 1 列は消せません）。これまで 2 列目以降は設定の JSON を直接書くしかありませんでした。編集画面のダブルクリックでは、常に空だった記録の一覧を開かず、集計項目の編集ダイアログを開きます
- 並べ替えのドラッグ＆ドロップで、挿入位置を線で見せるように（設定の構造ツリー 6 種・集計ビュー・関連情報）。フォルダの中へ入れるときは見出しの塗りと枠で示し、掴んでいる元は半透明になります
- ファイルアップロードの枠の文言を「ここをクリックまたはファイルをドロップ」に（クリックでも選べることが分かるように。GPX の枠も同じ）
- スマートフォン（Android）: ステータスバーを gkill のテーマ色に（Android 15 以上は裏に帯を敷きます）
- スマートフォン（Android）: サーバの待受アドレスと TLS が設定画面の「サーバ設定」に従うように。データの置き場所を `/sdcard/gkill` に戻し、共有ストレージの権限が許可されるまでサーバを起動しません（上の注意を参照）
- 保存済み検索条件の一覧ダイアログで、右下の＋ボタンの下に行が潜らないように。タスクの検索条件のエディタにもライフログビュー側と同じ最小の高さを付けました

### プラグイン

- ワード検索の新しい規則（ID の前方一致は 7 文字以上）は、プラグインの照合にも入っています。配布済みのプラグインのバイナリは、作り直して配るまで旧規則のまま動きます

### 腕時計（Wear OS）

- スマホ側アプリ（`gkill_wear_companion`）の不具合修正のみ（下の BugFix）。時計側アプリに変更はありません

### AI連携（MCP）

- スキルのツールを追加: `gkill_get_skill_list` / `gkill_get_skill`（read / write / readwrite すべて）、`gkill_add_skill` / `gkill_update_skill`（write / readwrite）。`gkill_status` にスキルの名前と説明を載せ、`gkill_get_mcp_help` に topic `skills` を追加。AI へ返すときだけ、`max_file_bytes` を超えるファイルは中身を省きます。AI からの削除は、履歴が無く取り消せないため公開していません
- ワード検索（`words`）の説明に「ID の前方一致は 7 文字以上」を追記
- ツール一覧（`tools/list`）の転送量が、read では約 1.6 KB（スキルのツール 2 本ぶん）、write / readwrite では約 3.5 KB（4 本ぶん）増えています

## BugFix

- 腕時計（Wear OS）のスマホ側アプリで、編集済みの打刻を時計から終了すると、作成後に入れたタイトル変更などがエラーも警告も出ないまま巻き戻る不具合と、時計の実行中一覧に元のタイトルが出る不具合を修正（版履歴の末尾＝最古の版を最新版として扱っていました）
- スマートフォン（Android）で、設定画面の「サーバ設定」の待受アドレスと TLS を変えて保存しても何も変わらない（エラーも出ない）不具合を修正（上の注意を参照）
- 設定の「ダッシュボード」ダイアログを開いて適用しただけで、未設定だった検索条件が空の条件で書き潰されていた不具合を修正。まとめた「検索条件」ダイアログは、触ったセクションだけを保存します
- 画面切替メニューで、行の余白（文字の外）を押すとメニューが閉じるだけで遷移しなかった不具合を修正（8 画面）
- タスクの追加画面で、通知の行が中身の幅に縮み、削除ボタンだけ他の画面と違う見た目だった不具合を修正（リポストタスクの追加画面も同じ）
- 設定の構造ツリーの並べ替えで、ドロップ先の判定が固定の行の高さで測られて境界がずれていた不具合を修正（見出し行の実際の矩形で測ります）
- プラグインが別の処理で手一杯のとき、パソコンに負荷がかかっていると「混んでいる」ではなく「時間切れ」のエラーになることがある不具合を修正
